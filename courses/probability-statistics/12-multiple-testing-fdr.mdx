## The multiple comparisons problem

Each test has a small chance of a false alarm. Run a hundred tests and those small chances
pile up: some false alarms become almost certain. Multiple-testing corrections make the
threshold stricter so the *whole batch* of tests stays honest.

When you run $m$ independent tests at level $\alpha$, the probability of at least one false positive is $1-(1-\alpha)^m$. For $m=100$ and $\alpha=0.05$, that's 99.4%. Without correction, multiple testing inflates your false-positive rate catastrophically.

> **Picture it:** buy one lottery ticket and you almost surely lose. Buy a hundred and
> winning *something* becomes likely. Testing 100 features is buying 100 tickets in the
> "spurious significance" lottery.

Two error rates to control:

- **FWER (family-wise error rate):** $P(\text{at least one false positive})$. Strict — needed for clinical trials.
- **FDR (false discovery rate):** Expected fraction of rejected nulls that are false positives. Less strict — better for discovery (genomics, feature selection).

> **In plain words:** FWER promises "probably *zero* false alarms in the whole batch". FDR
> promises "of the things I flag, only about 5% are false alarms on average" — you accept a
> few duds in exchange for finding many more real effects.

## Bonferroni correction

The simplest fix: if you run $m$ tests, demand each one be $m$ times stricter.

Control FWER by testing each hypothesis at level $\alpha/m$. If any $p_i < \alpha/m$, reject $H_i$.

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
m = 100
n = 40
alpha = 0.05

# All null: true difference = 0
X1 = rng.normal(0, 1, (n, m))
X2 = rng.normal(0, 1, (n, m))
p_vals = np.array([stats.ttest_ind(X1[:,j], X2[:,j]).pvalue for j in range(m)])

reject_uncorrected  = (p_vals < alpha).sum()
reject_bonferroni   = (p_vals < alpha/m).sum()

print(f"Tests: {m},  all null,  alpha={alpha}")
print(f"Rejections (uncorrected):  {reject_uncorrected}")
print(f"Rejections (Bonferroni):   {reject_bonferroni}")
print(f"FWER uncorrected: {(p_vals < alpha).any():.0f}")
```

```output
Tests: 100,  all null,  alpha=0.05
Rejections (uncorrected):  3
Rejections (Bonferroni):   0
FWER uncorrected: 1
```

All 100 tests compare pure noise with pure noise, so every "rejection" is false. Uncorrected,
3 tests came out significant and the batch had at least one false positive (FWER line = 1).
With Bonferroni's threshold $0.05/100 = 0.0005$, none survived.

Bonferroni is conservative — it controls FWER but loses power when there are many true effects.

> **Watch out:** Bonferroni treats every test as if it were the only chance for a false
> alarm. When the tests are strongly correlated (overlapping features), it's even more
> conservative than necessary.

## Benjamini-Hochberg procedure

**Benjamini–Hochberg** (BH) uses a sliding threshold: the smallest p-value faces the strictest
bar, the next one a slightly looser bar, and so on. It's the standard tool when you want
discoveries, not certainty.

BH controls the FDR at level $\alpha$ (or less) while having more power than Bonferroni. The procedure:

1. Sort the $m$ p-values: $p_{(1)} \le p_{(2)} \le \cdots \le p_{(m)}$.
2. Find the largest $k$ such that $p_{(k)} \le \frac{k}{m}\alpha$.
3. Reject all $H_{(i)}$ for $i \le k$.

> **In plain words:** line the p-values up from smallest to largest and draw a rising line
> $\frac{k}{m}\alpha$ next to them. Find the last p-value that sits under the line, and reject
> it and everything smaller. The $k$-th smallest p-value only needs to beat $k$ times the
> Bonferroni threshold.

```python
import numpy as np

def bh_correction(p_vals, alpha=0.05):
    m = len(p_vals)
    order = np.argsort(p_vals)
    sorted_p = p_vals[order]

    # BH threshold line: k/m * alpha
    thresholds = np.arange(1, m+1) / m * alpha
    below = np.where(sorted_p <= thresholds)[0]

    if len(below) == 0:
        return np.zeros(m, dtype=bool), np.full(m, np.inf)

    k = below[-1]
    rejected_sorted = np.zeros(m, dtype=bool)
    rejected_sorted[:k+1] = True

    # Map back to original order
    rejected = np.zeros(m, dtype=bool)
    rejected[order] = rejected_sorted

    # Adjusted p-values (BH adjusted = min(p*(m/rank)) cumulated from end)
    adj = np.minimum.accumulate((sorted_p * m / np.arange(1, m+1))[::-1])[::-1]
    adj_p = np.clip(adj, 0, 1)
    adj_p_original = np.zeros(m)
    adj_p_original[order] = adj_p

    return rejected, adj_p_original

# Quick test
p_vals = np.array([0.001, 0.008, 0.039, 0.041, 0.042, 0.06, 0.074, 0.2, 0.3, 0.5])
rejected, adj_p = bh_correction(p_vals, alpha=0.05)
print("p-val    rejected   adj-p")
for p, r, a in sorted(zip(p_vals, rejected, adj_p)):
    print(f"{p:.3f}     {'YES' if r else 'no ':<6}    {a:.4f}")
```

```output
p-val    rejected   adj-p
0.001     YES       0.0100
0.008     YES       0.0400
0.039     no        0.0840
0.041     no        0.0840
0.042     no        0.0840
0.060     no        0.1000
0.074     no        0.1057
0.200     no        0.2500
0.300     no        0.3333
0.500     no        0.5000
```

With 10 p-values the BH line is $0.005, 0.010, 0.015, \ldots$. The smallest two (0.001 and
0.008) sit under it, so both are rejected; 0.039 would need to be below $3/10 \times 0.05 =
0.015$ and isn't. The **adjusted p-values** in the last column are the same decision written
another way: reject exactly those with adjusted $p \le 0.05$. Bonferroni (threshold 0.005)
would have rejected only the first.

## FDR control simulation

To check the guarantee, simulate a study where you *know* which effects are real: 1000 tests,
100 of them with a real medium-sized effect.

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(1)
N_sims = 2000
m = 1000
m_true = 100    # number of true effects
alpha = 0.05

fdr_vals = np.zeros(N_sims)
power_vals = np.zeros(N_sims)
n = 30

for sim in range(N_sims):
    # First m_true features have true effect
    effect = np.zeros(m)
    effect[:m_true] = 0.5     # Cohen's d = 0.5

    x1 = rng.normal(0, 1, (n, m))
    x2 = rng.normal(effect, 1, (n, m))

    p_vals = stats.ttest_ind(x1, x2, axis=0).pvalue   # all m tests at once
    rejected, _ = bh_correction(p_vals, alpha)

    # FDR = false positives / total rejections
    false_pos = rejected[m_true:].sum()
    total_rej  = rejected.sum()
    fdr_vals[sim] = false_pos / total_rej if total_rej > 0 else 0

    # Power = true positives / m_true
    true_pos = rejected[:m_true].sum()
    power_vals[sim] = true_pos / m_true

print(f"m={m} tests, {m_true} true effects, d=0.5, n={n}")
print(f"BH FDR control at alpha={alpha}")
print(f"  Empirical FDR:   {fdr_vals.mean():.4f}  (should be <= {alpha})")
print(f"  Empirical power: {power_vals.mean():.4f}")
```

```output
m=1000 tests, 100 true effects, d=0.5, n=30
BH FDR control at alpha=0.05
  Empirical FDR:   0.0509  (should be <= 0.05)
  Empirical power: 0.0316
```

The empirical FDR is 0.051. BH's guarantee for independent tests is
$\text{FDR} \le \frac{m_0}{m}\alpha = \frac{900}{1000} \times 0.05 = 0.045$ on average ($m_0$ =
number of true nulls), and 0.051 is within the Monte Carlo noise of that: when only a handful
of tests are rejected, each simulation's false-discovery *proportion* is lumpy (0, 1/3, 1/2,
…), so its average converges slowly.

The power is the sobering part. BH controls FDR close to 0.05 while recovering only about 3%
of the true effects here. A medium effect ($d = 0.5$) with 30 per group has 47% power in a
single test (ch. 11), but surviving a 1000-test correction needs a far smaller p-value. Large
$m$ with weak effects and small samples is a recipe for finding almost nothing.

## Bonferroni vs BH comparison

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(2)
m, m_true, n_sims = 200, 20, 2000
n, alpha = 25, 0.05
effect_size = 0.6

bon_power, bh_power = 0.0, 0.0
for _ in range(n_sims):
    eff = np.zeros(m); eff[:m_true] = effect_size
    x1 = rng.normal(0, 1, (n, m))
    x2 = rng.normal(eff, 1, (n, m))
    p = stats.ttest_ind(x1, x2, axis=0).pvalue      # all m tests at once
    bon_power += (p[:m_true] < alpha/m).mean()
    rej, _ = bh_correction(p, alpha)
    bh_power  += rej[:m_true].mean()

print(f"Bonferroni power: {bon_power/n_sims:.4f}")
print(f"BH power:         {bh_power/n_sims:.4f}")
```

```output
Bonferroni power: 0.0464
BH power:         0.0834
```

BH found nearly twice as many of the real effects as Bonferroni (8.3% vs 4.6%) on the same
data, while controlling a looser but still meaningful error rate. Both numbers are low because
$n = 25$ per group is small for $d = 0.6$ after a 200-test correction.

BH has substantially higher power than Bonferroni — use BH for discovery tasks (e.g., finding predictive features), Bonferroni when any false positive is unacceptable.

## Recap in plain words

- Many tests at $\alpha$ each make at least one false positive likely: $1 - (1 - \alpha)^m$.
- FWER = chance of any false positive (strict); FDR = expected share of false positives among
  your discoveries (looser).
- Bonferroni tests each at $\alpha/m$ and controls FWER; it's conservative.
- Benjamini–Hochberg compares the $k$-th smallest p-value with $\frac{k}{m}\alpha$ and controls
  FDR, with more power.
- Corrections can't create power: weak effects, small $n$, and huge $m$ still find little.

## Try it Yourself

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(99)
# Feature selection: test 80 features for association with target
n, m = 60, 80
# 15 features truly correlated, rest are noise
y = rng.standard_normal(n)
X = rng.standard_normal((n, m))
# Inject correlation for first 15 features
X[:, :15] += 0.4 * y[:, None]

p_vals = np.array([stats.pearsonr(X[:,j], y).pvalue for j in range(m)])

print(f"Uncorrected (alpha=0.05): {(p_vals < 0.05).sum()} selected")
print(f"Bonferroni:               {(p_vals < 0.05/m).sum()} selected")
rej, _ = bh_correction(p_vals, 0.05)
print(f"BH (FDR=0.05):            {rej.sum()} selected")
print(f"  True discoveries (first 15): {rej[:15].sum()}")
print(f"  False discoveries (rest):    {rej[15:].sum()}")
```

```output
Uncorrected (alpha=0.05): 15 selected
Bonferroni:               2 selected
BH (FDR=0.05):            3 selected
  True discoveries (first 15): 3
  False discoveries (rest):    0
```

Fifteen features were built to correlate with `y`. Uncorrected testing flags 15 features,
but some of those could be noise and some real ones could be missing — you can't tell which.
Bonferroni keeps 2 and BH keeps 3, and all 3 of BH's picks are genuinely correlated. The price
of honesty is missing 12 of the 15 real features at this sample size. Try `n = 300` and watch
both corrected counts climb toward 15.

## Exercise

In a gene expression study with 5,000 tests (50 true effects, effect size 0.8, $n=20$), compare: (1) expected false positives without correction; (2) expected true positives with BH at $\alpha=0.05$. Run a simulation.

> **Hint:** uncorrected, every one of the 4,950 null tests is a 5% false alarm. For BH, reuse
> `bh_correction` and count rejections among the first 50 features.

<details>
<summary>Solution</summary>

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
m, m_true, n, effect_size = 5000, 50, 20, 0.8
alpha = 0.05
N_sims = 500

fdr_list, power_list = [], []
for _ in range(N_sims):
    eff = np.zeros(m); eff[:m_true] = effect_size
    x1 = rng.normal(0, 1, (n, m))
    x2 = rng.normal(eff, 1, (n, m))
    p = stats.ttest_ind(x1, x2, axis=0).pvalue      # all m tests at once

    # (1) Without correction: expected FP = alpha * (m - m_true)
    rej_none = p < alpha
    fdr_none = rej_none[m_true:].sum() / max(rej_none.sum(), 1)

    rej_bh, _ = bh_correction(p, alpha)
    tp = rej_bh[:m_true].sum()
    fdr_bh = rej_bh[m_true:].sum() / max(rej_bh.sum(), 1)

    fdr_list.append(fdr_bh)
    power_list.append(tp / m_true)

print(f"Expected FP without correction: {alpha * (m - m_true):.1f}")
print(f"BH FDR: {np.mean(fdr_list):.4f}  (should be <= {alpha})")
print(f"BH power: {np.mean(power_list):.4f}")
```

Without correction you'd expect $0.05 \times 4950 \approx 248$ false positives — burying the
50 real effects. BH keeps the FDR at or below 0.05, at the cost of detecting only a fraction of
the 50 true effects with $n = 20$. The t-tests are vectorized (`axis=0`), so all 5,000 run in
one call; a per-test Python loop here would take minutes.
