## The testing framework

A **hypothesis test** is a courtroom for data. The "defendant" is the boring explanation —
"there's no real difference, it's just luck" (the **null hypothesis**). You only convict
(reject it) if the evidence would be very surprising were it innocent.

A **hypothesis test** evaluates whether sample data is consistent with a null hypothesis $H_0$.

1. State $H_0$ (null) and $H_1$ (alternative).
2. Choose a test statistic that summarizes the evidence against $H_0$.
3. Compute the **p-value**: $P(\text{statistic at least as extreme} \mid H_0 \text{ true})$.
4. Reject $H_0$ if $p < \alpha$ (the significance level, typically 0.05).

> **In plain words:** the p-value answers "if nothing were going on, how often would I see
> evidence this strong or stronger just by chance?". A p-value of 0.01 means "1 time in 100".
> If that's rarer than your threshold $\alpha$, you conclude something probably *is* going on.

The p-value is **not** $P(H_0 \text{ true})$. It's a tail probability under $H_0$, not a probability about the hypothesis itself.

> **Watch out:** $p = 0.03$ does *not* mean "3% chance the null is true" or "97% chance the
> effect is real". It's $P(\text{data this extreme} \mid H_0)$, not $P(H_0 \mid \text{data})$
> — the same swap that ch. 1 warned about.

## Two-sample t-test

The **two-sample t-test** asks whether two groups' averages differ by more than random noise
would explain. Its statistic is "difference in averages, measured in standard errors".

Compare means of two groups: $H_0: \mu_1 = \mu_2$ vs $H_1: \mu_1 \ne \mu_2$.

The test statistic (Welch's, unequal variances):

$$
T = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{S_1^2/n_1 + S_2^2/n_2}}
$$

> **In plain words:** the top is the gap between the two sample means; the bottom is the
> standard error of that gap (each group's variance over its size, added, square-rooted).
> $|T| \approx 2$ or more is the rough "surprising if there's no real gap" zone. **Welch's**
> version doesn't assume the two groups share a variance.

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
mu1, mu2 = 10.0, 11.5     # true means differ
sigma1, sigma2 = 3.0, 3.0
n1, n2 = 40, 40

x1 = rng.normal(mu1, sigma1, n1)
x2 = rng.normal(mu2, sigma2, n2)

# From scratch: Welch t-test
se = np.sqrt(x1.var(ddof=1)/n1 + x2.var(ddof=1)/n2)
t_stat = (x1.mean() - x2.mean()) / se

# Welch-Satterthwaite degrees of freedom
v1, v2 = x1.var(ddof=1)/n1, x2.var(ddof=1)/n2
df = (v1 + v2)**2 / (v1**2/(n1-1) + v2**2/(n2-1))
p_val = 2 * stats.t.sf(abs(t_stat), df=df)

print(f"Group 1: mean={x1.mean():.4f}  std={x1.std(ddof=1):.4f}")
print(f"Group 2: mean={x2.mean():.4f}  std={x2.std(ddof=1):.4f}")
print(f"\nt-statistic = {t_stat:.4f}")
print(f"df (Welch)  = {df:.2f}")
print(f"p-value     = {p_val:.4f}")

# Verify with scipy
t2, p2 = stats.ttest_ind(x1, x2, equal_var=False)
print(f"\nscipy p-value: {p2:.4f}  (matches: {np.isclose(p_val, p2, atol=1e-4)})")
```

```output
Group 1: mean=9.8187  std=2.3915
Group 2: mean=12.4034  std=3.2894

t-statistic = -4.0196
df (Welch)  = 71.22
p-value     = 0.0001

scipy p-value: 0.0001  (matches: True)
```

The sample means differ by about 2.6, which is 4 standard errors ($T = -4.02$). Under the
null, a gap that large happens about once in 10,000 experiments ($p \approx 0.0001$), so you
reject $H_0$. The **Welch–Satterthwaite** degrees of freedom (71.2) are slightly below
$40 + 40 - 2 = 78$ because the two groups' spreads differ. The from-scratch p-value matches
SciPy's `ttest_ind(..., equal_var=False)`.

## Type I and Type II errors

A test can be wrong in two ways: crying wolf when there's no wolf (Type I), or sleeping
through a real wolf (Type II). You choose how often you're willing to cry wolf; how often you
miss real wolves depends on how big they are and how closely you look.

| Decision \ Truth | $H_0$ true | $H_0$ false |
|---|---|---|
| Reject $H_0$ | Type I error ($\alpha$) | Correct (power) |
| Fail to reject | Correct | Type II error ($\beta$) |

- **$\alpha$** = significance level = $P(\text{reject} \mid H_0 \text{ true})$ — you control this.
- **$\beta$** = $P(\text{fail to reject} \mid H_0 \text{ false})$ — depends on the true effect and sample size.
- **Power** $= 1-\beta = P(\text{reject} \mid H_1 \text{ true})$.

```python
import numpy as np
from scipy import stats

# Verify Type I error rate (reject rate when H0 is true)
rng = np.random.default_rng(1)
alpha = 0.05
N_sims = 10_000
n = 30

rejections_h0_true = sum(
    stats.ttest_ind(rng.normal(0,1,n), rng.normal(0,1,n)).pvalue < alpha
    for _ in range(N_sims)
)
print(f"Type I error rate (H0 true): {rejections_h0_true/N_sims:.4f}  (target: {alpha})")

# Power when true effect = 0.5 standard deviations
delta = 0.5  # effect size (Cohen's d)
rejections_h1_true = sum(
    stats.ttest_ind(rng.normal(0,1,n), rng.normal(delta,1,n)).pvalue < alpha
    for _ in range(N_sims)
)
print(f"Power (delta=0.5, n=30):     {rejections_h1_true/N_sims:.4f}")
```

```output
Type I error rate (H0 true): 0.0486  (target: 0.05)
Power (delta=0.5, n=30):     0.4711
```

When the null is true, the test rejects 4.86% of the time — right at the 5% you chose. When
there *is* a medium effect (half a standard deviation) and 30 per group, it detects it only
47% of the time.

Power ~48% for $n=30$, $d=0.5$. You'd miss the effect half the time — underpowered.

> **Picture it:** looking for a coin on a dark lawn. A big shiny coin (large effect) or a
> bright torch (large $n$) makes finding it likely. A small dull coin with a dim torch — you'll
> often walk right past it and wrongly conclude there's no coin.

## Cohen's d: effect size

A p-value tells you whether a difference is *detectable*; it doesn't tell you whether it's
*big*. **Effect size** measures the size itself, in units of standard deviations.

Statistical significance ($p < 0.05$) does not imply practical significance. A tiny difference can be significant with large $n$. **Cohen's d** measures practical importance:

$$
d = \frac{\mu_1 - \mu_2}{\sigma_{\text{pooled}}}
$$

Conventions: $d=0.2$ small, $d=0.5$ medium, $d=0.8$ large.

> **In plain words:** $d$ is the gap between the group means divided by the typical spread
> within a group (the **pooled** standard deviation). $d = 0.5$ means the groups' centres
> are half a standard deviation apart — their histograms overlap a lot, but visibly shift.

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(2)
n = 1_000_000  # very large n

# Tiny difference
x1 = rng.normal(10.00, 5, n)
x2 = rng.normal(10.05, 5, n)

t, p = stats.ttest_ind(x1, x2, equal_var=True)
pooled_std = np.sqrt(((n-1)*x1.var(ddof=1) + (n-1)*x2.var(ddof=1)) / (2*n-2))
cohen_d = (x1.mean() - x2.mean()) / pooled_std

print(f"n={n} per group")
print(f"Difference: {x2.mean()-x1.mean():.4f} units")
print(f"p-value:    {p:.4e}  (statistically significant!)")
print(f"Cohen's d:  {abs(cohen_d):.4f}  (negligible effect)")
```

```output
n=1000000 per group
Difference: 0.0472 units
p-value:    2.3971e-11  (statistically significant!)
Cohen's d:  0.0094  (negligible effect)
```

With a million observations per group, even a true difference of 0.05 units — Cohen's $d$
of about 0.01, far below "small" — produces a tiny p-value. The test is right that the
difference is real; it's just too small to matter. With enough data, *everything* is
statistically significant.

> **Watch out:** always report an effect size (and a confidence interval for it) next to a
> p-value. "Significant" in a paper with a huge sample can mean "real but negligible".

## Power curves

More data means a brighter torch: the chance of detecting a real effect climbs with sample
size. A **power curve** shows how fast, so you can choose $n$ *before* you collect data.

Power increases with $n$, effect size, and $\alpha$. Plotting power vs $n$ helps design studies.

```python
import numpy as np
from scipy import stats

delta = 0.5   # Cohen's d
alpha = 0.05
ns = [10, 20, 30, 50, 80, 120, 200]

rng = np.random.default_rng(3)
N_sims = 3000

print(f"Power vs n (delta={delta}, alpha={alpha})")
for n in ns:
    power = sum(
        stats.ttest_ind(rng.normal(0,1,n), rng.normal(delta,1,n)).pvalue < alpha
        for _ in range(N_sims)
    ) / N_sims
    bar = '#' * int(power * 40)
    print(f"  n={n:>4}: {power:.3f}  {bar}")
```

```output
Power vs n (delta=0.5, alpha=0.05)
  n=  10: 0.185  #######
  n=  20: 0.347  #############
  n=  30: 0.468  ##################
  n=  50: 0.684  ###########################
  n=  80: 0.884  ###################################
  n= 120: 0.973  ######################################
  n= 200: 0.997  #######################################
```

For a medium effect ($d = 0.5$), 10 per group finds it less than 1 time in 5; about 64 per
group gives the conventional target of 80% power (between the $n = 50$ and $n = 80$ rows);
200 per group almost never misses. Running the study with $n = 20$ would be mostly wasted
effort.

## p-hacking and multiple comparisons

Test enough things and some will look significant by pure luck. **p-hacking** is trying test
after test (or tweak after tweak) and reporting only the ones that "worked".

Running many tests and reporting only significant ones inflates the Type I error rate. With 20 independent tests at $\alpha=0.05$, you expect 1 false positive even when $H_0$ is always true.

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(4)
n_features = 50
n, N_sims = 30, 5000

false_positives = np.zeros(N_sims)
for sim in range(N_sims):
    y = rng.standard_normal(n)
    # Test each of 50 noise features
    X = rng.standard_normal((n, n_features))
    p_vals = np.array([stats.pearsonr(X[:,j], y).pvalue for j in range(n_features)])
    false_positives[sim] = (p_vals < 0.05).any()

print(f"P(at least one false positive | {n_features} null tests): {false_positives.mean():.4f}")
print(f"Theory: 1 - (0.95)^{n_features} = {1 - 0.95**n_features:.4f}")
```

```output
P(at least one false positive | 50 null tests): 0.9220
Theory: 1 - (0.95)^50 = 0.9231
```

Fifty features of pure noise, tested against a pure-noise target: at least one comes out
"significant" in 92% of simulations, matching $1 - 0.95^{50} \approx 0.92$. If you test 50
features and report the winner, you've almost guaranteed a false discovery. Ch. 12 shows the
corrections.

## Recap in plain words

- A test asks how surprising the data would be if nothing were going on; the p-value is that
  surprise, $P(\text{this extreme} \mid H_0)$, not $P(H_0)$.
- Welch's t-test compares two means using the gap in standard-error units.
- Type I = false alarm (rate $\alpha$, your choice); Type II = missed effect; power = $1 - \beta$.
- Effect size (Cohen's $d$) measures *how big*; significance only says *detectable*.
- Power grows with $n$ and effect size — plan $n$ in advance.
- Many tests produce false positives by chance; correct for it (ch. 12).

## Try it Yourself

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
# A/B test: does treatment raise the mean by at least 2 units?
n1, n2 = 50, 50
control   = rng.normal(100, 15, n1)
treatment = rng.normal(102, 15, n2)   # true delta = 2

t_stat, p_val = stats.ttest_ind(treatment, control, equal_var=False)
s_pool = np.sqrt((control.var(ddof=1) + treatment.var(ddof=1)) / 2)
cohen_d = (treatment.mean() - control.mean()) / s_pool

print(f"Control mean:   {control.mean():.2f}")
print(f"Treatment mean: {treatment.mean():.2f}")
print(f"t-stat: {t_stat:.4f}   p-value: {p_val:.4f}")
print(f"Cohen's d: {cohen_d:.4f}")
print(f"Reject H0 (p<0.05)? {p_val < 0.05}")
```

```output
Control mean:   101.37
Treatment mean: 99.12
t-stat: -0.9749   p-value: 0.3320
Cohen's d: -0.1950
Reject H0 (p<0.05)? False
```

The true lift is +2, yet in this sample the treatment group's mean came out *lower* than
control — with 50 users per group and a spread of 15, noise of a few units is normal. The test
correctly refuses to declare anything ($p = 0.33$). That isn't evidence that the treatment
does nothing: with $d = 2/15 \approx 0.13$ and $n = 50$, power is only about 10%. Try `n1 = n2 = 2000`
and watch the result stabilize.

## Exercise

You test 30 features for correlation with the target, and 4 come up significant at $\alpha=0.05$. (1) How many would you expect by chance under $H_0$? (2) Write code to simulate this and verify. (3) Should you trust those 4 significant results?

> **Hint:** under the null each test is a 5% coin flip, so the number of false positives
> among 30 independent tests is Binomial(30, 0.05).

<details>
<summary>Solution</summary>

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(5)
n_features = 30
n, N_sims = 60, 10_000
alpha = 0.05

# (1) Expected false positives = alpha * n_features = 0.05 * 30 = 1.5
print(f"Expected false positives (H0 always true): {alpha * n_features:.1f}")

# (2) Simulate
false_pos_counts = np.zeros(N_sims, dtype=int)
for sim in range(N_sims):
    y = rng.standard_normal(n)
    X = rng.standard_normal((n, n_features))
    p_vals = np.array([stats.pearsonr(X[:,j], y).pvalue for j in range(n_features)])
    false_pos_counts[sim] = (p_vals < alpha).sum()

print(f"Simulated mean false positives: {false_pos_counts.mean():.3f}")
print(f"P(4+ false positives): {(false_pos_counts >= 4).mean():.4f}")

# (3) With 30 tests, 4 significant results is plausible by chance alone.
# Need multiple testing correction (Bonferroni or BH) before trusting them.
print(f"\nBonferroni threshold: {alpha/n_features:.4f}  (only reject at this level)")
```

With 30 null tests, finding 4 or more significant at $\alpha=0.05$ happens in about 6% of
simulations — the Binomial(30, 0.05) tail $P(X \ge 4) \approx 0.061$. Uncommon, but not rare
enough to trust on its own: about 1.5 false positives are expected anyway, and you can't tell
which of the 4 are real. You should not trust them without correction (ch. 12), and ideally a
fresh dataset to confirm.
