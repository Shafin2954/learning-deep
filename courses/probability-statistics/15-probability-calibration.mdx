## What calibration means

A weather forecaster who says "70% chance of rain" is **calibrated** if it actually rains on
about 70% of those days. A model's probabilities can rank cases well (riskiest first) and still
be badly calibrated — too timid or too bold. Calibration is about whether the numbers mean what
they say.

A classifier that outputs $\hat{p}(x) = 0.8$ is well-calibrated if, among all examples where the model says 0.8, roughly 80% are truly positive. Formally:

$$
P(Y=1 \mid \hat{p}(X) = p) = p \quad \text{for all } p \in [0,1]
$$

> **In plain words:** gather every case where the model said $p$; the fraction that turned
> out positive should be $p$. Do that for every $p$ from 0 to 1.

Raw model scores are often miscalibrated. Random Forests tend to be **underconfident**: averaging
many trees pulls their probabilities toward 0.5, so true positives rarely get scores near 1.
Naive Bayes tends to be **overconfident** (probabilities too extreme), because it treats
correlated features as independent and counts the same evidence several times. Well-regularized
logistic regression is usually close to calibrated, since it directly optimizes log-loss.

> **Watch out:** many write-ups say the reverse for random forests. The tables below let you
> check the direction yourself: if the actual frequencies are *more* extreme than the
> predictions, the model is underconfident.

## The reliability diagram

A **reliability diagram** sorts predictions into buckets (0–10%, 10–20%, …) and, for each
bucket, compares the average prediction with how often the positive class really happened.

Bin predicted probabilities into $B$ equal-width buckets. For each bucket, plot the mean predicted probability (x-axis) vs the empirical fraction of positives (y-axis). A perfectly calibrated model lies on the diagonal.

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_predict

rng_seed = 0
X, y = make_classification(n_samples=2000, n_features=20, n_informative=10,
                             random_state=rng_seed)
clf = RandomForestClassifier(n_estimators=100, random_state=rng_seed)
probs = cross_val_predict(clf, X, y, cv=5, method='predict_proba')[:, 1]

def reliability_data(y_true, y_prob, n_bins=10):
    bins = np.linspace(0, 1, n_bins + 1)
    bin_means, bin_fracs, bin_counts = [], [], []
    for lo, hi in zip(bins[:-1], bins[1:]):
        mask = (y_prob >= lo) & (y_prob < hi)
        if mask.sum() > 0:
            bin_means.append(y_prob[mask].mean())
            bin_fracs.append(y_true[mask].mean())
            bin_counts.append(mask.sum())
    return np.array(bin_means), np.array(bin_fracs), np.array(bin_counts)

means, fracs, counts = reliability_data(y, probs)
print("Reliability diagram (predicted vs actual):")
print(f"{'Pred prob':>12}  {'Actual freq':>12}  {'Gap':>8}  {'Count':>6}")
for m, f, c in zip(means, fracs, counts):
    gap = f - m
    bar = '>' if gap > 0.02 else ('<' if gap < -0.02 else '=')
    print(f"  {m:.3f}         {f:.3f}         {gap:+.3f} {bar}    {c}")
```

```output

  0.142         0.029         -0.113 <    277

  0.349         0.128         -0.221 <    117
  0.445         0.361         -0.083 <    144
  0.551         0.577         +0.026 >    175
  0.657         0.780         +0.123 >    159
  0.752         0.934         +0.183 >    228
  0.845         0.980         +0.135 >    305
  0.933         0.994         +0.061 >    173
```

Read the first and last rows. When the forest said about 6%, the true rate was 0%; when it said
about 85%, the true rate was 98%. Every low bucket is *too high* and every high bucket is *too
low*: the forest's scores are squashed toward the middle. The `cross_val_predict` call makes
sure every probability comes from a model that didn't train on that row.

The RF overestimates probability at low values and underestimates it at high values — a classic S-curve miscalibration where extreme scores are pulled toward 0.5.

> **Picture it:** a timid forecaster who never dares say less than 10% or more than 90%. Their
> "10%" days are actually dry, their "90%" days are always wet — the numbers are right in
> order but squeezed toward the middle.

## Expected Calibration Error

**ECE** turns the reliability diagram into one number: the average gap between predicted and
actual, weighted by how many predictions fall in each bucket.

ECE summarizes miscalibration as a weighted average of gap magnitudes:

$$
\text{ECE} = \sum_{b=1}^B \frac{n_b}{n} \left|\bar{p}_b - \bar{y}_b\right|
$$

MCE is the maximum gap across bins.

> **In plain words:** $n_b / n$ is the share of predictions in bucket $b$; $\bar{p}_b$ is their
> average prediction and $\bar{y}_b$ their actual positive rate. ECE = "on average, how many
> percentage points off are the probabilities?" **MCE** (maximum calibration error) is the
> worst single bucket.

```python
import numpy as np

def calibration_errors(y_true, y_prob, n_bins=10):
    bins = np.linspace(0, 1, n_bins + 1)
    n = len(y_true)
    ece, mce = 0.0, 0.0
    for lo, hi in zip(bins[:-1], bins[1:]):
        mask = (y_prob >= lo) & (y_prob < hi)
        if mask.sum() > 0:
            gap = abs(y_true[mask].mean() - y_prob[mask].mean())
            ece += (mask.sum() / n) * gap
            mce = max(mce, gap)
    return ece, mce

ece, mce = calibration_errors(y, probs)
print(f"ECE = {ece:.4f}")
print(f"MCE = {mce:.4f}")

# Brier score: mean squared error of probability predictions
brier = np.mean((probs - y)**2)
print(f"Brier score = {brier:.4f}  (0=perfect, 0.25=random)")
```

```output
ECE = 0.1183
MCE = 0.2209
Brier score = 0.0957  (0=perfect, 0.25=random)
```

The forest's probabilities are off by about 12 percentage points on average, and by 22 in its
worst bucket. The **Brier score** (mean squared error between probability and the 0/1 outcome)
mixes calibration and sharpness; 0.25 is what always predicting 0.5 scores on a balanced
problem.

## Platt scaling

**Platt scaling** fixes a squashed or stretched probability scale by fitting a small logistic
regression that maps the model's scores to new, calibrated probabilities.

Fit a logistic regression on out-of-fold predictions to re-map scores to calibrated probabilities. The logistic model $\sigma(a\hat{p} + b)$ stretches or compresses the score distribution.

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold

def platt_calibrate(y_true, y_prob):
    """Fit Platt scaling (logistic on scores) with 5-fold CV to avoid overfitting."""
    calibrated = np.zeros_like(y_prob)
    skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=1)

    for tr_idx, val_idx in skf.split(y_prob.reshape(-1, 1), y_true):
        lr = LogisticRegression(C=1e4)
        lr.fit(y_prob[tr_idx].reshape(-1, 1), y_true[tr_idx])
        calibrated[val_idx] = lr.predict_proba(y_prob[val_idx].reshape(-1, 1))[:, 1]
    return calibrated

probs_platt = platt_calibrate(y, probs)

ece_before, _ = calibration_errors(y, probs)
ece_after,  _ = calibration_errors(y, probs_platt)
brier_before   = np.mean((probs       - y)**2)
brier_after    = np.mean((probs_platt - y)**2)

print(f"Before Platt:  ECE={ece_before:.4f}  Brier={brier_before:.4f}")
print(f"After  Platt:  ECE={ece_after:.4f}  Brier={brier_after:.4f}")
```

```output
Before Platt:  ECE=0.1183  Brier=0.0957
After  Platt:  ECE=0.0152  Brier=0.0780
```

A big improvement: ECE falls from 0.118 to 0.015, about 8× smaller, and the Brier score improves
too (0.096 to 0.078) because better-calibrated probabilities are also closer to the truth. The
calibrator itself is trained with 5-fold CV, so no row is calibrated by a mapping fitted on that
same row.

Platt scaling cuts the ECE by roughly 8× here while also improving the Brier score.

> **In plain words:** with a slope $a > 1$, $\sigma(a\hat{p} + b)$ stretches the middle-heavy
> scores back out toward 0 and 1 — exactly the fix an underconfident forest needs. Its limit is
> its shape: it can only apply S-shaped corrections.

## Isotonic regression calibration

**Isotonic regression** is a more flexible fix: any staircase that only goes up. It can bend
the scale into whatever monotone shape the data demands.

Isotonic regression is a more flexible calibrator: it fits a non-decreasing step function from scores to probabilities (no parametric assumption). Better when the miscalibration is not S-shaped
(any monotone distortion). Because it's flexible, it needs more data and can overfit small
calibration sets.

```python
import numpy as np
from sklearn.isotonic import IsotonicRegression
from sklearn.model_selection import StratifiedKFold

def isotonic_calibrate(y_true, y_prob):
    calibrated = np.zeros_like(y_prob)
    skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=2)
    for tr, val in skf.split(y_prob.reshape(-1,1), y_true):
        ir = IsotonicRegression(out_of_bounds='clip')
        ir.fit(y_prob[tr], y_true[tr])
        calibrated[val] = ir.predict(y_prob[val])
    return calibrated

probs_iso = isotonic_calibrate(y, probs)
ece_iso, _ = calibration_errors(y, probs_iso)
brier_iso   = np.mean((probs_iso - y)**2)
print(f"Isotonic: ECE={ece_iso:.4f}  Brier={brier_iso:.4f}")
print(f"Platt:    ECE={ece_after:.4f}  Brier={brier_after:.4f}")
```

```output
Isotonic: ECE=0.0104  Brier=0.0799
Platt:    ECE=0.0152  Brier=0.0780
```

Isotonic reaches the lowest ECE (0.010), while Platt has the slightly better Brier score
(0.0780 vs 0.0799) — the staircase fits the calibration bins more tightly but is a bit noisier
point by point. With 2000 rows both are fine; with a few hundred, Platt is usually the safer
choice.

Isotonic achieves lower ECE when the miscalibration is complex.

> **Watch out:** never fit a calibrator on the same data the model was trained on — training
> predictions are overconfident by construction. Use out-of-fold predictions (as here) or a
> separate calibration set. scikit-learn's `CalibratedClassifierCV` does this for you.

## Recap in plain words

- Calibrated means "of the cases scored $p$, a fraction $p$ are positive".
- Reliability diagrams compare predicted and actual rates per bucket; ECE averages the gaps.
- Random forests tend to be underconfident (squashed toward 0.5); Naive Bayes tends to be
  overconfident.
- Platt scaling (logistic, S-shaped) and isotonic regression (any increasing staircase)
  re-map scores to calibrated probabilities; fit them on out-of-fold predictions.
- Calibration changes the probabilities, not the ranking — AUC stays the same under a
  monotone re-mapping.

## Try it Yourself

```python
import numpy as np
from sklearn.naive_bayes import GaussianNB
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_predict

X, y = make_classification(n_samples=2000, n_features=20, n_informative=5,
                             random_state=7)
gnb = GaussianNB()
probs_nb = cross_val_predict(gnb, X, y, cv=5, method='predict_proba')[:, 1]

means_nb, fracs_nb, _ = reliability_data(y, probs_nb)
ece_nb, mce_nb = calibration_errors(y, probs_nb)

print("Naive Bayes calibration:")
print(f"  ECE={ece_nb:.4f}  MCE={mce_nb:.4f}")
print(f"  (NB often overestimates confidence — probabilities too extreme)")

print("\nReliability:")
for m, f in zip(means_nb, fracs_nb):
    print(f"  pred={m:.3f}  actual={f:.3f}  gap={f-m:+.3f}")
```

ECE is roughly stable across bin counts when $n$ is large. With small $n$ (<500), more bins leads to noisy per-bin estimates; prefer 5–10 bins.
