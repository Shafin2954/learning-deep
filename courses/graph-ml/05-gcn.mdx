## From spectral to spatial

The original GCN (Kipf & Welling, 2017) was motivated by spectral graph signal processing but
arrived at a beautifully simple spatial rule. Starting from a Chebyshev polynomial filter
approximation, they derived:

$$
H^{(l+1)} = \sigma\!\left(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2} H^{(l)} W^{(l)}\right)
$$

where:
- $\tilde{A} = A + I$ — adjacency matrix with added self-loops (each node is its own neighbor)
- $\tilde{D}_{ii} = \sum_j \tilde{A}_{ij}$ — degree matrix of $\tilde{A}$
- $\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$ — symmetric normalization
- $W^{(l)}$ — learnable weight matrix
- $\sigma$ — nonlinearity (ReLU)

The symmetric normalization ensures the scale of representations doesn't blow up or vanish
as messages propagate: each node's contribution is weighted by $1/\sqrt{d_v d_u}$.

## GCN from scratch

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def gcn_norm(edge_index, num_nodes):
    """Compute D^{-1/2} A_tilde D^{-1/2} as sparse tensors."""
    # Add self-loops
    self_loops = torch.arange(num_nodes, dtype=torch.long)
    self_loop_idx = torch.stack([self_loops, self_loops])
    edge_index_tilde = torch.cat([edge_index, self_loop_idx], dim=1)

    row, col = edge_index_tilde
    deg = torch.zeros(num_nodes)
    deg.scatter_add_(0, row, torch.ones(row.size(0)))

    deg_inv_sqrt = deg.pow(-0.5)
    deg_inv_sqrt[deg_inv_sqrt == float('inf')] = 0

    # Normalized edge weights
    norm = deg_inv_sqrt[row] * deg_inv_sqrt[col]
    return edge_index_tilde, norm

class GCNConvScratch(nn.Module):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.W = nn.Linear(in_channels, out_channels, bias=False)

    def forward(self, x, edge_index_tilde, norm):
        # x: (N, in_channels)
        x = self.W(x)                          # (N, out)
        row, col = edge_index_tilde
        out = torch.zeros_like(x)
        out.index_add_(0, row, norm.unsqueeze(-1) * x[col])
        return out

print("GCNConvScratch defined: one GCN layer in plain torch.")
```

```output
GCNConvScratch defined: one GCN layer in plain torch.
```

## Node classification on a synthetic citation graph

`torch_geometric` is not available here, and Cora needs a download, so you build a small Cora-like graph yourself: a stochastic block model with 5 research areas (classes) of 60 papers each. Papers in the same area cite each other far more often (probability 0.06) than papers in different areas (0.015). Each paper has 100 bag-of-words features, where each class favors its own 20 words, so the features are informative but noisy. Only 10 labeled papers per class are used for training, as in the semi-supervised Cora setup.

```python
import numpy as np
torch.set_num_threads(1)

def make_graph(n_per=60, k=5, p_in=0.06, p_out=0.015, d=100, seed=2):
    rng = np.random.default_rng(seed)
    y = np.repeat(np.arange(k), n_per)
    n = len(y)
    P = np.where(y[:, None] == y[None, :], p_in, p_out)
    U = np.triu(rng.random((n, n)) < P, 1)
    A = U | U.T
    base = np.full((k, d), 0.03)
    for c in range(k):
        base[c, c * 20:(c + 1) * 20] = 0.15        # class-favored words
    X = (rng.random((n, d)) < base[y]).astype(np.float32)
    X = X / np.maximum(X.sum(1, keepdims=True), 1)  # row-normalize like NormalizeFeatures
    train = np.zeros(n, bool)
    for c in range(k):
        train[np.nonzero(y == c)[0][:10]] = True
    rest = np.nonzero(~train)[0]
    rng.shuffle(rest)
    val = np.zeros(n, bool); val[rest[:100]] = True
    test = ~train & ~val
    return (torch.tensor(X), torch.tensor(np.stack(np.nonzero(A))), torch.tensor(y),
            torch.tensor(train), torch.tensor(val), torch.tensor(test))

x, edge_index, y, train_mask, val_mask, test_mask = make_graph()
num_nodes, num_classes = x.shape[0], 5
print(f"Nodes: {num_nodes}, Edges (directed): {edge_index.shape[1]}")
print(f"Node features: {tuple(x.shape)}, Classes: {num_classes}")
print(f"Train/Val/Test: {int(train_mask.sum())}/{int(val_mask.sum())}/{int(test_mask.sum())}")
same = (y[edge_index[0]] == y[edge_index[1]]).float().mean().item()
print(f"Fraction of edges joining same-class nodes (homophily): {same:.3f}")
```

```output
Nodes: 300, Edges (directed): 2174
Node features: (300, 100), Classes: 5
Train/Val/Test: 50/100/150
Fraction of edges joining same-class nodes (homophily): 0.479
```

```python
class GCN(nn.Module):
    def __init__(self, in_ch, hidden, out_ch):
        super().__init__()
        self.conv1 = GCNConvScratch(in_ch, hidden)
        self.conv2 = GCNConvScratch(hidden, out_ch)

    def forward(self, x, edge_index_tilde, norm):
        x = F.relu(self.conv1(x, edge_index_tilde, norm))
        x = F.dropout(x, p=0.5, training=self.training)
        return self.conv2(x, edge_index_tilde, norm)

edge_index_tilde, norm = gcn_norm(edge_index, num_nodes)

def accuracies(model, *args):
    model.eval()
    with torch.no_grad():
        pred = model(x, *args).argmax(dim=1)
    return [(pred[m] == y[m]).float().mean().item() for m in (train_mask, val_mask, test_mask)]

def fit(model, *args, epochs=200, lr=0.01):
    opt = torch.optim.Adam(model.parameters(), lr=lr, weight_decay=5e-4)
    for _ in range(epochs):
        model.train(); opt.zero_grad()
        out = model(x, *args)
        F.cross_entropy(out[train_mask], y[train_mask]).backward()
        opt.step()
    return accuracies(model, *args)

torch.manual_seed(0)
model = GCN(x.shape[1], 32, num_classes)
train_acc, val_acc, test_acc = fit(model, edge_index_tilde, norm)
print(f"Train: {train_acc:.3f}  Val: {val_acc:.3f}  Test: {test_acc:.3f}")
```

```output
Train: 1.000  Val: 0.720  Test: 0.720
```

## Checking against the dense formula

The edge-list implementation should equal the matrix formula $\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2} X W$ exactly. Build the dense matrix and compare, then do the same for a graph-free baseline (an MLP on the same features) to see what the graph contributes.

```python
A_t = torch.zeros(num_nodes, num_nodes)
A_t[edge_index[0], edge_index[1]] = 1.0
A_t = A_t + torch.eye(num_nodes)
d_inv_sqrt = A_t.sum(1).pow(-0.5)
A_hat = d_inv_sqrt[:, None] * A_t * d_inv_sqrt[None, :]

layer = GCNConvScratch(x.shape[1], 8)
dense_out = A_hat @ layer.W(x)
print("Edge-list matches dense formula:", torch.allclose(layer(x, edge_index_tilde, norm), dense_out, atol=1e-6))

class MLP(nn.Module):
    def __init__(self, in_ch, hidden, out_ch):
        super().__init__()
        self.l1, self.l2 = nn.Linear(in_ch, hidden), nn.Linear(hidden, out_ch)
    def forward(self, x):
        return self.l2(F.dropout(F.relu(self.l1(x)), 0.5, self.training))

torch.manual_seed(0)
mlp_acc = fit(MLP(x.shape[1], 32, num_classes))
print(f"MLP (no graph) test accuracy: {mlp_acc[2]:.3f}   GCN test accuracy: {test_acc:.3f}")
```

```output
Edge-list matches dense formula: True
MLP (no graph) test accuracy: 0.613   GCN test accuracy: 0.720
```

## Over-smoothing

Stack too many GCN layers and all node embeddings converge to the same value, the dominant eigenvector of the normalized adjacency. At depth $K$, every node aggregates its entire $K$-hop neighborhood, and the representations average out.

```python
class DeepGCN(nn.Module):
    def __init__(self, in_ch, hidden, out_ch, depth):
        super().__init__()
        dims = [in_ch] + [hidden] * (depth - 1) + [out_ch]
        self.convs = nn.ModuleList(GCNConvScratch(dims[i], dims[i + 1]) for i in range(depth))
    def forward(self, x, edge_index_tilde, norm):
        for conv in self.convs[:-1]:
            x = F.dropout(F.relu(conv(x, edge_index_tilde, norm)), 0.5, self.training)
        return self.convs[-1](x, edge_index_tilde, norm)

for d in [1, 2, 4, 8, 16]:
    torch.manual_seed(0)
    acc = fit(DeepGCN(x.shape[1], 32, num_classes, d), edge_index_tilde, norm)[2]
    print(f"Depth {d:2d}: test acc = {acc:.3f}")
```

```output
Depth  1: test acc = 0.653
Depth  2: test acc = 0.720
Depth  4: test acc = 0.240
Depth  8: test acc = 0.173
Depth 16: test acc = 0.193
```

Depth 2 is the sweet spot on this graph. From depth 4 on, accuracy collapses to roughly chance (0.2 for 5 classes): over-smoothing blurs the classes together, and with dropout on every layer and only 50 labels the deep stacks are also hard to optimize.

## Exercise

Add a **residual connection** to the 2-layer GCN: after the first conv, add a linear
projection of the raw input features $x$ to the hidden dimension, then add it to the
first conv's output before the second conv. Does this help or hurt accuracy on this graph?

<details>
<summary>Solution</summary>

```python
class ResGCN(nn.Module):
    def __init__(self, hidden=32):
        super().__init__()
        self.c1 = GCNConvScratch(x.shape[1], hidden)
        self.c2 = GCNConvScratch(hidden, num_classes)
        self.proj = nn.Linear(x.shape[1], hidden, bias=False)

    def forward(self, x, eit, norm):
        h = F.relu(self.c1(x, eit, norm)) + self.proj(x)   # residual
        h = F.dropout(h, 0.5, self.training)
        return self.c2(h, eit, norm)

for name, cls in [("GCN", lambda: GCN(x.shape[1], 32, num_classes)), ("ResGCN", ResGCN)]:
    accs = []
    for seed in range(5):
        torch.manual_seed(seed)
        accs.append(fit(cls(), edge_index_tilde, norm)[2])
    print(f"{name:7s} mean test acc over 5 seeds: {np.mean(accs):.3f}")
```

```output
GCN     mean test acc over 5 seeds: 0.721
ResGCN  mean test acc over 5 seeds: 0.660
```

On this graph the residual hurts (about 0.66 vs 0.72). The projection of the raw features gives the model a path that skips the graph, and with only 50 training labels it overfits the noisy features instead of leaning on neighbor averaging. Residuals help when depth is the problem; at depth 2 with a strong graph signal they mostly dilute smoothing.
</details>
