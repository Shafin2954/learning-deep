## Three mechanisms of missingness

A blank cell is not only "no data" — *why* it is blank matters. If blanks happen by pure
luck, you can ignore them. If they happen for a reason, ignoring them quietly skews your
results.

The mechanism that caused the missing value determines what you can safely do about it.

**MCAR — Missing Completely At Random.** Missingness is unrelated to any variable, observed or
unobserved. A sensor randomly drops packets; a form field was optional and people skipped it
randomly. You can drop those rows without bias — the complete cases are a random sample of the
full dataset. Little's test checks this formally.

**MAR — Missing At Random.** Missingness depends on *observed* variables, but not on the
missing value itself. Income is missing more often for older respondents (age is observed) but,
within the same age group, who is missing income is random. Imputation is valid when you
condition on the observed variables.

**MNAR — Missing Not At Random.** Missingness depends on the value itself. High earners
don't report income; very sick patients drop out of trials. No imputation method solves MNAR
without additional assumptions or external data. You can only model the missingness explicitly
or collect more data.

Here **imputation** means filling a blank with a best guess, and **bias** means a result
that is wrong in a consistent direction, not by random chance.

> **Picture it:** a teacher collecting homework. MCAR: a gust of wind blew a random few
> sheets away. MAR: students in the back row hand in less often — you can see who sits
> where, so you can adjust. MNAR: students who did badly "forgot" to hand it in — the
> missing sheets are missing *because* of what is written on them, and nothing on the
> sheets you do have tells you that.

```python
import pandas as pd
import numpy as np

rng = np.random.default_rng(0)
n = 300

df = pd.DataFrame({
    'age':    rng.integers(20, 70, n).astype(np.int32),
    'income': rng.normal(50_000, 15_000, n).astype(np.float64),
    'score':  rng.normal(0, 1, n).astype(np.float64),
})

# MCAR: randomly drop 15% of 'score'
mcar_mask = rng.random(n) < 0.15
df.loc[mcar_mask, 'score'] = np.nan

# MAR: older people (age > 50) more likely to have income missing
mar_mask = (df['age'] > 50) & (rng.random(n) < 0.40)
df.loc[mar_mask, 'income'] = np.nan

print(df.isnull().sum())
print(f"\nMCAR fraction: {mcar_mask.mean():.2f}")
print(f"Income missing rate age≤50: {df[df['age']<=50]['income'].isnull().mean():.2f}")
print(f"Income missing rate age>50: {df[df['age']>50]['income'].isnull().mean():.2f}")
```

```output
age        0
income    63
score     45
dtype: int64

MCAR fraction: 0.15
Income missing rate age≤50: 0.00
Income missing rate age>50: 0.48
```

The counts show 45 missing `score` values (15% of 300, as planted) and 63 missing
`income` values. The last two lines prove the mechanism: income is never missing for
people aged 50 or under (0.00), but missing for 48% of people over 50.

The income missingness is clearly higher for older respondents — that's MAR in action.

> **Watch out:** you can never *prove* data is MAR rather than MNAR from the data alone —
> the deciding information is exactly the values you don't have. Comparing missing rates
> across observed groups (as above) rules out MCAR; telling MAR from MNAR needs domain
> knowledge.

## Visualising missingness

Before you fix blanks, look at where they are. A picture shows in seconds whether blanks
are scattered, packed into one column, or lined up in the same rows.

A missingness heatmap is the fastest way to see patterns:

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
n = 200
df = pd.DataFrame({
    'A': np.where(rng.random(n) < 0.1, np.nan, rng.normal(0, 1, n)),
    'B': np.where(rng.random(n) < 0.3, np.nan, rng.normal(0, 1, n)),
    'C': rng.normal(0, 1, n),
    'D': np.where(rng.random(n) < 0.05, np.nan, rng.integers(0, 10, n).astype(float)),
})

# Missingness matrix (white = missing)
fig, axes = plt.subplots(1, 2, figsize=(10, 3))

# Heatmap: 1 = present, 0 = missing
present = df.notna().astype(int)
axes[0].imshow(present.T, aspect='auto', cmap='RdYlGn', vmin=0, vmax=1)
axes[0].set_yticks(range(len(df.columns)))
axes[0].set_yticklabels(df.columns)
axes[0].set_title('Missingness matrix (green=present, red=missing)')

# Bar chart of miss rates
miss_pct = df.isnull().mean() * 100
axes[1].barh(miss_pct.index, miss_pct.values, color='steelblue')
axes[1].set_xlabel('% missing')
axes[1].set_title('Missing rate per column')

fig.tight_layout()
plt.show()
print(df.isnull().sum())
```

```output
A    18
B    58
C     0
D     8
dtype: int64
```

The printed counts match the planted rates: column `B` is missing 58 of 200 values (about
30%), `A` 18 (about 10%), `D` 8 (about 5%), and `C` none. In the matrix plot, look for red
streaks that line up vertically across columns — rows that are missing several fields at
once usually share one cause.

## Imputation strategies

Filling blanks has two parts: learn the fill value from the training data, then apply it
everywhere. scikit-learn's imputers split these into `fit` (learn) and `transform`
(apply).

### SimpleImputer — fill with a statistic

**`SimpleImputer`** replaces every blank in a column with one number computed from that
column: the mean, the median, or the most frequent value.

```python
import pandas as pd
import numpy as np
from sklearn.impute import SimpleImputer
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(0)
n = 500
X = pd.DataFrame({
    'num1': rng.normal(10, 2, n),
    'num2': rng.exponential(5, n),
    'cat':  rng.choice(['a', 'b', 'c'], n),
})
# Plant 20% missing in num1
X.loc[rng.random(n) < 0.2, 'num1'] = np.nan

X_train, X_test = train_test_split(X[['num1', 'num2']], test_size=0.2, random_state=0)

# Correct: fit only on train
imp = SimpleImputer(strategy='median')
imp.fit(X_train)
X_train_imp = imp.transform(X_train)
X_test_imp  = imp.transform(X_test)

print(f"Imputed median (from train): {imp.statistics_[0]:.3f}")
print(f"True train median: {X_train['num1'].median():.3f}")
print(f"Any NaN after imputation: {np.isnan(X_train_imp).any()}")
```

```output
Imputed median (from train): 9.814
True train median: 9.814
Any NaN after imputation: False
```

The imputer learned 9.814 — exactly the median of the training column — and stored it in
`statistics_`. After `transform`, no `NaN` remains. The test set is filled with the same
9.814, learned from train only.

> **Watch out:** a single fill value shrinks the spread. If 20% of a column becomes the
> same number, the standard deviation drops and correlations with other columns weaken.
> Adding a "was missing" 0/1 indicator column (`add_indicator=True`) keeps that
> information for the model.

### KNNImputer — uses neighbour values

**`KNNImputer`** fills a blank by finding the $k$ rows most similar on the *other* columns
(the **nearest neighbours**) and averaging their values for the missing one.

> **Picture it:** you don't know a house's price, so you look up the 5 houses on the same
> street with the most similar size and age and take their average.

```python
import pandas as pd
import numpy as np
from sklearn.impute import KNNImputer
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(1)
n = 300
# Correlated features: num2 ≈ 2 * num1
num1 = rng.normal(5, 1, n)
df = pd.DataFrame({
    'num1': num1,
    'num2': 2 * num1 + rng.normal(0, 0.5, n),
    'num3': rng.normal(0, 1, n),
})
# Drop 20% of num1
df.loc[rng.random(n) < 0.2, 'num1'] = np.nan

X_train, X_test = train_test_split(df, test_size=0.2, random_state=0)

# KNN imputer leverages the correlation between num1 and num2
knn_imp = KNNImputer(n_neighbors=5)
knn_imp.fit(X_train)
X_train_imputed = pd.DataFrame(knn_imp.transform(X_train), columns=df.columns)

print("Missing before:", X_train['num1'].isnull().sum())
print("Missing after: ", X_train_imputed['num1'].isnull().sum())
print(f"Imputed num1 mean: {X_train_imputed['num1'].mean():.3f}")
print(f"True num1 mean:    {X_train['num1'].mean():.3f}")
```

```output
Missing before: 34
Missing after:  0
Imputed num1 mean: 4.910
True num1 mean:    4.909
```

34 training values were missing; after imputation, 0 are. The imputed column mean (4.910)
is within 0.001 of the observed mean (4.909).

KNN imputation recovers the true mean closely because `num1` and `num2` are correlated — the
neighbours' `num2` values guide the fill.

Matching the *mean* is the easy part, though: under MCAR even mean-filling matches it.
KNN's real advantage is that each filled value is close to that row's own true value,
because `num2` $\approx$ `2 * num1` tells it where each row should sit.

### The wrong way: fit on all data

**Leakage** is when information from the test set sneaks into training, so your test score
looks better than it will be on truly new data (ch. 12).

```python
import pandas as pd
import numpy as np
from sklearn.impute import SimpleImputer
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(2)
n = 200
X = pd.DataFrame({'x': np.where(rng.random(n) < 0.3, np.nan, rng.normal(0, 1, n))})
X_train, X_test = train_test_split(X, test_size=0.2, random_state=0)

# WRONG: fit on full dataset — test data leaks into the imputed mean
imp_leaky = SimpleImputer(strategy='mean')
imp_leaky.fit(X)  # uses test data!
print(f"Leaky mean (full dataset): {imp_leaky.statistics_[0]:.4f}")

# CORRECT: fit only on train
imp_clean = SimpleImputer(strategy='mean')
imp_clean.fit(X_train)
print(f"Clean mean (train only):   {imp_clean.statistics_[0]:.4f}")
print("Difference may seem small, but it violates the train/test contract.")
```

```output
Leaky mean (full dataset): -0.0850
Clean mean (train only):   -0.1646
Difference may seem small, but it violates the train/test contract.
```

Here the gap is large: the leaky mean is -0.0850 and the clean one -0.1646, almost a factor
of two, because the test rows (40 of 200) shift the mean noticeably. The printed line says
the difference "may seem small" — with small datasets it often is not. Either way, the leaky
version used test data to make a training decision, which breaks the train/test contract.

Always fit imputers — and every other statistic-computing transformer — on the training set
only, then apply the fitted transformer to the test set.

## Recap in plain words

- MCAR blanks are pure luck, MAR blanks depend on other columns you can see, MNAR blanks
  depend on the hidden value itself.
- Higher missing rates in one observed group rule out MCAR; MNAR can't be detected from the
  data alone.
- Plot where the blanks are before choosing a fix.
- `SimpleImputer` fills one statistic per column; `KNNImputer` borrows from similar rows.
- Always `fit` the imputer on the training set and only `transform` the test set.

## Try it Yourself

This experiment plants MCAR blanks in `feature_a` and MAR blanks in `feature_c`, then
compares mean-filling with KNN-filling.

```python
import pandas as pd
import numpy as np
from sklearn.impute import KNNImputer, SimpleImputer
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(99)
n = 400
x1 = rng.normal(10, 2, n)
df = pd.DataFrame({
    'feature_a': x1,
    'feature_b': 0.5 * x1 + rng.normal(0, 1, n),
    'feature_c': rng.normal(0, 5, n),
})

# Plant MCAR in feature_a (15%) and MAR in feature_c (high feature_b → more missing)
df.loc[rng.random(n) < 0.15, 'feature_a'] = np.nan
df.loc[(df['feature_b'] > 4) & (rng.random(n) < 0.6), 'feature_c'] = np.nan

print("Missing counts:")
print(df.isnull().sum())

X_train, X_test = train_test_split(df, test_size=0.2, random_state=0)

# Compare SimpleImputer vs KNNImputer on feature_a (MCAR)
for name, imp in [('mean', SimpleImputer(strategy='mean')),
                  ('knn5', KNNImputer(n_neighbors=5))]:
    imp.fit(X_train)
    filled = pd.DataFrame(imp.transform(X_train), columns=df.columns)
    err = abs(filled['feature_a'].mean() - 10)
    print(f"{name}: imputed mean={filled['feature_a'].mean():.3f}, error from true={err:.3f}")
```

```output
Missing counts:
feature_a     57
feature_b      0
feature_c    183
dtype: int64
mean: imputed mean=9.862, error from true=0.138
knn5: imputed mean=9.867, error from true=0.133
```

`feature_c` lost 183 of 400 values — the MAR rule (high `feature_b`) bit hard — while
`feature_a` lost 57 (about 15%). Both imputers land near the true mean of 10 (errors 0.138
and 0.133), and the error is mostly the observed train mean being 9.86 by chance. The
column mean is a weak test. A sharper variation: keep a copy of `feature_a` before planting
the blanks and compare each filled value with its true value. Measured that way (root mean
squared error on the filled cells), mean-filling is off by about 1.76 and KNN by about
1.33, because KNN uses the link between `feature_a` and `feature_b`.

## Exercise

You have a DataFrame with three columns: `hours_studied`, `exam_score`, and `absences`.
`hours_studied` is MCAR (15% missing); `absences` is MAR (missing more for high scorers).
Split 80/20, fit a `KNNImputer(n_neighbors=5)` on train only, and verify that:
(a) no NaN remain after imputation, and (b) the imputed mean of `hours_studied` matches
the observed train mean within 0.5 units.

> **Hint:** to make `absences` MAR, let its missing probability depend on `exam_score`,
> for example `np.where(score > 75, 0.5, 0.1)`. Fit the imputer on `X_train`, then call
> `transform` on both splits.

<details>
<summary>Solution</summary>

```python
import pandas as pd
import numpy as np
from sklearn.impute import KNNImputer
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(7)
n = 500
hours = rng.uniform(1, 10, n)
score = 50 + 4 * hours + rng.normal(0, 5, n)
df = pd.DataFrame({
    'hours_studied': np.where(rng.random(n) < 0.15, np.nan, hours),
    'exam_score':    score,
    'absences':      np.where(
        rng.random(n) < np.where(score > 75, 0.5, 0.1),  # MAR: high scorers miss more
        np.nan,
        rng.integers(0, 10, n).astype(float)
    ),
})

X_train, X_test = train_test_split(df, test_size=0.2, random_state=0)
observed_mean = X_train['hours_studied'].mean()

imp = KNNImputer(n_neighbors=5)
imp.fit(X_train)
X_train_imp = pd.DataFrame(imp.transform(X_train), columns=df.columns)
X_test_imp  = pd.DataFrame(imp.transform(X_test),  columns=df.columns)

print(f"NaN in train after: {X_train_imp.isnull().sum().sum()}")
print(f"NaN in test after:  {X_test_imp.isnull().sum().sum()}")
print(f"Observed mean: {observed_mean:.3f}")
print(f"Imputed mean:  {X_train_imp['hours_studied'].mean():.3f}")
print(f"Difference:    {abs(X_train_imp['hours_studied'].mean() - observed_mean):.3f}")
```

The KNNImputer fills missing values by averaging the 5 nearest observed neighbours, so the
imputed mean stays close to the true mean. The key insight: fit on train, transform both.
Running it gives 0 NaN in both splits and a mean difference of 0.006, far inside the 0.5
target. `exam_score` is the column that helps most here: it is built from `hours_studied`,
so rows with similar scores have similar study hours.
</details>
