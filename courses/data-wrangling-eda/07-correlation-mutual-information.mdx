## Three ways to measure association

"Do these two columns go together?" sounds like one question, but it has several
versions: do they lie on a straight line, does one always rise when the other rises, or
does knowing one tell you *anything at all* about the other? Each version has its own
measure.

No single measure captures every type of relationship between two variables. An
**association** is any pattern linking two variables; a **monotone** relationship is one
that only ever goes one way (always up, or always down), even if it curves.

| Measure | What it captures | Sensitive to outliers? | Works for categorical? |
|---------|-----------------|------------------------|------------------------|
| Pearson $r$ | Linear | Yes | No |
| Spearman $\rho$ | Monotone | Resistant | Ordinal only |
| Mutual information | Any | Resistant | Yes |

> **Picture it:** three detectives. Pearson only notices suspects walking in a straight
> line. Spearman notices anyone who keeps heading the same direction, however winding the
> road. Mutual information notices anyone whose position tells you something about
> someone else's — even if they walk in circles.

## Pearson correlation

Pearson's correlation asks: when $X$ is above its average, is $Y$ usually above its
average too — and how tightly do the points hug a straight line?

$$
r = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}
= \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_i (x_i-\bar{x})^2 \sum_i (y_i-\bar{y})^2}}
$$

> **In plain words:**
> - $x_i - \bar{x}$ is how far point $i$ is from the average $x$; same for $y$.
> - Multiplying the two gives a positive number when both are on the same side of their
>   averages, and a negative one when they are on opposite sides.
> - The top adds these up: the **covariance**, $\text{Cov}(X, Y)$, up to a factor of $n$.
> - The bottom divides by both spreads ($\sigma_X \sigma_Y$, the standard deviations), so
>   the answer doesn't depend on units.

$r \in [-1, 1]$. A perfect linear relationship gives $|r|=1$. Non-linear relationships can
give $r \approx 0$ even when the variables are strongly associated.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(0)
n = 500
x = rng.uniform(-3, 3, n).astype(np.float64)

# Three relationships
y_linear  = 2 * x + rng.normal(0, 0.5, n)      # strong linear
y_quad    = x**2 + rng.normal(0, 0.3, n)        # nonlinear (U-shape)
y_noise   = rng.normal(0, 1, n)                  # no relationship

df = pd.DataFrame({'x': x, 'y_linear': y_linear,
                   'y_quad': y_quad, 'y_noise': y_noise})

for col in ['y_linear', 'y_quad', 'y_noise']:
    r = df['x'].corr(df[col])
    print(f"Pearson r(x, {col}): {r:+.3f}")
```

```output
Pearson r(x, y_linear): +0.991
Pearson r(x, y_quad): +0.080
Pearson r(x, y_noise): -0.068
```

The linear pair scores +0.991, almost a perfect line. The U-shape scores only +0.080 even
though $y$ is almost fully determined by $x$. The pure-noise column scores -0.068 — not
exactly 0, because 500 random points always show a little accidental pattern.

Pearson assigns $r \approx 0$ to the quadratic relationship — it completely misses the
strong nonlinear association. On the left half of the U, $y$ falls as $x$ rises; on the
right half it rises. The two halves cancel.

### Outlier sensitivity

Because Pearson multiplies raw distances, one point very far away contributes a huge
product and can outvote all the others.

```python
import numpy as np

rng = np.random.default_rng(1)
x = rng.normal(0, 1, 100).astype(np.float64)
y = 0.5 * x + rng.normal(0, 0.5, 100)

r_clean = np.corrcoef(x, y)[0, 1]

# Add a single outlier
x_out = np.append(x, [10.0])
y_out = np.append(y, [-10.0])
r_outlier = np.corrcoef(x_out, y_out)[0, 1]

print(f"r without outlier: {r_clean:+.3f}")
print(f"r with outlier:    {r_outlier:+.3f}")
```

```output
r without outlier: +0.639
r with outlier:    -0.412
```

One extreme data point erased a genuine 0.64 correlation (+0.639) and flipped it to
-0.412. That one point at $(10, -10)$ outweighed the other 100. Pearson is not robust.

> **Watch out:** always scatter-plot a pair before trusting its Pearson $r$. A single
> data-entry error can create, hide, or reverse a correlation.

## Spearman rank correlation

Spearman throws away the actual values and keeps only their **ranks** — 1st smallest, 2nd
smallest, and so on — then runs Pearson on the ranks. A huge outlier becomes "the biggest",
which is only one rank above second-biggest.

Spearman $\rho$ applies Pearson correlation to the *ranks* of the values rather than the
values themselves. This captures any monotone relationship and is resistant to outliers.

$$
\rho = 1 - \frac{6 \sum d_i^2}{n(n^2 - 1)}
$$

where $d_i$ is the difference in ranks of $x_i$ and $y_i$.

> **In plain words:** if every point has the same rank in $x$ as in $y$, all $d_i = 0$ and
> $\rho = 1$. The more the two rankings disagree, the bigger $\sum d_i^2$ and the lower
> $\rho$. The $n(n^2 - 1)$ part scales it so the answer always lands between -1 and 1.
> This shortcut formula assumes no tied values.

```python
import numpy as np
import pandas as pd
from scipy.stats import spearmanr

rng = np.random.default_rng(2)
n = 500
x = rng.uniform(0.1, 10, n).astype(np.float64)

# Monotone but nonlinear: log relationship
y_log   = np.log(x) + rng.normal(0, 0.3, n)
# Outlier test
x_out = np.append(x, [1000.0])
y_out = np.append(np.log(x) + rng.normal(0, 0.3, n), [-1000.0])

print(f"Pearson  r(x, log(x)): {pd.Series(x).corr(pd.Series(y_log)):+.3f}")
print(f"Spearman ρ(x, log(x)): {spearmanr(x, y_log).statistic:+.3f}")
print(f"\nWith outlier:")
print(f"Pearson  r: {np.corrcoef(x_out, y_out)[0,1]:+.3f}")
print(f"Spearman ρ: {spearmanr(x_out, y_out).statistic:+.3f}")
```

```output
Pearson  r(x, log(x)): +0.858
Spearman ρ(x, log(x)): +0.900

With outlier:
Pearson  r: -0.997
Spearman ρ: +0.898
```

On the clean log curve, Spearman (+0.900) beats Pearson (+0.858) because the curve bends
but never turns around. Then the outlier at $x = 1000, y = -1000$: Pearson collapses to
-0.997 — the single point now dominates everything — while Spearman barely moves, from
+0.900 to +0.898.

Spearman correctly sees the monotone relationship and is almost completely unaffected by
the extreme outlier. It reads 0.900 rather than 1 here only because of the added noise:
with noise of 0.03 instead of 0.3 it reaches 0.998, and with less noise still it passes
$\rho = 0.999$.

## Mutual information — capture any association

**Mutual information** asks the most general question: how much does knowing $X$ shrink
your uncertainty about $Y$? If $X$ tells you nothing, the answer is 0. Any pattern —
straight, curved, wavy — makes it positive.

Mutual information (MI) measures how much knowing $X$ reduces uncertainty about $Y$:

$$
I(X; Y) = \sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)\,p(y)}
$$

> **In plain words:**
> - $p(x,y)$ is how often the pair $(x, y)$ occurs together.
> - $p(x)\,p(y)$ is how often it *would* occur if $X$ and $Y$ were unrelated.
> - The log of their ratio is 0 when the two agree, so independent variables score 0.
> - The sum weights each pair by how common it is. With natural logs, the unit is
>   **nats**; MI has no upper limit of 1, unlike $r$.

MI = 0 iff $X$ and $Y$ are independent. It captures nonlinear, non-monotone relationships
and works for both continuous and categorical variables via entropy estimation. (**Entropy**
is the information-theory measure of uncertainty; "iff" means "if and only if".)

> **Picture it:** playing "20 questions" about $Y$. MI is how many questions you save,
> on average, when someone tells you $X$ first.

```python
import numpy as np
from sklearn.feature_selection import mutual_info_regression

rng = np.random.default_rng(3)
n = 1000
x = rng.uniform(-3, 3, n).astype(np.float64).reshape(-1, 1)

# Three target types
y_linear   = (2 * x.ravel() + rng.normal(0, 0.5, n))
y_quad     = (x.ravel()**2 + rng.normal(0, 0.3, n))
y_circular = (np.sin(x.ravel() * 2) + rng.normal(0, 0.2, n))
y_noise    = rng.normal(0, 1, n)

for name, y in [('linear', y_linear), ('quadratic', y_quad),
                ('sinusoidal', y_circular), ('noise', y_noise)]:
    mi = mutual_info_regression(x, y, random_state=0)[0]
    r  = np.corrcoef(x.ravel(), y)[0, 1]
    print(f"{name:12s}  Pearson r={r:+.3f}  MI={mi:.3f}")
```

```output
linear        Pearson r=+0.990  MI=1.874
quadratic     Pearson r=-0.045  MI=1.929
sinusoidal    Pearson r=-0.374  MI=1.192
noise         Pearson r=+0.005  MI=0.000
```

The quadratic scores the *highest* MI (1.929), even above the linear pair (1.874), while
its Pearson $r$ is -0.045. The sine wave gets MI 1.192 while Pearson sees only a weak
-0.374. Pure noise gets exactly 0.000.

MI correctly assigns high scores to the quadratic and sinusoidal relationships that Pearson
scored low. MI = 0 only for the pure noise case.

> **Watch out:** scikit-learn estimates MI from neighbouring points, so it is an
> *estimate*: it changes a little with `random_state` and sample size, and it can't tell
> you the direction (up or down) of a relationship. Compare MI values with each other, not
> with $r$.

## When to use which

The three measures run side by side on four features with known shapes, so you can see
where they agree and where they split.

```python
import numpy as np
import pandas as pd
from scipy.stats import spearmanr
from sklearn.feature_selection import mutual_info_regression

rng = np.random.default_rng(4)
n = 500
target = rng.normal(0, 1, n).astype(np.float64)

features = pd.DataFrame({
    'linear':     target * 0.8 + rng.normal(0, 0.3, n),
    'rank_based': np.sign(target) * np.log1p(np.abs(target)) + rng.normal(0, 0.2, n),
    'nonlinear':  target**2 + rng.normal(0, 0.5, n),
    'noise':      rng.normal(0, 1, n),
})

print(f"{'Feature':<12} {'Pearson':>8} {'Spearman':>10} {'MI':>6}")
print("-" * 40)
for col in features.columns:
    f = features[col].values
    r     = np.corrcoef(target, f)[0, 1]
    rho   = spearmanr(target, f).statistic
    mi    = mutual_info_regression(f.reshape(-1,1), target, random_state=0)[0]
    print(f"{col:<12} {r:+8.3f} {rho:+10.3f} {mi:6.3f}")
```

```output
Feature       Pearson   Spearman     MI
----------------------------------------
linear         +0.932     +0.923  1.012
rank_based     +0.941     +0.953  1.175
nonlinear      -0.049     +0.000  0.803
noise          +0.009     +0.006  0.000
```

On `linear` and `rank_based` all three agree (Pearson and Spearman above +0.92, MI above
1). On `nonlinear` (a U-shape, $y$ = target squared) Pearson (-0.049) and Spearman
(+0.000) both see nothing, while MI (0.803) catches it. On `noise` all three are near 0.

Use Pearson for linear relationships. Prefer Spearman when you suspect monotone but not linear
associations, or when your data contains outliers. Use MI when you don't know the functional
form, or when the feature is categorical.

## Recap in plain words

- Pearson $r$ measures how close points are to a straight line, and one outlier can wreck
  it.
- Spearman $\rho$ is Pearson on ranks: it catches any always-up or always-down curve and
  shrugs off outliers.
- Both score near 0 on U-shapes and other relationships that change direction.
- Mutual information catches any dependence at all, but has no sign and no upper limit.
- Plot the pair first; pick the measure that matches the shape you suspect.

## Try it Yourself

A **step function** jumps from one level to another at a threshold — here $y$ jumps by 1
when $x$ passes 5.

```python
import numpy as np
from scipy.stats import spearmanr
from sklearn.feature_selection import mutual_info_regression

rng = np.random.default_rng(5)
n = 600
x = rng.uniform(0, 10, n).astype(np.float64)
y_thresh = (x > 5).astype(np.float64) + rng.normal(0, 0.2, n)  # step function

r   = np.corrcoef(x, y_thresh)[0, 1]
rho = spearmanr(x, y_thresh).statistic
mi  = mutual_info_regression(x.reshape(-1,1), y_thresh, random_state=0)[0]

print(f"Step function relationship:")
print(f"  Pearson r:   {r:+.3f}")
print(f"  Spearman ρ:  {rho:+.3f}")
print(f"  MI:          {mi:.3f}")
```

```output
Step function relationship:
  Pearson r:   +0.809
  Spearman ρ:  +0.760
  MI:          0.622
```

All three see the step. Pearson gives +0.809 and Spearman +0.760; the step is monotone (it
never goes back down), so both work. MI's 0.622 is not "weaker" — it is in nats, a
different unit. Try moving the noise from 0.2 to 1.0 and see which measure falls fastest,
or change the step to `(np.abs(x - 5) > 2)` so it is no longer monotone.

Create a 400-row DataFrame with `x = Uniform(0, 10)` and three target columns:
- `y_linear = 3x + noise` (linear)
- `y_abs = |x - 5| + noise` (V-shape, non-monotone)
- `y_cat_mean = mean of target in categorical bucket` (use `pd.cut` to create 4 bins)

Compute Pearson, Spearman, and MI for each (x vs target). Which measure catches the V-shape?

> **Hint:** for the V-shape, think about what Pearson saw for the U-shape earlier: the
> falling half and the rising half cancel. Then ask whether ranks fix that.

```python
import numpy as np
import pandas as pd
from scipy.stats import spearmanr
from sklearn.feature_selection import mutual_info_regression

rng = np.random.default_rng(0)
n = 400
x = rng.uniform(0, 10, n).astype(np.float64)

df = pd.DataFrame({
    'x':        x,
    'y_linear': 3 * x + rng.normal(0, 2, n),
    'y_abs':    np.abs(x - 5) + rng.normal(0, 0.5, n),
})
df['bin'] = pd.cut(df['x'], bins=4, labels=False)
df['y_cat_mean'] = df.groupby('bin')['x'].transform('mean') + rng.normal(0, 0.5, n)

print(f"{'Target':<12} {'Pearson':>8} {'Spearman':>10} {'MI':>6}")
for col in ['y_linear', 'y_abs', 'y_cat_mean']:
    y = df[col].values
    r   = np.corrcoef(x, y)[0, 1]
    rho = spearmanr(x, y).statistic
    mi  = mutual_info_regression(x.reshape(-1,1), y, random_state=0)[0]
    print(f"{col:<12} {r:+8.3f} {rho:+10.3f} {mi:6.3f}")
```

`y_abs` (V-shape) has Pearson $\approx 0$ and Spearman $\approx 0$ because the relationship
is symmetric — neither linear nor monotone. When run, Pearson gives +0.060 and Spearman
+0.114, while MI gives 1.211. MI correctly reports a non-zero value because knowing $x$
does reduce uncertainty about $|x-5|$. This is the core reason MI is the only safe choice
when you don't know the functional form of the relationship. The binned target
`y_cat_mean` is a staircase that only rises, so all three measures catch it (+0.956,
+0.934, 1.311).
