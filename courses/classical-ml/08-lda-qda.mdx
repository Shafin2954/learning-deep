## Generative classifiers

Instead of learning a boundary directly, a **generative** classifier first learns what each
class "looks like" — here, a cloud of points shaped like a tilted ellipse — and then asks,
for a new point, which cloud most likely produced it.

LDA and QDA are **generative models**: they model the joint distribution $P(x, y)$ by fitting a Gaussian for each class and applying Bayes' theorem. They differ only in whether classes share a covariance matrix.

A **joint distribution** $P(x, y)$ describes features and labels together. A **covariance
matrix** describes the shape of a cloud: how spread out it is along each feature, and how
features move together (the tilt). It is the multi-feature version of variance.

$$
P(Y=k \mid x) \propto P(x \mid Y=k)\,P(Y=k), \quad P(x\mid Y=k) = \mathcal{N}(x;\,\mu_k,\Sigma_k)
$$

> **In plain words:** the same Bayes rule as ch. 7, but now each class's likelihood is a
> full multi-dimensional bell curve $\mathcal{N}$ with its own centre $\mu_k$ and shape
> $\Sigma_k$ ("sigma k"). Unlike Naive Bayes, features may be correlated within a class.

> **Picture it:** each class is a swarm of bees around its hive. You learn where each hive
> is (the mean) and the shape of each swarm (the covariance). A new bee is assigned to the
> swarm it most plausibly belongs to.

## Linear Discriminant Analysis (LDA)

LDA forces every class's cloud to have the *same* shape and tilt, only centred in different
places. That one restriction makes the boundary between classes a straight line.

LDA assumes all classes share the same covariance: $\Sigma_k = \Sigma$ for all $k$.

### Decision boundary

Taking the log posterior and comparing two classes $k$ and $l$:

$$
\log\frac{P(Y=k\mid x)}{P(Y=l\mid x)} = (\mu_k - \mu_l)^T\Sigma^{-1}x - \frac{1}{2}(\mu_k^T\Sigma^{-1}\mu_k - \mu_l^T\Sigma^{-1}\mu_l) + \log\frac{\pi_k}{\pi_l}
$$

> **In plain words:** this is the log of "how many times more likely is class $k$ than class
> $l$ at point $x$". The first term is a fixed vector times $x$; everything else is a
> constant. $\pi_k$ is class $k$'s prior (its share of the data), not the number 3.14. The
> $x^T\Sigma^{-1}x$ terms you might expect cancel out, because both classes share $\Sigma$.

This is **linear** in $x$ — the boundary between two classes is a hyperplane.

A **hyperplane** is a flat dividing surface: a line in 2D, a plane in 3D, and so on.

### Fitting LDA

1. Estimate class means: $\hat\mu_k = \frac{1}{n_k}\sum_{y_i=k}x_i$
2. Estimate pooled within-class covariance: $\hat\Sigma = \frac{1}{n-K}\sum_k\sum_{y_i=k}(x_i-\hat\mu_k)(x_i-\hat\mu_k)^T$
3. Class priors: $\hat\pi_k = n_k/n$

**Pooled** means every class's spread is measured around its own mean, then all are averaged
into one shared shape. Dividing by $n - K$ instead of $n$ corrects for having estimated $K$
means first. Like Naive Bayes, fitting is pure counting and averaging — no iterations.

The test data has two classes built with the *same* tilted covariance, centred at $(0, 0)$
and $(4, 3)$ — exactly LDA's assumption.

```python
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)

# Two classes with similar covariance (good for LDA)
X_lda = np.vstack([
    rng.multivariate_normal([0, 0], [[2, 1],[1, 2]], 150),
    rng.multivariate_normal([4, 3], [[2, 1],[1, 2]], 150),
])
y_lda = np.array([0]*150 + [1]*150)

X_tr, X_te, y_tr, y_te = train_test_split(X_lda, y_lda, test_size=0.2, random_state=0)

lda = LinearDiscriminantAnalysis()
lda.fit(X_tr, y_tr)
print(f"LDA accuracy (equal cov): {lda.score(X_te, y_te):.3f}")
print(f"Learned means:\n  class 0: {lda.means_[0].round(3)}\n  class 1: {lda.means_[1].round(3)}")
```

```output
LDA accuracy (equal cov): 0.967
Learned means:
  class 0: [0.094 0.249]
  class 1: [3.912 2.932]
```

LDA classifies 58 of 60 test points correctly (0.967). The learned means, $(0.094, 0.249)$
and $(3.912, 2.932)$, are within 0.25 of the true centres $(0, 0)$ and $(4, 3)$.

## Fisher's discriminant direction

A second, older way to see LDA: find the single direction to look along so that the classes
appear as far apart as possible *relative to* how spread out each class is.

LDA can also be viewed as finding the projection direction $w$ that maximises:

$$
J(w) = \frac{w^T S_B w}{w^T S_W w}
$$

> **In plain words:** the top measures how far apart the class centres look along direction
> $w$; the bottom measures how wide each class looks along $w$. A good direction has centres
> far apart and narrow classes, so the ratio $J$ is large.

where $S_B$ is the **between-class scatter** matrix and $S_W$ is the **within-class scatter** matrix. The optimal $w = S_W^{-1}(\mu_1 - \mu_2)$ is the Fisher discriminant direction. This makes LDA useful for **dimensionality reduction**: project $p$-dimensional data onto the $K-1$ Fisher directions.

> **Picture it:** two overlapping flocks of birds seen from the ground. From most angles the
> flocks blur together. Walk around until, from one viewpoint, they appear as two separate
> clumps. That viewing angle is Fisher's direction.

```python
# LDA as a dimensionality reducer (3 classes → 2 Fisher directions)
from sklearn.datasets import load_iris

X_iris, y_iris = load_iris(return_X_y=True)
lda_dr = LinearDiscriminantAnalysis(n_components=2)
X_proj = lda_dr.fit_transform(X_iris, y_iris)

print(f"Original shape: {X_iris.shape}")
print(f"Projected shape: {X_proj.shape}")
print(f"Explained variance ratio: {lda_dr.explained_variance_ratio_.round(3)}")
```

```output
Original shape: (150, 4)
Projected shape: (150, 2)
Explained variance ratio: [0.991 0.009]
```

With 3 iris species, LDA can produce at most $K - 1 = 2$ directions, so the 4 measurements
are squeezed to 2. The first direction carries 99.1% of the between-class separation and the
second only 0.9% — essentially one number separates the three species.

> **Watch out:** unlike PCA (ch. 16), LDA uses the labels to choose its directions, and it can
> never produce more than $K - 1$ of them. For a 2-class problem that is a single direction.

## Quadratic Discriminant Analysis (QDA)

QDA lets every class have its own cloud shape — one long and thin, another round. With
different shapes, the dividing line can curve.

QDA allows each class its own covariance $\Sigma_k$. The log-posterior includes a quadratic term:

$$
\log P(Y=k\mid x) \propto -\frac{1}{2}\log|\Sigma_k| - \frac{1}{2}(x-\mu_k)^T\Sigma_k^{-1}(x-\mu_k) + \log\pi_k
$$

> **In plain words:**
> - $-\frac{1}{2}\log|\Sigma_k|$ penalizes a class with a big, spread-out cloud ($|\Sigma_k|$, the **determinant**, measures the cloud's volume) — a wide cloud spreads its probability thin.
> - $(x-\mu_k)^T\Sigma_k^{-1}(x-\mu_k)$ is the squared distance from $x$ to the class centre, measured in that class's own shape (the **Mahalanobis distance**).
> - $\log\pi_k$ is the log prior, as before.
>
> Because each class has its own $\Sigma_k$, the $x$-squared terms no longer cancel.

This is **quadratic** in $x$ — the boundary is a quadratic surface (ellipse, hyperbola, parabola).

The two classes below are shaped very differently: one stretched along the horizontal axis,
the other along the vertical axis, with centres only $(1, 1)$ apart.

```python
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(1)

# Two classes with DIFFERENT covariances (QDA should win)
X_qda = np.vstack([
    rng.multivariate_normal([0, 0], [[3, 0],[0, 0.5]], 200),   # elongated along x
    rng.multivariate_normal([1, 1], [[0.5, 0],[0, 3]], 200),   # elongated along y
])
y_qda = np.array([0]*200 + [1]*200)
X_tr, X_te, y_tr, y_te = train_test_split(X_qda, y_qda, test_size=0.2, random_state=0)

for name, clf in [("LDA", LinearDiscriminantAnalysis()),
                   ("QDA", QuadraticDiscriminantAnalysis())]:
    acc = clf.fit(X_tr, y_tr).score(X_te, y_te)
    print(f"{name}: {acc:.3f}")
```

```output
LDA: 0.675
QDA: 0.750
```

QDA gets 75.0% right against LDA's 67.5% — 6 more correct out of 80 test points. The true
best boundary bends around the narrow ends of each ellipse, which only QDA can draw.

QDA captures the different shapes; LDA uses a linear boundary that can't separate them as well.

> **Watch out:** when the class centres are far apart, a straight line can be good enough even
> if the shapes differ. With these same shapes centred at $(0, 0)$ and $(2, 2)$, LDA actually
> scores slightly higher (0.863 against 0.850). QDA's advantage shows up when the classes
> overlap and their shapes decide the boundary.

## When to use each

LDA is the cautious choice: fewer numbers to estimate, so it needs less data. QDA is the
flexible choice: it pays for its curved boundaries with many more numbers to estimate.

| Situation | Prefer |
|---|---|
| Few training samples per class | LDA (shared Σ → fewer parameters) |
| Large training set, class shapes differ | QDA |
| You need feature reduction to $K-1$ dims | LDA |
| Equal class covariances | Either (LDA is simpler) |

### Rule of thumb: compare $n/p$ ratio

LDA has $O(p^2)$ parameters (one shared $\Sigma$), QDA has $O(Kp^2)$ parameters. When $n/p$ is small, LDA generalises better.

Concretely, a $p \times p$ covariance has $p(p+1)/2$ free numbers. With $p = 50$ features
that is 1,275 for LDA's one shared matrix, but 12,750 for QDA with 10 classes. If you have
2,000 rows, QDA is trying to estimate more numbers than it has data points.

## Recap in plain words

- LDA and QDA model each class as a Gaussian cloud and classify with Bayes' rule.
- LDA gives every class the same cloud shape, which makes the boundaries straight (hyperplanes).
- QDA gives every class its own shape, which makes the boundaries curved (quadratic).
- LDA doubles as a supervised dimensionality reducer onto at most $K - 1$ Fisher directions.
- QDA wins when the classes overlap and differ in shape; LDA wins on small data or well-separated classes.
- Count parameters: QDA needs roughly $K$ times as many as LDA.

## Try it Yourself

```python
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis
from sklearn.model_selection import cross_val_score

rng = np.random.default_rng(42)
# 4-class problem in 6D; classes have different shapes
means = [[0,0,0,0,0,0], [3,0,0,0,0,0], [0,3,0,0,0,0], [3,3,0,0,0,0]]
covs  = [
    np.diag([2,0.5,1,1,1,1]),
    np.diag([0.5,2,1,1,1,1]),
    np.diag([1,1,2,0.5,1,1]),
    np.diag([1,1,0.5,2,1,1]),
]
X = np.vstack([rng.multivariate_normal(m, c, 100) for m, c in zip(means, covs)])
y = np.repeat([0,1,2,3], 100)

lda_cv = cross_val_score(LinearDiscriminantAnalysis(), X, y, cv=5).mean()
qda_cv = cross_val_score(QuadraticDiscriminantAnalysis(), X, y, cv=5).mean()
print(f"LDA 5-fold CV: {lda_cv:.3f}")
print(f"QDA 5-fold CV: {qda_cv:.3f}")
```

```output
LDA 5-fold CV: 0.830
QDA 5-fold CV: 0.832
```

Here the two methods tie: 0.830 against 0.832. The class shapes do differ (variances of 2
against 0.5), but the difference is mild, and QDA has to estimate four $6 \times 6$
covariance matrices from 80 rows per class per fold. Its extra flexibility is barely worth
its extra noise.

Try making the shapes more extreme: change every `2` in `covs` to `5` and every `0.5` to
`0.1`. QDA should pull far ahead — about 0.92 against LDA's 0.78.

```python
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(0)
X = np.vstack([
    rng.multivariate_normal([0, 0], [[4, 0],[0, 0.2]], 150),   # horizontal
    rng.multivariate_normal([3, 3], [[0.2, 0],[0, 4]], 150),   # vertical
    rng.multivariate_normal([-2, 3], [[1, 0],[0, 1]], 150),    # circle
])
y = np.repeat([0, 1, 2], 150)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)

for name, clf in [("LDA", LinearDiscriminantAnalysis()), ("QDA", QuadraticDiscriminantAnalysis())]:
    print(f"{name}: {clf.fit(X_tr, y_tr).score(X_te, y_te):.3f}")
```

This prints LDA 0.911 and QDA 0.956 on the 90 test points: QDA makes half as many mistakes.
LDA has to give all three classes one averaged shape, which is neither horizontal nor
vertical nor round, so its straight boundaries cut through the long ends of the ellipses.
