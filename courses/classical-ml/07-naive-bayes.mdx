## Bayes classifier

The best possible guess is the class that is most likely given what you see. Everything in
this chapter is a way to estimate "how likely is each class?" cheaply enough to compute.

The optimal classifier (minimising misclassification rate) predicts the most probable class:

$$
\hat{y} = \arg\max_k P(Y=k \mid X=x)
$$

> **In plain words:** for the features $x$ you observed, compute the probability of each
> class $k$, and predict the class with the biggest one. $\arg\max_k$ means "the $k$ that
> makes this largest" (not the largest value itself).

By Bayes' theorem: $P(Y=k\mid x) \propto P(x\mid Y=k)\,P(Y=k)$. The challenge is estimating the class-conditional density $P(x\mid Y=k)$ over all features jointly — expensive with many features.

Here $\propto$ means "proportional to". $P(Y=k)$ is the **prior** — how common class $k$ is
before you look at the features. $P(x \mid Y=k)$ is the **likelihood** — how typical these
features are for class $k$. The **class-conditional density** is that likelihood viewed as a
function of $x$.

> **Picture it:** a doctor deciding between flu and a cold. The prior is "colds are five
> times more common". The likelihood is "how often does a cold come with a 39-degree fever?"
> Multiply the two for each illness and pick the bigger product.

### The naive assumption

Assume features are **conditionally independent** given the class:

$$
P(x \mid Y=k) = \prod_{j=1}^p P(x_j \mid Y=k)
$$

> **In plain words:** once you know the class, each feature is treated as telling you
> nothing about the others. So the chance of seeing all the features together is the chance
> of each one, multiplied. Instead of learning one huge table over all feature combinations,
> you learn $p$ small tables, one per feature.

This is almost never true, but the classifier works surprisingly well in practice, especially for text. The class prediction becomes:

$$
\hat{y} = \arg\max_k \log P(Y=k) + \sum_{j=1}^p \log P(x_j \mid Y=k)
$$

> **In plain words:** take logs so the product becomes a sum (multiplying hundreds of small
> probabilities underflows to zero on a computer; adding their logs does not). The score of
> each class is its log prior plus one log likelihood per feature.

> **Watch out:** the assumption is false in almost every real dataset — "free" and "prize"
> come together in spam. Naive Bayes often still picks the right class, but its
> *probabilities* tend to be overconfident, because it counts correlated evidence several
> times. Don't read its `predict_proba` output as calibrated (Probability & Statistics,
> ch. 15).

## Gaussian Naive Bayes

For measurements like lengths and weights, assume each feature, within each class, follows
a bell curve. Learning is then only computing a mean and a spread per feature per class.

For continuous features, model each $P(x_j\mid Y=k)$ as a Gaussian with class-specific mean and variance:

$$
P(x_j \mid Y=k) = \frac{1}{\sqrt{2\pi\sigma_{jk}^2}}\exp\!\left(-\frac{(x_j - \mu_{jk})^2}{2\sigma_{jk}^2}\right)
$$

> **In plain words:** the standard bell-curve formula. $\mu_{jk}$ is the average of feature
> $j$ among class-$k$ examples, $\sigma_{jk}^2$ is their variance. A value near the class
> average gets high likelihood; one many standard deviations away gets almost none.

Fitting: estimate $\mu_{jk}=\text{mean of feature }j\text{ in class }k$ and $\sigma_{jk}^2=\text{variance}$.

```python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.naive_bayes import GaussianNB
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)

gnb = GaussianNB()
gnb.fit(X_tr, y_tr)
print(f"GaussianNB accuracy: {gnb.score(X_te, y_te):.3f}")
print(f"Class priors: {gnb.class_prior_.round(3)}")
print(f"Feature means per class (feature 2):\n{gnb.theta_[:, 2].round(3)}")
```

```output
GaussianNB accuracy: 0.967
Class priors: [0.325 0.308 0.367]
Feature means per class (feature 2):
[1.462 4.216 5.566]
```

Accuracy is 0.967 on the 30 test flowers — one mistake. The priors are the class shares in
the 120 training flowers: 32.5%, 30.8%, 36.7%. The last line is the average petal length
(feature 2) for each species: 1.462 cm for setosa, 4.216 for versicolor, 5.566 for virginica —
so petal length alone separates setosa cleanly.

### From-scratch Gaussian NB

The scratch version stores the same three things — priors, means, variances — and scores
each class by the log formula above. The `1e-9` added to each variance prevents division by
zero for a feature that is constant within a class.

```python
import numpy as np

class GaussianNBScratch:
    def fit(self, X, y):
        self.classes_ = np.unique(y)
        self.priors_  = np.array([np.mean(y == k) for k in self.classes_])
        self.means_   = np.array([X[y == k].mean(axis=0) for k in self.classes_])
        self.vars_    = np.array([X[y == k].var(axis=0) + 1e-9 for k in self.classes_])
        return self

    def _log_likelihood(self, x, k):
        mu, var = self.means_[k], self.vars_[k]
        return -0.5 * np.sum(np.log(2 * np.pi * var) + (x - mu)**2 / var)

    def predict(self, X):
        log_post = np.array([
            [np.log(self.priors_[k]) + self._log_likelihood(x, k)
             for k in range(len(self.classes_))]
            for x in X
        ])
        return self.classes_[np.argmax(log_post, axis=1)]

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)

scratch = GaussianNBScratch().fit(X_tr, y_tr)
acc = np.mean(scratch.predict(X_te) == y_te)
print(f"From-scratch GaussianNB: {acc:.3f}")
```

```output
From-scratch GaussianNB: 0.967
```

The from-scratch model also scores 0.967, matching sklearn exactly. There is no hidden
optimizer in Naive Bayes: fitting is counting and averaging, so two correct implementations
agree.

## Multinomial Naive Bayes

For text, the features are word counts. Multinomial Naive Bayes learns, for each class, how
often each word shows up, and scores a new document by how well its words fit each class's
word frequencies.

For **word counts** (or any non-negative integer features), model $P(x_j\mid Y=k)$ as a categorical distribution. The feature value is treated as a count — how many times word $j$ appears in a document of class $k$.

$$
P(x_j = c \mid Y=k) \propto \theta_{jk}^c
$$

> **In plain words:** $\theta_{jk}$ is the share of all words in class-$k$ documents that
> are word $j$. If a word appears $c$ times in the new document, its evidence is that share
> multiplied in $c$ times.

where $\theta_{jk} = \frac{\text{count}(j,k) + \alpha}{\text{total tokens in class } k + \alpha p}$. Adding $\alpha$ is **Laplace smoothing** — prevents zero probabilities for unseen words.

Without smoothing, one word that never appeared in a class during training would give that
class probability zero, overruling every other word. Adding $\alpha = 1$ is like pretending
you saw every word once more in every class. A **token** is one occurrence of a word.

> **Picture it:** two bags of fridge-magnet words, one filled from spam and one from normal
> mail. For a new email, ask which bag you would more likely draw its words from.

```python
import numpy as np
from sklearn.naive_bayes import MultinomialNB
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.model_selection import train_test_split

# Simulated spam/ham emails
spam_texts  = [
    "win free money now", "click here free prize", "buy cheap medication online",
    "free offer claim now", "urgent money transfer", "congratulations you won",
    "discount pills free", "exclusive deal win cash", "free bonus claim prize",
    "limited offer free gift"
]
ham_texts = [
    "meeting tomorrow at nine", "can you review this report", "the project deadline moved",
    "lunch with the team today", "please update the spreadsheet", "conference call at three",
    "quarterly review next week", "send me the document please", "budget approved for next quarter",
    "team building event friday"
]

texts  = spam_texts + ham_texts
labels = [1] * 10 + [0] * 10   # 1=spam, 0=ham

vec = CountVectorizer()
X = vec.fit_transform(texts)
X_tr, X_te, y_tr, y_te = train_test_split(X, labels, test_size=0.3, random_state=0)

mnb = MultinomialNB(alpha=1.0)
mnb.fit(X_tr, y_tr)
print(f"MultinomialNB accuracy: {mnb.score(X_te, y_te):.3f}")

# Top words per class
feature_names = vec.get_feature_names_out()
for cls, name in [(0, "ham"), (1, "spam")]:
    top = np.argsort(mnb.feature_log_prob_[cls])[-5:]
    print(f"{name} top words: {feature_names[top].tolist()}")
```

```output
MultinomialNB accuracy: 1.000
ham top words: ['week', 'update', 'with', 'review', 'the']
spam top words: ['win', 'money', 'offer', 'now', 'free']
```

All 6 test emails are classified correctly (accuracy 1.000). The spam list is what you'd
hope for: "free", "now", "offer", "money", "win". The ham list includes "the" and "with" —
**stopwords**, common words that carry little meaning. They rank high because the ham
training emails use them a lot, not because they signal anything.

> **Watch out:** this vocabulary was built from all 20 emails before splitting, so the model
> "knows" the test words exist. In real work fit the `CountVectorizer` on training text only.

## Bernoulli Naive Bayes

Bernoulli Naive Bayes ignores how many times a word appears and asks only *whether* it
appears — and, unlike the multinomial version, it also counts every missing word as
evidence.

When features are **binary** (word present or absent, not counts), use Bernoulli NB:

$$
P(x_j \mid Y=k) = \theta_{jk}^{x_j}(1 - \theta_{jk})^{1-x_j}
$$

> **In plain words:** $\theta_{jk}$ is the fraction of class-$k$ documents containing word
> $j$. If the word is present ($x_j = 1$) the factor is $\theta_{jk}$; if absent
> ($x_j = 0$) it is $1 - \theta_{jk}$. Every word in the vocabulary contributes, present or not.

Unlike MultinomialNB, BernoulliNB explicitly models the absence of a feature (if a spam word is absent, that's evidence against spam). Useful for short texts and document classification.

```python
from sklearn.naive_bayes import BernoulliNB
from sklearn.feature_extraction.text import CountVectorizer

vec_bin = CountVectorizer(binary=True)   # binary=True: presence/absence only
X_bin = vec_bin.fit_transform(texts)
X_trb, X_teb, y_trb, y_teb = train_test_split(X_bin, labels, test_size=0.3, random_state=0)

bnb = BernoulliNB(alpha=1.0).fit(X_trb, y_trb)
print(f"BernoulliNB accuracy: {bnb.score(X_teb, y_teb):.3f}")
```

```output
BernoulliNB accuracy: 0.500
```

Same emails, same split, and Bernoulli gets only half right (0.500). It labels 3 of the 4 ham
test emails as spam. The cause is absence evidence on a tiny dataset. The ham training
emails use many different words, each appearing in about 1 of 6 ham emails, while spam keeps
reusing the same few. A new ham email, using new words, is *missing* almost all the ham
training words — and each missing word counts as evidence against ham. With only 14 training
emails, that wrongly piled-up absence evidence wins.

> **Watch out:** when Bernoulli NB looks terrible and Multinomial looks fine, check
> vocabulary overlap between train and test. Bernoulli needs enough data for "this word is
> usually present in class $k$" to mean something.

## When to use Naive Bayes

| Situation | Best variant |
|---|---|
| Continuous features, roughly Gaussian | GaussianNB |
| Word counts / term frequencies | MultinomialNB |
| Binary features (presence/absence) | BernoulliNB |
| Very small datasets | All NB (few parameters) |
| Real-time prediction needed | All NB (O(p) prediction) |

O(p) means prediction time grows only in proportion to the number of features $p$: one
table lookup and one addition per feature.

NB is often the best baseline for text classification before trying logistic regression or transformers.

## Recap in plain words

- The best classifier picks the most probable class: prior times likelihood, compared across classes.
- Naive Bayes assumes features are independent within a class, so the likelihood becomes a product of one-feature pieces.
- Work in logs to turn the product into a sum and avoid underflow.
- Gaussian NB fits a mean and variance per feature per class; Multinomial NB uses word frequencies; Bernoulli NB uses word presence and absence.
- Laplace smoothing stops one unseen word from zeroing out a class.
- NB trains and predicts fast and is a strong text baseline, but its probabilities are overconfident.

## Try it Yourself

```python
import numpy as np
from sklearn.naive_bayes import GaussianNB
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

for n_train in [20, 50, 100, 500, 2000]:
    X, y = make_classification(n_samples=n_train+500, n_features=10,
                                n_informative=5, random_state=0)
    X_tr, X_te, y_tr, y_te = X[:n_train], X[n_train:], y[:n_train], y[n_train:]
    gnb_acc = GaussianNB().fit(X_tr, y_tr).score(X_te, y_te)
    lr_acc  = LogisticRegression(max_iter=500).fit(X_tr, y_tr).score(X_te, y_te)
    print(f"n={n_train:4}: GNB={gnb_acc:.3f}, LR={lr_acc:.3f}")
```

```output
n=  20: GNB=0.788, LR=0.802
n=  50: GNB=0.810, LR=0.790
n= 100: GNB=0.842, LR=0.872
n= 500: GNB=0.920, LR=0.898
n=2000: GNB=0.830, LR=0.818
```

There's no clear winner here. Gaussian NB wins at $n = 50$, 500, and 2000; logistic
regression wins at $n = 20$ and 100. The classic result — NB learns faster on tiny data,
logistic regression wins with more data — is a tendency, not a law, and on this data the
margins are within the noise of a 500-point test set. Note also that `make_classification`
draws a *different* dataset for every `n_samples`, so the rows are not the same problem at
growing sizes; that is why accuracy drops at $n = 2000$ for both models.

Try generating one dataset of 2500 rows once, outside the loop, and taking the first
`n_train` rows of it. Then the rows really do compare the same problem with more data.

```python
import numpy as np
from sklearn.datasets import fetch_20newsgroups
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB, BernoulliNB
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

cats = ['rec.sport.baseball', 'sci.space', 'talk.politics.guns']
train = fetch_20newsgroups(subset='train', categories=cats, remove=('headers','footers','quotes'))
test  = fetch_20newsgroups(subset='test',  categories=cats, remove=('headers','footers','quotes'))

for name, clf in [
    ("MultinomialNB", MultinomialNB()),
    ("BernoulliNB",   BernoulliNB()),
    ("LogisticReg",   LogisticRegression(max_iter=500)),
]:
    pipe = Pipeline([('tfidf', TfidfVectorizer(max_features=5000, binary=(name=='BernoulliNB'))), ('clf', clf)])
    pipe.fit(train.data, train.target)
    acc = pipe.score(test.data, test.target)
    print(f"{name}: {acc:.3f}")
```
