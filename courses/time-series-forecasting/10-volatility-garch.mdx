## When variance is the signal

Most forecasting models target the conditional mean $E[y_t | \mathcal{F}_{t-1}]$. In
finance and risk management, the target is often the **conditional variance**
$\text{Var}(y_t | \mathcal{F}_{t-1})$ — the volatility. High volatility means wide
prediction intervals and high risk.

**Volatility clustering**: large swings tend to cluster together. After a turbulent day,
the next day is likely to be turbulent too. This violates the i.i.d. residual assumption
of ARIMA — the variance is itself time-varying.

## ARCH(q): autoregressive conditional heteroskedasticity

Engle (1982) modeled the conditional variance as a linear function of past squared
residuals:

$$
\varepsilon_t = \sigma_t z_t, \quad z_t \sim \mathcal{N}(0,1)
$$
$$
\sigma_t^2 = \omega + \alpha_1 \varepsilon_{t-1}^2 + \cdots + \alpha_q \varepsilon_{t-q}^2
$$

$\omega > 0$, $\alpha_i \ge 0$. A large squared shock at $t-1$ increases $\sigma_t$.

## GARCH(1,1): the workhorse

Bollerslev (1986) added a lagged variance term:

$$
\sigma_t^2 = \omega + \alpha\, \varepsilon_{t-1}^2 + \beta\, \sigma_{t-1}^2
$$

This is the most common model. The persistence $\alpha + \beta < 1$ ensures stationarity;
typical values: $\alpha \approx 0.1$, $\beta \approx 0.85$ (high persistence).

```python
import numpy as np

rng   = np.random.default_rng(42)
n     = 500
omega = 0.02
alpha = 0.10
beta  = 0.85

# Simulate GARCH(1,1)
eps   = np.zeros(n)
sigma = np.zeros(n)
sigma[0] = np.sqrt(omega / (1 - alpha - beta))   # unconditional std
for t in range(1, n):
    sigma[t] = np.sqrt(omega + alpha*eps[t-1]**2 + beta*sigma[t-1]**2)
    eps[t]   = sigma[t] * rng.normal(0, 1)

print("Simulated returns statistics:")
print(f"  Mean:     {eps.mean():.4f}")
print(f"  Std:      {eps.std():.4f}")
print(f"  Kurtosis: {float(np.mean((eps - eps.mean())**4) / eps.std()**4):.2f}  (>3 = fat tails)")
```

```output
Simulated returns statistics:
  Mean:     -0.0091
  Std:      0.5629
  Kurtosis: 3.79  (>3 = fat tails)
```

Kurtosis above 3 (here 3.79, against 3 for a Normal) is the fingerprint of GARCH: the unconditional distribution has
fatter tails than Normal because periods of high variance generate extreme observations.

## Fitting GARCH by maximum likelihood

The `arch` package does this for you, but the likelihood is short enough to write by hand.
Given $\omega,\alpha,\beta$ the variance recursion produces $\sigma_t^2$ for every $t$, and
the Gaussian negative log-likelihood is

$$
-\ell(\omega,\alpha,\beta) = \frac{1}{2}\sum_t \left(\log 2\pi + \log\sigma_t^2 + \frac{\varepsilon_t^2}{\sigma_t^2}\right)
$$

which `scipy.optimize.minimize` can minimise directly.

```python
import numpy as np
from scipy.optimize import minimize

def simulate_garch(n, omega, alpha, beta, seed):
    rng = np.random.default_rng(seed)
    eps = np.zeros(n); sigma = np.zeros(n)
    sigma[0] = np.sqrt(omega / (1 - alpha - beta))
    for t in range(1, n):
        sigma[t] = np.sqrt(omega + alpha*eps[t-1]**2 + beta*sigma[t-1]**2)
        eps[t]   = sigma[t] * rng.normal(0, 1)
    return eps, sigma

def garch_sigma2(params, r):
    omega, alpha, beta = params
    s2 = np.empty(len(r))
    s2[0] = r.var()
    for t in range(1, len(r)):
        s2[t] = omega + alpha*r[t-1]**2 + beta*s2[t-1]
    return s2

def garch_nll(params, r):
    s2 = garch_sigma2(params, r)
    return 0.5 * np.sum(np.log(2*np.pi) + np.log(s2) + r**2 / s2)

def fit_garch(r):
    x0 = [0.05 * r.var(), 0.1, 0.8]
    bnds = [(1e-8, None), (1e-6, 0.999), (1e-6, 0.999)]
    return minimize(garch_nll, x0, args=(r,), method='L-BFGS-B', bounds=bnds)

omega = 0.02; alpha = 0.10; beta = 0.85
eps, sigma = simulate_garch(500, omega, alpha, beta, seed=42)

# Scale to percent returns
returns = eps * 100

res = fit_garch(returns)
print(f"omega={res.x[0]:.4f}  alpha={res.x[1]:.4f}  beta={res.x[2]:.4f}")
print(f"True:  omega={omega * 100**2:.4f}  alpha={alpha:.4f}  beta={beta:.4f}")
print(f"Log-likelihood: {-res.fun:.1f}")
```

```output
omega=158.4601  alpha=0.1131  beta=0.8392
True:  omega=200.0000  alpha=0.1000  beta=0.8500
Log-likelihood: -2707.2
```

Estimated $\hat\alpha \approx 0.113$ (true 0.10) and $\hat\beta \approx 0.839$ (true 0.85); $\hat\omega \approx 158$ against a true 200.
`omega` is scaled by $100^2$ because we multiplied returns by 100, so the true value to compare with is 200.

## Conditional volatility and VaR

The key output is the **conditional standard deviation** $\hat\sigma_t$ — the model's
estimate of the current volatility.

```python
import numpy as np
# uses simulate_garch, garch_sigma2 and fit_garch from the previous block

eps, sigma = simulate_garch(500, 0.02, 0.10, 0.85, seed=42)
returns = eps * 100

res = fit_garch(returns)
cond_vol = np.sqrt(garch_sigma2(res.x, returns))   # fitted conditional std series

# 1-day 95% VaR: lose more than this with 5% probability
var_95 = -1.645 * cond_vol   # Normal quantile

violations = (returns < var_95).mean()
print(f"Conditional vol — mean: {cond_vol.mean():.3f}  max: {cond_vol.max():.3f}")
print(f"True vol        — mean: {sigma.mean()*100:.3f}  max: {sigma.max()*100:.3f}")
print(f"VaR 95% violations: {violations:.3f}  (target: 0.050)")
```

```output
Conditional vol — mean: 55.365  max: 120.262
True vol        — mean: 57.733  max: 116.411
VaR 95% violations: 0.046  (target: 0.050)
```

VaR violation rate $\approx 4.6\%$, close to the nominal 5% — the model is reasonably calibrated.

## Try it Yourself

```python
import numpy as np
# uses simulate_garch and fit_garch from the fitting section

# High persistence GARCH: alpha+beta=0.98
omega_h = 0.005; alpha_h = 0.08; beta_h = 0.90
eps, sigma = simulate_garch(400, omega_h, alpha_h, beta_h, seed=7)
returns = eps * 100

res = fit_garch(returns)
persist = res.x[1] + res.x[2]
print(f"alpha+beta = {persist:.4f}  (true: {alpha_h+beta_h:.2f})")
print(f"Half-life of volatility shock: {-np.log(2)/np.log(persist):.1f} days")
```

```output
alpha+beta = 0.9520  (true: 0.98)
Half-life of volatility shock: 14.1 days
```

The estimated persistence (0.952) is below the true 0.98: with only 400 points, $\alpha+\beta$ near 1 is hard to pin down, and the half-life estimate (14 days against about 34 for the true value) is correspondingly unreliable.

## Exercise

Simulate GARCH(1,1) with `alpha=0.15, beta=0.80`. Fit the model and compute the 99% VaR
($z_{0.01} = -2.326$). Report the empirical violation rate and check whether it's near 1%.

<summary>Solution</summary>

```python
import numpy as np
# uses simulate_garch, garch_sigma2 and fit_garch from the fitting section

eps, sigma = simulate_garch(600, 0.01, 0.15, 0.80, seed=11)
returns = eps * 100

res     = fit_garch(returns)
vol     = np.sqrt(garch_sigma2(res.x, returns))
var_99  = -2.326 * vol
viols   = (returns < var_99).mean()
print(f"99% VaR violations: {viols:.3f}  (target: 0.010)")
print(f"alpha: {res.x[1]:.3f}  beta: {res.x[2]:.3f}")
```

```output
99% VaR violations: 0.012  (target: 0.010)
alpha: 0.162  beta: 0.796
```

The violation rate is 1.2% against the 1% target, with estimates close to the true $\alpha = 0.15$, $\beta = 0.80$. With 600 points, 1% is only 6 expected violations, so the rate is noisy.
