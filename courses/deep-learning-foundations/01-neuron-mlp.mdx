## From biological to artificial neuron

An artificial neuron is a tiny voting machine: it looks at a list of numbers, gives each one
a vote weight, adds the votes up, and then decides how strongly to "fire". Every deep network,
from a two-layer toy to a large language model, is built out of this one move repeated
millions of times.

A neuron receives signals, sums them up, and fires if the sum crosses a threshold. The artificial version does exactly that:

$$
z = w^T x + b, \qquad a = f(z)
$$

$w \in \mathbb{R}^d$ is the weight vector, $b$ is the bias, $z$ is the **pre-activation**, and $f$ is the **activation function**. The neuron learns which features to amplify ($w_i > 0$), suppress ($w_i \approx 0$), or invert ($w_i < 0$).

> **In plain words:**
> - $x$ is the input: a list of $d$ numbers (say, pixel brightnesses or house features).
> - $w$ is the list of **weights** — one "how much do I care about this input" number per input.
> - $w^T x$ multiplies each input by its weight and adds the results (a dot product).
> - $b$, the **bias**, is a constant nudge that shifts the firing point up or down.
> - $z$, the **pre-activation**, is the raw score before any squashing.
> - $f$, the **activation function**, turns that raw score into the neuron's output $a$.

A **perceptron** is the oldest version of this idea: a single neuron whose activation is a
hard step (output 1 if $z > 0$, else 0). Modern neurons replace the step with smooth or
piecewise-linear functions so that gradients (ch. 3) can flow through them.

> **Picture it:** a judge on a talent show scoring three things — singing, dancing, charm.
> The weights are how much the judge cares about each; the bias is the judge's mood that day
> (generous or harsh); the activation is the final "yes / no / maybe" they hold up. The
> analogy breaks in one place: a real neuron's weights are learned from data, not set by taste.

## Activation functions

An **activation function** is the bend in the pipe. Without it, every layer would only scale
and add numbers, and any stack of such layers collapses into a single scale-and-add — one
straight line, no matter how many layers you pile up.

The activation function introduces nonlinearity — without it, stacking linear layers is still linear.

Concretely, two linear layers $W_2(W_1 x)$ equal one linear layer $(W_2 W_1)x$. The bend is
what lets depth buy you new shapes. The code below evaluates four common activations on 200
evenly spaced points between $-4$ and $4$.

```python
import numpy as np

x = np.linspace(-4, 4, 200)

sigmoid = 1 / (1 + np.exp(-x))
tanh    = np.tanh(x)
relu    = np.maximum(0, x)
# GELU approximation: 0.5 * x * (1 + tanh(sqrt(2/pi)*(x + 0.044715*x^3)))
gelu    = 0.5 * x * (1 + np.tanh(np.sqrt(2/np.pi) * (x + 0.044715 * x**3)))

print("sigmoid range: [{:.3f}, {:.3f}]".format(sigmoid.min(), sigmoid.max()))
print("tanh    range: [{:.3f}, {:.3f}]".format(tanh.min(),    tanh.max()))
print("relu at x=2 : {:.1f}".format(float(np.maximum(0, 2))))
print("gelu at x=2 : {:.4f}".format(float(gelu[np.argmin(np.abs(x-2))])))
```

```output
sigmoid range: [0.018, 0.982]
tanh    range: [-0.999, 0.999]
relu at x=2 : 2.0
gelu at x=2 : 1.9437
```

Look at the first two lines. **Sigmoid** squashes every input into $(0, 1)$: even at $x = \pm 4$
it only reaches 0.018 and 0.982, never 0 or 1. **Tanh** squashes into $(-1, 1)$ and reaches
$\pm 0.999$ at the edges ($\tanh 4 \approx 0.99933$). **ReLU** at $x = 2$ returns 2.0 — it
passes positives through untouched. The GELU line prints 1.9437, not the exact
$\mathrm{GELU}(2) \approx 1.9546$, because the 200-point grid has no point at exactly 2: the
nearest grid value is $x \approx 1.990$.

| Activation | Formula | Gradient | Use |
|-----------|---------|----------|-----|
| Sigmoid | $1/(1+e^{-z})$ | $f(1-f)$ | Output layer (binary) |
| Tanh | $(e^z-e^{-z})/(e^z+e^{-z})$ | $1-f^2$ | RNNs, zero-centred |
| ReLU | $\max(0,z)$ | $\mathbf{1}_{z>0}$ | Default hidden layer |
| GELU | $z\Phi(z)$ | no closed form | Transformers, BERT |

Read the table by column. The "Gradient" column is the slope of each curve, which training
needs (ch. 3). Sigmoid's slope $f(1-f)$ is at most $0.25$, so it shrinks signals as they flow
backward; ReLU's slope $\mathbf{1}_{z>0}$ is exactly 1 for positive inputs and 0 otherwise.
**GELU** (Gaussian Error Linear Unit) multiplies $z$ by $\Phi(z)$, the probability that a
standard normal is below $z$: a soft version of ReLU that lets small negatives leak through.
"Zero-centred" means tanh's outputs average around 0, which keeps the next layer's inputs
balanced.

**Dying ReLU:** if a neuron's pre-activation is always negative, the gradient is always 0 — the neuron never recovers. Fix: He initialization (ch. 7) or Leaky ReLU ($\alpha z$ for $z<0$, $\alpha\approx0.01$).

> **Watch out:** a "dead" ReLU unit gives no error message. It quietly outputs 0 for every
> input, forever. If a large share of your hidden units are exactly 0 on every example, your
> network has lost capacity — ch. 12 shows how to measure this.

## The XOR problem: why depth matters

**XOR** ("exclusive or") outputs 1 when exactly one of two inputs is 1. It is the classic
puzzle that one neuron cannot solve but two layers can — and it shows in four rows of data
why networks need hidden layers.

A single neuron draws one linear hyperplane. XOR is not linearly separable — no single line separates the two positive inputs from the two negative ones.

A **hyperplane** is the higher-dimensional version of a straight line: everything on one side
gets "yes", everything on the other gets "no". Plot the four XOR points on a square: the
"1" answers sit at opposite corners $(0,1)$ and $(1,0)$, the "0" answers at the other two.
No straight cut puts both 1-corners on one side and both 0-corners on the other.

> **Picture it:** two kids in opposite corners of a room wear red shirts, the two in the other
> corners wear blue. One straight rope across the floor can never fence the reds in together.
> Two ropes can — and the second layer's job is to read "which side of each rope are you on".

The fix is to build XOR from two easier questions: "is at least one input 1?" (**OR**) and
"are both inputs 1?" (**AND**). XOR is "OR, but not AND". The code hand-sets weights that do
exactly that.

```python
import numpy as np

# XOR dataset
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=np.float64)
y = np.array([0, 1, 1, 0], dtype=np.float64)

# 2-layer MLP with fixed weights that solve XOR
# Layer 1: two hidden neurons (AND and OR)
W1 = np.array([[20., 20.], [20., 20.]])
b1 = np.array([-30., -10.])

# Layer 2: OR AND NOT(AND) of hidden activations
W2 = np.array([[-20.], [20.]])
b2 = np.array([-10.])

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

h = sigmoid(X @ W1 + b1)          # (4, 2)
out = sigmoid(h @ W2 + b2)        # (4, 1)

print("XOR predictions (threshold 0.5):")
for xi, yi, pi in zip(X, y, out.ravel()):
    print(f"  x={xi.astype(int)} y={int(yi)}  p={pi:.3f}  pred={int(pi>0.5)}")
```

```output
XOR predictions (threshold 0.5):
  x=[0 0] y=0  p=0.000  pred=0
  x=[0 1] y=1  p=1.000  pred=1
  x=[1 0] y=1  p=1.000  pred=1
  x=[1 1] y=0  p=0.000  pred=0
```

All four predictions match the labels: $p$ is 0.000 for $[0,0]$ and $[1,1]$ and 1.000 for
$[0,1]$ and $[1,0]$. Trace one row to see why. For $x = [1, 1]$ the first hidden neuron gets
$20 + 20 - 30 = 10$ (AND fires, about 1) and the second gets $20 + 20 - 10 = 30$ (OR fires,
about 1). The output gets $-20 \cdot 1 + 20 \cdot 1 - 10 = -10$, and $\mathrm{sigmoid}(-10) \approx 0.00005$
, which prints as 0.000. The large weights (20, 30) push sigmoid so far into
its flat tails that it behaves like a hard step.

Two hidden neurons learn two linear boundaries; the output neuron combines them. That is the essence of depth.

> **Watch out:** `X @ W1` multiplies rows of `X` by `W1`, so each *column* of `W1` is one
> neuron's weights. The MLP below stores weights the other way, as `(fan_out, fan_in)`, and
> uses `a @ W.T`. Both are common; mixing them up gives shape errors or silently wrong
> results when the matrix is square, as `W1` is here.

## Multi-layer perceptron structure

A **multi-layer perceptron (MLP)** is a stack of neuron layers where every neuron in one layer
feeds every neuron in the next. You compute it one layer at a time: multiply, add bias, bend,
hand the result to the next layer.

$$
z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \qquad a^{(l)} = f\!\left(z^{(l)}\right)
$$

with $a^{(0)} = x$ (the input). Notation:
- $L$ = number of layers (counting the output layer)
- $n^{(l)}$ = number of neurons in layer $l$
- $W^{(l)} \in \mathbb{R}^{n^{(l)} \times n^{(l-1)}}$, $b^{(l)} \in \mathbb{R}^{n^{(l)}}$

> **In plain words:** layer $l$ takes the previous layer's outputs $a^{(l-1)}$, multiplies by
> its weight matrix $W^{(l)}$ (one row per neuron, one column per incoming value), adds its
> bias vector $b^{(l)}$, and applies the activation $f$. The superscript $(l)$ is a layer
> label, not a power. So a layer with 4 neurons that reads 2 inputs has a $4 \times 2$ weight
> matrix and 4 biases.

**Universal approximation theorem:** a single hidden layer with enough neurons can approximate any continuous function on a compact set to arbitrary precision — but "enough" can be astronomically large. Depth lets you do it efficiently.

A **compact set** here means a bounded, closed region of inputs, like "every $x$ between $-5$
and 5". The theorem promises that a good approximation *exists*; it says nothing about how
to find the weights (that is training, ch. 3–6) or how many neurons it takes.

> **Picture it:** one hidden layer is like building any shape out of LEGO bricks laid side by
> side — possible, but you may need a mountain of bricks. Depth is like building with bricks
> that snap on top of earlier bricks, reusing pieces, so far fewer are needed.

The class below builds an MLP of any shape from a list of layer sizes. It uses ReLU on
hidden layers, leaves the last layer linear, and scales the random weights by
$\sqrt{2/\text{fan\_in}}$ (He initialization, ch. 7). **Fan-in** is the number of inputs
feeding a neuron.

```python
import numpy as np

rng = np.random.default_rng(0)

def relu(z):
    return np.maximum(0, z)

class MLP:
    def __init__(self, layer_sizes):
        self.params = []
        for fan_in, fan_out in zip(layer_sizes[:-1], layer_sizes[1:]):
            W = rng.standard_normal((fan_out, fan_in)) * np.sqrt(2 / fan_in)
            b = np.zeros(fan_out)
            self.params.append((W, b))

    def forward(self, x):
        a = x
        for i, (W, b) in enumerate(self.params):
            z = a @ W.T + b
            a = relu(z) if i < len(self.params) - 1 else z
        return a

net = MLP([2, 4, 4, 1])
x_test = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
out = net.forward(x_test)
print("Output shape:", out.shape)
print("Random init outputs:", out.ravel().round(3))
```

```output
Output shape: (4, 1)
Random init outputs: [ 0.    -0.519 -1.012 -1.619]
```

The shape `(4, 1)` confirms the plumbing: 4 input rows went in, one number per row came out.
The values ($0$, $-0.519$, $-1.012$, $-1.619$) are meaningless for XOR — they come from random
weights. Notice the first output is exactly 0: for input $[0, 0]$ every pre-activation equals
the bias, and all biases start at 0.

The outputs are random before training — the structure is correct, the weights need to be learned.

## Recap in plain words

- A neuron multiplies its inputs by weights, adds a bias, and bends the result with an activation.
- Without the bend, any stack of layers is equivalent to one linear layer.
- Sigmoid squashes to $(0, 1)$, tanh to $(-1, 1)$, ReLU zeroes negatives, GELU is a smooth ReLU.
- XOR cannot be solved by one straight cut, but two hidden neurons (OR and AND) plus one output can.
- An MLP repeats "multiply, add bias, bend" layer by layer; the weights start random and must be learned.

## Try it Yourself

The block below builds a $2 \to 4 \to 4 \to 1$ network by hand, with no class, and pushes one
input $[0, 1]$ through it so you can see every intermediate layer.

```python
import numpy as np

rng = np.random.default_rng(42)

def sigmoid(z): return 1 / (1 + np.exp(-z))
def relu(z):    return np.maximum(0, z)

# Build a 3-layer MLP manually (2 → 4 → 4 → 1)
W1 = rng.standard_normal((4, 2)) * 0.5
b1 = np.zeros(4)
W2 = rng.standard_normal((4, 4)) * 0.5
b2 = np.zeros(4)
W3 = rng.standard_normal((1, 4)) * 0.5
b3 = np.zeros(1)

x = np.array([[0., 1.]])
a1 = relu(x @ W1.T + b1)
a2 = relu(a1 @ W2.T + b2)
out = sigmoid(a2 @ W3.T + b3)

print("hidden layer 1:", a1.round(3))
print("hidden layer 2:", a2.round(3))
print("output (probability):", out.round(4))
```

```output
hidden layer 1: [[0.   0.47 0.   0.  ]]
hidden layer 2: [[0.    0.265 0.    0.   ]]
output (probability): [[0.4883]]
```

Three of the four hidden-layer-1 units are exactly 0: ReLU zeroed their negative scores, and
only the second unit (0.47) passes signal on. Layer 2 again keeps only one unit alive (0.265).
The final sigmoid output 0.4883 sits close to 0.5 — an untrained network is close to a coin
flip. Try changing the seed from 42 to 0, or the scale `0.5` to `2.0`, and watch how many
units survive and how far the output moves from 0.5.

```python
import numpy as np

def sigmoid(z): return 1 / (1 + np.exp(-z))

X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([0, 1, 1, 0])

W1 = np.array([[20., 20.], [20., 20.]])
b1 = np.array([-30., -10.])
W2 = np.array([[-20.], [20.]])
b2 = np.array([-10.])

h   = sigmoid(X @ W1 + b1)
out = sigmoid(h @ W2 + b2).ravel()
pred = (out > 0.5).astype(int)

print("y   :", y)
print("pred:", pred)
print("all correct:", np.all(pred == y))
```

The two hidden neurons compute something like "both 1" (AND) and "at least one 1" (OR). The output combines them to recover XOR.

The key is the output layer's signs: $+20$ on OR, $-20$ on AND, and bias $-10$. It only goes
positive when OR is on and AND is off, which is exactly XOR. The script prints
`all correct: True`.
