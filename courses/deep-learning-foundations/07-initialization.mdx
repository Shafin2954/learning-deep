## The problem with bad initialization

Before training starts, every weight needs some value. **Initialization** is the choice of
those starting values, and it matters more than it seems: a signal passes through every layer,
getting multiplied each time, so a small error in scale compounds into a huge one.

Weights control how signals flow through a network at step zero — before any gradient has been computed. If you initialize too large, activations explode layer by layer; too small, they vanish. Both kill gradients and prevent training.

**Activations** are the outputs of each layer (the `A` values from ch. 2). If they explode,
numbers overflow or saturate; if they vanish, they become too small for any gradient to carry
information back.

Consider an $L$-layer network where each layer multiplies its input by a weight matrix. If each weight has standard deviation $\sigma$, the signal after $L$ layers scales like $\sigma^L \cdot \text{fan-in}^{L/2}$. With $\sigma=1$ and fan-in 512, 10 layers later you're dealing with $512^5 \approx 10^{13}$ — the gradient is numerically meaningless.

Where does $\text{fan-in}^{L/2}$ come from? Each output of a layer sums **fan-in** terms (the
number of inputs feeding it). Adding $n$ random terms of size $\sigma$ gives a total of size
about $\sigma\sqrt{n}$, so each layer multiplies the signal by $\sigma\sqrt{n}$. Ten layers
multiply it by $(\sigma\sqrt{n})^{10}$.

> **Picture it:** a game of telephone with a megaphone. If every player speaks a bit louder
> than they heard, after 10 players it is deafening; a bit quieter, and the last player hears
> silence. Good initialization makes every player repeat at the same volume.

```python
import numpy as np

np.random.seed(0)
x = np.random.randn(1, 512)
L = 10

# All-ones init: explode
out = x.copy()
for _ in range(L):
    W = np.ones((512, 512))
    out = np.tanh(out @ W)
print(f"All-ones init:     output mean={out.mean():.4f}, std={out.std():.6f}")

# Too-large random: saturate tanh → dead gradients
out = x.copy()
for _ in range(L):
    W = np.random.randn(512, 512) * 1.0
    out = np.tanh(out @ W)
print(f"std=1.0 random:    output mean={out.mean():.4f}, std={out.std():.6f}")

# Good init (Xavier): signal stays alive
out = x.copy()
for _ in range(L):
    W = np.random.randn(512, 512) * np.sqrt(2/(512+512))
    out = np.tanh(out @ W)
print(f"Xavier init:       output mean={out.mean():.4f}, std={out.std():.6f}")
```

```output
All-ones init:     output mean=-1.0000, std=0.000000
std=1.0 random:    output mean=-0.0088, std=0.978935
Xavier init:       output mean=0.0047, std=0.225322
```

Three different failures and one success:

- **All ones:** every output unit computes exactly the same thing ($\tanh$ of the sum of all
  inputs), so the std across units is 0.000000 and the mean is pinned at $-1.0000$. The
  network has collapsed to one saturated number.
- **Random with std 1.0:** the std is 0.978935 — almost every value sits near $\pm 1$, the flat
  ends of tanh. **Saturated** units like these have slope near 0, so gradients die.
- **Xavier:** values stay spread out (std 0.225322) in the middle range of tanh, where the
  slope is healthy.

## Xavier / Glorot initialization

The goal of good initialization fits in one sentence: each layer's output should be about as
spread out as its input. Then ten layers or a hundred, the signal keeps the same size.

For activations like `tanh` and `sigmoid` that are approximately linear near zero, you want:

$$\text{Var}(\text{output}) \approx \text{Var}(\text{input})$$

> **In plain words:** the **variance** (spread, squared) of what comes out of a layer should
> roughly equal the variance of what went in.

If layer input has $n_{in}$ features and output has $n_{out}$, and weights are i.i.d. with mean zero, the variance of a dot product is $n_{in} \cdot \text{Var}(w)$. To preserve variance both forward (signal) and backward (gradient), set:

**i.i.d.** means "independent and identically distributed": every weight drawn separately from
the same distribution. Forward, preserving variance needs $n_{in} \cdot \text{Var}(w) = 1$;
backward, the gradient flows through $n_{out}$ connections and needs
$n_{out} \cdot \text{Var}(w) = 1$. Xavier compromises by averaging the two:

$$\text{Var}(w) = \frac{2}{n_{in} + n_{out}}$$

> **In plain words:** set the weight variance to 2 divided by (inputs plus outputs). For a
> $512 \to 512$ layer that is $2/1024$, a standard deviation of about 0.044.

**Uniform variant**: $w \sim U\!\left[-\sqrt{\frac{6}{n_{in}+n_{out}}},\ \sqrt{\frac{6}{n_{in}+n_{out}}}\right]$

The uniform version has the same variance: a uniform distribution on $[-a, a]$ has variance
$a^2/3$, and $\frac{6}{n_{in}+n_{out}} / 3 = \frac{2}{n_{in}+n_{out}}$.

```python
def xavier_normal(fan_in, fan_out):
    std = np.sqrt(2.0 / (fan_in + fan_out))
    return np.random.randn(fan_in, fan_out) * std

def xavier_uniform(fan_in, fan_out):
    bound = np.sqrt(6.0 / (fan_in + fan_out))
    return np.random.uniform(-bound, bound, (fan_in, fan_out))

# Check variance preservation across 5 layers
x = np.random.randn(256, 128)
print(f"Input variance: {x.var():.4f}")
for i in range(5):
    W = xavier_normal(128, 128)
    x = np.tanh(x @ W)
    print(f"Layer {i+1} variance: {x.var():.4f}")
```

```output
Input variance: 0.9873
Layer 1 variance: 0.3875
Layer 2 variance: 0.2362
Layer 3 variance: 0.1635
Layer 4 variance: 0.1281
Layer 5 variance: 0.1006
```

The variance does *not* stay at 1. It drops to 0.3875 after one tanh layer and keeps falling,
to 0.1006 after five. Two effects stack: tanh squashes anything beyond about $\pm 1$, which
shrinks the spread, and the shrunken signal then sits in tanh's near-linear zone, where the
layer passes variance through almost unchanged. So the decline slows layer by layer (0.39,
0.24, 0.16, 0.13, 0.10) instead of collapsing toward 0 exponentially.

So there is no explosion and no sudden collapse, but the drop from 0.99 to 0.10 is not
slight either: the tanh saturation at the tails costs real variance. Xavier keeps the signal
*usable* for tanh — spread out and away from the flat ends — which is the real goal.

> **Watch out:** the variance-preservation argument assumes the activation behaves like the
> identity near 0. That holds for tanh, but not for sigmoid (whose outputs are centred at 0.5,
> not 0) and not at all for ReLU, which is the next section.

## He / Kaiming initialization

ReLU throws away every negative number, so about half of each layer's signal is set to zero.
To keep the total size the same, the surviving half has to be twice as strong — so you double
the weight variance.

ReLU zeroes out half of its inputs. The effective fan-in contributing non-zero activations is roughly $n_{in}/2$. To compensate, double the variance:

$$\text{Var}(w) = \frac{2}{n_{in}}$$

> **In plain words:** weight variance = 2 divided by the number of inputs. For 256 inputs the
> standard deviation is $\sqrt{2/256} \approx 0.088$.

This is **He (Kaiming) initialization**. For leaky ReLU with negative slope $a$:

$$\text{Var}(w) = \frac{2}{(1+a^2)\,n_{in}}$$

> **In plain words:** a **leaky ReLU** keeps negatives but shrinks them by $a$ (say 0.01). It
> throws away less signal, so it needs less boost: with $a = 0$ this is plain He; with
> $a = 1$ (no bend at all) it becomes $1/n_{in}$.

```python
def he_normal(fan_in, fan_out):
    std = np.sqrt(2.0 / fan_in)
    return np.random.randn(fan_in, fan_out) * std

def relu(x): return np.maximum(0, x)

# Xavier vs He under ReLU
np.random.seed(1)
x_base = np.random.randn(256, 256)

for name, init_fn in [("Xavier", xavier_normal), ("He", he_normal)]:
    x = x_base.copy()
    for _ in range(8):
        W = init_fn(256, 256)
        x = relu(x @ W)
    frac_alive = (x > 0).mean()
    print(f"{name:6s}:  mean={x.mean():.4f}  std={x.std():.4f}  alive={frac_alive:.2%}")
```

```output
Xavier:  mean=0.0363  std=0.0533  alive=51.16%
He    :  mean=0.6658  std=0.9276  alive=53.75%
```

Both schemes keep about half the units active — 51.16% for Xavier and 53.75% for He — because
ReLU's on/off decision depends only on the *sign* of its input, and scaling the weights never
flips a sign. The difference is the size of the signal: after 8 layers Xavier's output has
std 0.0533 while He's has 0.9276. Here Xavier's variance is $2/512 = 1/256$, half of He's, so
every layer shrinks the signal by a factor of about $1/\sqrt{2}$: $0.71^8 \approx 0.06$.

So Xavier under ReLU causes progressive signal collapse in *size*, not in activity. He
initialization keeps half the units active *and* keeps the magnitude near 1 layer after layer,
which is what "stable" means here.

> **Watch out:** "fraction of units alive" is a poor test of initialization scale for ReLU
> networks: it stays near 50% at any scale. Measure the activation standard deviation per layer
> instead. A truly dead unit (ch. 1, ch. 12) is one that is zero for *every* input, which comes
> from large negative biases or bad updates, not from a small weight scale.

### LeCun initialization

For **SELU** (scaled exponential linear unit), which has self-normalizing properties:

$$\text{Var}(w) = \frac{1}{n_{in}}$$

> **In plain words:** weight variance = 1 divided by the number of inputs — half of He's,
> because SELU does not discard half the signal the way ReLU does.

This is LeCun normal. SELU requires this init to maintain the self-normalizing property throughout training.

**Self-normalizing** means SELU is built so that, with this initialization, activations drift
back toward mean 0 and variance 1 by themselves, layer after layer, without a normalization
layer (ch. 8).

## All-zeros and constant initialization: why they fail

If every weight starts at the same value, every neuron in a layer is an identical twin: same
output, same gradient, same update, forever. Randomness at the start is what lets neurons
become different from each other.

If you initialize all weights to zero (or any constant), every neuron in a layer computes the same function, receives the same gradient, and updates identically. The layer never breaks symmetry — you've effectively trained a width-1 network.

> **Picture it:** a choir where every singer starts on the same note and copies the same
> instructions. You paid for 100 voices but you only ever hear one. Random initialization
> hands each singer a slightly different starting note, so they can split into parts.

```python
# Symmetry breaking failure demo
np.random.seed(42)
x = np.array([[1.0, 2.0, 3.0]])

# Zero init: all neurons receive same gradient
W_zero = np.zeros((3, 4))
b_zero = np.zeros(4)
out_zero = relu(x @ W_zero + b_zero)
print(f"Zero init outputs (all same): {out_zero}")

# He init: neurons are different
W_he = he_normal(3, 4)
b_he = np.zeros(4)
out_he = relu(x @ W_he + b_he)
print(f"He init outputs (diverse):    {np.round(out_he, 3)}")
```

```output
Zero init outputs (all same): [[0. 0. 0. 0.]]
He init outputs (diverse):    [[0.    0.834 1.973 1.356]]
```

With zero weights, all four outputs are 0 — the same. With He weights, they are four different
numbers (0, 0.834, 1.973, 1.356), so each neuron gets a different gradient and can learn a
different feature. The first He output is 0 because its pre-activation was negative and ReLU
cut it.

## Practical: torch.nn.init

In PyTorch you rarely write initializers by hand. Every layer comes with a default, and the
`torch.nn.init` module has in-place functions (names ending in `_`) that overwrite a tensor
with any scheme from this chapter.

```python
import torch
import torch.nn as nn

layer = nn.Linear(256, 128)

# Default (Kaiming uniform for Linear layers in PyTorch)
print(f"Default std: {layer.weight.data.std():.4f}")

# Override to He normal
nn.init.kaiming_normal_(layer.weight, mode='fan_in', nonlinearity='relu')
print(f"He normal std: {layer.weight.data.std():.4f}")

# Xavier uniform for tanh layers
nn.init.xavier_uniform_(layer.weight)
print(f"Xavier uniform std: {layer.weight.data.std():.4f}")

# Zero bias is fine — asymmetry comes from weights
nn.init.zeros_(layer.bias)
print(f"Bias all zero: {layer.bias.data.sum().item():.1f}")
```

```output
Default std: 0.0363
He normal std: 0.0883
Xavier uniform std: 0.0723
Bias all zero: 0.0
```

Check each line against the formulas for a $256 \to 128$ layer:

- **Default** (0.0363): PyTorch's `nn.Linear` uses Kaiming uniform with a setting that works
  out to bounds $\pm 1/\sqrt{256} = \pm 0.0625$, whose std is $0.0625/\sqrt{3} \approx 0.036$.
- **He normal** (0.0883): $\sqrt{2/256} = 0.0884$.
- **Xavier uniform** (0.0723): $\sqrt{2/(256 + 128)} = 0.0722$.

> **Watch out:** PyTorch's default for `nn.Linear` is smaller than true He initialization (here
> 0.036 versus 0.088). For deep plain-ReLU stacks without normalization layers, call
> `kaiming_normal_` yourself.

## Recap in plain words

- Every layer multiplies the signal; a scale slightly off compounds into explosion or vanishing.
- Xavier sets weight variance to $2/(n_{in}+n_{out})$, suited to tanh-like activations.
- He sets it to $2/n_{in}$, doubling to make up for the half of the signal ReLU discards.
- For ReLU, measure the activation std per layer; the "alive" fraction stays near 50% at any scale.
- Constant initialization makes every neuron identical forever; randomness breaks the symmetry.
- `torch.nn.init` provides all these schemes as in-place functions.

## Try it Yourself

This block runs 20 ReLU layers of width 256 twice: once with He's standard deviation, once with
a third of it, and prints the activation std every 5 layers.

```python
import numpy as np

np.random.seed(7)

def relu(x): return np.maximum(0, x)

def simulate_init(init_std, layers=20, width=256, activation=relu):
    x = np.random.randn(64, width)
    stds = [x.std()]
    for _ in range(layers):
        W = np.random.randn(width, width) * init_std
        x = activation(x @ W)
        stds.append(x.std())
    return stds

he_std = np.sqrt(2.0 / 256)
small_std = he_std / 3

he_stds = simulate_init(he_std)
small_stds = simulate_init(small_std)

print("Layer | He std  | Too-small std")
for i in [0, 5, 10, 15, 20]:
    print(f"  {i:2d}  | {he_stds[i]:.4f}  | {small_stds[i]:.6f}")
```

```output
Layer | He std  | Too-small std
   0  | 0.9869  | 0.998704
   5  | 0.9125  | 0.003798
  10  | 1.1044  | 0.000014
  15  | 1.1195  | 0.000000
  20  | 1.0522  | 0.000000
```

With He, the std wanders between 0.91 and 1.12 for all 20 layers — stable. With a third of
He's std, each layer shrinks the signal by about 3: it is 0.0038 at layer 5, 0.000014 at
layer 10, and prints as 0.000000 from layer 15 on. Any gradient flowing back through such a
network shrinks the same way.

Swap `relu` for `np.tanh` and rerun — notice how Xavier (std=`sqrt(2/(256+256))`) behaves differently from He.

## Exercise

Simulate a 12-layer network with width 512 under three initialization schemes: (a) constant `std=0.01`, (b) Xavier normal, (c) He normal — all using ReLU. Track the fraction of alive neurons at each layer. Which scheme produces stable signal?

> **Hint:** reuse one input `x0` for all three schemes so the comparison is fair, and print
> the activation std at the last layer as well as the alive fraction — the two tell different stories.

<summary>Solution</summary>

```python
import numpy as np
np.random.seed(0)

def relu(x): return np.maximum(0, x)

configs = {
    "const-0.01": 0.01,
    "Xavier":     np.sqrt(2.0/(512+512)),
    "He":         np.sqrt(2.0/512),
}

x0 = np.random.randn(128, 512)
for name, std in configs.items():
    x = x0.copy()
    alive_per_layer = []
    for _ in range(12):
        W = np.random.randn(512, 512) * std
        x = relu(x @ W)
        alive_per_layer.append((x > 0).mean())
    print(f"{name:12s}: layer-1={alive_per_layer[0]:.2%}  layer-12={alive_per_layer[-1]:.2%}  "
          f"layer-12 std={x.std():.2e}")
```

All three schemes keep about 50% of units
positive at layer 12 (49.74%, 48.28%, 51.10%), because a scale factor never changes a sign.
What separates them is the layer-12 std: about $2 \times 10^{-10}$ for `std=0.01` (the signal
has vanished, not "died"), 0.0135 for Xavier (shrinking by about $1/\sqrt{2}$ per layer), and
0.966 for He. Only He produces stable signal.
