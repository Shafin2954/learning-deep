## From Bayesian linear regression to a prior over functions

Bayesian linear regression (ch. 2) puts a Gaussian prior on weights and gets a Gaussian over predictions. If you only
look at predictions, the weights are a detour: all you need is how strongly $f(x)$ and $f(x')$ co-vary under the prior.
Write that **kernel** down directly and you get infinitely many basis functions for the price of an $n \times n$ matrix
($n$ = number of training points). The resulting prior over functions is a **Gaussian process** (GP).

### Weight space to function space

This derivation shows that the ch. 2 predictive touches the features only through inner products. Take a feature map
$\boldsymbol\phi(x) \in \mathbb{R}^M$, $f(x) = \boldsymbol\phi(x)^\top\mathbf{w}$, prior
$\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \Sigma_p)$ and $y = f(x) + \varepsilon$ with noise variance $\sigma_n^2$.
At any inputs $\mathbf{f} = \Phi\mathbf{w}$ is a linear map of a Gaussian, so

$$
\mathbf{f} \sim \mathcal{N}\big(\mathbf{0},\; \Phi\Sigma_p\Phi^\top\big), \qquad
k(x, x') \equiv \mathrm{Cov}\big(f(x), f(x')\big) = \boldsymbol\phi(x)^\top\Sigma_p\,\boldsymbol\phi(x').
$$

The weight-space predictive mean is $\boldsymbol\phi_*^\top A^{-1}\Phi^\top\mathbf{y}/\sigma_n^2$ with
$A = \Phi^\top\Phi/\sigma_n^2 + \Sigma_p^{-1}$, an $M \times M$ system. The push-through identity
$A^{-1}\Phi^\top/\sigma_n^2 = \Sigma_p\Phi^\top(K + \sigma_n^2 I)^{-1}$, with $K = \Phi\Sigma_p\Phi^\top$, turns it into

$$
\bar f_* = \mathbf{k}_*^\top (K + \sigma_n^2 I)^{-1}\mathbf{y}, \qquad \mathbb{V}[f_*] = k(x_*, x_*) - \mathbf{k}_*^\top (K + \sigma_n^2 I)^{-1}\mathbf{k}_*,
$$

where $\mathbf{k}_*$ stacks $k(x_i, x_*)$. Only $k$ appears. Now use Gaussian bumps of width $\ell$ centred every
$\Delta c$, prior variance proportional to $\Delta c$. As $\Delta c \to 0$ the sum over bumps becomes an integral,

$$
\sum_j e^{-\frac{(x-c_j)^2}{2\ell^2}} e^{-\frac{(x'-c_j)^2}{2\ell^2}}\,\Delta c \;\to\; \int e^{-\frac{(x-c)^2}{2\ell^2}} e^{-\frac{(x'-c)^2}{2\ell^2}}\,dc
= \sqrt{\pi}\,\ell\, \exp\!\Big(-\frac{(x-x')^2}{4\ell^2}\Big),
$$

the squared-exponential (RBF) kernel with lengthscale $\sqrt 2\,\ell$: infinitely many features, one closed form.

```python
import numpy as np
from scipy import linalg, optimize, stats
rng = np.random.default_rng(0)
ell_phi, sn2 = 0.5, 0.1 ** 2
bumps = lambda x, c: np.exp(-0.5 * (x[:, None] - c[None, :]) ** 2 / ell_phi ** 2)
x15 = np.sort(rng.uniform(-3, 3, 15)); y15 = np.sin(2 * x15) + 0.1 * rng.standard_normal(15)
x_q = np.array([-2.0, 0.0, 1.5, 4.0, 10.0])                  # 10.0 lies beyond the last bump centre
print(f"{'M':>4} {'|mean_w - mean_f|':>18} {'|var_w - var_f|':>16} {'|K - RBF|':>10} {'prior sd at x=10':>17}")
for M in (10, 40, 160, 640):
    c, dc = np.linspace(-8, 8, M, retstep=True)
    sp2 = dc / (np.sqrt(np.pi) * ell_phi)                     # prior variance per weight
    P, Pq = bumps(x15, c), bumps(x_q, c)
    A = P.T @ P / sn2 + np.eye(M) / sp2                       # weight space: M x M (ch. 2)
    mean_w, var_w = Pq @ np.linalg.solve(A, P.T @ y15 / sn2), np.einsum("ij,ji->i", Pq, np.linalg.solve(A, Pq.T))
    K, Kq = sp2 * P @ P.T, sp2 * P @ Pq.T                     # function space: 15 x 15
    G = np.linalg.solve(K + sn2 * np.eye(15), np.c_[y15, Kq])
    mean_f, var_f = Kq.T @ G[:, 0], sp2 * (Pq ** 2).sum(1) - np.sum(Kq * G[:, 1:], 0)
    print(f"{M:>4} {np.abs(mean_w - mean_f).max():>18.1e} {np.abs(var_w - var_f).max():>16.1e} "
          f"{np.abs(K - np.exp(-0.25 * (x15[:, None] - x15) ** 2 / ell_phi ** 2)).max():>10.1e} {np.sqrt(sp2 * (Pq[-1] ** 2).sum()):>17.2e}")
```

The two views agree to $10^{-14}$ at every $M$: one model, computed in two spaces. With 10 bumps (spacing 1.8) the

A finite feature map is a **degenerate** GP, a flaw the sparse approximations below inherit.

## Kernels decide what functions look like

Choosing a kernel is choosing, before any data, what shapes you find plausible: wiggly or smooth, repeating or not,
straight or curved. With $r = |x - x'|$, lengthscale $\ell$ (how far you move before $f$ changes appreciably) and
signal variance $\sigma_f^2$ (the typical squared size of $f$; set to 1 below):

$$
k_{\mathrm{RBF}} = e^{-\frac{r^2}{2\ell^2}},\ \ k_{1/2} = e^{-\frac{r}{\ell}},\ \ k_{3/2} = \Big(1 + \tfrac{\sqrt3 r}{\ell}\Big)e^{-\frac{\sqrt3 r}{\ell}},\ \
k_{5/2} = \Big(1 + \tfrac{\sqrt5 r}{\ell} + \tfrac{5r^2}{3\ell^2}\Big)e^{-\frac{\sqrt5 r}{\ell}},\ \ k_{\mathrm{per}} = e^{-\frac{2\sin^2(\pi r/p)}{\ell^2}},\ \
k_{\mathrm{lin}} = (x - c)(x' - c).
$$

A Matérn-$\nu$ process is $k$ times mean-square differentiable for $k < \nu$: Matérn-1/2 (the Ornstein-Uhlenbeck
process) is continuous but nowhere differentiable, 3/2 has one derivative, 5/2 two, and the RBF ($\nu \to \infty$) all
of them. You can measure this. Draw 200 functions per prior on $[0, 4]$ and compute zero crossings and total variation
$\mathrm{TV} = \sum_i |f_{i+1} - f_i|$ at two grid steps $h$. A smooth path gives the same number at both; a rough
one keeps revealing new wiggles as you zoom in. For a differentiable stationary process, Rice's formula predicts
$\frac{1}{\pi}\sqrt{-k''(0)/k(0)}$ zero crossings per unit length.

```python
KERN = {
    "RBF":        lambda r, l: np.exp(-0.5 * (r / l) ** 2),
    "Matern-1/2": lambda r, l: np.exp(-r / l),
    "Matern-3/2": lambda r, l: (1 + np.sqrt(3) * r / l) * np.exp(-np.sqrt(3) * r / l),
    "Matern-5/2": lambda r, l: (1 + np.sqrt(5) * r / l + 5 * r ** 2 / (3 * l ** 2)) * np.exp(-np.sqrt(5) * r / l),
    "periodic":   lambda r, l: np.exp(-2 * np.sin(np.pi * r / 1.0) ** 2 / l ** 2),       # period p = 1
}
rice = {"RBF": 1 / (np.pi * 0.5), "Matern-3/2": np.sqrt(3) / (np.pi * 0.5), "Matern-5/2": np.sqrt(5 / 3) / (np.pi * 0.5)}
xg = np.linspace(0, 4, 801)                                   # fine grid h = 0.005; coarse = every 8th point
covs = {name: k(np.abs(xg[:, None] - xg), 1.0 if name == "periodic" else 0.5) for name, k in KERN.items()}
covs["linear"] = np.outer(xg - 2, xg - 2) / 4
def sample_prior(Cm, n_draws, rng):                           # eigh tolerates the near-singular RBF matrix
    lam, U = np.linalg.eigh(Cm)
    return U @ (np.sqrt(np.clip(lam, 0, None))[:, None] * rng.standard_normal((len(Cm), n_draws)))
rng = np.random.default_rng(1)                                # metrics below average over 200 draws
crossings = lambda F: np.mean(np.sum(np.diff(np.sign(F), axis=0) != 0, 0)) / 4
tv = lambda F: np.mean(np.abs(np.diff(F, axis=0)).sum(0))
print(f"{'kernel':11} {'zeros/unit h=.04':>16} {'h=.005':>7} {'Rice':>5} | {'TV(f) h=.04':>11} {'h=.005':>7} | "
      f"{'TV(df) h=.04':>12} {'h=.005':>7}")
for name, Cm in covs.items():
    F = sample_prior(Cm, 200, rng); Fc = F[::8]
    print(f"{name:11} {crossings(Fc):>16.2f} {crossings(F):>7.2f} {rice.get(name, np.nan):>5.2f} | "
          f"{tv(Fc):>11.2f} {tv(F):>7.2f} | {tv(np.diff(Fc, axis=0) / 0.04):>12.1f} {tv(np.diff(F, axis=0) / 0.005):>7.1f}")
```

RBF and Matérn-5/2 give the same crossings, $\mathrm{TV}(f)$ and $\mathrm{TV}(f')$ at both steps, and match Rice
(0.66 vs 0.64, 0.80 vs 0.82). Matérn-3/2 is stable in $f$, but $\mathrm{TV}(f')$ triples when you refine: $f$ is
differentiable, $f'$ is not. Matérn-1/2 is unstable already in $f$: $\mathrm{TV}(f)$ grows by $2.9 \approx \sqrt 8$ when
$h$ shrinks 8-fold (Brownian $\sqrt h$ scaling) and its crossings have no finite limit. Linear draws are straight lines,
periodic ones repeat every unit. Matérn-5/2 is often a more honest default than the RBF's infinite smoothness.

## The posterior by Gaussian conditioning

Before data, the observations $\mathbf{y}$ and the value $f_*$ at a test input are jointly Gaussian. Observing
$\mathbf{y}$ is conditioning that joint Gaussian, like conditioning one coordinate of a bivariate Normal on the other.

### Conditioning, and why Cholesky

This shows that the posterior is the formula above, and how to compute it without ever forming an inverse:

$$
\begin{bmatrix}\mathbf{y}\\ f_*\end{bmatrix} \sim \mathcal{N}\!\left(\mathbf{0},
\begin{bmatrix} K_y & \mathbf{k}_*\\ \mathbf{k}_*^\top & k_{**}\end{bmatrix}\right) \;\Rightarrow\;
f_* \mid \mathbf{y} \sim \mathcal{N}\big(\mathbf{k}_*^\top K_y^{-1}\mathbf{y},\; k_{**} - \mathbf{k}_*^\top K_y^{-1}\mathbf{k}_*\big),
$$

with $K_y = K + \sigma_n^2 I$ and $k_{**} = k(x_*, x_*)$, by the Schur complement. Rasmussen and Williams' Algorithm
2.1 factors $K_y = LL^\top$ once ($n^3/3$ flops) and then uses only triangular solves ($n^2$ flops each):

$$
\boldsymbol\alpha = L^\top \backslash (L \backslash \mathbf{y}),\quad \bar f_* = \mathbf{k}_*^\top\boldsymbol\alpha,\quad
\mathbf{v} = L \backslash \mathbf{k}_*,\quad \mathbb{V}[f_*] = k_{**} - \mathbf{v}^\top\mathbf{v},\quad
\log p(\mathbf{y}) = -\tfrac12\mathbf{y}^\top\boldsymbol\alpha - \textstyle\sum_i \log L_{ii} - \tfrac n2\log 2\pi .
$$

The Cholesky fails loudly if $K_y$ is not positive definite instead of returning garbage, costs half an LU, gives
$\log|K_y| = 2\sum_i\log L_{ii}$ without overflow, and is backward stable; an explicit inverse is none of these. The
predictive for a new $y_*$ adds $\sigma_n^2$ to $\mathbb{V}[f_*]$.

```python
kmat = lambda a, b, ell, sf, kind="RBF": sf ** 2 * KERN[kind](np.abs(a[:, None] - b[None, :]), ell)
def gp_fit(x, y, ell, sf, sn, kind="RBF"):                   # R&W Algorithm 2.1
    L = np.linalg.cholesky(kmat(x, x, ell, sf, kind) + sn ** 2 * np.eye(len(x)))
    alpha = linalg.cho_solve((L, True), y)
    lml = -0.5 * y @ alpha - np.log(np.diag(L)).sum() - 0.5 * len(x) * np.log(2 * np.pi)
    return dict(x=x, L=L, alpha=alpha, lml=lml, hyp=(ell, sf, sn), kind=kind)
def gp_predict(m, xs):                                        # mean, latent variance, predictive variance
    ell, sf, sn = m["hyp"]; Ks = kmat(m["x"], xs, ell, sf, m["kind"])
    var_f = sf ** 2 - np.sum(linalg.solve_triangular(m["L"], Ks, lower=True) ** 2, 0)
    return Ks.T @ m["alpha"], var_f, var_f + sn ** 2
f_true = lambda x: np.sin(x) + 0.4 * np.sin(3 * x)
rng = np.random.default_rng(2)
x_tr = np.sort(np.r_[rng.uniform(0, 4, 20), rng.uniform(6, 10, 20)]); y_tr = f_true(x_tr) + 0.2 * rng.standard_normal(40)
x_te = rng.uniform(0, 10, 400); y_te = f_true(x_te) + 0.2 * rng.standard_normal(400)
gp = gp_fit(x_tr, y_tr, ell=0.7, sf=1.0, sn=0.2)
print(f"{'x':>5} {'region':>8} {'true f':>7} {'mean':>7} {'sd(f)':>6} {'sd(y)':>6}")
for xq, reg in [(2.0, "data"), (5.0, "gap"), (8.0, "data"), (11.0, "beyond"), (14.0, "beyond")]:
    mu, vf, vy = gp_predict(gp, np.array([xq]))
    print(f"{xq:>5} {reg:>8} {f_true(xq):>7.3f} {mu[0]:>7.3f} {np.sqrt(vf[0]):>6.3f} {np.sqrt(vy[0]):>6.3f}")

                               optimizer=None).fit(x_tr[:, None], y_tr)

      f"{np.abs(sd_s - np.sqrt(vy_m)).max():.1e} | log ML {gp['lml']:.4f} vs {skl.log_marginal_likelihood_value_:.4f}")
```

## The log marginal likelihood and Occam's razor

The hyperparameters $\theta = (\ell, \sigma_f, \sigma_n)$ are knobs on the prior. The evidence (ch. 2) scores each
setting by how probable it made the observed data *before* fitting: a too-flexible prior spreads its probability over
countless datasets and so gives yours little; a too-rigid one cannot produce yours at all. For a GP it has three terms,

$$
\log p(\mathbf{y} \mid \theta) = \underbrace{-\tfrac12\mathbf{y}^\top K_y^{-1}\mathbf{y}}_{\text{data fit}}
\;\underbrace{-\tfrac12\log|K_y|}_{\text{complexity penalty}} \;\underbrace{-\tfrac n2\log 2\pi}_{\text{constant}} .
$$

The data-fit term rewards explaining $\mathbf{y}$. The log-determinant measures the volume of datasets the prior can
generate: a short lengthscale gives many nearly independent directions, a large determinant, a very negative term.

```python
def lml_terms(x, y, ell, sf, sn, kind="RBF"):
    m = gp_fit(x, y, ell, sf, sn, kind)
    return -0.5 * y @ m["alpha"], -np.log(np.diag(m["L"])).sum(), -0.5 * len(x) * np.log(2 * np.pi), m
print(f"{'ell':>5} {'data fit':>9} {'complexity':>10} {'constant':>9} {'log ML':>8} | {'test RMSE':>9} {'test NLPD':>9}")
for ell in (0.05, 0.2, 0.4, 0.7, 1.0, 2.0, 5.0):

          f"{np.sqrt(np.mean((y_te - mu) ** 2)):>9.3f} {-stats.norm.logpdf(y_te, mu, np.sqrt(vy)).mean():>9.3f}")
```

### The gradient

This derivation gives the exact gradient, so a quasi-Newton optimiser can climb the evidence. Using
$\partial K_y^{-1} = -K_y^{-1}(\partial K_y)K_y^{-1}$ and $\partial\log|K_y| = \mathrm{tr}(K_y^{-1}\partial K_y)$,

$$
\frac{\partial \log p(\mathbf{y}\mid\theta)}{\partial \theta_j}
= \tfrac12\mathbf{y}^\top K_y^{-1}\frac{\partial K_y}{\partial\theta_j}K_y^{-1}\mathbf{y} - \tfrac12\mathrm{tr}\Big(K_y^{-1}\frac{\partial K_y}{\partial\theta_j}\Big)
= \tfrac12\mathrm{tr}\Big(\big(\boldsymbol\alpha\boldsymbol\alpha^\top - K_y^{-1}\big)\frac{\partial K_y}{\partial\theta_j}\Big).
$$

Work in log-parameters so positivity is automatic and scales are comparable. For the RBF with
$K_f = \sigma_f^2 e^{-r^2/2\ell^2}$: $\partial K_y/\partial\log\ell = K_f \odot r^2/\ell^2$,
$\partial K_y/\partial\log\sigma_f = 2K_f$, $\partial K_y/\partial\log\sigma_n = 2\sigma_n^2 I$. One gradient costs one
$O(n^3)$ inverse plus $O(n^2)$ per hyperparameter, where central finite differences would need six more factorisations.

```python
def neg_lml(lp, x, y):                                       # lp = log(ell, sf, sn); returns value and gradient
    (ell, sf, sn), r2 = np.exp(lp), (x[:, None] - x[None, :]) ** 2
    Kf = sf ** 2 * np.exp(-0.5 * r2 / ell ** 2)
    L = np.linalg.cholesky(Kf + sn ** 2 * np.eye(len(x))); a = linalg.cho_solve((L, True), y)
    W = np.outer(a, a) - linalg.cho_solve((L, True), np.eye(len(x)))
    grad = [0.5 * np.sum(W * D) for D in (Kf * r2 / ell ** 2, 2 * Kf, 2 * sn ** 2 * np.eye(len(x)))]
    return 0.5 * y @ a + np.log(np.diag(L)).sum() + 0.5 * len(x) * np.log(2 * np.pi), -np.array(grad)
lp0 = np.log([0.5, 1.0, 0.5])
fd = optimize.approx_fprime(lp0, lambda p: neg_lml(p, x_tr, y_tr)[0], 1e-6)
print(f"analytic grad {np.round(neg_lml(lp0, x_tr, y_tr)[1], 5)} | finite diff {np.round(fd, 5)}")
best = min((optimize.minimize(neg_lml, np.log(s), args=(x_tr, y_tr), jac=True, method="L-BFGS-B")
            for s in ([0.3, 1, 0.1], [1, 1, 0.5], [3, 2, 1])), key=lambda r: r.fun)
ell_h, sf_h, sn_h = np.exp(best.x)
print(f"mine:    ell {ell_h:.4f} sf {sf_h:.4f} sn {sn_h:.4f} | log ML {-best.fun:.4f} | {best.nfev} evaluations")
skl = GaussianProcessRegressor(C(1.0) * RBF(1.0) + WhiteKernel(0.1), n_restarts_optimizer=3, random_state=0).fit(x_tr[:, None], y_tr)
kp = skl.kernel_.get_params()

      f"sn {np.sqrt(kp['k2__noise_level']):.4f} | log ML {skl.log_marginal_likelihood_value_:.4f}")
```

## Are the predictive intervals honest?

A 95% interval is only useful if it contains the truth about 95% of the time on data the model has not seen. Check it
like a weather forecaster's record: collect held-out points and count. The 400 test points include the gap; each row
distorts one fitted hyperparameter by a factor of 3.

```python
print(f"{'model':8} {'50%':>5} {'80%':>5} {'95%':>5} | {'95% gap':>7} | {'NLPD':>6} {'RMSE':>6}")
for label, h in [("fitted", (ell_h, sf_h, sn_h)), ("ell / 3", (ell_h / 3, sf_h, sn_h)), ("ell x 3", (ell_h * 3, sf_h, sn_h)),
                 ("sn / 3", (ell_h, sf_h, sn_h / 3)), ("sn x 3", (ell_h, sf_h, sn_h * 3))]:
    mu, _, vy = gp_predict(gp_fit(x_tr, y_tr, *h), x_te)
```

## Composing kernels: a CO2-like series

Real series are several things at once: a slow trend, a seasonal cycle whose shape drifts, medium-term wobbles, noise.
Kernels combine like the components they describe. A sum $k_1 + k_2$ is the prior of $f_1 + f_2$ for independent
$f_1, f_2$; a product modulates one structure by another, so periodic times a long RBF is "a cycle whose shape slowly
changes". This is the Mauna Loa model of Rasmussen and Williams §5.4.3, on synthetic monthly data: 20 years to train on,
the next 5 to extrapolate.

## The $O(n^3)$ wall and inducing points

Exact GP regression factors an $n \times n$ matrix: $n^3/3$ flops and $n^2$ memory, so $10^5$ points is out of reach.
Sparse methods summarise the data through $m \ll n$ **inducing points**, locations where the function is pinned down
and from which everything else is predicted, the way a few weather stations stand in for a whole map.

### Subset of regressors is a GP with a Nyström kernel

This shows what the cheap approximation actually is. The Nyström approximation replaces $K$ by the rank-$m$ matrix
$Q = K_{nm}K_{mm}^{-1}K_{mn}$, built from covariances to the inducing inputs. Using $Q$ as the kernel is a finite
feature map $\boldsymbol\phi(x) = K_{mm}^{-1/2}\mathbf{k}_m(x)$, so by the first section the weight-space form costs
$O(nm^2)$:

$$
\bar f_* = \mathbf{k}_{*m}\Sigma K_{mn}\mathbf{y},\quad \mathbb{V}_{\mathrm{SoR}}[f_*] = \sigma_n^2\,\mathbf{k}_{*m}\Sigma\mathbf{k}_{m*},\quad
\Sigma = \big(\sigma_n^2 K_{mm} + K_{mn}K_{nm}\big)^{-1}.
$$

Subset of regressors (SoR) is thus a degenerate GP. DTC (deterministic training conditional) keeps its mean but adds
back $k_{**} - Q_{**}$, the prior variance the inducing points cannot explain. Subset of data (SoD), an exact GP on $m$
random points, is the naive baseline.

```python
rng = np.random.default_rng(4)
```

## GP classification via the Laplace approximation

For class labels the likelihood is not Gaussian and the posterior over $\mathbf{f}$ has no closed form, the situation
of Bayesian logistic regression in ch. 3. Laplace fits a Gaussian at the mode: find the most probable latent function,
measure the curvature there, and call the result Gaussian.

### Newton for the mode, then a Gaussian predictive

This gives the stable Newton step of R&W Algorithm 3.1. With labels $y_i \in \{-1, +1\}$ and
$p(y_i \mid f_i) = \sigma(y_i f_i)$, the log posterior $\log p(\mathbf{y}\mid\mathbf{f}) - \tfrac12\mathbf{f}^\top K^{-1}\mathbf{f}$
has Hessian $-(W + K^{-1})$, $W = \mathrm{diag}(\pi_i(1-\pi_i))$, $\pi_i = \sigma(f_i)$. Newton's step
$\mathbf{f} \leftarrow (K^{-1} + W)^{-1}(W\mathbf{f} + \nabla\log p)$ goes through the well-conditioned
$B = I + W^{1/2}KW^{1/2} = LL^\top$, and at the mode $\hat{\mathbf{f}}$

$$
\mathbb{E}[f_*] = \mathbf{k}_*^\top\nabla\log p(\mathbf{y}\mid\hat{\mathbf{f}}),\quad \mathbb{V}[f_*] = k_{**} - \|L\backslash(W^{1/2}\mathbf{k}_*)\|^2,\quad
\bar\pi_* \approx \sigma\Big(\mathbb{E}[f_*]\big/\sqrt{1 + \pi\mathbb{V}[f_*]/8}\Big),
$$

the last being the probit approximation to $\mathbb{E}[\sigma(f_*)]$ under the Gaussian.

```python
rng = np.random.default_rng(5)
xc = np.sort(np.r_[rng.uniform(-4, 1, 50), rng.uniform(3, 4, 10)])            # little data in (1, 3)

Kc, f = kmat(xc, xc, 1.0, 2.0), np.zeros(60)

    pi = 1 / (1 + np.exp(-f)); W = pi * (1 - pi); sW = np.sqrt(W); b = W * f + (yc + 1) / 2 - pi
    Lc = np.linalg.cholesky(np.eye(60) + sW[:, None] * Kc * sW[None, :])
    a = b - sW * linalg.cho_solve((Lc, True), sW * (Kc @ b))
    f, f_old = Kc @ a, f
    if np.abs(f - f_old).max() < 1e-10: break
approx_lml = -0.5 * a @ f - np.sum(np.log1p(np.exp(-yc * f))) - np.log(np.diag(Lc)).sum()

p_avg = 1 / (1 + np.exp(-mu_c / np.sqrt(1 + np.pi * var_c / 8)))

print(f"{'x':>5} {'E[f]':>6} {'sd[f]':>6} | {'sigma(E f)':>10} {'averaged':>8} {'sklearn':>8} | {'true p':>6}")
for i, x0 in enumerate(xs):
    print(f"{x0:>5} {mu_c[i]:>6.2f} {np.sqrt(var_c[i]):>6.2f} | {1 / (1 + np.exp(-mu_c[i])):>10.3f} "
          f"{p_avg[i]:>8.3f} {gpc.predict_proba([[x0]])[0, 1]:>8.3f} | {1 / (1 + np.exp(-3 * np.sin(x0))):>6.3f}")
```

## Fully Bayesian hyperparameters

Type-II maximum likelihood picks one hill and acts as if it were certain; with twelve points and two close hills that is
not earned. Instead give $\log\theta$ a prior and sample it, here with random-walk Metropolis (ch. 4); HMC (ch. 6) with
the gradient above scales better. Predictions average over draws: a mixture of GPs, whose variance adds the spread of means.

```python
import arviz as az

      f"ell 90% interval [{np.quantile(ell_d, 0.05):.2f}, {np.quantile(ell_d, 0.95):.2f}]")
```
