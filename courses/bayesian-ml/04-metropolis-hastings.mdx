## A Markov chain forgets where it started

Chapter 3 ended with a problem: in more than a handful of dimensions you cannot draw independent
samples from a posterior you can only evaluate up to a constant. Markov chain Monte Carlo gives up
independence. It builds a random walk whose long-run distribution *is* the posterior, and then it
averages along the walk. Before you build one for a continuous posterior, it helps to see the
machinery on a state space small enough to write down exactly.

A Markov chain on $K$ states is a $K \times K$ **transition matrix** $P$ with
$P_{ij} = p(x_{t+1} = j \mid x_t = i)$ and rows summing to one. If $\mu_t$ is the row vector of state
probabilities at time $t$, then $\mu_{t+1} = \mu_t P$ and $\mu_t = \mu_0 P^t$. A **stationary
distribution** is a fixed point, $\pi P = \pi$. So $\pi$ is a *left* eigenvector of $P$ with eigenvalue 1,
which is an ordinary eigenvector of $P^\top$. The chain below is a daily user state for a shop.

### Why the chain converges, and how fast

If $P$ is diagonalisable with eigenvalues $1 = \lambda_1 > |\lambda_2| \ge \dots$, write
$P^t = \mathbf{1}\pi + \sum_{k \ge 2} \lambda_k^t\, r_k l_k$ with right and left eigenvectors $r_k, l_k$. Then

$$
\mu_0 P^t - \pi = \sum_{k \ge 2} \lambda_k^t\,(\mu_0 r_k)\, l_k
\quad\Longrightarrow\quad
\lVert \mu_0 P^t - \pi \rVert = O\big(|\lambda_2|^t\big)
$$

whatever $\mu_0$ is, because $\mu_0 \mathbf{1} = 1$ always picks out $\pi$. The general theorem needs no
diagonalisability: an **irreducible** (every state reachable from every other) and **aperiodic**
finite chain has a unique $\pi$ and converges to it from any start. The spectral gap
$1 - |\lambda_2|$ sets the speed.

```python
import numpy as np
from scipy import stats, special, optimize

rng = np.random.default_rng(0)
names = ["idle", "browse", "cart", "buy"]
P = np.array([[0.80, 0.15, 0.04, 0.01],     # row i = distribution of tomorrow's state given today = i
              [0.40, 0.40, 0.15, 0.05],
              [0.20, 0.30, 0.30, 0.20],
              [0.50, 0.30, 0.10, 0.10]])
evals, evecs = np.linalg.eig(P.T)                     # left eigenvectors of P
order = np.argsort(-np.abs(evals))
pi = np.real(evecs[:, order[0]]); pi /= pi.sum()
print("eigenvalue moduli:", np.round(np.abs(evals[order]), 4))
print("stationary pi    :", np.round(pi, 4), "| max |pi P - pi| =", f"{np.abs(pi @ P - pi).max():.1e}")

lam2 = np.abs(evals[order[1]])
print(f"\n{'t':>3}" + "".join(f"{'TV from ' + s:>16}" for s in names) + f"{'lambda2^t':>12}")
Pt = np.eye(4)
for t in range(1, 41):
    Pt = Pt @ P
    if t in (1, 2, 5, 10, 20, 40):
        tv = 0.5 * np.abs(Pt - pi).sum(axis=1)           # row i = distribution after t steps from state i
        print(f"{t:>3}" + "".join(f"{v:>16.2e}" for v in tv) + f"{lam2 ** t:>12.2e}")

T = 200_000                                           # ergodic theorem: time averages -> pi
cum, u, x = np.cumsum(P, axis=1), rng.random(T), 3
visits = np.zeros(4)
for t in range(T):
    x = np.searchsorted(cum[x], u[t]); visits[x] += 1
print("\nfraction of time in each state over one 200k-step path:", np.round(visits / T, 4))
```

The total-variation distance $\tfrac12\sum_j |(P^t)_{ij} - \pi_j|$ falls by a factor of
$|\lambda_2| = 0.444$ per step from every starting state, tracking the $\lambda_2^t$ column almost
exactly. After 40 steps the start is forgotten to $10^{-15}$. The last line is the result MCMC actually
relies on, the **ergodic theorem**: the fraction of time *one* path spends in each state converges to
$\pi$ (0.6456 vs 0.643, 0.0395 vs 0.0399). More generally $\frac{1}{T}\sum_t f(x_t) \to \mathbb{E}_\pi[f]$.
MCMC runs this logic backwards. You are given $\pi$ (the posterior), and you must design a $P$ that
has it as its stationary distribution.

## Detailed balance is a sufficient condition

Stationarity, $\sum_i \pi_i P_{ij} = \pi_j$ for every $j$, is called **global balance**: total
probability flowing into state $j$ equals $\pi_j$. It is a set of $K$ coupled equations and hard to
design for. **Detailed balance** is a much stronger local condition: the flow from $i$ to $j$ equals
the flow back, for every pair.

### Detailed balance implies stationarity

$$
\pi_i P_{ij} = \pi_j P_{ji} \;\;\forall i, j
\quad\Longrightarrow\quad
\sum_i \pi_i P_{ij} = \sum_i \pi_j P_{ji} = \pi_j \sum_i P_{ji} = \pi_j
$$

The last step uses only that rows of $P$ sum to one. A chain satisfying detailed balance is
**reversible**: run at stationarity, the sequence $(x_t)$ has the same law forwards and backwards. The
condition is sufficient, not necessary. The shop chain is stationary but not reversible:

```python
F = pi[:, None] * P                                   # F[i, j] = probability flow i -> j at stationarity
print("flow matrix pi_i P_ij (x1000):\n", np.round(1000 * F, 2))
print(f"global balance  max |sum_i F_ij - pi_j| = {np.abs(F.sum(0) - pi).max():.1e}")
print(f"detailed balance max |F_ij - F_ji|       = {np.abs(F - F.T).max():.4f}")

      f"cart->buy {F[2,3]-F[3,2]:+.4f}, buy->idle {F[3,0]-F[0,3]:+.4f}")
```

Global balance holds to machine precision, but the flow matrix is not symmetric. There is a net
probability current around the loop idle $\to$ browse $\to$ cart $\to$ buy $\to$ idle. Non-reversible
chains can mix *faster* (lifted and non-reversible samplers exploit this), but they are harder to
build. Detailed balance turns the design problem into $K(K-1)/2$ independent pairwise equations,
and Metropolis–Hastings solves each pair separately.

## Building a chain for a target you can only evaluate up to a constant

You have an unnormalised target $\tilde\pi = Z\pi$, where $Z$ is the evidence you cannot compute. You also
have a **proposal** $Q_{ij} = q(j \mid i)$ that you can sample from. On its own $Q$ has the wrong
stationary distribution. Metropolis–Hastings fixes it by accepting a proposed move $i \to j$ with
probability $\alpha_{ij}$ and otherwise staying at $i$, so $P_{ij} = Q_{ij}\alpha_{ij}$ for $j \ne i$.

### Deriving the acceptance probability

Detailed balance for the pair $(i, j)$ reads
$\pi_i Q_{ij}\alpha_{ij} = \pi_j Q_{ji}\alpha_{ji}$, so the acceptance probabilities need only satisfy

$$
\frac{\alpha_{ij}}{\alpha_{ji}} = \frac{\pi_j Q_{ji}}{\pi_i Q_{ij}} \equiv r_{ij}, \qquad r_{ji} = 1/r_{ij}
$$

You want both as large as possible (rejections waste work), and both are at most 1. So set the larger one to 1:

$$
\boxed{\alpha_{ij} = \min\!\left(1,\; \frac{\tilde\pi_j\, Q_{ji}}{\tilde\pi_i\, Q_{ij}}\right)}
$$

If $r_{ij} < 1$ then $\alpha_{ij} = r_{ij}$ and $\alpha_{ji} = 1$, and the ratio is right. The other case is the same with $i$ and $j$ swapped.
$Z$ cancels in $\tilde\pi_j/\tilde\pi_i$, which is the whole reason MCMC works on posteriors:
you only ever need $p(y\mid\theta)p(\theta)$. The factor $Q_{ji}/Q_{ij}$ is the **Hastings
correction**. It vanishes for symmetric proposals (Metropolis et al., 1953), and Hastings (1970) added it
for asymmetric ones. Other choices satisfy the ratio too. Barker's $\alpha = r/(1+r)$ is one, but
$\min(1, r)$ accepts more often for every pair. By Peskun's theorem that makes its estimators'
asymptotic variance no larger.

```python
K = 12
w = np.array([1, 3, 8, 20, 35, 30, 12, 4, 9, 25, 14, 2], float)   # unnormalised target
target = w / w.sum()

def mh_matrix(w, Q, hastings=True):
    """Exact MH transition matrix on a finite state space. Uses only ratios of w."""
    K = len(w)
    M = np.zeros((K, K))
    for i in range(K):
        for j in range(K):
            if i != j and Q[i, j] > 0:
                r = w[j] / w[i] * (Q[j, i] / Q[i, j] if hastings else 1.0)
                M[i, j] = Q[i, j] * min(1.0, r)
        M[i, i] = 1 - M[i].sum()                     # rejected mass stays put
    return M

def stationary(M):
    ev, V = np.linalg.eig(M.T)
    p = np.real(V[:, np.argmin(np.abs(ev - 1))])
    return p / p.sum()

idx = np.arange(K)
Q_sym = np.zeros((K, K)); Q_sym[idx, (idx + 1) % K] = 0.5; Q_sym[idx, (idx - 1) % K] = 0.5
Q_asym = np.zeros((K, K)); Q_asym[idx, (idx + 1) % K] = 0.8; Q_asym[idx, (idx - 1) % K] = 0.2
for name, Q, h in (("symmetric proposal", Q_sym, True), ("asymmetric 0.8/0.2, Hastings", Q_asym, True),
                   ("asymmetric 0.8/0.2, no correction", Q_asym, False)):
    M = mh_matrix(w, Q, h)
    s = stationary(M)
    Fm = s[:, None] * M
    print(f"{name:34} max|stationary - target| {np.abs(s - target).max():.1e} | "
          f"max|F - F^T| {np.abs(Fm - Fm.T).max():.1e} | TV {0.5 * np.abs(s - target).sum():.3f}")
```

```output

asymmetric 0.8/0.2, Hastings       max|stationary - target| 3.1e-15 | max|F - F^T| 1.6e-16 | TV 0.000
```

The exact transition matrices confirm the derivation. With a symmetric $\pm 1$ proposal on a ring
of 12 states, and with a drifting 0.8/0.2 proposal plus the Hastings factor, the stationary
distribution matches the target to $10^{-15}$ and the flow matrix is symmetric. Drop the correction
and the chain still converges, just to the wrong distribution, a total-variation distance of 0.333
away. The code never computed `w.sum()` to build the chain. It only appears in `target` for checking.

## Random-walk Metropolis in log space

On a continuous space the same construction gives a transition kernel
$K(x, dx') = q(x'\mid x)\,\alpha(x, x')\,dx' + \big(1 - a(x)\big)\,\delta_x(dx')$, where $a(x)$ is the
total acceptance probability from $x$. The simplest proposal is a Gaussian step,
$x' = x + s\,\varepsilon$ with $\varepsilon \sim \mathcal{N}(0, I)$. It is symmetric, so
$\alpha = \min(1, \tilde p(x')/\tilde p(x))$. That is **random-walk Metropolis** (RWM).

Never compute $\tilde p$ itself. A likelihood is a product of $n$ numbers below one and underflows
to 0.0 for any real dataset. Work with $\log\tilde p$, and accept when
$\log u < \log\tilde p(x') - \log\tilde p(x)$ with $u \sim U(0,1)$. Mixture likelihoods need one more
step. $\log(a + b)$ must be computed as
$\mathrm{logsumexp}(\log a, \log b) = m + \log(e^{\log a - m} + e^{\log b - m})$ with $m = \max$, so no
component density is ever formed outside log space. The model below has response times from a fast
path (90%) and a slow path (10%, 300 ms slower) sharing the location $\mu$. It is a non-conjugate posterior.

```python
rng = np.random.default_rng(1)
n_obs = 2000
slow = rng.random(n_obs) < 0.1
y_rt = np.where(slow, rng.normal(480, 80, n_obs), rng.normal(180, 20, n_obs))   # ms: fast path + slow path

def log_post_naive(mu):          # mixture likelihood computed on the probability scale; mu: (C, 1)
    dens = 0.9 * stats.norm.pdf(y_rt, mu, 20) + 0.1 * stats.norm.pdf(y_rt, mu + 300, 80)
    return np.log(dens).sum(axis=-1) + stats.norm.logpdf(mu[..., 0], 200, 100)

def log_post(mu):                # same thing, in log space with log-sum-exp; mu has shape (C, 1)
    a = np.log(0.9) + stats.norm.logpdf(y_rt, mu, 20)
    b = np.log(0.1) + stats.norm.logpdf(y_rt, mu + 300, 80)
    return np.logaddexp(a, b).sum(axis=-1) + stats.norm.logpdf(mu[..., 0], 200, 100)

with np.errstate(divide="ignore", invalid="ignore"):
    for m in (180.0, -700.0, -3000.0, -5000.0):
        print(f"mu = {m:6.0f}: naive {log_post_naive(np.array([[m]]))[0]:12.2f} | "
              f"log-sum-exp {log_post(np.array([[m]]))[0]:12.2f}")
print("product of the 2000 mixture densities at mu=180:",
      np.prod(0.9 * stats.norm.pdf(y_rt, 180, 20) + 0.1 * stats.norm.pdf(y_rt, 480, 80)))

def rwm(logp, x0, n_iter, scale, L=None, rng=rng, keep=None):
    """Random-walk Metropolis on C chains at once. x0: (C, d). One logp evaluation per chain per iteration."""
    x = np.array(x0, float)
    C, d = x.shape
    lp = logp(x)
    s = np.broadcast_to(np.asarray(scale, float), (C,))[:, None]
    L = np.eye(d) if L is None else L
    keep = np.arange(d) if keep is None else np.asarray(keep)
    out, acc = np.empty((n_iter, C, len(keep))), np.zeros(C)
    for t in range(n_iter):
        prop = x + s * (rng.standard_normal((C, d)) @ L.T)      # symmetric: q(x'|x) = q(x|x')
        lp_prop = logp(prop)
        ok = np.log(rng.random(C)) < lp_prop - lp                # accept w.p. min(1, p(x')/p(x))
        x[ok], lp[ok] = prop[ok], lp_prop[ok]
        acc += ok
        out[t] = x[:, keep]
    return out, acc / n_iter

with np.errstate(divide="ignore", invalid="ignore"):
    _, acc_naive = rwm(log_post_naive, np.array([[-5000.0]]), 500, 1.0)
_, acc_lse = rwm(log_post, np.array([[-5000.0]]), 500, 1.0)
print(f"500 iterations started at mu=-5000: acceptance naive {acc_naive[0]:.3f} | log-sum-exp {acc_lse[0]:.3f}")
draws, acc = rwm(log_post, np.full((4, 1), 100.0), 6000, 1.0)
mu_mc = draws[1000:, :, 0]
g = np.linspace(170, 190, 4001)
lg = log_post(g[:, None]); pg = np.exp(lg - lg.max()); pg /= pg.sum()
m_g = np.sum(g * pg)
print(f"\nRWM (4 chains, 5000 kept each): acceptance {acc.round(3)}")
print(f"posterior mean  RWM {mu_mc.mean():.3f} | grid {m_g:.3f}")
print(f"posterior sd    RWM {mu_mc.std():.3f} | grid {np.sqrt(np.sum((g - m_g) ** 2 * pg)):.3f}")
```

Near the posterior the naive and log-sum-exp versions agree, because each observation's mixture
density is still representable even though their product (last line before the chain) is 0.0. Far
out, every component density underflows. The naive log posterior is $-\infty$ everywhere in the
neighbourhood, every acceptance test compares $-\infty$ with $-\infty$ (NaN, so always rejected), and
the chain never moves. The stable version still has a slope to climb. Started at $\mu = 100$, four
chains agree with a 4001-point grid on the mean to 0.003 ms and on the sd to about 3%. That residual
is Monte Carlo error, which the next section quantifies. The `rwm` function runs $C$ chains in lockstep, so the
Python loop costs the same for 1 chain or 32, and it is reused for the rest of the chapter.

## Measuring efficiency: effective sample size

Successive MCMC draws are correlated, so $N$ draws carry less information than $N$ independent
ones. For a stationary chain with lag-$k$ autocorrelation $\rho_k$, the variance of the sample mean is

$$
\mathrm{Var}\big(\bar f_N\big) \approx \frac{\sigma_f^2}{N}\Big(1 + 2\sum_{k=1}^{\infty}\rho_k\Big) = \frac{\sigma_f^2}{N}\,\tau,
\qquad \mathrm{ESS} = \frac{N}{\tau}
$$

$\tau$ is the **integrated autocorrelation time**: how many draws one independent draw is worth. The
empirical $\rho_k$ are noisy at large lags, so the sum must be truncated. Geyer's initial positive
sequence sums pairs $\Gamma_m = \rho_{2m} + \rho_{2m+1}$, which are positive for reversible chains,
and stops at the first negative pair. Chapter 7 does the full multi-chain version (rank-normalised
$\hat R$, bulk and tail ESS). This single-chain estimator is enough to compare samplers. It is
validated here on AR(1) processes, where $\tau = (1+\phi)/(1-\phi)$ exactly.

```python
def ess(x):
    """ESS of one chain: n / tau, tau = 1 + 2 sum_k rho_k, truncated by Geyer's initial positive sequence."""
    n = len(x)
    x = x - x.mean()
    f = np.fft.rfft(x, 2 * n)
    acov = np.fft.irfft(f * np.conj(f))[:n] / n
    rho = acov / acov[0]
    pairs = rho[:-1:2] + rho[1::2]                       # Gamma_k = rho_2k + rho_2k+1 > 0 for reversible chains
    m = np.argmax(pairs < 0) if (pairs < 0).any() else len(pairs)
    return n / (-1 + 2 * pairs[:m].sum())

for phi in (0.0, 0.5, 0.9, 0.99):
    z = np.empty(100_000); z[0] = 0
    e = rng.standard_normal(100_000)
    for t in range(1, len(z)):
        z[t] = phi * z[t - 1] + e[t]
    print(f"AR(1) phi={phi:<4}: ESS {ess(z):8.0f} | theory n(1-phi)/(1+phi) = {len(z) * (1 - phi) / (1 + phi):8.0f}")
print(f"RWM chain above: ESS per chain {[round(ess(mu_mc[:, c])) for c in range(4)]} of 5000")
```

**ESS per log-density evaluation**, since the evaluation is the expensive part in every real model.

## Tuning the proposal scale

The step size $s$ trades two failure modes. Too small and almost every proposal is accepted, but
the chain diffuses: covering a distance $D$ takes $(D/s)^2$ steps. Too large and proposals land in
the tails and are rejected, so the chain sits still. Acceptance rate is a proxy you can observe;
ESS per evaluation is what you actually want.

### The optimal-scaling results

Roberts, Gelman and Gilks (1997) analysed RWM on a product target
$\prod_{i=1}^{d} f(x_i)$ with $s = \ell/\sqrt{d}$. As $d \to \infty$, each coordinate, sped up by a factor of
$d$, converges to a Langevin diffusion with speed

$$
h(\ell) = 2\ell^2\,\Phi\!\left(-\frac{\ell\sqrt{I}}{2}\right), \qquad a(\ell) = 2\,\Phi\!\left(-\frac{\ell\sqrt{I}}{2}\right)
$$

where $a(\ell)$ is the limiting acceptance rate and $I = \mathbb{E}[(\log f)'^2]$ (equal to 1 for a standard normal). Maximising
$h$ gives $\ell^\star \approx 2.38/\sqrt{I}$ and $\boxed{a(\ell^\star) \approx 0.234}$. In one
dimension there is no limit theorem, but numerical work gives an optimum near $s = 2.4\sigma$ with
acceptance about 0.44. The sweep below measures both regimes, using ESS per evaluation averaged over coordinates.

```python
def sweep(d, scales, n_iter=30_000, seed=2):
    r = np.random.default_rng(seed)
    logp = lambda x: -0.5 * np.sum(x * x, axis=1)                       # N(0, I_d)
    out, acc = rwm(logp, r.standard_normal((len(scales), d)), n_iter, scales, rng=r)
    eff = [np.mean([ess(out[2000:, c, j]) for j in range(min(d, 10))]) / (n_iter - 2000) for c in range(len(scales))]
    return acc, np.array(eff)

sc1 = np.array([0.1, 0.5, 1.0, 1.8, 2.4, 3.0, 4.5, 8.0, 20.0])
acc1, eff1 = sweep(1, sc1)
print(f"d = 1   {'scale':>7} {'accept':>7} {'ESS/eval':>9}")
for s, a, e in zip(sc1, acc1, eff1):
    print(f"        {s:7.2f} {a:7.3f} {e:9.4f}")

c2 = np.array([0.3, 0.8, 1.4, 2.0, 2.38, 2.8, 3.5, 5.0])

print(f"\nd = {d}  {'c (scale = c/sqrt(d))':>22} {'accept':>7} {'ESS/eval':>9} {'d x ESS/eval':>13}")
for s, a, e in zip(c2, acc2, eff2):
    print(f"        {s:22.2f} {a:7.3f} {e:9.4f} {d * e:13.3f}")
```

## Asymmetric proposals need the Hastings correction

Positive parameters (rates, scales, variances) invite multiplicative proposals,
$x' = x\,e^{s\varepsilon}$, because the step automatically scales with $x$ and never leaves
$(0, \infty)$. This proposal is a log-normal centred at $\log x$, and it is **not** symmetric in $x$:

### The correction for a log-normal proposal

$$
q(x'\mid x) = \frac{1}{x' s\sqrt{2\pi}}\exp\!\left(-\frac{(\log x' - \log x)^2}{2s^2}\right)
\quad\Longrightarrow\quad
\frac{q(x\mid x')}{q(x'\mid x)} = \frac{x'}{x}
$$

The exponentials are identical and only the $1/x'$ prefactor differs. The correct acceptance ratio is
$\tilde p(x')\,x' / (\tilde p(x)\,x)$. If you forget the factor, the chain is still a perfectly
valid MH chain, but for the target $\tilde p(x)/x$. For a Gamma$(3, 2)$ target that is Gamma$(2, 2)$,
so you can predict the wrong answer before you see it.

```python
a_sh, b_rt = 3.0, 2.0                                    # target: Gamma(shape 3, rate 2), mean 1.5, var 0.75
log_gamma = lambda x: np.where(x[:, 0] > 0, (a_sh - 1) * np.log(np.abs(x[:, 0])) - b_rt * x[:, 0], -np.inf)

def mh_lognormal(n_iter, s, hastings, C=8, rng=rng):
    x = np.ones((C, 1)); lp = log_gamma(x)
    out = np.empty((n_iter, C)); acc = 0
    for t in range(n_iter):
        prop = x * np.exp(s * rng.standard_normal((C, 1)))           # multiplicative: q is log-normal
        lp_prop = log_gamma(prop)
        log_r = lp_prop - lp + (np.log(prop[:, 0]) - np.log(x[:, 0]) if hastings else 0.0)
        ok = np.log(rng.random(C)) < log_r
        x[ok], lp[ok] = prop[ok], lp_prop[ok]
        out[t], acc = x[:, 0], acc + ok.mean()
    return out[2000:].ravel(), acc / n_iter

ref = stats.gamma(a_sh, scale=1 / b_rt)

        ("log-normal, correction forgotten", *mh_lognormal(40_000, 0.8, False)),
        ("Gaussian RW, reject x <= 0", rw[2000:, :, 0].ravel(), acc_rw.mean())]
print(f"{'sampler':34} {'mean':>7} {'var':>7} {'q90':>7} {'accept':>7}")
```

## Transformations and the Jacobian

The cleaner way to handle constraints is to sample an unconstrained variable and transform it,
which is what every probabilistic programming language does (ch. 8). If $u = \log\sigma$, the density of $u$ is

$$
p_u(u) = p_\sigma(e^u)\,\left|\frac{d\sigma}{du}\right| = p_\sigma(e^u)\,e^u
\quad\Longrightarrow\quad
\log p_u(u) = \log p_\sigma(e^u) + u
$$

A symmetric random walk on $u$ is exactly the log-normal proposal on $\sigma$. The ratio of
Jacobians $e^{u'}/e^{u} = \sigma'/\sigma$ is the Hastings factor from the previous section, so the two views
are the same algorithm. Bounded parameters use logit ($p_u = p_\theta\,\theta(1-\theta)$) and
simplexes use stick-breaking, each with its own log-Jacobian term. Here is the two-parameter Normal model
from chapter 1, sampled in $(\mu, \log\sigma)$ with a diagonal step matrix, and checked against a grid in $(\mu, \sigma)$.

```python
rng = np.random.default_rng(3)
y_lat = np.round(rng.normal(212, 25, 15), 1)

def lp_mu_logsig(th, jacobian=True):           # th[:, 0] = mu, th[:, 1] = u = log sigma
    mu, u = th[:, :1], th[:, 1:]
    sig = np.exp(u)
    ll = stats.norm.logpdf(y_lat, mu, sig).sum(axis=1)
    return ll + stats.norm.logpdf(mu[:, 0], 200, 50) + stats.halfnorm.logpdf(sig[:, 0], scale=50) + (u[:, 0] if jacobian else 0)

       + stats.halfnorm.logpdf(SG, scale=50))

      f"{sg_g[np.searchsorted(c_sg, .025)]:11.2f} {sg_g[np.searchsorted(c_sg, .975)]:12.2f}")

    out, acc = rwm(lambda th: lp_mu_logsig(th, jac), np.tile([200.0, np.log(20)], (4, 1)),
```

## The independence sampler

The proposal does not have to depend on the current state at all. With $q(x'\mid x) = q(x')$ the
Hastings ratio becomes

$$
\alpha(x, x') = \min\!\left(1, \frac{\tilde p(x')\,q(x)}{\tilde p(x)\,q(x')}\right) = \min\!\left(1, \frac{w(x')}{w(x)}\right), \qquad w = \tilde p / q
$$

These are exactly the importance weights of chapter 3. The independence sampler is uniformly ergodic
if and only if $w$ is bounded (Mengersen and Tweedie, 1996): $q$ needs heavier tails than the posterior. If
$q$ is too light somewhere, the chain eventually lands on a point with a huge weight and stays there
for a very long time. The natural $q$ is the Laplace approximation (ch. 3), with Student-t tails.

```python
th_map = optimize.minimize(lambda t: -lp_mu_logsig(t[None, :])[0], [200.0, 3.0]).x
eps = 1e-4
def hess(f, x):
    H = np.zeros((2, 2))
    for i in range(2):
        for j in range(2):
            ei, ej = np.eye(2)[i] * eps, np.eye(2)[j] * eps
            H[i, j] = (f(x + ei + ej) - f(x + ei - ej) - f(x - ei + ej) + f(x - ei - ej)) / (4 * eps ** 2)
    return H
S_lap = np.linalg.inv(-hess(lambda t: lp_mu_logsig(t[None, :])[0], th_map))
print("Laplace approximation (ch. 3): mode", th_map.round(3), "sds", np.sqrt(np.diag(S_lap)).round(3))

def independence_mh(q, n_iter, rng):
    xs = q.rvs(n_iter + 1, random_state=rng)
    lw = lp_mu_logsig(xs) - q.logpdf(xs)                        # log importance weight w = p/q
    out, cur, acc = np.empty((n_iter, 2)), 0, 0
    logu = np.log(rng.random(n_iter))
    for t in range(n_iter):
        if logu[t] < lw[t + 1] - lw[cur]:                         # accept w.p. min(1, w(x')/w(x))
            cur, acc = t + 1, acc + 1
        out[t] = xs[cur]
    return out, acc / n_iter, lw

for name, q in (("multivariate t_4, Laplace cov", stats.multivariate_t(th_map, S_lap, df=4)),
                ("Normal, Laplace cov x 0.25", stats.multivariate_normal(th_map, 0.25 * S_lap))):
    out, a, lw = independence_mh(q, 20_000, rng)
    print(f"{name:30} accept {a:.3f} | ESS(mu) {ess(out[:, 0]):6.0f} ESS(log sigma) {ess(out[:, 1]):6.0f} "
          f"of 20000 | E[sigma] {np.exp(out[:, 1]).mean():6.2f} | sigma 97.5% {np.quantile(np.exp(out[:, 1]), .975):6.2f}")
```


With $t_4$ tails, 78% of proposals are accepted and the 20,000 draws are worth about 11,000

## Warmup: forgetting a bad start

The ergodic theorem holds from any start, but finite averages remember the start. The first stretch
of the chain, while it travels from an arbitrary initial point to the typical set (ch. 3), is
called **burn-in**. Modern samplers call it **warmup**, because they also tune the proposal
during it (next section). Start the $(\mu, \log\sigma)$ chain at an absurd point and watch it travel.

```python
rng = np.random.default_rng(4)

```

## Adaptation: tune during warmup, then freeze

Tuning by hand does not scale, so adapt the scale automatically. A Robbins–Monro update
$\log s \leftarrow \log s + \gamma_t(\mathbb{1}[\text{accepted}] - a^\star)$ pushes the acceptance rate toward
the target $a^\star$. The catch: once $s$ depends on the chain's history, the process is **no longer
a Markov chain**, and the stationarity argument above no longer applies. Roberts and Rosenthal
(2007) show that adaptive MCMC stays valid under **diminishing adaptation** ($\gamma_t \to 0$) plus a
technical containment condition. The adaptive Metropolis algorithm of Haario et al. (2001) satisfies
these. The safe engineering answer, used by Stan and PyMC, is simpler: adapt only during warmup,
then freeze the tuning parameters and sample from a genuine Markov chain.

The target below is a spike-and-slab mixture, $\tfrac12\mathcal{N}(0, 0.1^2) + \tfrac12\mathcal{N}(0, 3^2)$. The ideal
step differs by a factor of 30 between the two parts, so any adaptation that tracks *where the chain
currently is* changes the dynamics. Each variant runs 32 chains and keeps the second half of 40,000 iterations.

```python
log_mix = lambda x: np.logaddexp(np.log(0.5) + stats.norm.logpdf(x[:, 0], 0, 0.1),
                                  np.log(0.5) + stats.norm.logpdf(x[:, 0], 0, 3.0))
truth = 0.5 * (stats.norm.cdf(0.2, 0, 0.1) - stats.norm.cdf(-0.2, 0, 0.1)) + \
        0.5 * (stats.norm.cdf(0.2, 0, 3) - stats.norm.cdf(-0.2, 0, 3))

def adaptive_rwm(n_iter, gain, freeze_at=None, C=32, rng=rng):
    x = rng.standard_normal((C, 1)); lp = log_mix(x); log_s = np.zeros(C); avg = np.zeros(C)
    out = np.empty((n_iter, C))
    for t in range(n_iter):
        prop = x + np.exp(log_s)[:, None] * rng.standard_normal((C, 1))
        lp_prop = log_mix(prop)
        ok = np.log(rng.random(C)) < lp_prop - lp
        x[ok], lp[ok] = prop[ok], lp_prop[ok]
        if freeze_at is None or t < freeze_at:
            log_s += gain(t) * (ok - 0.44)                    # Robbins-Monro toward 44% acceptance
            if freeze_at is not None and t >= freeze_at // 2:
                avg += log_s / (freeze_at - freeze_at // 2)   # average the iterates of late warmup
        if t + 1 == freeze_at:
            log_s = avg.copy()                                # freeze at the averaged scale
        out[t] = x[:, 0]
    return out[n_iter // 2:], np.exp(log_s)

print(f"target: P(|x| < 0.2) = {truth:.4f}, var = {0.5 * 0.01 + 0.5 * 9:.3f}")
for name, gain, frz in (("constant gain 0.1, never stops", lambda t: 0.1, None),
                        ("diminishing gain (t+1)^-0.7", lambda t: (t + 1) ** -0.7, None),
                        ("constant gain, frozen at warmup end", lambda t: 0.1, 20_000)):
    smp, s_final = adaptive_rwm(40_000, gain, frz)
    ind = (np.abs(smp) < 0.2).astype(float)
    mcse = np.sqrt(ind.var() / sum(ess(ind[:, c]) for c in range(ind.shape[1])))
    print(f"{name:36} P(|x|<0.2) {ind.mean():.4f} +- {2 * mcse:.4f} | var {smp.var():6.3f} | "
          f"final scales {np.quantile(s_final, [0, 0.5, 1]).round(2)}")
```

```output

diminishing gain (t+1)^-0.7          P(|x|<0.2) 0.4996 +- 0.0064 | var  4.594 | final scales [1.48 1.89 2.35]
```

iterates matters. Freezing at the last noisy iterate would give each chain a random step size, which
is valid but needlessly inefficient. Stan's dual averaging does exactly this averaging.

## Preconditioning with an estimated covariance

The scalar step is only half the story. On a posterior with strongly correlated or
very differently scaled parameters, an isotropic proposal must use a step small enough for the
*narrowest* direction, and then needs about $\kappa = \lambda_{\max}/\lambda_{\min}$ times more steps to cross the
widest one. The fix is to propose from $\mathcal{N}(x, s^2\Sigma)$ with $\Sigma \approx$ the posterior
covariance, i.e. $x' = x + sL\varepsilon$ with $LL^\top = \Sigma$. This is RWM on the whitened variable
$z = L^{-1}x$, where the target is roughly isotropic, and the optimal scale is again $2.38/\sqrt{d}$.

Haario's adaptive Metropolis uses $\Sigma_t = \frac{2.38^2}{d}\,\widehat{\mathrm{Cov}}(x_{0:t}) + \epsilon I$.
The version below adapts in stages during warmup (500, 1000, 2000, 4000 iterations). After each stage it
re-estimates $\Sigma$ from the later half of the warmup history, then freezes it. Two Gaussian targets
are compared, so the truth is known exactly.

```python
def gaussian_target(Sigma):
    Pm = np.linalg.inv(Sigma)
    return lambda x: -0.5 * np.einsum("ci,ij,cj->c", x, Pm, x)

def adaptive_warmup(logp, x0, stages=(500, 1000, 2000, 4000), rng=rng):
    """Haario-style stagewise adaptation: re-estimate the covariance from the later half of the warmup draws."""
    C, d = x0.shape
    x, L, hist = x0, np.eye(d) * 0.1, []
    for n in stages:
        out, acc = rwm(logp, x, n, 2.38 / np.sqrt(d), L=L, rng=rng)
        hist.append(out.reshape(-1, d)); x = out[-1]
        S_hat = np.cov(np.concatenate(hist[len(hist) // 2:]).T) + 1e-8 * np.eye(d)
        L = np.linalg.cholesky(S_hat)
    return x, L, acc

def compare(Sigma, label, n_iter=20_000, C=4):
    d = len(Sigma)
    logp = gaussian_target(Sigma)
    x0 = rng.standard_normal((C, d))
    sd = np.sqrt(np.diag(Sigma)); lam = np.linalg.eigvalsh(Sigma)
    rows = {}
    rows["isotropic, scale 2.38 sqrt(lam_min/d)"] = rwm(logp, x0, n_iter, 2.38 * np.sqrt(lam.min() / d))
    xw, Lw, _ = adaptive_warmup(logp, x0)
    rows["preconditioned, warmup cov (frozen)"] = rwm(logp, xw, n_iter, 2.38 / np.sqrt(d), L=Lw)
    rows["preconditioned, true cov"] = rwm(logp, x0, n_iter, 2.38 / np.sqrt(d), L=np.linalg.cholesky(Sigma))
    print(f"{label}: condition number {lam.max() / lam.min():.0f}")
    for name, (out, acc) in rows.items():
        e = np.array([[ess(out[1000:, c, j]) for j in range(d)] for c in range(C)]).mean(0) / (n_iter - 1000)
        err = np.abs(out[1000:].reshape(-1, d).std(0) / sd - 1).max()
        print(f"  {name:38} accept {acc.mean():.3f} | min ESS/eval {e.min():.4f} | max |sd error| {err:.1%}")

compare(np.array([[1.0, 0.99 * 10], [0.99 * 10, 100.0]]), "2-D, sds (1, 10), corr 0.99")
A = np.linalg.qr(np.random.default_rng(5).standard_normal((10, 10)))[0]
compare(A @ np.diag(np.logspace(-2, 1, 10)) @ A.T, "10-D, eigenvalues 0.01 .. 10")
```

## Bayesian logistic regression, checked against a reference

Now a real posterior: logistic regression with an intercept, five correlated features, 300
observations and a $\mathcal{N}(0, 2.5^2)$ prior on each coefficient. The log-likelihood
$\sum_i y_i\eta_i - \log(1 + e^{\eta_i})$ uses `logaddexp(0, eta)`, the two-term log-sum-exp, so it never
overflows for large $|\eta|$.

You need a reference answer to trust any sampler. Here it is importance sampling (ch. 3) with a $t_5$
proposal built from the Laplace approximation and 200,000 draws. In six dimensions with a near-Gaussian
posterior that is very accurate, and its own effective sample size reports how accurate. Then two RWM
variants each run 4 chains of 20,000 post-warmup iterations, and the error in each posterior mean is
measured in units of its Monte Carlo standard error, $\mathrm{sd}/\sqrt{\mathrm{ESS}}$.

```python
rng = np.random.default_rng(6)
n_lr, p_lr = 300, 5
Z = rng.standard_normal((n_lr, p_lr)) @ np.linalg.cholesky(0.6 * np.eye(p_lr) + 0.4).T   # correlated features
Xd = np.column_stack([np.ones(n_lr), Z])
beta_true = np.array([-0.7, 1.2, -0.8, 0.0, 0.5, 0.3])
y_lr = (rng.random(n_lr) < special.expit(Xd @ beta_true)).astype(float)

def lp_logit(B):                                   # B: (C, 6)
    eta = B @ Xd.T
    return (y_lr * eta - np.logaddexp(0, eta)).sum(1) - 0.5 * np.sum(B ** 2, 1) / 2.5 ** 2

res = optimize.minimize(lambda b: -lp_logit(b[None])[0], np.zeros(6), method="BFGS")
pr = special.expit(Xd @ res.x)
S_lp = np.linalg.inv(Xd.T @ (Xd * (pr * (1 - pr))[:, None]) + np.eye(6) / 2.5 ** 2)

q = stats.multivariate_t(res.x, S_lp, df=5)       # reference: importance sampling (ch. 3), 200k draws
lw_all, xs_all = [], []
for _ in range(10):
    xs = q.rvs(20_000, random_state=rng); xs_all.append(xs); lw_all.append(lp_logit(xs) - q.logpdf(xs))
xs, lw = np.concatenate(xs_all), np.concatenate(lw_all)
wt = np.exp(lw - special.logsumexp(lw))
ref_mean = wt @ xs; ref_sd = np.sqrt(wt @ (xs - ref_mean) ** 2)
print(f"IS reference: 200000 draws, IS effective sample size {1 / np.sum(wt ** 2):.0f}")

C = 4
x0 = res.x + rng.standard_normal((C, 6))
runs = {}
iso_out, _ = rwm(lp_logit, x0, 3000, 0.05, rng=rng)              # warmup a crude isotropic scale
s_iso = 2.38 / np.sqrt(6) * iso_out[1500:].reshape(-1, 6).std(0).min()
runs["isotropic RWM"] = rwm(lp_logit, iso_out[-1], 20_000, s_iso, rng=rng)
xw, Lw, _ = adaptive_warmup(lp_logit, x0, rng=rng)
runs["preconditioned RWM (warmup cov)"] = rwm(lp_logit, xw, 20_000, 2.38 / np.sqrt(6), L=Lw, rng=rng)
print(f"{'':32}" + "".join(f"{'b' + str(j):>8}" for j in range(6)))
print(f"{'reference mean':32}" + "".join(f"{v:8.3f}" for v in ref_mean))
print(f"{'reference sd':32}" + "".join(f"{v:8.3f}" for v in ref_sd))
for name, (out, acc) in runs.items():
    flat = out.reshape(-1, 6)
    e = np.array([[ess(out[:, c, j]) for j in range(6)] for c in range(C)]).sum(0)
    z = np.abs(flat.mean(0) - ref_mean) / (ref_sd / np.sqrt(e))       # error in Monte Carlo standard errors
    print(f"{name:32}" + "".join(f"{v:8.3f}" for v in flat.mean(0)))
    print(f"{'   accept ' + f'{acc.mean():.3f}' + ', min ESS/eval':32}{e.min() / (C * 20_000):8.4f} "
          f"| max |error| / MCSE {z.max():.2f}")
```

```output

                                      b0      b1      b2      b3      b4      b5
reference mean                    -0.818   1.149  -0.860   0.056   0.632   0.197
reference sd                       0.150   0.194   0.178   0.178   0.177   0.179
isotropic RWM                     -0.817   1.146  -0.858   0.052   0.629   0.202
   accept 0.287, min ESS/eval     0.0299 | max |error| / MCSE 1.70
preconditioned RWM (warmup cov)   -0.820   1.152  -0.862   0.053   0.634   0.195
   accept 0.278, min ESS/eval     0.0456 | max |error| / MCSE 1.04
```

The importance-sampling reference has an effective sample size of 158,000 out of 200,000, so the
Laplace-t proposal is an excellent fit. Both RWM samplers agree with it to within 2 Monte Carlo standard
errors on every coefficient, which is what correct sampling with an honest ESS should give. The
preconditioned sampler's worst-coordinate ESS/eval is 0.046 against 0.030. That is a smaller gain than
on the synthetic targets, because this posterior is only mildly correlated (the prior and the
intercept column keep it well conditioned). It is also an instructive negative result: for a
six-parameter GLM, 80,000 log-density evaluations buy only about 2,400 to 3,600 effective draws. The
importance sampler did far better here. MCMC earns its keep when no good global approximation exists.

## Why random-walk Metropolis does not scale

The optimal-scaling theory makes a sharp prediction. At $s = 2.38/\sqrt{d}$ on an isotropic target, the
efficiency per coordinate is $h(\ell^\star)/d \approx 1.3/d$ in diffusion time, which works out to an
ESS per evaluation of about $0.3/d$ (Gelman et al., BDA3, ch. 12). The cost of one effective draw grows
**linearly** in $d$ *after* perfect preconditioning, and it gets multiplied by the condition number when the
preconditioning is imperfect.

```python
rng = np.random.default_rng(7)
std_normal = lambda x: -0.5 * np.sum(x * x, axis=1)
print(f"{'d':>4} {'accept':>7} {'ESS/eval':>9} {'d x ESS/eval':>13} {'evals per indep. draw':>22}")
for d in (1, 2, 5, 10, 20, 50, 100):
    out, acc = rwm(std_normal, rng.standard_normal((4, d)), 40_000, 2.38 / np.sqrt(d), rng=rng, keep=range(min(d, 5)))
    e = np.mean([ess(out[2000:, c, j]) for c in range(4) for j in range(out.shape[2])]) / 38_000
    print(f"{d:4d} {acc.mean():7.3f} {e:9.4f} {d * e:13.3f} {1 / e:22.0f}")
```

```output
   d  accept  ESS/eval  d x ESS/eval  evals per indep. draw
   1   0.445    0.2188         0.219                      5
   2   0.356    0.1322         0.264                      8
   5   0.288    0.0597         0.299                     17
  10   0.260    0.0301         0.301                     33
  20   0.249    0.0164         0.328                     61
  50   0.239    0.0068         0.339                    147
 100   0.235    0.0033         0.329                    304
```

Acceptance falls from 0.445 to 0.235, converging on the 0.234 limit. $d \times$ ESS/eval settles at about
0.33, so one independent draw costs 5 evaluations in one dimension and about 300 at $d = 100$. For a
neural network with $10^5$ weights (ch. 13) that is hopeless. The reason is geometric. A random direction
in high dimensions is almost orthogonal to the direction that keeps you in the typical set (ch. 3), so
only tiny steps survive. Langevin proposals (MALA) use the gradient to choose the direction and scale
as $d^{1/3}$. Hamiltonian Monte Carlo (ch. 6) follows the gradient for many steps and scales as
$d^{1/4}$, with acceptance rates near 0.65 to 0.8 and ESS per *gradient evaluation* that barely moves with $d$.
Gibbs sampling (ch. 5) takes another route: exact conditional draws, no tuning, when the model's structure allows them.

## Try it Yourself

The "banana" of Haario et al. is a standard stress test: $x_1 \sim \mathcal{N}(0, 10^2)$ and
$x_2 \mid x_1 \sim \mathcal{N}(b x_1^2 - 100b, 1)$. No single covariance fits it, because the local
orientation changes along the curve. The moments are known exactly:
$\mathbb{E}[x_2] = 0$ and $\mathrm{Var}(x_2) = 1 + 2b^2\cdot 10^4$.

```python
import numpy as np

rng = np.random.default_rng(11)
b = 0.03                                    # banana curvature (Haario et al.); try 0.01 or 0.1

def log_banana(x):                          # x1 ~ N(0, 10^2), x2 | x1 ~ N(b x1^2 - 100 b, 1)
    return -0.5 * (x[0] / 10) ** 2 - 0.5 * (x[1] - b * x[0] ** 2 + 100 * b) ** 2

def run(n_iter, L, x0):
    x, lp, out, acc = np.array(x0, float), log_banana(x0), np.empty((n_iter, 2)), 0
    for t in range(n_iter):
        prop = x + L @ rng.standard_normal(2)
        lp_prop = log_banana(prop)
        if np.log(rng.random()) < lp_prop - lp:
            x, lp, acc = prop, lp_prop, acc + 1
        out[t] = x
    return out, acc / n_iter

warm, a0 = run(5_000, np.eye(2) * 1.0, [0.0, 0.0])               # try other isotropic scales
L = np.linalg.cholesky(2.38 ** 2 / 2 * np.cov(warm[2_500:].T))  # freeze the warmup covariance
draws, a1 = run(200_000, L, warm[-1])
print(f"warmup acceptance {a0:.3f} | sampling acceptance {a1:.3f}")
print(f"E[x1] {draws[:, 0].mean():+.3f} (truth 0) | E[x2] {draws[:, 1].mean():+.3f} (truth 0)")
print(f"Var x1 {draws[:, 0].var():.1f} (truth 100) | Var x2 {draws[:, 1].var():.2f} (truth {1 + 2 * 1e4 * b**2:.2f})")
```

```output
warmup acceptance 0.681 | sampling acceptance 0.176
E[x1] +0.023 (truth 0) | E[x2] +0.005 (truth 0)
Var x1 100.3 (truth 100) | Var x2 20.84 (truth 19.00)
```

With $b = 0.03$ the frozen global covariance gives an acceptance of only 0.18, and $\mathrm{Var}(x_2)$
is still about 10% off after 200,000 iterations, because the heavy upper arms are visited rarely and
in long excursions. Try $b = 0.1$, a shorter or longer warmup, a hand-picked isotropic scale for the
whole run, or several independent chains from dispersed starts, and compare the moment errors.
Position-dependent geometry like this is exactly what HMC's gradient (ch. 6) and Riemannian variants
handle and what a fixed random walk cannot.

## Exercise

Incident counts are logged for 150 services with exposure $e_i$ (thousands of requests) and two
standardised covariates. The model is
$y_i \sim \mathrm{Poisson}\big(e_i \exp(x_i^\top\beta)\big)$ with $\beta_j \sim \mathcal{N}(0, 1)$, three
coefficients including the intercept. Simulate data with $\beta = (0.3, 0.5, -0.4)$, exposures
uniform on $[0.5, 5]$, and seed 12.

1. Write the log posterior in a form that cannot overflow or underflow for reasonable $\beta$ (log-rate with a $\log e_i$ offset).
2. Build a reference: Laplace approximation (mode and inverse Hessian), then importance sampling with a $t_5$ proposal.
3. Run an isotropic RWM with step $\frac{2.38}{\sqrt{3}}\min_j \mathrm{sd}_j$, and a preconditioned RWM whose covariance comes from staged adaptive warmup and is then frozen. Use 4 chains of 20,000 iterations each.
4. Report posterior means, acceptance rates and the worst-coordinate ESS per evaluation, and say which sampler you would use and why.

```python
rng = np.random.default_rng(12)
n_ex = 150
expo = rng.uniform(0.5, 5.0, n_ex)                          # exposure (e.g. 1000s of requests)
Xp = np.column_stack([np.ones(n_ex), rng.standard_normal((n_ex, 2))])
y_ex = rng.poisson(expo * np.exp(Xp @ np.array([0.3, 0.5, -0.4])))

def lp_pois(B):
    eta = B @ Xp.T + np.log(expo)                           # log rate with offset
    return (y_ex * eta - np.exp(eta)).sum(1) - special.gammaln(y_ex + 1).sum() - 0.5 * np.sum(B ** 2, 1)

m_hat = optimize.minimize(lambda b: -lp_pois(b[None])[0], np.zeros(3)).x
lam_hat = expo * np.exp(Xp @ m_hat)
S_p = np.linalg.inv(Xp.T @ (Xp * lam_hat[:, None]) + np.eye(3))
qp = stats.multivariate_t(m_hat, S_p, df=5)
xs = qp.rvs(100_000, random_state=rng); lw = lp_pois(xs) - qp.logpdf(xs)
wt = np.exp(lw - special.logsumexp(lw)); r_mean = wt @ xs; r_sd = np.sqrt(wt @ (xs - r_mean) ** 2)

x0 = m_hat + rng.standard_normal((4, 3))
iso, acc_i = rwm(lp_pois, x0, 20_000, 2.38 / np.sqrt(3) * np.sqrt(np.diag(S_p)).min(), rng=rng)
xw, Lw, _ = adaptive_warmup(lp_pois, x0, rng=rng)
pre, acc_p = rwm(lp_pois, xw, 20_000, 2.38 / np.sqrt(3), L=Lw, rng=rng)
print(f"{'':16} {'b0':>7} {'b1':>7} {'b2':>7} {'accept':>7} {'min ESS/eval':>13}")
print(f"{'IS reference':16} " + " ".join(f"{v:7.3f}" for v in r_mean) + f"   (sd {r_sd.round(3)})")
for name, out, a in (("isotropic", iso[1000:], acc_i), ("preconditioned", pre, acc_p)):
    e = min(sum(ess(out[:, c, j]) for c in range(4)) for j in range(3)) / out[:, :, 0].size
    print(f"{name:16} " + " ".join(f"{v:7.3f}" for v in out.reshape(-1, 3).mean(0)) + f" {a.mean():7.3f} {e:13.4f}")
```
