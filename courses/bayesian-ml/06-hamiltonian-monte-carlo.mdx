## Random walks cannot follow the typical set

Chapter 3 showed where the probability mass of a $d$-dimensional posterior lives: not at the mode,
but in a thin shell, the **typical set**, at distance about $\sqrt{d}$ from it for a standard Normal.
Chapter 4 showed what that does to random-walk Metropolis. A proposal that is isotropic in
$\mathbb{R}^d$ points almost entirely *out* of the shell, so the step size has to shrink like
$1/\sqrt{d}$ for anything to be accepted, and the chain diffuses around the shell with a cost per
independent draw that grows like $d$.

What you want is a proposal that moves *along* the shell. The gradient of $\log p$ does not give you
that by itself: it points at the mode, perpendicular to the shell. Follow it and you collapse onto
the one point that has almost no mass around it. The fix, due to Duane et al. (1987) and explained
geometrically by Betancourt (2017), is to add **momentum**: a particle with the right amount of
sideways velocity, pulled toward the mode by the gradient, goes into orbit instead of falling in.
The block below sets up the helpers used all chapter (the ESS estimator and a vectorised
random-walk Metropolis from ch. 4) and compares the three moves on $\mathcal{N}(0, I_{100})$.

```python
import numpy as np
from scipy import stats, special, optimize
import torch
torch.set_num_threads(1)

rng = np.random.default_rng(0)

def ess(x):
    """ESS of one chain (Geyer initial positive sequence, as in ch. 4), capped at n log10(n) like Stan."""
    n = len(x)
    x = x - x.mean()
    f = np.fft.rfft(x, 2 * n)
    acov = np.fft.irfft(f * np.conj(f))[:n] / n
    if acov[0] <= 1e-300:
        return 0.0                                           # a chain that never moved
    rho = acov / acov[0]
    pairs = rho[:-1:2] + rho[1::2]
    m = np.argmax(pairs < 0) if (pairs < 0).any() else len(pairs)
    tau = -1 + 2 * pairs[:m].sum()
    return n / max(tau, 1 / np.log10(n))                     # antithetic chains can give tau < 1

def ess_chains(out):
    """out: (n_iter, C, d) -> ESS per coordinate, summed over chains."""
    return np.array([sum(ess(out[:, c, j]) for c in range(out.shape[1])) for j in range(out.shape[2])])

def rwm(logp, x0, n_iter, scale, chol=None, rng=rng):
    """Random-walk Metropolis on C chains (ch. 4). Proposal x + scale * chol @ z."""
    x = np.array(x0, float); lp = logp(x)
    out, acc = np.empty((n_iter,) + x.shape), 0.0
    for t in range(n_iter):
        z = rng.standard_normal(x.shape)
        prop = x + scale * (z if chol is None else z @ chol.T)
        lpp = logp(prop)
        ok = np.log(rng.random(len(x))) < lpp - lp
        x[ok], lp[ok] = prop[ok], lpp[ok]
        acc += ok.mean(); out[t] = x
    return out, acc / n_iter

d = 100
q0 = rng.standard_normal(d)                              # a typical draw from N(0, I_100)
print(f"|q0| = {np.linalg.norm(q0):.2f}   (typical-set radius sqrt(d) = {np.sqrt(d):.2f}, mode at radius 0)")

q = q0.copy()                                            # (a) follow the gradient of log p
for _ in range(50):
    q = q + 0.1 * (-q)
print(f"(a) 50 gradient-ascent steps : |q| = {np.linalg.norm(q):6.2f} | cos(q, q0) = {q @ q0 / np.linalg.norm(q) / np.linalg.norm(q0):+.3f}")

out, acc = rwm(lambda x: -0.5 * np.sum(x * x, 1), q0[None, :], 1000, 2.38 / np.sqrt(d))   # (b) optimal RWM
qb = out[-1, 0]
print(f"(b) 1000 RWM steps (acc {acc:.2f}): |q| = {np.linalg.norm(qb):6.2f} | cos(q, q0) = {qb @ q0 / np.linalg.norm(qb) / np.linalg.norm(q0):+.3f}")

p0 = rng.standard_normal(d)                              # (c) Hamiltonian flow, exact for this target
for t in (0.25, 0.5, 1.0, np.pi / 2):
    qt = q0 * np.cos(t) + p0 * np.sin(t)
    print(f"(c) flow for time {t:4.2f}       : |q| = {np.linalg.norm(qt):6.2f} | cos(q, q0) = {qt @ q0 / np.linalg.norm(qt) / np.linalg.norm(q0):+.3f}")
```

getting that behaviour for targets where you cannot solve the flow exactly.

## Hamiltonian dynamics

Picture the negative log posterior as a bowl-shaped landscape and the sampler as a frictionless puck
on it. Pushed sideways, the puck does not slide to the bottom. It circles, trading height for speed
and back, and it covers the whole rim at the height its energy allows. Hamiltonian dynamics is that
physics written down.

Augment the position $q \in \mathbb{R}^d$ (your parameters) with a momentum $p \in \mathbb{R}^d$ and
define the joint density $\pi(q, p) \propto e^{-H(q,p)}$ with

$$
H(q, p) = \underbrace{-\log p(q \mid y)}_{U(q),\ \text{potential energy}} + \underbrace{\tfrac{1}{2} p^\top M^{-1} p}_{K(p),\ \text{kinetic energy}}
$$

The joint factorises as $p(q \mid y)\,\mathcal{N}(p \mid 0, M)$, so the $q$-marginal is exactly your
posterior: sample $(q, p)$ jointly and throw $p$ away. The **mass matrix** $M$ is a free choice;
take $M = I$ until the mass-matrix section. Hamilton's equations move the pair through phase space:

$$
\frac{dq}{dt} = \frac{\partial H}{\partial p} = M^{-1} p, \qquad
\frac{dp}{dt} = -\frac{\partial H}{\partial q} = \nabla_q \log p(q \mid y)
$$

The gradient now changes the *momentum*, not the position. Three properties of this flow make it
a valid MCMC proposal.

### Energy is conserved

This shows that $H$ stays constant along the exact flow. By the chain rule and the equations of motion,

$$
\frac{dH}{dt} = \frac{\partial H}{\partial q}^{\!\top}\frac{dq}{dt} + \frac{\partial H}{\partial p}^{\!\top}\frac{dp}{dt}
= \frac{\partial H}{\partial q}^{\!\top}\frac{\partial H}{\partial p} - \frac{\partial H}{\partial p}^{\!\top}\frac{\partial H}{\partial q} = 0
$$

The flow moves along a level set of $H$, so $\pi(q,p) \propto e^{-H}$ is the same at the start and
the end of a trajectory. A Metropolis step would accept with probability one.

### Volume is preserved

This shows that the flow neither squeezes nor stretches regions of phase space. The velocity field $F(q,p) = (\partial H/\partial p,\ -\partial H/\partial q)$ has divergence

$$
\nabla \cdot F = \sum_i \frac{\partial^2 H}{\partial q_i \partial p_i} - \frac{\partial^2 H}{\partial p_i \partial q_i} = 0
$$

so by Liouville's theorem the flow map has Jacobian determinant 1. No density correction for a
change of variables is needed (contrast the Jacobian you had to add for $\log\sigma$ in ch. 4).

### The flow is reversible

This shows that the flow can be run backwards exactly. If you run the flow for time $T$, negate $p$, and run it for $T$ again, you return to the start with
negated momentum. So the map "flow for $T$, then flip $p$" is its own inverse, an **involution**.
That is what makes a deterministic proposal satisfy detailed balance, as the HMC section shows.

## Euler drifts, leapfrog does not

You cannot solve Hamilton's equations exactly for a real posterior, so you discretise with step
size $\varepsilon$. The obvious scheme, Euler, updates $q$ and $p$ simultaneously from the old state.
The **leapfrog** (Störmer–Verlet) integrator splits the momentum update into two half steps around a
full position step:

$$
p_{1/2} = p_0 + \tfrac{\varepsilon}{2}\nabla \log p(q_0), \quad
q_1 = q_0 + \varepsilon M^{-1} p_{1/2}, \quad
p_1 = p_{1/2} + \tfrac{\varepsilon}{2}\nabla \log p(q_1)
$$

The test below integrates $U(q) = q^2/2$ (a standard Normal target) with all three schemes to time 100,
and estimates the Jacobian determinant of one step by finite differences.

```python
def leapfrog_1d(q, p, eps, n, grad):
    traj = [(q, p)]
    for _ in range(n):
        p = p + 0.5 * eps * grad(q)
        q = q + eps * p
        p = p + 0.5 * eps * grad(q)
        traj.append((q, p))
    return np.array(traj)

def euler_1d(q, p, eps, n, grad):
    traj = [(q, p)]
    for _ in range(n):
        q, p = q + eps * p, p + eps * grad(q)
        traj.append((q, p))
    return np.array(traj)

def symplectic_euler_1d(q, p, eps, n, grad):
    traj = [(q, p)]
    for _ in range(n):
        p = p + eps * grad(q)
        q = q + eps * p
        traj.append((q, p))
    return np.array(traj)

grad_std = lambda q: -q                                   # U(q) = q^2 / 2: target N(0, 1)
H_std = lambda tr: 0.5 * tr[:, 0] ** 2 + 0.5 * tr[:, 1] ** 2
eps, n = 0.1, 1000                                        # integrate to time 100 (about 16 orbits)
print(f"{'integrator':18} {'H(0)':>7} {'H(10)':>9} {'H(100)':>11} {'max|dH|':>10} {'det J (1 step)':>15}")
for name, f in (("Euler", euler_1d), ("symplectic Euler", symplectic_euler_1d), ("leapfrog", leapfrog_1d)):
    tr = f(1.0, 0.0, eps, n, grad_std)
    h = 1e-6                                              # Jacobian of one step by finite differences
    a = (f(1 + h, 0, eps, 1, grad_std)[-1] - f(1 - h, 0, eps, 1, grad_std)[-1]) / (2 * h)
    b = (f(1, h, eps, 1, grad_std)[-1] - f(1, -h, eps, 1, grad_std)[-1]) / (2 * h)
    H = H_std(tr)
    print(f"{name:18} {H[0]:7.3f} {H[100]:9.3f} {H[1000]:11.3e} {np.abs(H - H[0]).max():10.3e} {a[0] * b[1] - a[1] * b[0]:15.6f}")

tr = leapfrog_1d(1.0, 0.3, 0.1, 25, grad_std)              # reversibility: integrate, flip p, integrate back
back = leapfrog_1d(tr[-1, 0], -tr[-1, 1], 0.1, 25, grad_std)
tre = euler_1d(1.0, 0.3, 0.1, 25, grad_std)
backe = euler_1d(tre[-1, 0], -tre[-1, 1], 0.1, 25, grad_std)
print(f"\nforward 25 steps, flip p, 25 steps back: leapfrog lands {abs(back[-1, 0] - 1.0):.1e} from start, Euler {abs(backe[-1, 0] - 1.0):.1e}")
for e in (0.5, 1.0, 1.9, 1.99, 2.01, 2.2):
    H = H_std(leapfrog_1d(1.0, 0.0, e, 200, grad_std))
    print(f"leapfrog eps = {e:4.2f}: max |H - H0| over 200 steps = {np.abs(H - H[0]).max():.3g}")
```

Euler's energy goes from 0.5 to $10^4$: every step multiplies phase-space volume by
$1 + \varepsilon^2 = 1.01$ (the determinant of $\begin{pmatrix}1 & \varepsilon\\ -\varepsilon & 1\end{pmatrix}$),
so the orbit spirals outward and $1.01^{1000} \approx 2 \times 10^4$. Leapfrog's error stays bounded
at $1.25 \times 10^{-3}$ forever. It is not zero, but it does not accumulate. Running leapfrog
forward, flipping $p$ and running back returns to the start to $10^{-16}$; Euler misses by 0.28.

### Why leapfrog works: shears and a shadow Hamiltonian

This explains why leapfrog's energy error stays bounded. Each leapfrog sub-step changes only one of $q, p$ by an amount that depends only on the other.
That is a **shear**, with Jacobian $\begin{pmatrix} I & 0 \\ \ast & I\end{pmatrix}$ or
$\begin{pmatrix} I & \ast \\ 0 & I\end{pmatrix}$ and determinant exactly 1. A composition of shears
is volume-preserving, and in fact **symplectic**, which is stronger. The symmetric
half–full–half arrangement makes it time-reversible too. Symplectic Euler, a single
momentum shear followed by a position shear, is also volume-preserving but not symmetric: its error
is $O(\varepsilon)$ (2.6e-2 above) where leapfrog's is $O(\varepsilon^2)$ (1.25e-3). The deep reason
the error stays bounded is backward error analysis. A symplectic integrator exactly conserves a
nearby **shadow Hamiltonian** $\tilde H = H + O(\varepsilon^2)$, so $H$ can only oscillate around its
initial value, never drift.

### The stability limit

This shows that leapfrog has a hard maximum step size. For $U = q^2/(2\sigma^2)$ one leapfrog step is a linear map with eigenvalues on the unit circle
exactly when $\varepsilon < 2\sigma$. Beyond that they become real and one exceeds 1 in modulus, so
the orbit grows geometrically. The table shows a cliff, not a slope: the energy error is 0.495 at
$\varepsilon = 1.99$ and $10^{33}$ at $2.01$. In $d$ dimensions the binding constraint is the
*smallest* posterior scale. Keep this in mind for divergences.

## The HMC algorithm

Each iteration gives the puck a random kick, lets it slide for a while, and then runs a Metropolis
check. The check only exists to correct the small energy error of the integrator.

One HMC iteration from the current $q$:

1. Draw a fresh momentum $p \sim \mathcal{N}(0, M)$. This is a Gibbs step on $p$ given $q$, and it is what lets the sampler change energy level.
2. Run $L$ leapfrog steps of size $\varepsilon$ to get $(q^\ast, p^\ast)$, then negate $p^\ast$.
3. Accept $q^\ast$ with probability $\min\left(1, e^{-\Delta H}\right)$, $\Delta H = H(q^\ast, p^\ast) - H(q, p)$.

### Why the acceptance is $e^{-\Delta H}$

This shows that the Metropolis ratio reduces to the energy error. The proposal $\Phi$ (leapfrog $L$ times, then flip $p$) is deterministic. For a deterministic
proposal, the Metropolis–Hastings ratio of ch. 4 becomes a ratio of densities times the Jacobian of
the map. It is valid only if $\Phi$ is an involution, $\Phi(\Phi(z)) = z$, so that the reverse move
proposes the original point. Leapfrog plus flip is an involution (reversibility) and has
$|\det \nabla\Phi| = 1$ (shears), so

$$
\alpha(z \to \Phi(z)) = \min\left(1, \frac{\pi(\Phi(z))}{\pi(z)}\,\lvert\det \nabla\Phi(z)\rvert\right) = \min\left(1, e^{H(z) - H(\Phi(z))}\right)
$$

The flip is never visible because the next step redraws $p$, and $K$ is symmetric anyway. The
integrator's energy error is the *only* reason anything gets rejected. Since that error is bounded and
$O(\varepsilon^2)$, you can take long trajectories with high acceptance. The implementation below runs
$C$ chains in lockstep. It also records, for each transition, the largest energy error seen *along*
the trajectory, which the divergence section needs. The test target is the banana of ch. 4, with a
hand-derived gradient checked against finite differences.

```python
def hmc(logp_grad, x0, n_iter, eps, L=None, Minv=None, jitter=False, rng=rng, adapt=None, T=None):
    """Vectorised HMC on C chains. logp_grad(x) -> (logp (C,), grad (C, d)).
    Minv: inverse mass matrix, None (identity), (d,) diagonal or (d, d) dense.
    L: leapfrog steps, or T: path length (L = T / eps). jitter: L ~ Uniform{L/2, ..., 3L/2}.
    adapt: optional object with .eps and .update(mean_accept_stat) (dual averaging)."""
    x = np.array(x0, float); C, d = x.shape
    lp, g = logp_grad(x)
    Minv = np.ones(d) if Minv is None else np.asarray(Minv, float)
    if Minv.ndim == 2:
        Lm = np.linalg.cholesky(np.linalg.inv(Minv))
        draw_p, vel = (lambda: rng.standard_normal((C, d)) @ Lm.T), (lambda p: p @ Minv)
    else:
        draw_p, vel = (lambda: rng.standard_normal((C, d)) / np.sqrt(Minv)), (lambda p: p * Minv)
    kin = lambda p: 0.5 * np.sum(p * vel(p), 1)
    out = np.empty((n_iter, C, d)); acc_stat = np.empty((n_iter, C))
    div = np.zeros((n_iter, C), bool); n_grad = 0
    for t in range(n_iter):
        e = adapt.eps if adapt is not None else eps
        Lt = L if T is None else max(1, int(round(T / e)))
        n_steps = int(rng.integers(max(1, Lt // 2), Lt + Lt // 2 + 1)) if jitter else Lt
        p = draw_p(); H0 = -lp + kin(p)
        q, pq, lq, gq = x.copy(), p + 0.5 * e * g, lp, g
        max_err = np.zeros(C)
        with np.errstate(over="ignore", invalid="ignore"):
            for s in range(n_steps):
                q = q + e * vel(pq)
                lq, gq = logp_grad(q)
                pq = pq + (e if s < n_steps - 1 else 0.5 * e) * gq
                err = -lq + kin(pq - (0.5 * e * gq if s < n_steps - 1 else 0)) - H0   # energy at a full step
                max_err = np.maximum(max_err, np.nan_to_num(err, nan=np.inf))
            dH = np.nan_to_num(-lq + kin(pq) - H0, nan=np.inf)
        n_grad += n_steps
        a = np.exp(np.minimum(0.0, -dH))                       # Metropolis on the energy error
        ok = rng.random(C) < a
        x[ok], lp[ok], g[ok] = q[ok], lq[ok], gq[ok]
        out[t], acc_stat[t], div[t] = x, a, max_err > 1000
        if adapt is not None:
            adapt.update(a.mean())
    return dict(draws=out, accept=acc_stat, div=div, n_grad=n_grad * C, x=x)

b_ban = 0.03                                               # the banana of ch. 4, gradients by hand
def banana(x):
    r = x[:, 1] - b_ban * x[:, 0] ** 2 + 100 * b_ban
    lp = -0.5 * (x[:, 0] / 10) ** 2 - 0.5 * r ** 2
    g = np.column_stack([-x[:, 0] / 100 + 2 * b_ban * x[:, 0] * r, -r])
    return lp, g

xt = rng.standard_normal((3, 2)) * 5                       # always check a hand gradient numerically
fd = np.column_stack([(banana(xt + h)[0] - banana(xt - h)[0]) / 2e-6 for h in np.eye(2) * 1e-6])
print(f"max |analytic - finite-difference gradient| = {np.abs(banana(xt)[1] - fd).max():.1e}")

res = hmc(banana, rng.standard_normal((16, 2)), 1500, 0.6, 20, jitter=True)
dr = res["draws"][300:]
e_h = ess_chains(dr)
print(f"HMC : accept {res['accept'].mean():.3f} | E[x1] {dr[..., 0].mean():+.3f} | E[x2] {dr[..., 1].mean():+.3f} | "
      f"Var x1 {dr[..., 0].var():6.1f} (100) | Var x2 {dr[..., 1].var():5.2f} ({1 + 2e4 * b_ban ** 2:.2f})")
print(f"      ESS {e_h.round(0)} from {dr.shape[0] * 16} draws, {res['n_grad']} gradients -> ESS/grad {e_h.min() / res['n_grad']:.4f}")
out, acc = rwm(lambda x: banana(x)[0], rng.standard_normal((16, 2)), 25_000, 2.0)
e_r = ess_chains(out[5000:])
print(f"RWM : accept {acc:.3f} | Var x1 {out[5000:, :, 0].var():6.1f} | Var x2 {out[5000:, :, 1].var():5.2f} | ESS {e_r.round(0)} from {20_000 * 16} evals -> ESS/eval {e_r.min() / 320_000:.4f}")
```

## Step size and path length

HMC has two knobs. The step size $\varepsilon$ trades integration error (rejections) against cost
per unit of simulated time. The integration time $T = L\varepsilon$ sets how far each proposal
travels. The grid below is on a 50-dimensional Normal with scales from 0.5 to 2, so leapfrog is
unstable above $\varepsilon = 1$. Efficiency is reported per gradient evaluation, for both the
coordinates and their squares. Squares matter because they measure how well the sampler explores
the *radius* of the typical set, and HMC can be good at one and bad at the other.

```python
sd50 = np.linspace(0.5, 2.0, 50)                           # 50-d Gaussian, scales 0.5 .. 2
def gauss_diag(sd):
    prec = 1 / sd ** 2
    return lambda x: (-0.5 * np.sum(x * x * prec, 1), -x * prec)
target50 = gauss_diag(sd50)

def summarize(res, burn=100):
    dr = res["draws"][burn:]
    n_grad = res["n_grad"] * (len(res["draws"]) - burn) / len(res["draws"])
    return (res["accept"][burn:].mean(), ess_chains(dr).min() / n_grad, ess_chains(dr ** 2).min() / n_grad,
            res["div"].sum())

print(f"{'eps':>5} {'T':>4} {'L':>4} {'accept':>7} {'ESS(x)/grad':>12} {'ESS(x^2)/grad':>14}")
for e in (0.1, 0.3, 0.6, 0.9, 1.05):
    for T in (0.6, 2.0, 4.0):
        r = hmc(target50, rng.standard_normal((4, 50)) * sd50, 600, e, T=T, jitter=True)
        a, ex, ex2, _ = summarize(r)
        print(f"{e:5.2f} {T:4.1f} {max(1, round(T / e)):4d} {a:7.3f} {ex:12.4f} {ex2:14.4f}")
```

### Resonance: why the path length must be jittered

For a Gaussian, every trajectory is a rotation in each $(q_i, p_i)$ plane with period $2\pi\sigma_i$.
A fixed $T$ that hits a multiple of the half-period for some coordinate gives that coordinate a
perfectly predictable move. Here is $\mathcal{N}(0, I_{10})$ with $\varepsilon = 0.2$.

$\varepsilon$. The $T = \pi/2$ row is the oracle answer for this target, the quarter period where $q(T) = p(0)$.

## Tuning the step size by dual averaging

You rarely know a good step size in advance, so you let warmup find it. Shrink the step when too many
proposals are rejected, grow it when too few are, and settle on the size that gives about 80%
acceptance.

You want $\varepsilon$ such that the average acceptance statistic $\alpha_t = \min(1, e^{-\Delta H_t})$
hits a target $\delta$ (0.8 by default). This is a stochastic root-finding problem in $\log\varepsilon$.
The plain Robbins–Monro update of ch. 4 works but is slow to recover from a bad start. Hoffman and Gelman
(2014) adapt Nesterov's **dual averaging**.

### The update

This is the recursion Stan runs during warmup. With $\bar H_t$ the running average of $\delta - \alpha_t$,

$$
\bar H_t = \left(1 - \frac{1}{t + t_0}\right)\bar H_{t-1} + \frac{\delta - \alpha_t}{t + t_0}, \qquad
\log\varepsilon_t = \mu - \frac{\sqrt{t}}{\gamma}\,\bar H_t
$$

$$
\log\bar\varepsilon_t = t^{-\kappa}\log\varepsilon_t + \left(1 - t^{-\kappa}\right)\log\bar\varepsilon_{t-1}
$$

If acceptance runs too low, $\bar H$ grows positive and $\varepsilon$ shrinks. The $\sqrt{t}/\gamma$
gain lets early iterations take big exploratory jumps around the shrinkage point
$\mu = \log(10\,\varepsilon_0)$. The $t_0$ term damps the first few, and $\gamma = 0.05$,
$t_0 = 10$, $\kappa = 0.75$ are Stan's defaults. The iterate $\varepsilon_t$ keeps
oscillating. What you *use* after warmup is the weighted average $\bar\varepsilon$, which converges.
Then you freeze it: adapting forever breaks the Markov property (ch. 4).

```python
class DualAveraging:
    """Nesterov dual averaging on log eps (Hoffman & Gelman 2014, Alg. 5)."""
    def __init__(self, eps0, delta=0.8, gamma=0.05, t0=10.0, kappa=0.75):
        self.mu, self.delta, self.gamma, self.t0, self.kappa = np.log(10 * eps0), delta, gamma, t0, kappa
        self.eps, self.t, self.Hbar, self.log_eps_bar = eps0, 0, 0.0, 0.0
    def update(self, alpha):
        self.t += 1
        t = self.t
        self.Hbar += (self.delta - alpha - self.Hbar) / (t + self.t0)
        log_eps = self.mu - np.sqrt(t) / self.gamma * self.Hbar
        w = t ** -self.kappa
        self.log_eps_bar = w * log_eps + (1 - w) * self.log_eps_bar
        self.eps = np.exp(log_eps)
    @property
    def final(self):
        return np.exp(self.log_eps_bar)

for eps0 in (2.0, 0.01):
    da = DualAveraging(eps0)
    trace = {}
    x_w = rng.standard_normal((4, 50)) * sd50

        x_w = r["x"]
        if t in (1, 5, 20, 50, 100, 200, 400):
            trace[t] = da.eps
    print(f"eps0 = {eps0:5.2f}: " + "  ".join(f"t={k}: {v:.3f}" for k, v in trace.items()) + f"  | eps_bar {da.final:.3f}")

print(f"\n{'delta':>6} {'eps_bar':>8} {'accept in sampling':>19} {'ESS(x^2)/grad':>14}")
for delta in (0.6, 0.8, 0.95, 0.99):
    da = DualAveraging(0.5, delta=delta)
    warm = hmc(target50, rng.standard_normal((4, 50)) * sd50, 400, None, T=3.0, jitter=True, adapt=da)
    r = hmc(target50, warm["x"], 600, da.final, T=3.0, jitter=True)
    a, ex, ex2, _ = summarize(r)
    print(f"{delta:6.2f} {da.final:8.3f} {a:19.3f} {ex2:14.4f}")
```

## The mass matrix: preconditioning from warmup

If one parameter has scale 0.1 and another has scale 3, a single step size is too big for the first
and too small for the second. The mass matrix rescales the space so every direction looks about
equally wide. This is the HMC version of preconditioning.

The leapfrog stability limit is set by the smallest scale, while the time needed to cross the
posterior is set by the largest. Their ratio, the square root of the condition number, is roughly the number of leapfrog
steps per independent draw. The mass matrix fixes this.

### A mass matrix is a change of coordinates

This shows that a mass matrix is the same as running identity-mass HMC on rescaled parameters. Substitute $q = M^{-1/2} z$. Then $\mathcal{N}(p \mid 0, M)$ momentum with dynamics
$\dot q = M^{-1}p$ is exactly identity-mass HMC on $z$, whose target has covariance
$M^{1/2}\,\Sigma\,M^{1/2}$. Choosing $M^{-1} \approx \Sigma$, the posterior covariance, makes the $z$
target close to isotropic, so one step size fits all directions. This is the same preconditioning
as the proposal covariance of RWM in ch. 4. Here it lives in the kinetic energy, so the sampler's
correctness never depends on it.

Stan estimates $M^{-1}$ from warmup draws in expanding windows. The simplified version below uses
three windows: tune $\varepsilon$, collect draws to estimate the metric (diagonal variances or the full
covariance, shrunk slightly toward the identity), then re-tune $\varepsilon$ under the new metric. To
isolate the metric's effect, the path length is set by an oracle, $\pi/2$ times the largest scale in
the metric's coordinates. NUTS will remove the need for that oracle.

```python
def warmup(logp_grad, x0, metric, T_fn, windows=(100, 300, 200), rng=rng):
    """Window 1: step size only. Window 2: collect draws -> metric. Window 3: re-tune step size."""
    d = x0.shape[1]; Minv = np.ones(d); x = x0; n_grad = 0
    for w, n in enumerate(windows):
        da = DualAveraging(0.1 if w == 0 else da.final)
        r = hmc(logp_grad, x, n, None, T=T_fn(Minv), Minv=Minv, jitter=True, adapt=da, rng=rng)
        x, n_grad = r["x"], n_grad + r["n_grad"]
        if w == 1 and metric != "identity":
            S = r["draws"][n // 2:].reshape(-1, d); m = len(S)
            S = np.cov(S.T) if metric == "dense" else np.diag(S.var(0))
            S = m / (m + 5) * S + 1e-3 * 5 / (m + 5) * np.eye(d)          # Stan's regularisation
            Minv = S if metric == "dense" else np.diag(S)
    return x, Minv, da.final, n_grad

sd20 = np.logspace(-1, 0.5, 20)                              # scales 0.1 .. 3.2
Rot = np.linalg.qr(np.random.default_rng(5).standard_normal((20, 20)))[0]
for label, Sigma in (("axis-aligned scales", np.diag(sd20 ** 2)), ("same scales, rotated", Rot @ np.diag(sd20 ** 2) @ Rot.T)):
    Prec = np.linalg.inv(Sigma)
    tgt = lambda x, P=Prec: (-0.5 * np.einsum("ci,ij,cj->c", x, P, x), -x @ P)
    def T_oracle(Minv, Sigma=Sigma):                         # pi/2 x largest scale in the metric's coordinates
        M = np.linalg.inv(Minv) if np.ndim(Minv) == 2 else np.diag(1 / Minv)
        return np.pi / 2 * np.sqrt(np.linalg.eigvals(Sigma @ M).real.max())
    print(f"{label}: condition number {sd20.max() ** 2 / sd20.min() ** 2:.0f}")
    for metric in ("identity", "diagonal", "dense"):
        x, Minv, e, ng_w = warmup(tgt, rng.standard_normal((4, 20)), metric, T_oracle)
        r = hmc(tgt, x, 600, e, T=T_oracle(Minv), Minv=Minv, jitter=True)
        dr = r["draws"]
        err = np.abs(dr.reshape(-1, 20).std(0) / np.sqrt(np.diag(Sigma)) - 1).max()
        print(f"  {metric:9} eps {e:.3f} | steps/iter {r['n_grad'] / 2400:5.1f} | accept {r['accept'].mean():.3f} | "
              f"min ESS(x^2)/grad {ess_chains(dr ** 2).min() / r['n_grad']:.4f} | max sd error {err:.1%}")
```

## Any differentiable model: gradients from autograd

Hand gradients do not scale to real models. Write the log density in torch and let reverse-mode autodiff
supply $\nabla \log p$ at a few times the cost of $\log p$ itself. The wrapper below turns any
torch function of a $(C, d)$ tensor into the `(logp, grad)` interface `hmc()` already uses. Nothing
else changes. The model is Bayesian logistic regression, 13 coefficients, correlated features,
$\beta_j \sim \mathcal{N}(0, 2.5^2)$, checked against an importance-sampling reference as in ch. 4.

```python
torch.set_default_dtype(torch.float64)

def autograd(logp_torch):
    """Turn a torch log density on (C, d) into the numpy (logp, grad) interface hmc() expects."""
    def f(x):
        xt = torch.tensor(x, requires_grad=True)
        lp = logp_torch(xt)
        g, = torch.autograd.grad(lp.sum(), xt)
        return lp.detach().numpy(), g.numpy()
    return f

rng = np.random.default_rng(6)
n_lr, p_lr = 400, 12
Z = rng.standard_normal((n_lr, p_lr)) @ np.linalg.cholesky(0.5 * np.eye(p_lr) + 0.5).T   # correlated features
Xd = np.column_stack([np.ones(n_lr), Z])
beta_true = rng.normal(0, 0.7, p_lr + 1)
y_lr = (rng.random(n_lr) < special.expit(Xd @ beta_true)).astype(float)
Xt, yt = torch.tensor(Xd), torch.tensor(y_lr)

def lp_logit_torch(B):                                       # B: (C, 13) -> (C,)
    eta = B @ Xt.T
    return (yt * eta - torch.nn.functional.softplus(eta)).sum(1) - 0.5 * (B ** 2).sum(1) / 2.5 ** 2

lp_logit = autograd(lp_logit_torch)
B_test = rng.normal(0, 1, (3, 13))
g_hand = (y_lr - special.expit(B_test @ Xd.T)) @ Xd - B_test / 2.5 ** 2
print(f"autograd vs hand-derived gradient X^T(y - sigmoid) - B / tau^2: max diff {np.abs(lp_logit(B_test)[1] - g_hand).max():.1e}")

def lp_np(B):
    eta = B @ Xd.T
    return (y_lr * eta - np.logaddexp(0, eta)).sum(1) - 0.5 * np.sum(B ** 2, 1) / 2.5 ** 2
mode = optimize.minimize(lambda b: -lp_np(b[None])[0], np.zeros(13), method="BFGS").x

q_is = stats.multivariate_t(mode, S_lap, df=5)               # reference by importance sampling (ch. 3)

wt = np.exp(lw - special.logsumexp(lw))
ref_mean, ref_sd = wt @ xs, np.sqrt(wt @ (xs - wt @ xs) ** 2)
print(f"IS reference: effective sample size {1 / np.sum(wt ** 2):.0f} of 100000")

def report(name, draws, cost, acc):

    z = np.abs(draws.reshape(-1, 13).mean(0) - ref_mean) / (ref_sd / np.sqrt(e))
    print(f"{name:30} accept {acc:.3f} | min ESS {e.min():6.0f} | ESS per eval/grad {e.min() / cost:.4f} | "
          f"max |err|/MCSE {z.max():.2f}")

x0 = mode + 0.5 * rng.standard_normal((4, 13))

report("RWM, Laplace covariance", out[2000:], 4 * 18_000, acc)
xw, Minv_lr, eps_lr, ng_w = warmup(lp_logit, x0, "dense", lambda M: 1.5 * np.sqrt(np.max(M)), rng=rng)
```

## How the cost grows with dimension

A random walk in 100 dimensions needs about 50 times as many steps per independent draw as in 2
dimensions. HMC needs only slightly more. This section measures that.

The scaling theory is the reason HMC exists. For product targets, optimally tuned RWM needs
$O(d)$ density evaluations per independent draw (ch. 4). MALA, one Langevin step with a gradient, needs $O(d^{1/3})$. HMC needs
$O(d^{1/4})$ gradients (Beskos et al., 2013).

### Where $d^{1/4}$ comes from

This shows why the step size only has to shrink like $d^{-1/4}$. Leapfrog's local energy error per unit time is $O(\varepsilon^2)$ per coordinate. Over a trajectory
of fixed length $T$, the per-coordinate errors behave like independent terms with mean
$O(\varepsilon^4)$ and comparable variance, so $\Delta H$ summed over $d$ coordinates has mean and
variance $O(d\,\varepsilon^4)$. Acceptance stays bounded away from zero iff $d\,\varepsilon^4 = O(1)$,
so $\varepsilon \propto d^{-1/4}$, and a fixed $T$ costs $T/\varepsilon \propto d^{1/4}$ gradients.

The experiment uses $\mathcal{N}(0, I_d)$, $d$ from 2 to 100. RWM uses the optimal $2.38/\sqrt{d}$ scale.
HMC uses dual-averaged $\varepsilon$ and a jittered $T = 1.5$. Cost per independent draw is measured
on the worse of $x_j$ and $x_j^2$ for the first five coordinates.

## Divergences: when the integrator breaks

The stability limit $\varepsilon < 2\sigma$ is *local*. In a posterior whose curvature varies, a
step size tuned to the bulk can be unstable in a small region of high curvature, and in that region
the energy error explodes rather than oscillating. Stan calls a transition **divergent** when the energy
error along the trajectory exceeds a threshold (1000 here, as in Stan). A divergence is not a numerical nuisance.
It tells you the sampler cannot enter that region, so expectations computed from your draws are
**biased**, not just noisy.

Neal's funnel is the canonical example and the prototype of every hierarchical model (ch. 10):
$v \sim \mathcal{N}(0, 3)$, $x_i \mid v \sim \mathcal{N}(0, e^{v/2})$ for $i = 1..9$. At $v = -5$
the $x$-scale is $e^{-2.5} \approx 0.08$, so the stable step size there is about 0.16. At $v = 5$
the $x$-scale is 12. No single step size works everywhere. The **non-centred** parameterisation samples
$\tilde v, z_i \sim \mathcal{N}(0, 1)$ and computes $v = 3\tilde v$, $x_i = e^{v/2} z_i$ afterwards.
Same model, but the geometry the sampler sees is an isotropic Gaussian.


## NUTS: let the trajectory decide when to stop

Too short a trajectory wastes the momentum, and too long a trajectory comes back to where it started. NUTS keeps
integrating until the path starts heading back toward its start, then stops, so you never choose
$T$ yourself.

The step-size and resonance tables showed that the best $T$ depends on the target, the statistic, and the
region of the posterior. The No-U-Turn Sampler (Hoffman & Gelman, 2014) picks the trajectory length
per iteration, adaptively, without breaking detailed balance.

### The U-turn criterion

This shows how to detect, from the two ends alone, that a trajectory has started coming back. The squared distance from the start grows at rate

$$
\frac{d}{dt}\,\frac{1}{2}\lVert q(t) - q(0)\rVert^2 = \bigl(q(t) - q(0)\bigr)^\top \frac{dq}{dt} = \bigl(q(t) - q(0)\bigr)^\top M^{-1} p(t)
$$

When this goes negative, the trajectory has started coming back and further simulation is wasted.
NUTS applies the check symmetrically to both ends of a trajectory $[q^-, q^+]$. It stops when
$(q^+ - q^-)^\top M^{-1} p^- < 0$ or $(q^+ - q^-)^\top M^{-1} p^+ < 0$. Stan uses a generalised
version that replaces $q^+ - q^-$ by the sum of momenta along the trajectory, which also works on
non-Euclidean metrics. The idea is the same.

### Doubling keeps it reversible

This explains why NUTS grows the trajectory by doubling. Stopping "when you U-turn" naively breaks detailed balance, because the trajectory you would build
from the end point is not the one you built from the start. NUTS restores the symmetry by building
the trajectory as a **random binary tree**. At each depth $j$ it picks a direction (forward or backward
in time) with probability 1/2 and integrates $2^j$ new steps from that end, doubling the length.
Any point on the final trajectory could have generated the same trajectory with the same probability,
*except* that a new subtree which contains a U-turn among its own balanced sub-trees must be thrown
away. From some of its points the trajectory would have stopped earlier. Those internal checks are
the inner loop of the code below.

### Choosing the next state: multinomial sampling

This explains how one state is picked from the whole trajectory. Every state on the trajectory has weight $e^{-H}$. Choosing among them in proportion to that weight
is a valid transition, a generalisation of the Metropolis step to many candidates (Betancourt,
2017). The original NUTS used slice sampling for this. Modern Stan uses the multinomial version. It also
biases the choice toward the newest subtree: it moves to the new subtree's candidate with probability
$\min(1, W_{\text{new}}/W_{\text{old}})$, which favours states far from the start and stays valid.
Divergences end the tree too: a step with energy error above 1000 stops the iteration and is
flagged. The implementation below is a compact single-chain version of that scheme. It is tuned
with the same dual averaging, using the mean acceptance statistic over the trajectory, and then
compared with fixed-length HMC across a range of $T$ on the 50-dimensional target.

```python
def nuts(logp_grad, x0, n_iter, eps, Minv=None, max_depth=10, rng=rng, adapt=None):
    """Multinomial NUTS, one chain. logp_grad(x (d,)) -> (logp, grad)."""
    x = np.array(x0, float); d = len(x)
    Minv = np.ones(d) if Minv is None else np.asarray(Minv, float)
    lp, g = logp_grad(x)
    out = np.empty((n_iter, d)); stats_ = np.empty((n_iter, 4))
    for t in range(n_iter):
        e = adapt.eps if adapt is not None else eps
        p0 = rng.standard_normal(d) / np.sqrt(Minv)
        H0 = -lp + 0.5 * np.sum(p0 * p0 * Minv)
        ends = {-1: (x, p0, g), 1: (x, p0, g)}             # (q, p, grad) at the backward / forward end
        sample, logW = (x, lp, g), 0.0                      # initial point has weight exp(0)
        n_steps, acc_sum, div, depth = 0, 0.0, False, 0
        for depth in range(max_depth):
            v = 1 if rng.random() < 0.5 else -1
            q, p, gq = ends[v]
            sub, logw_sub, cand, ok = [], -np.inf, None, True
            for s in range(2 ** depth):                      # extend by 2^depth leapfrog steps
                p = p + 0.5 * v * e * gq
                q = q + v * e * Minv * p
                lq, gq = logp_grad(q)
                p = p + 0.5 * v * e * gq
                n_steps += 1
                dH = -lq + 0.5 * np.sum(p * p * Minv) - H0
                dH = np.inf if np.isnan(dH) else dH
                acc_sum += min(1.0, np.exp(-dH))
                if dH > 1000:
                    div, ok = True, False; break
                sub.append((q, p))
                logw_new = np.logaddexp(logw_sub, -dH)
                if np.log(rng.random()) < -dH - logw_new:    # multinomial choice within the subtree
                    cand = (q, lq, gq)
                logw_sub = logw_new
                k = 1                                         # U-turn checks on every completed sub-subtree
                while (s + 1) % 2 ** k == 0 and k <= depth:
                    a, b = sub[s + 1 - 2 ** k], sub[s]
                    lo, hi = (a, b) if v == 1 else (b, a)
                    dq = hi[0] - lo[0]
                    if dq @ (Minv * lo[1]) < 0 or dq @ (Minv * hi[1]) < 0:
                        ok = False; break
                    k += 1
                if not ok: break
            if not ok:
                break                                         # discard the offending subtree
            if np.log(rng.random()) < logw_sub - logW:        # biased progressive sampling
                sample = cand
            logW = np.logaddexp(logW, logw_sub)
            ends[v] = (q, p, gq)
            dq = ends[1][0] - ends[-1][0]
            if dq @ (Minv * ends[-1][1]) < 0 or dq @ (Minv * ends[1][1]) < 0:
                break                                         # whole trajectory U-turned
        x, lp, g = sample
        out[t] = x
        stats_[t] = (acc_sum / n_steps, n_steps, depth, div)
        if adapt is not None:
            adapt.update(acc_sum / n_steps)
    return out, stats_


def run_nuts(logp_grad1, x0s, n_warm, n_iter, delta=0.8, Minv=None, rng=rng):
    draws, st_all = [], []
    for x0 in x0s:                                           # chains run one after another
        da = DualAveraging(0.5, delta=delta)
        w, _ = nuts(logp_grad1, x0, n_warm, None, Minv, rng=rng, adapt=da)
        out, st = nuts(logp_grad1, w[-1], n_iter, da.final, Minv, rng=rng)
        draws.append(out); st_all.append(st)
    return np.stack(draws, 1), np.concatenate(st_all), da.final

rng = np.random.default_rng(9)
one = lambda f: (lambda x: tuple(a[0] for a in f(x[None])))  # (C, d) interface -> single-chain interface

      f"tree depth counts {np.bincount(st[:, 2].astype(int)).tolist()}")
```

## Try it Yourself

A complete HMC sampler in 20 lines on an equicorrelated 20-dimensional Gaussian: a narrow direction
with scale 0.32 and a wide one (the sum of the coordinates) with scale 4.25. The last line of output
checks a useful identity. Because the leapfrog map preserves volume and is reversible, $\mathbb{E}[e^{-\Delta H}] = 1$
at stationarity. A value far from 1 means a bug in the gradient or the integrator.

```python
import numpy as np

rng = np.random.default_rng(42)
d, rho = 20, 0.9                             # equicorrelated Gaussian; try rho = 0.99 or d = 100
Sigma = rho * np.ones((d, d)) + (1 - rho) * np.eye(d)
P = np.linalg.inv(Sigma)
logp = lambda q: -0.5 * q @ P @ q
grad = lambda q: -P @ q

eps, L, n_iter = 0.1, 30, 2000               # try eps = 0.3, 0.6, 0.7 and L = 5, 60
print(f"scales: smallest {np.sqrt(1 - rho):.3f} (stability limit eps < {2 * np.sqrt(1 - rho):.3f}), "
      f"largest {np.sqrt(1 + (d - 1) * rho):.2f}")
q, draws, acc, dHs = rng.standard_normal(d), [], 0, []
for t in range(n_iter):
    p = rng.standard_normal(d)
    H0 = -logp(q) + 0.5 * p @ p
    n_steps = rng.integers(L // 2, 3 * L // 2 + 1)            # jittered path length
    qn, pn = q.copy(), p + 0.5 * eps * grad(q)
    for s in range(n_steps):
        qn = qn + eps * pn
        pn = pn + (eps if s < n_steps - 1 else 0.5 * eps) * grad(qn)
    dH = -logp(qn) + 0.5 * pn @ pn - H0
    dHs.append(dH)
    if np.log(rng.random()) < -dH:
        q, acc = qn, acc + 1
    draws.append(q)
draws, dHs = np.array(draws[200:]), np.array(dHs)
tot = draws.sum(1)                                            # the slowest direction
ac = lambda z: np.corrcoef(z[:-1], z[1:])[0, 1]
print(f"accept {acc / n_iter:.3f} | mean |dH| {np.abs(dHs).mean():.3f} | E[exp(-dH)] {np.exp(-dHs).mean():.3f} (theory 1)")
print(f"Var(sum x) {tot.var():.1f} (truth {d + d * (d - 1) * rho:.1f}) | lag-1 autocorr: x1 {ac(draws[:, 0]):+.3f}, sum x {ac(tot):+.3f}")
```
