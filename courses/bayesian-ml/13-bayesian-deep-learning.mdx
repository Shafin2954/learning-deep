## Two kinds of not knowing

A weather forecaster can be unsure for two reasons. Tomorrow may be genuinely chaotic (more data would not help), or
the forecaster may never have seen this kind of sky before (more data would). The first is **aleatoric** uncertainty,
noise in $y$ given $x$; the second is **epistemic** uncertainty, ignorance about the function itself, which a Bayesian
writes as a posterior $p(\theta \mid \mathcal D)$ over the network weights $\theta$ given data $\mathcal D$. Two
synthetic problems make the difference visible: 1-D regression of $f(x) = x\sin x$ with noise that grows with $|x|$ and
**no training data for** $|x| < 1.5$, and 2-D two-moons classification with a ring of inputs far from both moons.

```python
import copy
import numpy as np, torch, torch.nn as nn, torch.nn.functional as F
from sklearn.datasets import make_moons
from sklearn.metrics import roc_auc_score
torch.set_num_threads(1)

f = lambda x: x * np.sin(x)                               # true regression function
noise_sd = lambda x: 0.1 + 0.25 * np.abs(x) / 4           # aleatoric sd: 0.10 at x = 0, 0.35 at |x| = 4
rng = np.random.default_rng(0)
def draw(n):                                              # x in [-4, -1.5] U [1.5, 4]: no data in the middle
    x = rng.uniform(1.5, 4.0, n) * rng.choice([-1, 1], n)
    return x, f(x) + noise_sd(x) * rng.standard_normal(n)
xtr, ytr = draw(160); xte, yte = draw(1000)
xgap = rng.uniform(-1.5, 1.5, 1000); ygap = f(xgap) + noise_sd(xgap) * rng.standard_normal(1000)
T = lambda a: torch.tensor(a, dtype=torch.float32).reshape(len(a), -1)
Xtr, Ytr, Xte, Yte, Xgap, Ygap = map(T, (xtr, ytr, xte, yte, xgap, ygap))

xc_tr, yc_tr = make_moons(400, noise=0.2, random_state=0)            # 2-D classification
xc_te, yc_te = make_moons(1000, noise=0.2, random_state=1)
ang, rad = rng.uniform(0, 2 * np.pi, 1000), rng.uniform(2.5, 4.5, 1000)
xc_ood = np.c_[0.5 + rad * np.cos(ang), 0.25 + rad * np.sin(ang)]   # a ring of inputs far from both moons
Xc_tr, Yc_tr, Xc_te, Xc_ood = T(xc_tr), T(yc_tr), T(xc_te), T(xc_ood)
dist = np.sqrt(((xc_ood[:, None] - xc_tr[None]) ** 2).sum(-1)).min(1)
print(f"regression: {len(xtr)} train points, |x| in [{np.abs(xtr).min():.2f}, {np.abs(xtr).max():.2f}], "
      f"gap test set x in [-1.5, 1.5], truth there ranges {f(xgap).min():.2f} .. {f(xgap).max():.2f}")
print(f"classification: {len(xc_tr)} train points, class balance {yc_tr.mean():.2f}, "
      f"OOD ring distance to nearest train point {dist.min():.2f} .. {dist.max():.2f}")
```

```output
regression: 160 train points, |x| in [1.51, 3.99], gap test set x in [-1.5, 1.5], truth there ranges 0.00 .. 1.50
classification: 400 train points, class balance 0.50, OOD ring distance to nearest train point 0.63 .. 3.62
```

The gap is where $f$ dips from 1.5 to 0 and back, so a network that bridges it smoothly is wrong there and should say
so. The OOD ring starts 0.63 from the nearest training point and reaches 3.6 away.

## A heteroscedastic head learns the noise, not the ignorance

Make the network output two numbers per input, a mean $\mu(x)$ and a log-variance $\log\sigma^2(x)$, and it can say
"the data here are noisy" by itself. That handles aleatoric noise. It cannot say "I have never been here", because
$\sigma^2(x)$ is just another function the optimiser fits to the training points and extrapolates however it likes.

### Deriving the Gaussian negative log-likelihood

This derivation shows the loss the two-headed network minimises. Under $y_i \sim \mathcal N(\mu(x_i), \sigma^2(x_i))$
the negative log-likelihood of point $i$ is

$$
-\log p(y_i \mid x_i) = \tfrac12\log 2\pi + \tfrac12\log\sigma^2(x_i) + \frac{(y_i-\mu(x_i))^2}{2\sigma^2(x_i)} .
$$

Setting its derivative in $\sigma^2$ to zero gives $\sigma^2(x_i) = (y_i - \mu(x_i))^2$: the variance head learns the local
squared residual; the $\log\sigma^2$ term stops it claiming infinite noise everywhere.

```python
def reg_net(p=0.0, h=50):                                 # 1 -> 50 tanh -> (mean, log-variance)
    return nn.Sequential(nn.Linear(1, h), nn.Tanh(), nn.Dropout(p), nn.Linear(h, 2))
def cls_net(p=0.0, h=64):                                 # 2 -> 64 -> 64 ReLU -> logit
    return nn.Sequential(nn.Linear(2, h), nn.ReLU(), nn.Dropout(p),
                         nn.Linear(h, h), nn.ReLU(), nn.Dropout(p), nn.Linear(h, 1))
def gnll(out, y):                                         # mean Gaussian NLL with per-point variance
    mu, lv = out[:, :1], out[:, 1:]
    return 0.5 * (np.log(2 * np.pi) + lv + (y - mu) ** 2 / lv.exp()).mean()
bce = lambda out, y: F.binary_cross_entropy_with_logits(out, y)
def train(make, X, Y, loss, steps, seed=0, lr=1e-2, wd=1e-3):
    torch.manual_seed(seed); net = make()
    opt = torch.optim.AdamW(net.parameters(), lr=lr, weight_decay=wd)
    for _ in range(steps):
        opt.zero_grad(); loss(net(X), Y).backward(); opt.step()
    return net.eval()
REG_STEPS, CLS_STEPS = 1500, 600

point = train(reg_net, Xtr, Ytr, gnll, REG_STEPS)
xs = np.array([-3.5, -2.5, -1.5, -0.75, 0.0, 0.75, 1.5, 2.5, 3.5])
with torch.no_grad():
    o = point(T(xs)); mu, sd = o[:, 0].numpy(), (0.5 * o[:, 1]).exp().numpy()
print(f"{'x':>6} {'f(x)':>6} {'mean':>6} {'|err|':>6} {'true sd':>8} {'pred sd':>8} {'|err|/sd':>9}")
for x, m, s in zip(xs, mu, sd):
    print(f"{x:6.2f} {f(x):6.2f} {m:6.2f} {abs(m - f(x)):6.2f} {noise_sd(x):8.2f} {s:8.2f} {abs(m - f(x)) / s:9.1f}")
```

## A point network is overconfident off the data

Classifiers fail the same way, and ReLU networks fail worst. A ReLU net is piecewise linear, so far from the data the
logit grows linearly with distance and the sigmoid saturates (Hein et al. 2019 prove this happens for almost every
direction). Walk straight out from the moons and watch the confidence.

```python
cpoint = train(cls_net, Xc_tr, Yc_tr, bce, CLS_STEPS)
with torch.no_grad():
    p_te, p_ood = torch.sigmoid(cpoint(Xc_te))[:, 0].numpy(), torch.sigmoid(cpoint(Xc_ood))[:, 0].numpy()
    logit_ood = cpoint(Xc_ood)[:, 0].abs().numpy()
conf = lambda p: np.maximum(p, 1 - p)
print(f"in-distribution test: accuracy {np.mean((p_te > 0.5) == yc_te):.3f} | mean confidence {conf(p_te).mean():.3f}")
print(f"OOD ring:             mean confidence {conf(p_ood).mean():.3f} | share above 0.99 {np.mean(conf(p_ood) > 0.99):.2f}"
      f" | median |logit| {np.median(logit_ood):.1f}")
for r in (3, 6, 12, 24):                                  # walk straight out along one direction
    with torch.no_grad():
        z = cpoint(T(np.array([[0.5 + r * 0.6, 0.25 + r * 0.8]])))[0, 0].item()
    print(f"distance {r:2d} from centre: logit {z:+8.1f}, confidence {conf(1 / (1 + np.exp(-z))):.4f}")
```

## The law of total variance splits what you see

If you have several plausible networks, each with its own noise estimate, your total uncertainty is the average noise
plus how much the networks disagree. That one identity is how every method below reports uncertainty, so it is worth
having exactly. Throughout, a method is a **sampler**: it returns $S$ draws of the network output, from an ensemble, a
dropout mask, or a weight posterior.

### Deriving the decomposition

This derivation shows the predictive variance splits into an aleatoric and an epistemic part. The predictive
distribution averages the likelihood over the posterior, $p(y \mid x, \mathcal D) = \int p(y\mid x,\theta)\,p(\theta\mid
\mathcal D)\,d\theta$, which with draws $\theta_s$ is a mixture of $S$ Gaussians. The law of total variance, conditioning
on $\theta$, gives

$$
\mathrm{Var}(y \mid x) = \mathbb E\big[\mathrm{Var}(y\mid x,\theta)\big] + \mathrm{Var}\big(\mathbb E[y\mid x,\theta]\big)
= \underbrace{\mathbb E_\theta\big[\sigma^2_\theta(x)\big]}_{\text{aleatoric}} + \underbrace{\mathrm{Var}_\theta\big[\mu_\theta(x)\big]}_{\text{epistemic}} .
$$

Proof: $\mathrm{Var}(y) = \mathbb E[y^2] - \mathbb E[y]^2 = \mathbb E_\theta\big[\sigma^2_\theta + \mu^2_\theta\big] -
(\mathbb E_\theta \mu_\theta)^2$, and the last two terms are $\mathrm{Var}_\theta(\mu_\theta)$. The epistemic term
vanishes for one network, and it is the term that should grow in the gap. For classification the analogue is total
entropy $\mathrm H[\bar p]$ = expected entropy + mutual information; the helpers also score the variance of the logit
across draws, the epistemic part measured before the sigmoid can saturate it. The predictive NLL is the exact mixture
log-density, and the gap AUROC asks whether epistemic sd ranks gap inputs above in-data inputs.

```python
RES, REG, CLS = {}, {}, {}                                # metrics, regression samplers, classifier samplers
def reg_eval(name, sampler):                              # sampler(X) -> (S, N, 2): S draws of (mean, log-var)
    REG[name] = sampler; row = {}
    for tag, X, Y in (("test", Xte, Yte), ("gap", Xgap, Ygap)):
        torch.manual_seed(0)
        with torch.no_grad(): o = sampler(X)
        mu, va, y = o[..., 0], o[..., 1].exp(), Y[:, 0]
        epi = mu.var(0, unbiased=False)                   # Var over draws of the mean
        ll = torch.logsumexp(-0.5 * (np.log(2 * np.pi) + va.log() + (y - mu) ** 2 / va), 0) - np.log(len(o))
        row[tag] = dict(nll=-ll.mean().item(), rmse=(mu.mean(0) - y).pow(2).mean().sqrt().item(),
                        epi=epi.sqrt().mean().item(), alea=va.mean(0).sqrt().mean().item(), score=epi.numpy())
    t, g = row["test"], row["gap"]
    auc = roc_auc_score(np.r_[np.zeros(1000), np.ones(1000)], np.r_[t["score"], g["score"]])
    RES.setdefault(name, {}).update(r_nll=t["nll"], r_rmse=t["rmse"], gap_nll=g["nll"], epi_t=t["epi"],
                                    epi_g=g["epi"], r_auc=auc)
    print(f"{name:13} test NLL {t['nll']:5.2f} RMSE {t['rmse']:.3f} | sd alea {t['alea']:.3f} epi {t['epi']:.3f}"
          f" | gap NLL {g['nll']:6.2f} epi {g['epi']:.3f} ({g['epi'] / max(t['epi'], 1e-9):5.1f}x) | AUROC {auc:.3f}")

H2 = lambda p: -(p * np.log(p) + (1 - p) * np.log(1 - p))
def ece(p, y, bins=10):                                   # equal-width bins on confidence (Evaluation & Tuning, ch. 4)
    c = np.maximum(p, 1 - p); hit = (p > 0.5) == y; b = np.minimum(((c - 0.5) * 2 * bins).astype(int), bins - 1)
    return sum(abs(c[b == k].mean() - hit[b == k].mean()) * np.mean(b == k) for k in range(bins) if np.any(b == k))
def cls_eval(name, sampler):                              # sampler(X) -> (S, N, 1) logits
    CLS[name] = sampler; torch.manual_seed(0)
    with torch.no_grad(): zt, zo = sampler(Xc_te)[..., 0], sampler(Xc_ood)[..., 0]
    pt, po = torch.sigmoid(zt).mean(0).double().clamp(1e-7, 1 - 1e-7).numpy(), torch.sigmoid(zo).mean(0).double().clamp(1e-7, 1 - 1e-7).numpy()
    nll = -np.mean(yc_te * np.log(pt) + (1 - yc_te) * np.log(1 - pt))
    lab = np.r_[np.zeros(1000), np.ones(1000)]
    auc_h = roc_auc_score(lab, np.r_[H2(pt), H2(po)])
    auc_v = roc_auc_score(lab, np.r_[zt.var(0, unbiased=False).numpy(), zo.var(0, unbiased=False).numpy()])
    RES.setdefault(name, {}).update(c_nll=nll, acc=np.mean((pt > 0.5) == yc_te), ece=ece(pt, yc_te),
                                    auc_h=auc_h, auc_v=auc_v, conf_ood=np.maximum(po, 1 - po).mean())
    r = RES[name]
    print(f"{name:13} NLL {nll:.3f} acc {r['acc']:.3f} ECE {r['ece']:.3f} | OOD conf {r['conf_ood']:.3f}"
          f" | AUROC entropy {auc_h:.3f} logit-var {auc_v:.3f}")

reg_eval("point", lambda X: point(X)[None])
cls_eval("point", lambda X: cpoint(X)[None])
```

```output
point         test NLL  0.20 RMSE 0.281 | sd alea 0.252 epi 0.000 | gap NLL   2.40 epi 0.000 (  0.0x) | AUROC 0.500
point         NLL 0.215 acc 0.949 ECE 0.038 | OOD conf 0.986 | AUROC entropy 0.352 logit-var 0.500
```

A single network has zero epistemic variance by construction, so it cannot rank gap or OOD inputs (AUROC 0.500), and
its gap NLL is 2.40 against 0.20 on test data. Entropy AUROC is 0.352, *below* chance: the in-distribution moons overlap,
so boundary test points have high aleatoric entropy, while the OOD ring is saturated at confidence 1.

## Deep ensembles: train it five times

The simplest posterior approximation is to train the same network five times from different random inits and treat the
five as posterior draws (Lakshminarayanan, Pritzel and Blundell 2017). Where data pin the function down, all five agree;
in the gap each init settles into a different bridge, and that disagreement is the epistemic term.

```python
ens_r = [point] + [train(reg_net, Xtr, Ytr, gnll, REG_STEPS, seed=s) for s in range(1, 5)]
ens_c = [cpoint] + [train(cls_net, Xc_tr, Yc_tr, bce, CLS_STEPS, seed=s) for s in range(1, 5)]
reg_eval("ensemble", lambda X: torch.stack([m(X) for m in ens_r]))
cls_eval("ensemble", lambda X: torch.stack([m(X) for m in ens_c]))
```

```output
ensemble      test NLL  0.21 RMSE 0.283 | sd alea 0.252 epi 0.013 | gap NLL   0.92 epi 0.142 ( 11.1x) | AUROC 0.989
ensemble      NLL 0.191 acc 0.948 ECE 0.034 | OOD conf 0.948 | AUROC entropy 0.312 logit-var 0.983
```

On the data the members agree (epistemic sd 0.013); in the gap epistemic sd is 11 times larger, gap NLL drops from
2.40 to 0.92 and the gap AUROC is 0.989, at no cost in test RMSE. On the OOD ring the logit-variance AUROC is 0.983.
Ensembles are not Bayesian in the strict sense (no prior, no weighting), but each member sits in a different basin, and
covering several modes is what the local methods below cannot do. That is why they are usually the strongest baseline.

## MC dropout: a free ensemble with a blind spot

Dropout zeroes each hidden unit with probability $p$ during training. Gal and Ghahramani (2016) showed that leaving
it on at test time and averaging $S$ stochastic passes is approximate Bayesian inference: each mask is one draw of a
thinned network. It costs one network and $S$ forward passes.

### What dropout approximates

This section shows which posterior dropout corresponds to. Write each weight row as $W_j = z_j M_j$ with
$z_j \sim \mathrm{Bernoulli}(1-p)$ and learnable $M_j$: that is a variational family $q(W)$, a spike at zero and a spike
at $M_j$. Gal and Ghahramani show that dropout training with weight decay $\lambda$ minimises, up to constants, the
negative ELBO (ch. 11) $-\mathbb E_q[\log p(\mathcal D\mid W)] + \mathrm{KL}(q \,\|\, p)$ with a Gaussian prior whose
precision is tied to $\lambda$ and $p$. The catch is the family: the spread of $q$ is fixed by $p$, not learned from the
data, so the uncertainty it produces has roughly the same size everywhere.

```python
mcd_r = train(lambda: reg_net(p=0.1), Xtr, Ytr, gnll, 2 * REG_STEPS).train()      # train(): dropout stays on
mcd_c = train(lambda: cls_net(p=0.1), Xc_tr, Yc_tr, bce, 2 * CLS_STEPS).train()
reg_eval("MC dropout", lambda X: torch.stack([mcd_r(X) for _ in range(100)]))
cls_eval("MC dropout", lambda X: torch.stack([mcd_c(X) for _ in range(100)]))
```

```output
MC dropout    test NLL  0.36 RMSE 0.295 | sd alea 0.398 epi 0.249 | gap NLL   2.80 epi 0.288 (  1.2x) | AUROC 0.832
MC dropout    NLL 0.190 acc 0.957 ECE 0.031 | OOD conf 0.981 | AUROC entropy 0.344 logit-var 0.920
```

The blind spot is visible in the ratio: epistemic sd is 0.249 on the data and 0.288 in the gap, only 1.2 times larger,
and the gap NLL (2.80) is no better than the point network. Dropout noise inflates uncertainty *everywhere* (test NLL
worsens from 0.20 to 0.36) instead of where data are missing, which is the in-between-uncertainty failure Foong et al.
(2019) proved for dropout and mean-field Gaussians on exactly this kind of gap. On the ring, logit variance still
detects OOD (0.920).

## Bayes by Backprop: a Gaussian over every weight

Bayes by Backprop (Blundell et al. 2015) gives every weight its own Gaussian, $q(w_k) = \mathcal N(m_k, s_k^2)$, and
learns all $2P$ numbers by gradient descent on the ELBO (ch. 11). Doubling the parameter count buys an explicit,
learned uncertainty per weight.

### The ELBO for network weights

This derivation gives the loss that the code minimises. With prior $p(w) = \mathcal N(0, \sigma_p^2 I)$ and $N$ training
points, the negative ELBO divided by $N$ is

$$
\mathcal L(m, \rho) = \frac{1}{N}\Big(-\mathbb E_{q}\big[\log p(\mathcal D \mid w)\big] + \mathrm{KL}(q\,\|\,p)\Big),
\qquad w = m + \mathrm{softplus}(\rho)\odot\varepsilon,\ \ \varepsilon \sim \mathcal N(0, I).
$$

The reparameterisation moves the randomness into $\varepsilon$, so one draw gives an unbiased gradient of the expectation.
For Gaussians the KL is closed form per weight, with $s = \mathrm{softplus}(\rho)$:

$$
\mathrm{KL}\big(\mathcal N(m, s^2)\,\|\,\mathcal N(0, \sigma_p^2)\big) = \log\frac{\sigma_p}{s} + \frac{s^2 + m^2}{2\sigma_p^2} - \frac12 .
$$

The KL charges every weight for moving away from the prior, and with 160 points the likelihood has little to pay with.

```python
class BayesLinear(nn.Module):                             # q(w) = N(mu, softplus(rho)^2), mean-field
    def __init__(self, d_in, d_out, prior_sd=1.0):
        super().__init__()
        self.mu = nn.Parameter(torch.randn(d_in + 1, d_out) / np.sqrt(d_in))   # last row is the bias
        self.rho = nn.Parameter(torch.full((d_in + 1, d_out), -5.0))
        self.prior_sd = prior_sd
    def forward(self, x):
        w = self.mu + F.softplus(self.rho) * torch.randn_like(self.mu)          # reparameterisation (ch. 11)
        return x @ w[:-1] + w[-1]
    def kl(self):                                         # KL(q || N(0, prior_sd^2)) in closed form
        s, p = F.softplus(self.rho), self.prior_sd
        return (torch.log(p / s) + (s ** 2 + self.mu ** 2) / (2 * p ** 2) - 0.5).sum()
class BBBNet(nn.Module):
    def __init__(self, sizes, act):
        super().__init__(); self.layers, self.act = nn.ModuleList(BayesLinear(a, b) for a, b in zip(sizes, sizes[1:])), act
    def forward(self, x):
        for l in self.layers[:-1]: x = self.act(l(x))
        return self.layers[-1](x)
    def kl(self): return sum(l.kl() for l in self.layers)
def train_bbb(sizes, act, X, Y, loss, steps=5000, lr=1e-2, kl_weight=1.0):
    torch.manual_seed(0); net = BBBNet(sizes, act)
    opt = torch.optim.Adam(net.parameters(), lr=lr); sch = torch.optim.lr_scheduler.CosineAnnealingLR(opt, steps, lr / 100)
    for _ in range(steps):
        opt.zero_grad(); (loss(net(X), Y) + kl_weight * net.kl() / len(X)).backward(); opt.step(); sch.step()
    return net
bbb_r = train_bbb([1, 50, 2], torch.tanh, Xtr, Ytr, gnll)
bbb_c = train_bbb([2, 64, 64, 1], torch.relu, Xc_tr, Yc_tr, bce)
reg_eval("BBB", lambda X: torch.stack([bbb_r(X) for _ in range(200)]))
cls_eval("BBB", lambda X: torch.stack([bbb_c(X) for _ in range(200)]))
sd_all = torch.cat([F.softplus(l.rho).flatten() for l in bbb_r.layers])
print(f"regression q: {len(sd_all)} weights, posterior sd median {sd_all.median():.3f}, "
      f"share with sd > 0.5 (prior-like) {(sd_all > 0.5).float().mean():.2f}, KL {bbb_r.kl().item():.0f} nats")
```

```output
BBB           test NLL  0.81 RMSE 0.396 | sd alea 0.809 epi 0.410 | gap NLL   2.74 epi 0.334 (  0.8x) | AUROC 0.008
BBB           NLL 0.135 acc 0.958 ECE 0.037 | OOD conf 0.904 | AUROC entropy 0.426 logit-var 1.000
regression q: 202 weights, posterior sd median 0.169, share with sd > 0.5 (prior-like) 0.18, KL 280 nats
```

Classification is BBB's best result here: NLL 0.135, the lowest in the chapter, and logit-variance AUROC 1.000.
Regression is its worst. The KL (280 nats against 160 data points) keeps 18% of the weights at prior-like sd above 0.5,
the noise head absorbs the misfit (aleatoric sd 0.81 against the true 0.25) and test NLL is 0.81. Worse, epistemic sd
is *smaller* in the gap than on the data (0.8x, AUROC 0.008): mean-field noise is largest where $|x|$ multiplies the
first-layer weight noise, not where data are missing: the Foong et al. failure again.

## Last-layer Laplace: Gaussian around the trained head

Train the network normally, then put a Gaussian only over the last layer, centred at the trained weights and shaped by
the curvature of the loss there. This is the Laplace approximation from ch. 3, made cheap because the last layer of a
50-unit net has 51 weights. Daxberger et al. (2021) found this post-hoc fix competitive with far costlier methods.

### The GGN and the evidence for the last layer

This section shows that for the last layer the Laplace posterior is available in closed form. Write the output as
$z = w^\top\phi(x)$, with $\phi$ the frozen penultimate features plus a 1. The Hessian of the NLL in $w$ is
$\sum_i \phi_i \phi_i^\top \,\partial^2_z \ell_i$, and the generalised Gauss-Newton (GGN) keeps exactly that form with the
always-positive output curvature: $1/\sigma_i^2$ for the Gaussian mean, $p_i(1-p_i)$ for the logistic logit. With prior
$\mathcal N(0, \lambda^{-1} I)$,

$$
q(w) = \mathcal N\big(w_\star,\ \Sigma\big), \qquad \Sigma^{-1} = \sum_i \phi_i\,\phi_i^\top\,\partial^2_z\ell_i + \lambda I,
\qquad \mathrm{Var}[z(x)] = \phi(x)^\top \Sigma\, \phi(x).
$$

The Laplace evidence (ch. 3) chooses $\lambda$ without a validation set:
$\log Z(\lambda) \approx \log p(\mathcal D\mid w_\star) + \frac P2\log\lambda - \frac\lambda2\|w_\star\|^2 - \frac12\log\det\Sigma^{-1}$.

```python
def feats(net, X):                                        # penultimate activations plus a constant 1
    return torch.cat([net[:-1](X), torch.ones(len(X), 1)], 1)
def last_layer_laplace(net, X, curv, loglik):             # curv: per-point second derivative of NLL in the output
    with torch.no_grad():
        Phi = feats(net, X).double(); w = torch.cat([net[-1].weight[0], net[-1].bias[:1]]).double()
        G, I = Phi.T @ (Phi * curv[:, None]), torch.eye(len(w), dtype=torch.float64)
        logZ = lambda lam: (loglik + 0.5 * len(w) * np.log(lam) - 0.5 * lam * (w @ w) - 0.5 * torch.logdet(G + lam * I)).item()
        grid = np.logspace(-3, 2, 21); lam = max(grid, key=logZ)
        L = torch.linalg.cholesky(torch.cholesky_inverse(torch.linalg.cholesky(G + lam * I)))
    return w.float(), L.float(), lam

with torch.no_grad():
    o = point(Xtr); curv_r = (-o[:, 1]).exp().double()                           # 1 / sigma_i^2
    ll_r = -gnll(o, Ytr).item() * len(Xtr)
    zc = cpoint(Xc_tr)[:, 0]; pc = torch.sigmoid(zc).double(); curv_c = pc * (1 - pc)   # p (1 - p)
    ll_c = -bce(cpoint(Xc_tr), Yc_tr).item() * len(Xc_tr)
w_r, L_r, lam_r = last_layer_laplace(point, Xtr, curv_r, ll_r)
w_c, L_c, lam_c = last_layer_laplace(cpoint, Xc_tr, curv_c, ll_c)
print(f"evidence-optimal prior precision: regression {lam_r:.3g}, classification {lam_c:.3g}")
def lla_reg(X, S=200):
    W = w_r + torch.randn(S, len(w_r)) @ L_r.T                                   # (S, 51) head draws
    return torch.stack([W @ feats(point, X).T, point(X)[:, 1].expand(S, -1)], -1)
def lla_cls(X, S=200):
    W = w_c + torch.randn(S, len(w_c)) @ L_c.T
    return (W @ feats(cpoint, X).T)[..., None]
reg_eval("LL-Laplace", lla_reg)
cls_eval("LL-Laplace", lla_cls)
```

evidence-optimal prior precision: regression 0.316, classification 0.178
LL-Laplace    test NLL  0.19 RMSE 0.281 | sd alea 0.252 epi 0.056 | gap NLL   0.60 epi 0.380 (  6.8x) | AUROC 0.996
LL-Laplace    NLL 0.146 acc 0.948 ECE 0.026 | OOD conf 0.938 | AUROC entropy 0.378 logit-var 0.938

For free (no retraining) the gap epistemic sd jumps to 0.380, 6.8 times its in-data value, gap NLL falls to 0.60, the

## Priors in weight space and the cold posterior

Weight-space priors are hard to choose: $\mathcal N(0,1)$ on every weight says nothing intuitive about functions,
and its effect scales with width and depth. Wenzel et al. (2020) found that "cold" posteriors, $p(\theta\mid\mathcal
D)^{1/T}$ with $T < 1$, predict better than the Bayes posterior $T = 1$, which suggests misspecified priors or
likelihoods (data augmentation, curated labels). Izmailov et al. (2021) ran full-batch HMC on ResNets and found the
effect largely vanishes without augmentation. Down-weighting the KL in BBB is the variational version of a cold
posterior.

## Under the Trench

Rare and advanced topics you should at least know the name of. You won't need them daily, but you'll stop being
surprised when you meet them.

- **Empirical Bayes** — estimate prior hyperparameters from the data by maximising the marginal likelihood, as the Laplace $\lambda$ above did.
- **Nonparametric Bayes (Dirichlet process)** — a prior over distributions whose number of clusters grows with the data.
- **Bayesian optimization** — a GP surrogate (ch. 12) plus an acquisition function to minimise expensive black-box functions.
- **PGMs (Bayes nets, MRFs, belief propagation)** — graphs encode conditional independence; message passing computes exact or loopy marginals.
- **Expectation propagation** — fits each likelihood factor by moment matching instead of the reverse KL that VI uses.
- **Stochastic VI & normalizing-flow posteriors** — minibatch natural-gradient VI for huge data, and invertible networks as flexible $q$.
- **Causal Bayesian models & do-calculus** — distinguish $p(y\mid x)$ from $p(y\mid \mathrm{do}(x))$ and identify interventional effects.
- **SMC / particle filters** — weighted, resampled particle populations for sequential posteriors and annealed static ones.
- **Reversible-jump MCMC** — Metropolis-Hastings moves between parameter spaces of different dimension.
- **Bayesian model averaging vs stacking** — BMA weights by evidence and collapses onto one model; stacking optimises predictive weights.
- **Simulation-based inference (ABC, neural posterior estimation)** — inference when you can simulate data but cannot evaluate the likelihood.
- **Stein variational gradient descent** — a set of particles pushed by a kernelised gradient flow toward the posterior.
- **Riemannian HMC** — HMC with a position-dependent metric that adapts to funnels and curved geometry.
- **Bayesian GP-LVM** — a GP mapping from latent inputs, marginalised variationally, for nonlinear dimensionality reduction.
- **Conformal vs Bayesian intervals** — conformal gives distribution-free marginal coverage; Bayesian intervals are conditional and only as good as the model.
