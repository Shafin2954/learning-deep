## The MDP formalism

To reason about decision-making precisely, you write the problem down as five ingredients: the
situations you can be in, the moves you can make, how moves change the situation, what each
move pays, and how much you care about the future.

A **Markov Decision Process** (MDP) is the standard mathematical framework for sequential
decision-making — "sequential" because each decision changes what you face next. It's defined
by the tuple $(S, A, P, R, \gamma)$:

- $S$: state space — every situation the agent can be in.
- $A$: action space — every move it can make.
- $P(s' | s, a)$: transition probability (dynamics model) — the chance of landing in state $s'$ after doing $a$ in $s$.
- $R(s, a, s')$: reward function (often just $R(s, a)$) — the points for that transition.
- $\gamma \in [0,1)$: discount factor — how much a reward one step later is worth today (ch. 1).

The transition dynamics $P(s'|s,a)$ define how the world responds to actions. In model-free RL
you don't know $P$ and must learn from samples. In model-based RL or dynamic programming, you
have $P$ and can plan.

> **Picture it:** a board game with dice. The squares are states, the moves you may choose are
> actions, the dice decide where a move actually lands you (that randomness is $P$), and the
> points printed on squares are rewards. Knowing the rulebook means knowing $P$; learning by
> playing without the rulebook is model-free RL.

## Policies

A policy is the agent's playbook: for each situation, what to do (or how likely it is to do
each thing).

A **policy** $\pi$ maps states to action probabilities: $\pi(a|s) = P(A_t = a | S_t = s)$. A
**deterministic policy** maps each state to exactly one action: $\pi(s) = a$. A policy that
gives probabilities is called **stochastic** — it rolls a die to decide.

The goal: find the policy $\pi^*$ that maximizes expected return $G_t$ from every starting
state. The star means "optimal" — the best possible.

> **Watch out:** "optimal from every starting state" is a strong requirement, yet in a finite
> MDP one policy achieves it in all states at once. You never have to trade off "good from
> here" against "good from there".

## Value functions

A value function answers "how good is it to be here?" — measured as the total reward you can
expect to collect from this point on if you keep playing a certain way.

The **state-value function** $v_\pi(s)$ is the expected return when starting in state $s$ and
following policy $\pi$:

$$
v_\pi(s) = \mathbb{E}_\pi[G_t | S_t = s] = \mathbb{E}_\pi\left[\sum_{k=0}^\infty \gamma^k R_{t+k+1} \,\Big|\, S_t = s\right]
$$

> **In plain words:** $v_\pi(s)$ is the average return over many runs that all start in $s$
> and always pick actions using $\pi$. $\mathbb{E}_\pi$ means "average, when actions come from
> $\pi$"; the sum inside is the return $G_t$ from ch. 1, written out.

The **action-value function** $q_\pi(s, a)$ is the expected return of taking action $a$ in
state $s$, then following $\pi$:

$$
q_\pi(s, a) = \mathbb{E}_\pi[G_t | S_t = s, A_t = a]
$$

> **In plain words:** $q_\pi(s, a)$ asks a slightly different question: "if I do $a$ right now,
> and then play by $\pi$, how much will I collect on average?" It scores a state *and* a first
> move together.

The relationship: $v_\pi(s) = \sum_a \pi(a|s)\, q_\pi(s, a)$. The value of a state is the
average of its action values, weighted by how often the policy picks each action.

> **Picture it:** $v$ is a sign at each crossroads saying "from here, travellers like you get
> 50 points on average". $q$ is a sign on each road leaving the crossroads: "take this road,
> and you get 60; that road, 40". If you take each road half the time, the crossroads sign
> reads $0.5 \cdot 60 + 0.5 \cdot 40 = 50$.

## Bellman equations

The big trick: the value of where you are can be written in terms of the value of where you go
next. Value is "reward now + value of the next spot".

The key insight: value functions satisfy recursive consistency conditions. **Recursive** here
means a quantity defined in terms of itself one step later.

### Bellman expectation equation for $v_\pi$

$$
v_\pi(s) = \sum_a \pi(a|s) \sum_{s', r} p(s', r | s, a)\bigl[r + \gamma\, v_\pi(s')\bigr]
$$

> **In plain words:** to get the value of $s$, consider every action $a$ (weighted by how likely
> $\pi$ is to pick it), every next state $s'$ and reward $r$ (weighted by how likely the world
> is to produce them), and add up "reward now plus discounted value of the next state".
> - $\pi(a|s)$ — chance the policy picks $a$.
> - $p(s', r | s, a)$ — chance the world answers with next state $s'$ and reward $r$.
> - $r + \gamma\, v_\pi(s')$ — what that one outcome is worth.

In words: the value of a state equals the expected immediate reward plus discounted value of
the next state, averaged over actions (under $\pi$) and transitions (under $P$).

### Bellman optimality equations

Swap "average over what the policy would do" for "pick the best action", and you get the
equation the best possible values obey.

The **optimal value functions** $v_*(s) = \max_\pi v_\pi(s)$ and $q_*(s,a) = \max_\pi q_\pi(s,a)$ satisfy:

$$
v_*(s) = \max_a \sum_{s', r} p(s', r | s, a)\bigl[r + \gamma\, v_*(s')\bigr]
$$

> **In plain words:** the best value of $s$ is found by trying every action, computing "average
> reward now plus discounted best value of where you land", and keeping the largest. The only
> change from the expectation equation is that $\sum_a \pi(a|s)$ became $\max_a$.

$$
q_*(s, a) = \sum_{s', r} p(s', r | s, a)\bigl[r + \gamma \max_{a'} q_*(s', a')\bigr]
$$

> **In plain words:** the best value of doing $a$ in $s$ is the average over outcomes of
> "reward now, plus the best action value available in the next state $s'$". The $\max_{a'}$
> sits inside, because you get to choose again after landing.

Once you have $q_*$, the optimal policy is greedy — no further search needed:
$\pi^*(s) = \arg\max_a q_*(s, a)$. In every state, pick the action with the highest optimal
action value.

> **Watch out:** the max makes the optimality equations **nonlinear**, so you cannot solve them
> with one matrix inversion the way you can for a fixed policy (Try it Yourself below). Chapter
> 4 solves them by iterating instead.

## Gridworld example

A tiny maze makes all of this concrete: 16 squares, two exits, and every step costs a point —
so a state's value tells you how far it is from an exit.

A $4 \times 4$ gridworld has 16 states, 4 actions (up/down/left/right), transitions that stay in
place at edges, and a reward of $-1$ per step (goal: reach terminal states quickly). The two
**terminal** states (0 and 15, the top-left and bottom-right corners) end the episode. In this
code, the step that *enters* a terminal costs 0; every other step costs $-1$.

The code below runs **policy evaluation**: it applies the Bellman expectation equation to every
state, again and again, until the values stop changing. Each pass over all states is a
**sweep**.

```python
import numpy as np

# 4x4 gridworld: states 0-15, terminal = {0, 15}
N_STATES = 16
ACTIONS = ['U', 'D', 'L', 'R']
GAMMA = 1.0

def next_state(s, a):
    row, col = divmod(s, 4)
    if a == 0: row = max(row-1, 0)      # Up
    elif a == 1: row = min(row+1, 3)    # Down
    elif a == 2: col = max(col-1, 0)    # Left
    elif a == 3: col = min(col+1, 3)    # Right
    return row * 4 + col

# Policy evaluation for uniform random policy (each action prob 0.25)
V = np.zeros(N_STATES)
terminal = {0, 15}

for sweep in range(200):
    delta = 0
    for s in range(N_STATES):
        if s in terminal:
            continue
        v_new = 0
        for a in range(4):
            s_prime = next_state(s, a)
            reward = 0 if s_prime in terminal else -1
            v_new += 0.25 * (reward + GAMMA * V[s_prime])
        delta = max(delta, abs(v_new - V[s]))
        V[s] = v_new
    if delta < 1e-6:
        print(f"Converged after {sweep+1} sweeps")
        break

print("Value function (random policy):")
print(np.round(V.reshape(4, 4), 1))
```

```output
Converged after 166 sweeps
Value function (random policy):
[[  0. -13. -19. -21.]
 [-13. -17. -19. -19.]
 [-19. -19. -17. -13.]
 [-21. -19. -13.   0.]]
```

The first line: 166 sweeps until no value changed by more than $10^{-6}$. In the grid, the two
corners with 0 are the terminals. Their neighbours sit at $-13$, and the two far corners
(top-right and bottom-left) are the worst at $-21$. The grid is symmetric along the diagonal
because the two exits are placed symmetrically.

States near the terminals have values closest to 0 (few steps to escape). Corner states far from
terminals have values around $-21$ (many expected steps).

> **Watch out:** "near" is relative. State 1 is one step from the exit, yet its value is $-13$,
> because a *random* walker steps the wrong way three times out of four and wanders. Values
> describe the policy you evaluate, not the shortest path.

### Interpreting the value matrix

Because each step costs one point and there is no discounting, the value reads as a count of
steps.

The values tell you: if you follow the random policy starting from state $s$, you expect to take
$|v_\pi(s)|$ steps before the final step into a terminal (since each step costs $-1$, the final
step costs 0, and $\gamma=1$). Add one for that last free step: from a far corner, a random
walker needs 22 steps on average to finish.

## Recap in plain words

- An MDP lists states, actions, transition chances, rewards, and a discount factor.
- A policy says what to do in each state, either with certainty or with probabilities.
- $v_\pi(s)$ is how much reward you expect from state $s$ when you follow $\pi$; $q_\pi(s, a)$ also fixes the first action.
- Bellman equations say: value here = expected reward now + discounted value of the next state.
- The optimality version replaces "average over the policy" with "take the best action".
- Policy evaluation repeats the Bellman update until the values stop changing.

## Try it Yourself

For a fixed policy the Bellman equation is linear, so you can also solve it in one shot. Write
all 16 values as a vector $V$, the per-state expected reward as $R$, and the policy's
state-to-state transition chances as a matrix $P$. Then $V = R + \gamma P V$, which rearranges
to $V = (I - \gamma P)^{-1} R$.

```python
import numpy as np

# Build the full transition matrix P and reward R for the gridworld
# then verify that V satisfies the Bellman equation: V = R + γ P V

N_STATES = 16
terminal = {0, 15}
GAMMA = 1.0

def next_state(s, a):
    row, col = divmod(s, 4)
    if a == 0: row = max(row-1, 0)
    elif a == 1: row = min(row+1, 3)
    elif a == 2: col = max(col-1, 0)
    elif a == 3: col = min(col+1, 3)
    return row * 4 + col

# Build P (16x16) and R (16,) for uniform random policy
P = np.zeros((N_STATES, N_STATES))
R = np.zeros(N_STATES)
for s in range(N_STATES):
    if s in terminal:
        continue  # terminal rows stay zero, so V[terminal] = 0
    for a in range(4):
        sp = next_state(s, a)
        P[s, sp] += 0.25
        if sp not in terminal:
            R[s] += 0.25 * (-1)

# Solve V = (I - γP)^{-1} R via matrix inversion
V_exact = np.linalg.solve(np.eye(N_STATES) - GAMMA * P, R)
print("Exact solution (matrix inverse):")
print(np.round(V_exact.reshape(4, 4), 1))
```

```output
Exact solution (matrix inverse):
[[  0. -13. -19. -21.]
 [-13. -17. -19. -19.]
 [-19. -19. -17. -13.]
 [-21. -19. -13.   0.]]
```

The grid matches the sweep-by-sweep answer above exactly: $-13$ next to the exits and $-21$ in the
far corners. One linear solve replaced 166 sweeps. This is only practical for small state
spaces: a solve costs on the order of $n^3$ operations for $n$ states.

> **Watch out:** the terminal rows of $P$ must stay all-zero. If you write $P[s, s] = 1$ for a
> terminal (a "self-loop") while $\gamma = 1$, the matrix $I - \gamma P$ gets an all-zero row
> and `np.linalg.solve` fails with "Singular matrix".

Try setting `GAMMA = 0.9` here: with $\gamma < 1$ the matrix is always invertible, and you can
check your exercise answer below.
