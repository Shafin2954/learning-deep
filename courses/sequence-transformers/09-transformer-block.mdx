## The encoder block

A Transformer is a stack of identical blocks. Each block does two things to every token:
first it lets tokens exchange information (attention), then it lets each token think on its
own (a small feed-forward network). Two safety features keep a deep stack trainable.

Each encoder layer has two sub-layers with **residual connections** and **layer normalization**:

1. Multi-head self-attention
2. Position-wise feed-forward network (FFN)

A **residual connection** adds a sub-layer's input back to its output ($x + f(x)$), so the
sub-layer only has to learn a correction, and gradients have a direct path backward.
**Layer normalization** rescales each token's vector to mean 0 and variance 1 (then applies a
learned scale and shift), keeping the numbers in a healthy range layer after layer.

**Pre-norm** (modern default): normalize before the sub-layer.

$$
x' = x + \text{MHA}(\text{LayerNorm}(x))
$$
$$
x'' = x' + \text{FFN}(\text{LayerNorm}(x'))
$$

> **In plain words:** first, normalize, run attention, and add the result to the original
> $x$. Then normalize that, run the FFN, and add again. The un-normalized $x$ flows straight
> through both additions — the "residual stream".

> **Picture it:** a shared document passed down a line of editors. Each editor reads a clean
> copy (layer norm), writes suggested edits, and the edits are added to the document rather
> than replacing it. If an editor has nothing useful to add, the document passes through
> unchanged.

**Post-norm** (original paper): normalize after the residual. Pre-norm is more stable and trains without learning-rate warmup more readily.

Post-norm is $x' = \text{LayerNorm}(x + \text{MHA}(x))$: the normalization sits on the main
path, so every gradient must pass through all $N$ of them. In pre-norm the residual path has
no normalization at all, which is why it behaves better in deep stacks.

## The feed-forward network

After attention mixes information between tokens, the FFN processes each token on its own:
widen the vector, apply a nonlinearity, shrink it back. It is the same small network for
every position.

The FFN applies two linear transformations with a nonlinearity between:

$$
\text{FFN}(x) = \text{GELU}(x W_1 + b_1) W_2 + b_2
$$

> **In plain words:** multiply by $W_1$ to go from $d$ to $4d$ numbers, add a bias, pass
> through GELU (a smooth gate that lets positive values through and squashes negative ones
> toward 0), then multiply by $W_2$ to come back to $d$ numbers. "Position-wise" means each
> token goes through it separately.

The inner dimension is $4 d_{\text{model}}$ by convention (from the original paper). GELU is preferred over ReLU in modern Transformers — it's smoother and avoids the "dead unit" problem of ReLU.

A **dead unit** is a ReLU neuron whose input is negative for every example: its output and
gradient are always 0, so it never recovers. GELU has a small nonzero slope for negative
inputs.

## Implementing the encoder block

The block wires the two equations together, reusing multi-head attention from ch. 7 and
adding dropout on each sub-layer's output.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask, float('-inf'))
    return torch.matmul(F.softmax(scores, dim=-1), V)

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.h = n_heads; self.dk = d_model // n_heads
        self.Wq = nn.Linear(d_model, d_model, bias=False)
        self.Wk = nn.Linear(d_model, d_model, bias=False)
        self.Wv = nn.Linear(d_model, d_model, bias=False)
        self.Wo = nn.Linear(d_model, d_model, bias=False)

    def forward(self, q, k, v, mask=None):
        B, T, D = q.shape
        Tk = k.shape[1]
        def proj(W, x, Tx):
            return W(x).view(B, Tx, self.h, self.dk).transpose(1, 2)
        Q, K, V = proj(self.Wq, q, T), proj(self.Wk, k, Tk), proj(self.Wv, v, Tk)
        out = scaled_dot_product_attention(Q, K, V, mask)
        return self.Wo(out.transpose(1, 2).contiguous().view(B, T, D))

class FFN(nn.Module):
    def __init__(self, d_model, d_ff=None):
        super().__init__()
        d_ff = d_ff or 4 * d_model
        self.fc1 = nn.Linear(d_model, d_ff)
        self.fc2 = nn.Linear(d_ff, d_model)

    def forward(self, x):
        return self.fc2(F.gelu(self.fc1(x)))

class EncoderBlock(nn.Module):
    def __init__(self, d_model, n_heads, dropout=0.1):
        super().__init__()
        self.mha  = MultiHeadAttention(d_model, n_heads)
        self.ffn  = FFN(d_model)
        self.ln1  = nn.LayerNorm(d_model)
        self.ln2  = nn.LayerNorm(d_model)
        self.drop = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        # Pre-norm
        x = x + self.drop(self.mha(self.ln1(x), self.ln1(x), self.ln1(x), mask))
        x = x + self.drop(self.ffn(self.ln2(x)))
        return x

d, h, T = 64, 8, 10
block = EncoderBlock(d, h)
x   = torch.randn(3, T, d)
out = block(x)
print("EncoderBlock output shape:", out.shape)
print("Params:", sum(p.numel() for p in block.parameters()))
```

```output
EncoderBlock output shape: torch.Size([3, 10, 64])
Params: 49728
```

Shape in equals shape out, `[3, 10, 64]` — that is what makes blocks stackable. The 49,728
parameters split as 16,384 for attention ($4 \times 64^2$), 33,088 for the FFN
($64 \times 256 + 256 + 256 \times 64 + 64$), and 256 for the two layer norms
($2 \times (64 + 64)$).

> **Watch out:** a block's output keeps the input's scale only because of the residual.
> Remove the `x +` and stack 12 blocks, and the signal and gradients typically collapse or
> blow up within a few layers.

## The decoder block

The decoder block adds one sub-layer in the middle: after looking at earlier target tokens,
it looks at the encoder's output — this is where the translation "reads" the source.

The decoder block has three sub-layers:
1. **Masked self-attention** — causal mask prevents attending to future tokens.
2. **Cross-attention** — queries from decoder, keys/values from encoder output.
3. **FFN** — identical to encoder.

```python
class DecoderBlock(nn.Module):
    def __init__(self, d_model, n_heads, dropout=0.1):
        super().__init__()
        self.self_attn  = MultiHeadAttention(d_model, n_heads)
        self.cross_attn = MultiHeadAttention(d_model, n_heads)
        self.ffn  = FFN(d_model)
        self.ln1  = nn.LayerNorm(d_model)
        self.ln2  = nn.LayerNorm(d_model)
        self.ln3  = nn.LayerNorm(d_model)
        self.drop = nn.Dropout(dropout)

    def forward(self, x, enc_out, self_mask=None, cross_mask=None):
        x = x + self.drop(self.self_attn(self.ln1(x), self.ln1(x), self.ln1(x), self_mask))
        x = x + self.drop(self.cross_attn(self.ln2(x), enc_out, enc_out, cross_mask))
        x = x + self.drop(self.ffn(self.ln3(x)))
        return x

enc_out = torch.randn(3, 15, d)  # encoder: 15 source tokens
dec_in  = torch.randn(3, 8,  d)  # decoder: 8 target tokens so far
dec_block = DecoderBlock(d, h)

T_dec = 8
causal_mask = torch.triu(torch.ones(T_dec, T_dec, dtype=torch.bool), diagonal=1)
causal_mask = causal_mask[None, None]  # (1, 1, T, T) for broadcasting

dec_out = dec_block(dec_in, enc_out, self_mask=causal_mask)
print("DecoderBlock output shape:", dec_out.shape)
```

```output
DecoderBlock output shape: torch.Size([3, 8, 64])
```

The decoder keeps its own length, 8, even though it attends to 15 encoder tokens:
cross-attention returns one vector per query, and queries come from the decoder. The causal
mask has shape `(1, 1, 8, 8)` so it broadcasts over batch and heads.

> **Watch out:** `enc_out` is not passed through `ln2` here — only the decoder's queries are
> normalized. That is fine because the encoder stack already ends with its own final
> LayerNorm (see the next block).

## Stacking blocks: full encoder

A full encoder is embeddings plus positions (ch. 8), then $N$ blocks, then one final layer
norm.

```python
class TransformerEncoder(nn.Module):
    def __init__(self, vocab_size, d_model, n_heads, n_layers, max_len=512, dropout=0.1):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model, padding_idx=0)
        self.pe    = nn.Embedding(max_len, d_model)  # learned PE
        self.blocks = nn.ModuleList([EncoderBlock(d_model, n_heads, dropout) for _ in range(n_layers)])
        self.norm  = nn.LayerNorm(d_model)
        self.drop  = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        B, T = x.shape
        pos  = torch.arange(T, device=x.device)
        emb  = self.drop(self.embed(x) + self.pe(pos))
        for block in self.blocks:
            emb = block(emb, mask)
        return self.norm(emb)

enc = TransformerEncoder(vocab_size=1000, d_model=64, n_heads=8, n_layers=4)
tokens = torch.randint(1, 1000, (2, 20))
out    = enc(tokens)
print("Encoder output shape:", out.shape)
total  = sum(p.numel() for p in enc.parameters())
print(f"Total encoder params: {total:,}")
```

```output
Encoder output shape: torch.Size([2, 20, 64])
Total encoder params: 295,808
```

Check the 295,808 by hand: 4 blocks of 49,728 is 198,912; the token embedding is
$1000 \times 64 = 64{,}000$; the learned positions add $512 \times 64 = 32{,}768$; and the
final LayerNorm adds 128. The final norm is needed with pre-norm, because the last block's
residual stream has never been normalized.

## Parameter count formula

Most of a Transformer's weights live in a handful of square-ish matrices, so you can estimate
the size of any model from three numbers: width, depth, and vocabulary.

For a transformer with $d$ model dimension, $h$ heads, $N$ layers:

- Per MHA: $4 d^2$ (4 projection matrices)
- Per FFN: $2 \cdot d \cdot 4d = 8d^2$
- Per block total: $12 d^2$
- Embeddings: $V \cdot d + T_{\max} \cdot d$

Note that $h$ does not appear: splitting into more heads reshapes the same matrices (ch. 7).
The formula ignores biases and layer norms, which are only $O(d)$ per block — 576 of the
49,728 above. $V$ is the vocabulary size and $T_{\max}$ the longest position.

GPT-2 small: $d=768$, $N=12$, $V=50257$. Block params: $12 \times 768^2 \approx 7.1$M per layer, $12 \times 7.1 \approx 85$M for blocks, plus about 39M of embeddings, for about $124$M total.

```python
d, N, V = 768, 12, 50257
block_params = 12 * d * d * N
embed_params = V * d + 1024 * d
total = block_params + embed_params
print(f"GPT-2 small estimate: {total/1e6:.1f}M params")
```

```output
GPT-2 small estimate: 124.3M params
```

The estimate is 124.3M; GPT-2 small's published count is about 124M. Almost a third of it is
the token embedding: $50{,}257 \times 768 \approx 38.6$M. The output layer adds nothing,
because GPT-2 reuses the embedding matrix as its output projection (**weight tying**).

## Recap in plain words

- A block is attention (tokens share information) then an FFN (each token processed alone).
- Residual connections add each sub-layer's output to its input, giving gradients a direct
  path.
- Pre-norm normalizes before each sub-layer and is the stable modern default.
- The decoder block adds cross-attention, with queries from the decoder and keys/values from
  the encoder.
- Per block, parameters are about $12d^2$: $4d^2$ for attention plus $8d^2$ for the FFN.

## Try it Yourself

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# Minimal self-contained transformer block demo
class SimpleTransformerBlock(nn.Module):
    def __init__(self, d, h):
        super().__init__()
        dk = d // h
        self.Wq = nn.Linear(d, d, bias=False)
        self.Wk = nn.Linear(d, d, bias=False)
        self.Wv = nn.Linear(d, d, bias=False)
        self.Wo = nn.Linear(d, d, bias=False)
        self.fc1 = nn.Linear(d, 4*d)
        self.fc2 = nn.Linear(4*d, d)
        self.ln1 = nn.LayerNorm(d)
        self.ln2 = nn.LayerNorm(d)
        self.h = h; self.dk = dk

    def attn(self, x):
        B, T, D = x.shape
        def proj(W): return W(x).view(B, T, self.h, self.dk).transpose(1, 2)
        Q, K, V = proj(self.Wq), proj(self.Wk), proj(self.Wv)
        s = torch.matmul(Q, K.transpose(-2,-1)) / self.dk**0.5
        a = torch.matmul(F.softmax(s, dim=-1), V)
        return self.Wo(a.transpose(1,2).contiguous().view(B, T, D))

    def forward(self, x):
        x = x + self.attn(self.ln1(x))
        x = x + self.fc2(F.gelu(self.fc1(self.ln2(x))))
        return x

block = SimpleTransformerBlock(32, 4)
x = torch.randn(2, 10, 32)
print("Output shape:", block(x).shape)
print("Params:", sum(p.numel() for p in block.parameters()))
```

```output
Output shape: torch.Size([2, 10, 32])
Params: 12576
```

With $d = 32$, the formula predicts $12 \times 32^2 = 12{,}288$; the real 12,576 adds 160
FFN biases and 128 layer-norm numbers. Try `SimpleTransformerBlock(64, 4)` and check that the
count is about four times bigger (doubling $d$ quadruples $d^2$). Then change $h$ to 8: the
count does not move.

## Exercise

Stack 2 `EncoderBlock` layers and 2 `DecoderBlock` layers into a minimal seq2seq Transformer. Verify shapes: encoder input `(2, 12, 64)` → encoder output `(2, 12, 64)` → decoder input `(2, 8, 64)` → decoder output `(2, 8, 64)`.

> **Hint:** run the source through every encoder block first. Only then run the target
> through the decoder blocks, giving every decoder block the same final encoder output.

<details>
<summary>Solution</summary>

```python
import torch
import torch.nn as nn

class TinyTransformer(nn.Module):
    def __init__(self, d=64, h=4, n=2):
        super().__init__()
        self.enc_layers = nn.ModuleList([EncoderBlock(d, h) for _ in range(n)])
        self.dec_layers = nn.ModuleList([DecoderBlock(d, h) for _ in range(n)])

    def forward(self, src, tgt, tgt_mask=None):
        enc = src
        for layer in self.enc_layers:
            enc = layer(enc)
        dec = tgt
        for layer in self.dec_layers:
            dec = layer(dec, enc, self_mask=tgt_mask)
        return enc, dec

d = 64
model = TinyTransformer(d=d, h=4, n=2)
src = torch.randn(2, 12, d)
tgt = torch.randn(2,  8, d)
enc_out, dec_out = model(src, tgt)
print("Encoder output:", enc_out.shape)  # (2, 12, 64)
print("Decoder output:", dec_out.shape)  # (2, 8, 64)
```

The decoder processes 8 target tokens while attending to all 12 source tokens in cross-attention. Each decoder block does three operations in sequence.

Every decoder layer attends to the top encoder layer's output, not to the encoder layer at the
same depth. For a real model you would also pass a causal `tgt_mask` and add embeddings,
positions, final LayerNorms, and an output projection to the vocabulary.
</details>
