## Quadratic forms

A **quadratic form** is a recipe that turns a vector into one number by multiplying its
entries in pairs. Plot that number over every possible vector and you get a surface: a bowl,
a saddle, or a flat-bottomed valley. Which one you get is the whole story of this chapter.

A **quadratic form** maps a vector to a scalar via a symmetric matrix $A \in \mathbb{R}^{d \times d}$:

$$
q(x) = x^T A x = \sum_{i,j} A_{ij} x_i x_j
$$

> **In plain words:** for two variables, $x^T A x = A_{11}x_1^2 + 2A_{12}x_1x_2 + A_{22}x_2^2$
> — the multi-variable version of $a x^2$. Just as $a x^2$ is a cup when $a > 0$ and a cap
> when $a < 0$, $x^T A x$ is a bowl when $A$ is "positive" in every direction.

The shape of this bowl (or saddle, or flat valley) is determined entirely by the eigenvalues of $A$.

| Eigenvalues | Shape | Name |
|---|---|---|
| All $> 0$ | Strict bowl (unique minimum) | **Positive definite (PD)** |
| All $\ge 0$ | Flat directions possible | **Positive semi-definite (PSD)** |
| Mixed signs | Saddle | Indefinite |
| All $\le 0$ | Inverted bowl | Negative semi-definite |

> **Picture it:** a PD matrix is a salad bowl — every direction curves up. A PSD matrix is a
> half-pipe — up in some directions, perfectly flat along the pipe. An indefinite matrix is
> a horse saddle — up front-to-back, down side-to-side. Each eigenvalue is the curvature
> along its eigenvector (ch. 4).

```python
import numpy as np

# PD matrix: all eigenvalues > 0
A_pd = np.array([[4.0, 1.0], [1.0, 3.0]])
eigvals = np.linalg.eigvalsh(A_pd)
print("PD matrix eigenvalues:", np.round(eigvals, 4))

# Evaluate q(x) at several points
for x in [np.array([1.0, 0.0]), np.array([0.0, 1.0]), np.array([1.0, -1.0])]:
    print(f"  q({x}) = {x @ A_pd @ x:.4f}")
```

```output
PD matrix eigenvalues: [2.382 4.618]
  q([1. 0.]) = 4.0000
  q([0. 1.]) = 3.0000
  q([ 1. -1.]) = 5.0000
```

Both eigenvalues (2.38 and 4.62) are positive, so every direction curves up. The three
test points agree: $q(1, 0) = A_{11} = 4$, $q(0, 1) = A_{22} = 3$, and
$q(1, -1) = 4 - 2 \cdot 1 + 3 = 5$.

All values are positive — as guaranteed for a PD matrix.

## Equivalent characterisations of PD

There are three different-looking tests for "is this a bowl?". They always agree, so you
can use whichever is cheapest.

Three equivalent conditions for $A$ to be positive definite:

1. **All eigenvalues positive:** $\lambda_i > 0$ for all $i$.
2. **Sylvester's criterion:** all leading principal minors are positive ($\det(A_{1:k,1:k}) > 0$ for $k = 1, \ldots, d$).
3. **Cholesky factorisation exists:** $A = LL^T$ with $L$ lower-triangular and positive diagonal.

A **leading principal minor** is the determinant of the top-left $k \times k$ corner of the
matrix. A **lower-triangular** matrix has zeros everywhere above its diagonal.

```python
import numpy as np

A = np.array([[4.0, 2.0, 1.0],
              [2.0, 5.0, 3.0],
              [1.0, 3.0, 6.0]])

# Test 1: eigenvalues
eigvals = np.linalg.eigvalsh(A)
print("Eigenvalues:", np.round(eigvals, 4))
print("All positive:", (eigvals > 0).all())

# Test 2: leading minors
minors = [np.linalg.det(A[:k, :k]) for k in range(1, 4)]
print("Leading minors:", np.round(minors, 4))
print("All positive  :", all(m > 0 for m in minors))

# Test 3: Cholesky
try:
    L = np.linalg.cholesky(A)
    print("Cholesky succeeded — A is PD")
    print("L diagonal:", np.round(np.diag(L), 4))
except np.linalg.LinAlgError:
    print("Cholesky failed — A is not PD")
```

```output
Eigenvalues: [1.9213 3.7302 9.3485]
All positive: True
Leading minors: [ 4. 16. 67.]
All positive  : True
Cholesky succeeded — A is PD
L diagonal: [2.     2.     2.0463]
```

All three tests pass: eigenvalues 1.92, 3.73, 9.35; corner determinants 4, 16, 67; and
Cholesky finds an $L$ with positive diagonal. In practice the Cholesky test is the one to
use — it's the fastest, and `try: cholesky` is the standard way code checks for PD.

> **Watch out:** a matrix with all *positive entries* need not be PD, and a PD matrix can
> have negative entries. `[[1, 2], [2, 1]]` has eigenvalues 3 and $-1$ — a saddle — despite
> being all positive. Check eigenvalues or Cholesky, never the signs of the entries.

## Why covariance matrices are PSD

A covariance matrix can never curve downward, because the "height" it gives any direction
is a variance — and variances can't be negative.

A sample covariance matrix $C = X_c^T X_c / (n-1)$ is always PSD:

$$
x^T C x = x^T \frac{X_c^T X_c}{n-1} x = \frac{\|X_c x\|^2}{n-1} \ge 0
$$

> **In plain words:** $X_c x$ projects every sample onto the direction $x$; its squared
> length divided by $n - 1$ is the variance of the data along $x$. A sum of squares is
> never negative.

It is PD only when $X_c$ has full column rank (i.e., $n > d$ and no perfectly collinear features). When $n < d$, at least $d - n$ eigenvalues are zero — the matrix is PSD but not PD.
(**Collinear** features are exact combinations of each other, like temperature in °C and
in °F.)

```python
import numpy as np

rng = np.random.default_rng(3)

# Under-determined: n < d → PSD not PD
n, d = 50, 100
X = rng.standard_normal((n, d))
C = (X - X.mean(axis=0)).T @ (X - X.mean(axis=0)) / (n - 1)
eigvals = np.linalg.eigvalsh(C)
zero_eigvals = (eigvals < 1e-10).sum()
print(f"n={n}, d={d}: {zero_eigvals} eigenvalues are effectively 0 — matrix is PSD only")

# Over-determined: n >> d → PD
n2, d2 = 500, 10
X2 = rng.standard_normal((n2, d2))
C2 = (X2 - X2.mean(axis=0)).T @ (X2 - X2.mean(axis=0)) / (n2 - 1)
eigvals2 = np.linalg.eigvalsh(C2)
print(f"n={n2}, d={d2}: min eigenvalue = {eigvals2.min():.4f} — matrix is PD")
```

```output
n=50, d=100: 51 eigenvalues are effectively 0 — matrix is PSD only
n=500, d=10: min eigenvalue = 0.7647 — matrix is PD
```

With 50 samples in 100 dimensions, 51 eigenvalues are zero: centring uses up one more
degree of freedom, so the rank is at most $n - 1 = 49$ and $100 - 49 = 51$ directions have no
spread at all. With 500 samples in 10 dimensions the smallest eigenvalue is a healthy 0.76
— a true bowl.

## Cholesky factorisation

**Cholesky** writes a PD matrix as a lower-triangular matrix times its own transpose — a
kind of "square root" of the matrix. Triangular systems are trivial to solve, so this is
the fastest safe way to solve equations with a PD matrix.

For a PD matrix $A$, the **Cholesky factorisation** $A = LL^T$ (with $L$ lower-triangular, positive diagonal) exists and is unique. It is twice as fast as LU decomposition and numerically the most stable path for solving $Ax = b$ when $A$ is symmetric and PD.

```python
import numpy as np

rng = np.random.default_rng(0)
d = 5

# Build a guaranteed-PD matrix: A = Q^T Q + εI
Q = rng.standard_normal((d, d))
A = Q.T @ Q + 0.5 * np.eye(d)

L = np.linalg.cholesky(A)
print("L (lower triangular):")
print(np.round(L, 4))
print("\nReconstruction error:", np.max(np.abs(L @ L.T - A)))

# Solve Ax = b via Cholesky: L L^T x = b
b = rng.standard_normal(d)
y = np.linalg.solve(L, b)           # forward substitution: Ly = b
x = np.linalg.solve(L.T, y)         # back substitution: L^T x = y

residual = np.linalg.norm(A @ x - b)
print(f"\nResidual ||Ax - b|| = {residual:.2e}")
```

```output
L (lower triangular):
[[ 1.2601  0.      0.      0.      0.    ]
 [ 0.5175  2.0286  0.      0.      0.    ]
 [ 1.7374 -0.2867  2.1575  0.      0.    ]
 [-0.3583 -0.2459  0.0452  1.0753  0.    ]
 [-0.4983 -0.3479  0.5518  1.4551  1.7471]]

Reconstruction error: 2.220446049250313e-16

Residual ||Ax - b|| = 5.42e-16
```

The printed $L$ has zeros above the diagonal and positive numbers on it; multiplying it by
its transpose recovers $A$ to $10^{-16}$. Solving then takes two easy triangular steps:
**forward substitution** ($Ly = b$, solved top row first) and **back substitution**
($L^T x = y$, solved bottom row first). The residual $10^{-16}$ confirms the answer.

> **In plain words:** you've met this idea as $a = (\sqrt{a})^2$. Cholesky is the matrix
> version — and, just like $\sqrt{a}$, it only exists when the thing you're square-rooting
> is positive.

### Adding regularisation to make a PSD matrix PD

Adding a tiny amount to the diagonal lifts every flat direction of the half-pipe slightly,
turning it into a (very shallow) bowl.

Ridge regularisation $A + \varepsilon I$ shifts all eigenvalues up by $\varepsilon$, guaranteeing PD:

```python
import numpy as np

rng = np.random.default_rng(7)
n, d = 30, 50
X = rng.standard_normal((n, d))
C = X.T @ X / (n - 1)   # PSD: rank at most 30

eps = 1e-4
C_reg = C + eps * np.eye(d)

try:
    np.linalg.cholesky(C_reg)
    print(f"With epsilon={eps}: Cholesky succeeded (C_reg is PD)")
except np.linalg.LinAlgError:
    print("Still not PD — increase epsilon")
```

```output
With epsilon=0.0001: Cholesky succeeded (C_reg is PD)
```

A 50×50 covariance from 30 samples has at least 20 zero eigenvalues, so Cholesky would
fail on `C` itself; adding $10^{-4}$ to the diagonal makes every eigenvalue at least
$10^{-4}$, and it succeeds. This is exactly what ridge regression does to $X^T X$, and what
Gaussian-process and Kalman-filter code calls "adding jitter".

## Recap in plain words

- $x^T A x$ is a surface whose shape is set by the eigenvalues of $A$: all positive = bowl
  (PD), all non-negative = bowl with flat directions (PSD), mixed = saddle.
- Three tests always agree: all eigenvalues $> 0$, all leading corner determinants $> 0$,
  and Cholesky succeeds.
- Covariance matrices are always PSD; they're PD only with more samples than features and
  no exact duplicates.
- Cholesky $A = LL^T$ is the fast, stable way to solve PD systems.
- $A + \varepsilon I$ lifts every eigenvalue by $\varepsilon$ and turns PSD into PD.

## Try it Yourself

```python
import numpy as np

rng = np.random.default_rng(42)
d = 4
Q = rng.standard_normal((d, d))
eps = 0.1

A = Q.T @ Q + eps * np.eye(d)
eigvals = np.linalg.eigvalsh(A)
print("Eigenvalues:", np.round(eigvals, 4))
print("Min eigenvalue:", np.round(eigvals.min(), 4), "— must be > 0")

L = np.linalg.cholesky(A)
print("Cholesky diagonal:", np.round(np.diag(L), 4))
print("Reconstruction max error:", np.max(np.abs(L @ L.T - A)))
```

```output
Eigenvalues: [0.1101 1.1529 4.3081 7.408 ]
Min eigenvalue: 0.1101 — must be > 0
Cholesky diagonal: [2.001  1.8815 1.1342 0.4714]
Reconstruction max error: 8.881784197001252e-16
```

`Q.T @ Q` is PSD by construction, and adding `0.1 * I` pushes every eigenvalue up by 0.1 —
so the smallest one (0.1101) sits just above 0.1, meaning `Q.T @ Q` itself had an eigenvalue
of about 0.01. Cholesky succeeds and reconstructs `A` to $10^{-15}$. Try `eps = 0` and a
singular `Q` (set one row to zeros) and watch Cholesky raise `LinAlgError`.

## Exercise

Estimate a covariance matrix from 20 samples of a 50-dimensional Gaussian. Determine whether it is PD or only PSD. Add the smallest regularisation $\varepsilon$ (search over powers of 10) that makes it PD, and verify with Cholesky.

> **Hint:** with 20 samples, the rank is at most 19, so most eigenvalues must be zero.
> Computed "zeros" come out as tiny positive or negative numbers like $10^{-15}$.

<details>
<summary>Solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.standard_normal((20, 50))
C = (X - X.mean(axis=0)).T @ (X - X.mean(axis=0)) / 19

eigvals = np.linalg.eigvalsh(C)
print(f"Min eigenvalue: {eigvals.min():.6f} — {'PD' if eigvals.min() > 0 else 'PSD only'}")

for exp in range(-8, 1):
    eps = 10.0 ** exp
    try:
        np.linalg.cholesky(C + eps * np.eye(50))
        print(f"epsilon = 1e{exp}: Cholesky succeeded → PD")
        break
    except np.linalg.LinAlgError:
        print(f"epsilon = 1e{exp}: still not PD")
```

With n=20 and d=50, you'll find 31 zero eigenvalues. A regularisation of $10^{-10}$ or smaller typically suffices.
In fact the computed minimum eigenvalue is about $-1.4 \times 10^{-15}$ — a rounding-error
"negative" — so the first value the loop tries, $10^{-8}$, already succeeds; you'd have to go
down to about $10^{-16}$ before Cholesky fails again. Any $\varepsilon$ comfortably above
float64 rounding noise works.
