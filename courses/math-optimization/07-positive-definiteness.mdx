## A quadratic form is a bowl, a saddle, or a trough

Take a function built only from squares and a cross term, like $q(x) = 3x_1^2 + 2x_1x_2 + 2x_2^2$. Plot it and you get
a bowl (rises in every direction), a saddle (rises one way, falls another) or a trough (flat along a line). Every loss
near its minimum, every Gaussian log-density and every portfolio variance is such a shape; telling them apart is this chapter.

Any such function can be written with a symmetric matrix $A$ (a square grid with $A_{ij} = A_{ji}$) as the
**quadratic form** $q(x) = x^\top A x = \sum_{i,j} A_{ij}x_ix_j$; for the example, $A = \begin{pmatrix}3&1\\1&2\end{pmatrix}$
(the cross coefficient 2 is split as 1 + 1). Because $q(tx) = t^2 q(x)$, the shape is decided by the values of $q$ on
the unit circle: scale those up and you have the whole surface.

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

forms = {"bowl":   np.array([[3.0, 1.0], [1.0, 2.0]]),
         "saddle": np.array([[1.0, 2.0], [2.0, -1.0]]),
         "trough": np.array([[1.0, 1.0], [1.0, 1.0]])}
g = np.linspace(-1, 1, 201)
G = np.stack(np.meshgrid(g, g), -1).reshape(-1, 2)                 # 40,401 grid points in [-1,1]^2
th = np.linspace(0, 2 * np.pi, 100_000, endpoint=False)
U = np.stack([np.cos(th), np.sin(th)], 1)                           # unit circle
for name, A in forms.items():
    qg = np.einsum("ni,ij,nj->n", G, A, G)
    qu = np.einsum("ni,ij,nj->n", U, A, U)
    print(f"{name:6s} grid: min {qg.min():6.3f} max {qg.max():6.3f} share<0 {np.mean(qg < -1e-12):5.1%} | "
          f"unit circle: min {qu.min():7.4f} max {qu.max():7.4f} | eigvalsh {np.linalg.eigvalsh(A)}")
```

```output
bowl   grid: min  0.000 max  7.000 share<0  0.0% | unit circle: min  1.3820 max  3.6180 | eigvalsh [1.382 3.618]
saddle grid: min -4.000 max  4.000 share<0 50.0% | unit circle: min -2.2361 max  2.2361 | eigvalsh [-2.2361  2.2361]
trough grid: min -0.000 max  4.000 share<0  0.0% | unit circle: min -0.0000 max  2.0000 | eigvalsh [0. 2.]
```

The bowl is never negative, the saddle is negative on half the square, the trough touches zero along a line. On the
unit circle the extreme values of $q$ (brute force, 100,000 directions) are exactly the eigenvalues of $A$. Why:

### Why the extremes on the unit circle are eigenvalues

This shows the eigenvalues (ch. 4) are the minimum and maximum of $q$ over unit vectors. A symmetric matrix has an
orthonormal eigenbasis, $A = Q\Lambda Q^\top$ with $\Lambda = \mathrm{diag}(\lambda_1 \le \dots \le \lambda_d)$. In
that basis, $y = Q^\top x$ and $\|y\|_2 = \|x\|_2 = 1$:

$$
x^\top A x = y^\top \Lambda y = \sum_i \lambda_i y_i^2, \qquad \sum_i y_i^2 = 1
\quad\Longrightarrow\quad
\boxed{\lambda_1 \le \frac{x^\top A x}{x^\top x} \le \lambda_d}
$$

The middle is the **Rayleigh quotient**, an average of eigenvalues with weights $y_i^2$, extreme on the extreme
eigenvectors. So the eigenvalue signs *are* the shape: all positive a bowl, mixed a saddle, a zero a flat direction.

## Only the symmetric part of A matters

Any square matrix splits into a symmetric half and an antisymmetric half, $A = S + K$ with $S = \tfrac12(A + A^\top)$
and $K = \tfrac12(A - A^\top)$. The antisymmetric half is invisible to a quadratic form, the way a pure rotation
"pushes sideways" and never along: $x^\top K x$ is a number equal to its own transpose $x^\top K^\top x = -x^\top K x$,
so it is zero. Any statement "A is positive definite" about a non-symmetric $A$ is really about $S$.

```python
rng = np.random.default_rng(0)
A_ns = np.array([[1.0, 4.0], [-2.0, 1.0]])                          # not symmetric
S_ = (A_ns + A_ns.T) / 2; K_ = (A_ns - A_ns.T) / 2
X = rng.standard_normal((100_000, 2))
qA = np.einsum("ni,ij,nj->n", X, A_ns, X); qS = np.einsum("ni,ij,nj->n", X, S_, X)
print("S =", S_.tolist(), "| K =", K_.tolist())
print(f"max |x^T A x - x^T S x| over 100k x: {np.abs(qA - qS).max():.1e} | max |x^T K x|: "
      f"{np.abs(np.einsum('ni,ij,nj->n', X, K_, X)).max():.1e}")
print("eigvals(A) =", np.linalg.eigvals(A_ns), "| eigvalsh(S) =", np.linalg.eigvalsh(S_))
```

```output
S = [[1.0, 1.0], [1.0, 1.0]] | K = [[0.0, 3.0], [-3.0, 0.0]]
max |x^T A x - x^T S x| over 100k x: 7.1e-15 | max |x^T K x|: 3.6e-15
eigvals(A) = [1.+2.8284j 1.-2.8284j] | eigvalsh(S) = [0. 2.]
```

The forms agree to rounding. The eigenvalues of $A$ are complex with positive real part, which says nothing about $q$;
the symmetric part has eigenvalues 0 and 2, so $q$ is a trough. Symmetrize first, then test: finite-difference
Hessians and hand-assembled matrices often are not symmetric.

## Five equivalent tests for positive definiteness

A symmetric $A$ is **positive definite (PD)** if $x^\top A x > 0$ for every $x \ne 0$, **positive semidefinite (PSD)**
if $x^\top A x \ge 0$, and **indefinite** if $q$ takes both signs. Negative (semi)definite means $-A$ is PD (PSD). The
definition quantifies over infinitely many $x$, so in practice you use one of five finite tests, all equivalent for PD:

1. all eigenvalues are positive;
2. Cholesky $A = LL^\top$ with a positive diagonal succeeds (ch. 3);
3. all leading principal minors $\det A_k > 0$, where $A_k$ is the top-left $k \times k$ block (**Sylvester**);
4. all pivots of Gaussian elimination without row swaps are positive;
5. $A = B^\top B$ for some $B$ with independent columns.

### Why the five tests agree

This shows each test is a different view of the same positive numbers. (1) is the Rayleigh bound above. Elimination
without swaps on a symmetric matrix gives $A = LDL^\top$ with unit lower-triangular $L$ and the pivots on $D$; since
$\det A_k = d_1 \cdots d_k$, the $k$-th pivot is $d_k = \det A_k / \det A_{k-1}$, so (3) and (4) are the same condition.
Positive pivots let you write $A = (L D^{1/2})(L D^{1/2})^\top$, which is (2). Cholesky gives (5) with $B = L^\top$, and
(5) gives the definition back:

$$
x^\top B^\top B x = \|Bx\|_2^2 > 0 \quad \text{for } x \ne 0 \text{ when } B \text{ has independent columns.}
$$

Finally the definition gives (1): plug in a unit eigenvector, $q(v) = \lambda\,v^\top v = \lambda > 0$. For PSD the
analogue of (3) is subtler: *all* principal minors (every subset of rows and the same columns) must be $\ge 0$, not just
the leading ones. The matrix $\mathrm{diag}(0, -1)$ has leading minors $0, 0$ and is not PSD.

```python
def pd_tests(A, tol=1e-12):
    ev = np.linalg.eigvalsh(A).min() > tol
    try: np.linalg.cholesky(A); ch = True
    except np.linalg.LinAlgError: ch = False
    minors = [np.linalg.det(A[:k, :k]) for k in range(1, len(A) + 1)]
    syl = all(m > tol for m in minors)
    M = A.copy(); piv = []                                          # elimination without row swaps
    for k in range(len(A)):
        piv.append(M[k, k])
        if abs(M[k, k]) < 1e-14: break
        M[k + 1:] -= np.outer(M[k + 1:, k] / M[k, k], M[k])
    pv = len(piv) == len(A) and min(piv) > tol
    w, V = np.linalg.eigh(A); B = np.sqrt(np.clip(w, 0, None))[:, None] * V.T   # B^T B: symmetric square root
    bb = np.allclose(B.T @ B, A) and np.linalg.matrix_rank(B) == len(A)
    return bool(ev), ch, syl, bool(pv), bool(bb), np.round(minors, 3), np.round(piv, 3)

A3 = np.array([[4.0, 2.0, 1.0], [2.0, 5.0, 3.0], [1.0, 3.0, 6.0]])
r = pd_tests(A3)
print("A3 tests (eig, chol, sylvester, pivots, B^T B):", r[:5])
print("leading minors", r[5], "| pivots", r[6], "| minor ratios", np.round(r[5] / np.r_[1, r[5][:-1]], 3))
agree, counts = 0, {True: 0, False: 0}
for _ in range(2000):
    M = rng.standard_normal((4, 4)); M = M @ M.T - rng.uniform(0, 3) * np.eye(4)   # mostly not PD
    res = pd_tests(M)[:5]
    agree += len(set(res)) == 1; counts[res[0]] += 1
print(f"2000 random symmetric 4x4: all five tests agree on {agree}; PD {counts[True]}, not PD {counts[False]}")
```

```output
A3 tests (eig, chol, sylvester, pivots, B^T B): (True, True, True, True, True)
leading minors [ 4. 16. 67.] | pivots [4.    4.    4.188] | minor ratios [4.    4.    4.188]
2000 random symmetric 4x4: all five tests agree on 2000; PD 129, not PD 1871
```

On the example every test says PD, and the pivots are visibly the ratios of consecutive minors ($16/4 = 4$,
$67/16 = 4.19$). Over 2000 random matrices (129 PD, 1871 not) the five verdicts never disagree. In code, use
Cholesky: cheapest ($n^3/3$ flops), and what scipy, PyMC and GP libraries do (ch. 3). Determinants are
the worst choice numerically: they overflow and underflow long before the matrix is in trouble (ch. 2).

## Covariance matrices are always PSD, and sometimes only PSD

A variance is never negative, and every weighted sum of features is itself a feature with a variance: that alone makes
every covariance matrix PSD. With centered data $X_c$ ($n \times d$, column means removed) and $C = X_c^\top X_c/(n-1)$,
the combined feature $X_c w$ has sample variance

$$
w^\top C w = \frac{w^\top X_c^\top X_c w}{n-1} = \frac{\|X_c w\|_2^2}{n-1} \ge 0 ,
$$

which is test (5) with $B = X_c/\sqrt{n-1}$. It is PD exactly when no nonzero $w$ makes $X_c w = 0$: when the centered
columns are independent. Two things break that: fewer rows than features ($\mathrm{rank}\,X_c \le n - 1$ because
centering removes one dimension, so at least $d - n + 1$ zero eigenvalues), and an exactly collinear feature (a total
column, a unit conversion, one-hot columns summing to 1).

```python
def cov_report(X, label):
    C = np.cov(X, rowvar=False); ev = np.linalg.eigvalsh(C)
    try: np.linalg.cholesky(C); ch = "ok"
    except np.linalg.LinAlgError: ch = "fails"
    print(f"{label:34s} min eig {ev.min():9.1e} | #eig < 1e-10*max: {np.sum(ev < 1e-10 * ev.max()):3d} | cholesky {ch}")

cov_report(rng.standard_normal((500, 10)), "n=500, d=10")
cov_report(rng.standard_normal((50, 100)), "n=50, d=100 (expect >= 51 zeros)")
Xcol = rng.standard_normal((500, 5)); Xcol = np.column_stack([Xcol, Xcol[:, 0] + 2 * Xcol[:, 1]])
cov_report(Xcol, "n=500, col 6 = col1 + 2 col2")
```

```output
n=500, d=10                        min eig   7.8e-01 | #eig < 1e-10*max:   0 | cholesky ok
n=50, d=100 (expect >= 51 zeros)   min eig  -1.4e-15 | #eig < 1e-10*max:  51 | cholesky fails
n=500, col 6 = col1 + 2 col2       min eig   1.0e-15 | #eig < 1e-10*max:   1 | cholesky ok
```

With plenty of rows the smallest eigenvalue is comfortably positive. With 50 rows and 100 features, 51 eigenvalues are
zero to rounding (the smallest slightly negative), and the exact linear relation leaves one zero eigenvalue. Cholesky
"succeeds" on that singular matrix only because rounding made its zero eigenvalue $+10^{-15}$ rather than
$-10^{-15}$: the worst kind of bug, one that works on your laptop and fails in production.

### Jitter versus Ledoit–Wolf shrinkage

This shows two repairs that are not equally good. **Jitter** adds $\varepsilon I$, shifting every eigenvalue up by
$\varepsilon$: minimal and cosmetic.
**Shrinkage** blends the sample covariance $C$ with a simple target, $\hat\Sigma = (1 - \delta)C + \delta\,\mu I$ with
$\mu = \mathrm{tr}(C)/d$ (the average variance) and $0 \le \delta \le 1$. Since the eigenvalues of $\hat\Sigma$ are
$(1-\delta)\lambda_i + \delta\mu \ge \delta\mu > 0$, it is PD for any $\delta > 0$, and it pulls the too-spread
sample eigenvalues back toward their mean. Ledoit and Wolf (2004) derive the $\delta$ that minimizes the expected
Frobenius error in closed form from the data, no cross-validation needed.

```python
from sklearn.covariance import LedoitWolf
d, n = 100, 60
true_ev = np.geomspace(10, 0.5, d)
Qt, _ = np.linalg.qr(rng.standard_normal((d, d))); Sig = Qt @ np.diag(true_ev) @ Qt.T
Xs = rng.multivariate_normal(np.zeros(d), Sig, size=n)
C = np.cov(Xs, rowvar=False)
lw = LedoitWolf().fit(Xs); S_lw = lw.covariance_
print(f"true eigenvalues      : min {true_ev.min():.3f} max {true_ev.max():6.3f}")
for name, M in (("sample", C), ("sample + 1e-6 I", C + 1e-6 * np.eye(d)), (f"Ledoit-Wolf (delta={lw.shrinkage_:.3f})", S_lw)):
    e = np.linalg.eigvalsh(M)
    print(f"{name:26s}: min {e.min():9.2e} max {e.max():6.3f} | cond {e.max() / max(e.min(), 1e-300):9.2e} | "
          f"rel. Frobenius error {np.linalg.norm(M - Sig) / np.linalg.norm(Sig):.3f}")
```

```output
true eigenvalues      : min 0.500 max 10.000
sample                    : min -4.97e-15 max 20.911 | cond 2.09e+301 | rel. Frobenius error 1.010
sample + 1e-6 I           : min  1.00e-06 max 20.911 | cond  2.09e+07 | rel. Frobenius error 1.010
Ledoit-Wolf (delta=0.730) : min  2.31e+00 max  7.864 | cond  3.40e+00 | rel. Frobenius error 0.541
```

The sample covariance spreads the eigenvalues far beyond the truth (largest 20.9 against 10, and 41 exactly zero since
$n - 1 = 59 < d$); jitter makes it technically PD with a condition number of $2 \times 10^7$ and the same error.
Ledoit–Wolf picks $\delta = 0.73$, a condition number of 3.4 and half the Frobenius error. In LDA or a Mahalanobis
distance (ch. 1) it is the inverse you use, which is where that difference bites.

## Kernel matrices are PSD, and that is what makes something a kernel

A kernel is meant to be an inner product of features, $k(x, y) = \phi(x)^\top \phi(y)$, in a feature space you never
compute. The **Gram matrix** $K_{ij} = k(x_i, x_j)$ is then $\Phi\Phi^\top$ (rows $\phi(x_i)$), PSD by test (5). **Mercer's theorem** says the converse: a symmetric
function whose Gram matrices are PSD for *every* finite set of points is an inner product in some feature space. So
"is it a valid kernel?" means "are all its Gram matrices PSD?".

The intuition: $\sum_{ij} c_i c_j k(x_i, x_j) = \|\sum_i c_i \phi(x_i)\|^2$ is a squared length. A negative value
would mean a GP assigns negative variance to the combination $\sum_i c_i f(x_i)$.

```python
from scipy.spatial.distance import cdist
Xk = rng.standard_normal((300, 5))
D2 = cdist(Xk, Xk, "sqeuclidean"); Dot = Xk @ Xk.T
kernels = {"RBF exp(-|x-y|^2/2)":       np.exp(-D2 / 2),
           "Laplacian exp(-|x-y|_1)":   np.exp(-cdist(Xk, Xk, "cityblock")),
           "polynomial (1+x.y)^3":      (1 + Dot) ** 3,
           "sigmoid tanh(x.y - 1)":     np.tanh(Dot - 1.0),
           "negative distance -|x-y|":  -np.sqrt(D2),
           "truncated 1-|x-y|/2 (d=5)": np.clip(1 - np.sqrt(D2) / 2, 0, None)}
for name, Kx in kernels.items():
    e = np.linalg.eigvalsh(Kx)
    print(f"{name:27s} min eig {e.min():10.3e} | #negative (< -1e-8 * max) {np.sum(e < -1e-8 * e.max()):3d}")
```

```output

Laplacian exp(-|x-y|_1)     min eig  3.658e-01 | #negative (< -1e-8 * max)   0
polynomial (1+x.y)^3        min eig -5.720e-12 | #negative (< -1e-8 * max)   0
sigmoid tanh(x.y - 1)       min eig -1.199e+02 | #negative (< -1e-8 * max) 149
```

RBF, Laplacian and polynomial Gram matrices have no negative eigenvalues beyond rounding ($-6 \times 10^{-12}$ for the
polynomial). The sigmoid "kernel" offered by SVM libraries has 149 negative eigenvalues of 300, $-\|x - y\|$ has one
large one ($-887$), and the truncated triangle, valid in one dimension, has 40 in five dimensions. An SVM may still run on
them, but its dual is no longer a convex problem (ch. 9, ch. 13) and the solver's answer is not the margin you think.

## Level sets are ellipses aligned with the eigenvectors

The set where a PD form equals a constant, $\{x : x^\top A x = c\}$, is an ellipse (an ellipsoid in $d$ dimensions). In
the eigenbasis it reads $\sum_i \lambda_i y_i^2 = c$, which is the textbook ellipse with semi-axis $\sqrt{c/\lambda_i}$
along eigenvector $v_i$. Big eigenvalue, steep wall, short axis; small eigenvalue, gentle slope, long axis.

This is the Mahalanobis ball of ch. 1 with $A = \Sigma^{-1}$, and the contour of the Gaussian density
$p(x) \propto |\Sigma|^{-1/2}\exp\big(-\tfrac12 (x - \mu)^\top \Sigma^{-1} (x - \mu)\big)$. The eigenvalues of
$\Sigma^{-1}$ are $1/\sigma_i^2$, so the axis along $v_i$ is proportional to $\sigma_i$. The density needs $\Sigma$ PD
for the inverse and determinant, which is why a singular covariance has no density (its mass sits on a flat subspace).

```python
Sig2 = np.array([[3.0, 1.2], [1.2, 1.0]])
P2 = np.linalg.inv(Sig2)
lam, V = np.linalg.eigh(P2)
radius = 1 / np.sqrt(np.einsum("ni,ij,nj->n", U, P2, U))        # along unit u, x = r u with r^2 u^T P u = 1
print("eigvals of Sigma^-1:", lam, "| predicted semi-axes 1/sqrt(lambda):", 1 / np.sqrt(lam))
print(f"contour: longest {radius.max():.4f} at {np.degrees(th[radius.argmax()]) % 180:.2f} deg, shortest "
      f"{radius.min():.4f} | v_min at {np.degrees(np.arctan2(V[1, 0], V[0, 0])) % 180:.2f} deg | sqrt(eig Sigma) {np.sqrt(np.linalg.eigvalsh(Sig2))}")
```

```output
eigvals of Sigma^-1: [0.2807 2.2834] | predicted semi-axes 1/sqrt(lambda): [1.8873 0.6618]
contour: longest 1.8873 at 25.10 deg, shortest 0.6618 | v_min at 25.10 deg | sqrt(eig Sigma) [0.6618 1.8873]
```

The brute-force radii match $1/\sqrt{\lambda}$, the long axis (at 25.1 degrees) is the eigenvector with the smallest
eigenvalue of $\Sigma^{-1}$, and its length 1.887 is the largest standard deviation of $\Sigma$.

## The Hessian test: minimum, maximum, or saddle

Where the gradient vanishes, a smooth function looks like its Taylor expansion $f(x^\star + h) \approx f(x^\star) +
\tfrac12 h^\top H h$ with $H_{ij} = \partial^2 f/\partial x_i \partial x_j$, so the local shape is the quadratic form of the **Hessian** $H$ (the matrix of second derivatives, ch. 8). $H$ PD means
a strict local minimum, negative definite a strict maximum, indefinite a saddle. If $H$ is only PSD with a zero
eigenvalue the test is inconclusive: higher-order terms decide. Below, $f(x, y) = x^3 - 3x + y^2 - xy$: setting
$\partial_y f = 2y - x = 0$ and $\partial_x f = 3x^2 - 3 - y = 0$ gives two critical points, $y = x/2$ with $3x^2 - x/2 - 3 = 0$.

```python
def hessian_fd(f, x, h=1e-4):
    """Central-difference Hessian, symmetrized."""
    n = len(x); H = np.zeros((n, n)); E = np.eye(n) * h
    for i in range(n):
        for j in range(n):
            H[i, j] = (f(x + E[i] + E[j]) - f(x + E[i] - E[j]) - f(x - E[i] + E[j]) + f(x - E[i] - E[j])) / (4 * h * h)
    return (H + H.T) / 2

f2 = lambda z: z[0] ** 3 - 3 * z[0] + z[1] ** 2 - z[0] * z[1]
for xr in np.roots([3, -0.5, -3]):
    pt = np.array([xr, xr / 2]); H = hessian_fd(f2, pt); e = np.linalg.eigvalsh(H)
    kind = "minimum" if e.min() > 0 else "maximum" if e.max() < 0 else "saddle"
    print(f"critical point ({pt[0]:7.4f}, {pt[1]:7.4f}): Hessian eigs {e} -> {kind}")
```

```output
critical point ( 1.0868,  0.5434): Hessian eigs [1.7887 6.7321] -> minimum
critical point (-0.9201, -0.4601): Hessian eigs [-5.6515  2.1307] -> saddle
```

One critical point has a PD Hessian (a minimum), the other an indefinite one (a saddle). In a million dimensions the
saddle is the typical critical point, which is the next example.

### A two-layer linear network: saddles and flat valleys

This shows a neural-net loss has saddles at symmetric points and singular PSD Hessians at its minima. Fit $y \approx
w_2 w_1 x$ (one hidden unit, no activation) to slope-2 data with $L(w_1, w_2) = \tfrac1n \sum_k (y_k - w_2 w_1 x_k)^2$.
The gradient vanishes at $w = 0$, and the rescaling $(w_1, w_2) \to (t w_1, w_2 / t)$ never changes the loss.

```python
xd = rng.standard_normal(200); yd = 2.0 * xd + 0.1 * rng.standard_normal(200)
L_net = lambda w: np.mean((yd - w[1] * w[0] * xd) ** 2)
c = (xd @ yd) / (xd @ xd)                                           # best product w1 w2
for label, w in (("origin (0, 0)", np.zeros(2)), ("minimum (1, c)", np.array([1.0, c])),
                 ("minimum (2, c/2)", np.array([2.0, c / 2]))):
    e, Vh = np.linalg.eigh(hessian_fd(L_net, w))
    print(f"{label:17s} loss {L_net(w):.4f} | Hessian eigs {np.round(e, 4)} | flat direction {np.round(Vh[:, 0], 3)}")
print("loss along (t, c/t):", [round(float(L_net(np.array([t, c / t]))), 4) for t in (0.5, 1, 2, 4)])
```

```output
origin (0, 0)     loss 3.4598 | Hessian eigs [-3.4287  3.4287] | flat direction [-0.707 -0.707]
minimum (1, c)    loss 0.0097 | Hessian eigs [0.    8.604] | flat direction [ 0.445 -0.896]
minimum (2, c/2)  loss 0.0097 | Hessian eigs [0.     8.5397] | flat direction [-0.893  0.449]
loss along (t, c/t): [0.0097, 0.0097, 0.0097, 0.0097]
```

At the origin the Hessian has eigenvalues $\pm 2\,\overline{xy}$: a saddle, which a gradient method can escape along the
negative-curvature direction $(1, 1)/\sqrt 2$. At either minimum one eigenvalue is zero, and its eigenvector is the
tangent $(w_1, -w_2)$ of the curve $w_1 w_2 = c$, along which the loss is constant. Real networks have this on a huge
scale (hidden-unit permutations, per-layer rescaling), so a PD Hessian at a minimum is the exception, and the useful
question is how large the positive eigenvalues are.

## The condition number of the Hessian controls gradient descent

In a bowl much steeper one way than another, gradient descent bounces: a step big enough to progress along the gentle
floor overshoots across the steep wall. The **condition number** $\kappa = \lambda_{\max}/\lambda_{\min}$ of the Hessian,
steepest over gentlest curvature, measures how badly.

### Gradient descent on a quadratic, one eigen-direction at a time

This shows the convergence rate depends on $\kappa$ alone. For $f(x) = \tfrac12 x^\top A x$ the gradient is $Ax$, so
$x_{t+1} = (I - \eta A)x_t$ with step size $\eta$. In the eigenbasis each coordinate is multiplied by $1 - \eta\lambda_i$
per step. The best fixed step $\eta = 2/(\lambda_{\min} + \lambda_{\max})$ balances the two extremes:

$$
|1 - \eta\lambda_{\min}| = |1 - \eta\lambda_{\max}| = \frac{\kappa - 1}{\kappa + 1}
\quad\Longrightarrow\quad
\text{steps to shrink the error by } \varepsilon \approx \frac{\kappa}{2}\ln\frac{1}{\varepsilon}.
$$

The factor on the steep direction is negative, so that coordinate flips sign every step: the zig-zag. Ch. 10 proves the
general rate, ch. 11 shows momentum cuts $\kappa$ to $\sqrt\kappa$, and ch. 12 shows Newton's method removes it by
multiplying by $H^{-1}$.

```python
def gd_steps(kappa, tol=1e-6, max_steps=200_000):
    A = np.diag([kappa, 1.0]); eta = 2 / (kappa + 1); x = np.array([1.0, 1.0]); path = [x.copy()]
    for t in range(1, max_steps + 1):
        x = x - eta * (A @ x); path.append(x.copy())
        if np.linalg.norm(x) < tol * np.sqrt(2): return t, np.array(path)
for kappa in (1, 10, 100, 1000):
    t, path = gd_steps(kappa)
    print(f"kappa {kappa:6d}: steps to 1e-6 = {t:6d} | prediction (kappa/2) ln(1e6) = {kappa / 2 * np.log(1e6):8.0f}"
          f" | first steep-coordinate signs {np.sign(path[1:7, 0]).astype(int)}")
```


A round bowl ($\kappa = 1$) takes one step; otherwise the count matches $\tfrac{\kappa}{2}\ln 10^6$ to the step and the
steep coordinate flips sign every step. This is why you standardize features before gradient descent on a linear model:
its Hessian is $X^\top X/n$, and features on wildly different scales make $\kappa$ huge.

## Completing the square in matrix form

In school you rewrite $ax^2 + bx$ as $a(x + b/2a)^2 - b^2/4a$ to read off the vertex. The matrix version is the most
used trick in Gaussian inference: a log-density that is a PD quadratic in $x$ is a Gaussian, mean and covariance readable.

### The identity

This shows a PD quadratic plus a linear term is a shifted bowl. For PD $A$ and any vector $b$,

$$
\tfrac12 x^\top A x - b^\top x = \tfrac12 (x - A^{-1}b)^\top A\,(x - A^{-1}b) - \tfrac12 b^\top A^{-1} b ,
$$

which you verify by expanding the right side. The minimizer is $x^\star = A^{-1}b$ (the normal equations of least
squares are this with $A = X^\top X$, $b = X^\top y$), and $\exp(-\tfrac12 x^\top Ax + b^\top x)$ is proportional to
a Gaussian with **precision** (inverse covariance) $A$ and mean $A^{-1}b$.

### The Gaussian posterior for Bayesian linear regression

Prior $w \sim \mathcal{N}(0, \tau^2 I)$ and likelihood $y \mid w \sim \mathcal{N}(Xw, \sigma^2 I)$ multiply to
$\exp\big(-\tfrac{1}{2\sigma^2}\|y - Xw\|^2 - \tfrac{1}{2\tau^2}\|w\|^2\big)$. Collecting the terms in $w$ gives
$A = X^\top X/\sigma^2 + I/\tau^2$ and $b = X^\top y/\sigma^2$, so completing the square gives the posterior directly
(Bayesian ML ch. 2 does the conjugate algebra in general):

$$
w \mid y \sim \mathcal{N}\big(A^{-1}b,\; A^{-1}\big), \qquad A^{-1}b = (X^\top X + \tfrac{\sigma^2}{\tau^2}I)^{-1}X^\top y \;\text{ (the ridge solution).}
$$

```python
from scipy.linalg import cho_factor, cho_solve
from sklearn.linear_model import Ridge
n, d, sig, tau = 40, 3, 0.5, 1.0
Xb = rng.standard_normal((n, d)); yb = Xb @ np.array([1.0, -0.5, 0.25]) + sig * rng.standard_normal(n)
Ab = Xb.T @ Xb / sig**2 + np.eye(d) / tau**2; bb = Xb.T @ yb / sig**2
cf = cho_factor(Ab); m_post = cho_solve(cf, bb)                    # posterior covariance: cho_solve(cf, I)
neglogpost = lambda w: 0.5 / sig**2 * np.sum((yb - Xb @ w) ** 2) + 0.5 / tau**2 * w @ w
W = rng.standard_normal((5, d))                                     # check the identity at random points
gap = [neglogpost(w) - 0.5 * (w - m_post) @ Ab @ (w - m_post) for w in W]
print("posterior mean    :", m_post, "| ridge (alpha = sigma^2/tau^2):",
      Ridge(alpha=sig**2 / tau**2, fit_intercept=False).fit(Xb, yb).coef_)
print("neg-log-post minus completed square at 5 random w (must be constant):", np.round(gap, 8))
```

```output
posterior mean    : [ 0.9597 -0.4609  0.1727] | ridge (alpha = sigma^2/tau^2): [ 0.9597 -0.4609  0.1727]
neg-log-post minus completed square at 5 random w (must be constant): [23.3956 23.3956 23.3956 23.3956 23.3956]
```

The posterior mean equals ridge with $\alpha = \sigma^2/\tau^2$, and the negative log-posterior minus the completed
square is the same constant (23.3956) at every test point: same shape, same center. Every Kalman update and GP posterior
(Bayesian ML ch. 12) is this computation with different $A$ and $b$, through a Cholesky factor rather than an inverse.

## The Schur complement: positive definiteness of a block matrix

Split a symmetric matrix into blocks, $M = \begin{pmatrix} A & B \\ B^\top & C \end{pmatrix}$, with $A$ PD. One block
step of elimination leaves the **Schur complement** $M/A = C - B^\top A^{-1} B$: what remains of $C$ after explaining
away what $A$ explains. It tells you whether $M$ is PD, and what a Gaussian does when you observe some coordinates.

### Block elimination and the PD condition

This shows $M$ is PD exactly when $A$ and the Schur complement are. Block elimination factors $M$ as

$$
M = \begin{pmatrix} I & 0 \\ B^\top A^{-1} & I \end{pmatrix}
\begin{pmatrix} A & 0 \\ 0 & C - B^\top A^{-1} B \end{pmatrix}
\begin{pmatrix} I & A^{-1}B \\ 0 & I \end{pmatrix},
$$

a congruence $M = T^\top D T$ with $T$ invertible, so $x^\top M x = (Tx)^\top D (Tx)$ and $M$ is PD iff $D$ is, i.e.
iff $A \succ 0$ and $M/A \succ 0$ ($\succ 0$ is shorthand for PD). Inverting the factorization also gives the lower-right
block of $M^{-1}$ as $(M/A)^{-1}$, and $\det M = \det A \cdot \det(M/A)$.

### Gaussian conditioning falls out

For a joint Gaussian $(x_a, x_b)$ with covariance blocks $\Sigma_{aa}, \Sigma_{ab}, \Sigma_{bb}$, the joint density in
$x_a$ (with $x_b$ fixed) is a PD quadratic; completing the square with the block inverse gives

$$
x_a \mid x_b \sim \mathcal{N}\big(\mu_a + \Sigma_{ab}\Sigma_{bb}^{-1}(x_b - \mu_b),\;\; \Sigma_{aa} - \Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba}\big).
$$

The conditional covariance is the Schur complement $\Sigma/\Sigma_{bb}$: PD, and never larger than $\Sigma_{aa}$
(observing can only remove uncertainty), and the mean is a linear regression of $x_a$ on $x_b$. Below: check against
the block of $\Sigma^{-1}$ and against a regression on samples.

```python
Qs, _ = np.linalg.qr(rng.standard_normal((4, 4))); Sg = Qs @ np.diag([4.0, 2.0, 1.0, 0.5]) @ Qs.T
a, b = [0, 1], [2, 3]
Saa, Sab, Sbb = Sg[np.ix_(a, a)], Sg[np.ix_(a, b)], Sg[np.ix_(b, b)]
schur = Saa - Sab @ np.linalg.solve(Sbb, Sab.T)
print("Schur complement eigs:", np.linalg.eigvalsh(schur), "| Sigma_aa eigs:", np.linalg.eigvalsh(Saa))
print("inv(Schur) == block aa of inv(Sigma):", np.allclose(np.linalg.inv(schur), np.linalg.inv(Sg)[np.ix_(a, a)]))
Zs = rng.multivariate_normal(np.zeros(4), Sg, 400_000)
coef, *_ = np.linalg.lstsq(Zs[:, b], Zs[:, a], rcond=None)            # regress x_a on x_b
print("regression coef^T  :", coef.T.round(3).tolist(), "\nSab Sbb^-1         :", (Sab @ np.linalg.inv(Sbb)).round(3).tolist())
print("residual covariance:", np.cov((Zs[:, a] - Zs[:, b] @ coef).T).round(3).tolist(), "\nSchur complement   :", schur.round(3).tolist())
M_bad = Sg.copy(); M_bad[np.ix_(b, b)] = Sab.T @ np.linalg.solve(Saa, Sab) - 0.01 * np.eye(2)   # make the other Schur complement negative
print("M with C below B^T A^-1 B: Schur eigs", np.linalg.eigvalsh(M_bad[np.ix_(b, b)] - Sab.T @ np.linalg.solve(Saa, Sab)),
      "| min eig of M", round(np.linalg.eigvalsh(M_bad).min(), 4))
```

```output

inv(Schur) == block aa of inv(Sigma): True
regression coef^T  : [[-0.493, 0.909], [0.315, -0.27]]
Sab Sbb^-1         : [[-0.495, 0.911], [0.314, -0.268]]
```

The Schur complement's eigenvalues are below those of $\Sigma_{aa}$, its inverse is the precision block, and the
regression on 400,000 samples recovers $\Sigma_{ab}\Sigma_{bb}^{-1}$ with residual covariance equal to the complement up

## The nearest PSD matrix: clip the negative eigenvalues

Matrices assembled piece by piece often fail to be PSD: correlations on pairwise-complete rows with missing data, a
correlation matrix typed in by hand, a finite-difference Hessian. Each entry is plausible, the whole is not; the repair
is the closest PSD matrix.

### Why clipping is optimal in the Frobenius norm

This shows the best PSD approximation keeps the eigenvectors and replaces negative eigenvalues by zero. Write the
symmetric $A = Q\Lambda Q^\top$. The Frobenius norm (square root of the sum of squared entries) is unchanged by
orthogonal rotations, so for any PSD $X$, with $Y = Q^\top X Q$ (also PSD, so $Y_{ii} \ge 0$),

$$
\|A - X\|_F^2 = \|\Lambda - Y\|_F^2 \ge \sum_i (\lambda_i - Y_{ii})^2 \ge \sum_{i:\,\lambda_i < 0} \lambda_i^2 ,
$$

and $X_+ = Q\max(\Lambda, 0)Q^\top$ attains the bound. For a correlation matrix you also want a unit diagonal; Higham's
(2002) alternating projections handle that, and the one-step version below (clip, then rescale) is the common shortcut.

```python
d = 8
Xm = rng.multivariate_normal(np.zeros(d), 0.6 * np.ones((d, d)) + 0.4 * np.eye(d), 30)
Xm[rng.random(Xm.shape) < 0.5] = np.nan                            # half the values missing
import pandas as pd
R_pw = pd.DataFrame(Xm).corr(min_periods=3).to_numpy()            # pairwise-complete correlations
e, Qe = np.linalg.eigh(R_pw)
R_clip = Qe @ np.diag(np.clip(e, 0, None)) @ Qe.T
s = np.sqrt(np.diag(R_clip)); R_fix = R_clip / np.outer(s, s)
print("pairwise corr eigs  :", np.round(e, 3))
for name, R in (("clipped", R_clip), ("clipped + unit diag", R_fix)):
    print(f"{name:20s} min eig {np.linalg.eigvalsh(R).min():8.1e} | ||R - R_pw||_F {np.linalg.norm(R - R_pw):.4f}"
          f" | max |diag - 1| {np.abs(np.diag(R) - 1).max():.3f}")
```

```output
pairwise corr eigs  : [-0.707  0.005  0.173  0.31   0.665  1.505  1.668  4.383]
clipped              min eig  4.2e-16 | ||R - R_pw||_F 0.7075 | max |diag - 1| 0.250
clipped + unit diag  min eig  1.6e-16 | ||R - R_pw||_F 0.8477 | max |diag - 1| 0.000
```

The pairwise matrix has an eigenvalue of $-0.707$, so no data set could have produced it. Clipping moves it by
0.7075, exactly that eigenvalue's size (the bound), but breaks the unit diagonal by up to 0.25; rescaling restores the
diagonal at some extra distance (0.848).

```python
def R_eq(rho, d): return (1 - rho) * np.eye(d) + rho * np.ones((d, d))
def chol_ok(M):
    try: np.linalg.cholesky(M); return True
    except np.linalg.LinAlgError: return False

d = 10
print("eigvalsh R(0.3):", np.unique(np.linalg.eigvalsh(R_eq(0.3, d)).round(6)),
      "| formula: 1 + (d-1) rho =", round(1 + 9 * 0.3, 6), ", 1 - rho =", 0.7)
lo, hi = -0.5, 0.0                                   # Cholesky fails at lo, succeeds at hi
for _ in range(50):
    mid = (lo + hi) / 2
    lo, hi = (lo, mid) if chol_ok(R_eq(mid, d)) else (mid, hi)
print(f"bisection boundary {hi:.8f} | formula -1/(d-1) = {-1 / (d - 1):.8f}")

R = R_eq(-0.2, d); e, Q = np.linalg.eigh(R)
R_plus = Q @ np.diag(np.clip(e, 0, None)) @ Q.T
print("eigs of R(-0.2):", np.unique(e.round(6)), "| ||R - R+||_F =", round(np.linalg.norm(R - R_plus), 6),
      "| bound |lambda_neg| =", round(abs(e.min()), 6))
```


$R\mathbf{1} = (1 - \rho + \rho d)\mathbf{1}$, and for $v \perp \mathbf{1}$, $Rv = (1 - \rho)v$, so the eigenvalues are
$1 + (d-1)\rho$ (once) and $1 - \rho$ ($d - 1$ times). PD therefore needs $-1/(d-1) < \rho < 1$: in high dimension,
many variables cannot all be strongly negatively correlated with each other, because their sum would have negative
variance. Bisection on the Cholesky verdict lands on $-1/9$. At $\rho = -0.2$ only the eigenvalue along $\mathbf{1}$ is
negative, clipping sets it to zero, and the distance equals its absolute value as the optimality bound says. The
repaired matrix is still equicorrelated (eigenvectors are kept), with diagonal $1.08$ and off-diagonal $-0.12$: after
rescaling to unit diagonal that is $\rho = -0.12/1.08 = -1/9$, exactly the boundary of the PD range.
