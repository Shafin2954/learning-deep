## The constrained problem

Sometimes you want the lowest point of a landscape, but you're only allowed to stand on a
particular path — "find the cheapest diet that still has exactly 2000 calories". That's a
**constrained** problem: minimize something *subject to* a rule you must obey.

Unconstrained gradient descent finds $\min_w f(w)$ over all of $\mathbb{R}^d$. Real problems often have **equality constraints**:

$$
\min_{x \in \mathbb{R}^d} f(x) \quad \text{subject to} \quad g(x) = 0
$$

> **In plain words:** "find the $x$ that makes $f$ as small as possible, but only among the
> $x$ that make $g(x)$ exactly zero". Any rule can be written as $g(x) = 0$: "$x_1 + x_2 = 1$"
> becomes $g(x) = x_1 + x_2 - 1$.

Examples: minimum-norm solution with $Ax = b$, SVM margin maximisation with $y_i(w^T x_i + b) = 1$ for support vectors, PCA with orthonormal loading constraint $W^T W = I$.

> **Picture it:** you're hiking on a mountain, but you must stay on a marked trail. The
> lowest point of the trail is usually *not* the lowest point of the mountain — it's where
> the trail runs level with the hillside's contour lines.

## The Lagrangian

Lagrange's trick turns a constrained problem into an unconstrained one: add the constraint
to the objective, multiplied by a new unknown number $\lambda$ that says "how hard the rule
pushes back".

Attach a **Lagrange multiplier** $\lambda \in \mathbb{R}$ to each constraint and form the **Lagrangian**:

$$
\mathcal{L}(x, \lambda) = f(x) + \lambda g(x)
$$

**Theorem (KKT stationarity for equality constraints):** At a constrained minimum, there exists $\lambda^*$ such that:

$$
\nabla_x \mathcal{L}(x^*, \lambda^*) = \nabla_x f(x^*) + \lambda^* \nabla_x g(x^*) = 0
$$
$$
\nabla_\lambda \mathcal{L}(x^*, \lambda^*) = g(x^*) = 0
$$

The second equation just says the constraint is satisfied.

> **In plain words:** set the derivative of $\mathcal{L}$ to zero with respect to *every*
> unknown — the original $x$ and the new $\lambda$. The $x$-equations say "the slopes of $f$
> and $g$ balance"; the $\lambda$-equation gives back the rule $g(x) = 0$. Then solve them
> together like any system of equations. (**KKT** = Karush–Kuhn–Tucker, the names behind the
> general version with inequality constraints.)

## Geometric intuition

At the best point on the trail, the trail can't be leading you downhill any more — so the
hill's steepest direction must point straight *across* the trail, not along it.

At the constrained optimum, the **gradient of $f$ must be parallel to the gradient of $g$**. Equivalently, the level curves of $f$ and $g$ are tangent — if they weren't, you could move along the constraint surface $\{g=0\}$ to decrease $f$.

A **level curve** is a contour line: all the points where a function has the same value.
$\nabla g$ points straight out of the trail $\{g = 0\}$; if $\nabla f$ had any piece pointing
*along* the trail, you could walk that way and do better. At the optimum,
$\nabla f = -\lambda \nabla g$ — parallel — and $\lambda$ is the ratio between them.

### Worked example: maximise $x_1 x_2$ subject to $x_1 + x_2 = 1$

This is "two numbers add up to 1; make their product as big as possible" — the same as
"which rectangle with a fixed perimeter has the largest area?".

$$
\mathcal{L} = x_1 x_2 + \lambda(x_1 + x_2 - 1)
$$

Stationarity:
$$
\frac{\partial \mathcal{L}}{\partial x_1} = x_2 + \lambda = 0 \implies \lambda = -x_2
$$
$$
\frac{\partial \mathcal{L}}{\partial x_2} = x_1 + \lambda = 0 \implies \lambda = -x_1
$$

So $x_1 = x_2$. Combined with $x_1 + x_2 = 1$: $x_1^* = x_2^* = 1/2$, $\lambda^* = -1/2$, maximum $= 1/4$.
The answer is a square — the familiar fact that, for a fixed perimeter, the square has the
largest area. The same equations find maxima as well as minima; you check which one you got
afterwards.

```python
import numpy as np
from scipy.optimize import minimize

# Verify analytically: x1=x2=0.5
x_star = np.array([0.5, 0.5])
print("f(x*) = x1*x2 =", x_star[0]*x_star[1])
print("Constraint satisfied:", np.isclose(x_star.sum(), 1.0))

# Also verify via numerical constrained optimization
def neg_f(x): return -x[0]*x[1]
constraint = {'type': 'eq', 'fun': lambda x: x[0]+x[1]-1}
result = minimize(neg_f, [0.3, 0.7], constraints=[constraint])
print("Numerical solution:", result.x.round(6))
print("Numerical f*:", -result.fun)
```

```output
f(x*) = x1*x2 = 0.25
Constraint satisfied: True
Numerical solution: [0.5 0.5]
Numerical f*: 0.25
```

SciPy's general constrained solver (`minimize` with an `'eq'` constraint, maximizing by
minimizing $-f$) lands on exactly $(0.5, 0.5)$ with value 0.25 — the hand derivation agrees.

> **In plain words:** the multiplier has a meaning. $\lambda^*$ measures how much the best
> value would change if you loosened the rule a little: here $|\lambda^*| = 1/2$, so allowing
> $x_1 + x_2 = 1.01$ raises the best product by about $0.01 \times 1/2 = 0.005$. Economists call
> $\lambda$ the **shadow price** of the constraint.

## Multiple constraints

With $m$ constraints $g_i(x) = 0$, the Lagrangian is:

$$
\mathcal{L}(x, \lambda) = f(x) + \sum_{i=1}^m \lambda_i g_i(x)
$$

Stationarity gives $d + m$ equations for the $d + m$ unknowns $(x^*, \lambda^*)$.

One multiplier per rule; one equation per unknown. That's why the method always gives a
square system to solve.

## The minimum-norm solution to $Ax = b$

When a system has fewer equations than unknowns, there are infinitely many solutions. The
natural tie-breaker is "the smallest one" — and Lagrange multipliers find it in closed form.

Minimise $\|x\|^2$ subject to $Ax = b$ (under-determined system, infinitely many solutions):

$$
\mathcal{L}(x, \lambda) = x^T x + \lambda^T (Ax - b)
$$

Here $\lambda$ is a *vector* (one multiplier per equation), so the term is the dot product
$\lambda^T (Ax - b)$.

Stationarity: $2x + A^T \lambda = 0 \implies x = -\frac{1}{2} A^T \lambda$.

Substituting into $Ax = b$: $-\frac{1}{2} A A^T \lambda = b \implies \lambda = -2(AA^T)^{-1} b$.

So the minimum-norm solution is:

$$
x^* = A^T (A A^T)^{-1} b
$$

This is the **Moore–Penrose pseudoinverse** $A^\dagger b$ when $m < n$.

> **In plain words:** the first line says the best $x$ is a mix of the rows of $A$ — any
> part of $x$ outside those rows would add length without helping satisfy $Ax = b$. The
> second line finds the mix. The **pseudoinverse** is the "best possible inverse" for
> matrices that don't have a real one.

```python
import numpy as np

rng = np.random.default_rng(0)
m, n = 3, 8   # under-determined: fewer equations than unknowns
A = rng.standard_normal((m, n))
b = rng.standard_normal(m)

# Minimum-norm solution via Lagrange
x_star = A.T @ np.linalg.solve(A @ A.T, b)

# Verify via pseudoinverse
x_pinv = np.linalg.lstsq(A, b, rcond=None)[0]

print("Residual ||Ax* - b||:", np.linalg.norm(A @ x_star - b))
print("||x_star||:          ", np.linalg.norm(x_star))
print("||x_pinv||:          ", np.linalg.norm(x_pinv))
print("Both solutions match:", np.allclose(x_star, x_pinv))
```

```output
Residual ||Ax* - b||: 2.618455766672135e-16
||x_star||:           0.686460044181314
||x_pinv||:           0.6864600441813142
Both solutions match: True
```

The residual is $10^{-16}$, so $x^*$ satisfies all 3 equations, and its length (0.6865)
matches NumPy's `lstsq` (which uses the pseudoinverse via SVD) to the last digit. Any other of
the infinitely many solutions would be longer.

## Augmented Lagrangian solver

A practical algorithm alternates two moves: take gradient steps on $x$ for a fixed
$\lambda$, then nudge $\lambda$ in the direction that punishes the current rule violation.
An extra penalty term keeps it stable.

For numerical problems, the **augmented Lagrangian** adds a quadratic penalty to stabilise the solve:

$$
\mathcal{L}_\rho(x, \lambda) = f(x) + \lambda g(x) + \frac{\rho}{2} g(x)^2
$$

> **In plain words:** $\frac{\rho}{2} g(x)^2$ is a spring that pulls $x$ back toward the
> constraint, getting stronger the further you stray; $\rho$ is the spring's stiffness. The
> multiplier update `lam += rho * g(x)` (a **dual update**) remembers how much the rule has
> been violated, so the spring doesn't have to be infinitely stiff.

```python
import numpy as np

# Solve: min x1^2 + x2^2  s.t. x1 + x2 = 1
# Analytic solution: x1* = x2* = 0.5

def f(x):     return x[0]**2 + x[1]**2
def g(x):     return x[0] + x[1] - 1
def grad_f(x): return 2*x
def grad_g(x): return np.array([1.0, 1.0])

rho = 10.0
lam = 0.0
x = np.array([0.0, 0.0])
eta = 0.01

for outer in range(50):
    # Inner loop: minimise augmented Lagrangian wrt x
    for _ in range(200):
        g_val = g(x)
        grad = grad_f(x) + lam * grad_g(x) + rho * g_val * grad_g(x)
        x = x - eta * grad
    # Dual update
    lam += rho * g(x)

print(f"x* = {x.round(6)}  (expected [0.5, 0.5])")
print(f"Constraint: g(x*) = {g(x):.2e}  (expected ~0)")
print(f"f(x*) = {f(x):.6f}  (expected 0.5)")
```

```output
x* = [0.5 0.5]  (expected [0.5, 0.5])
Constraint: g(x*) = 0.00e+00  (expected ~0)
f(x*) = 0.500000  (expected 0.5)
```

After 50 rounds of (200 inner gradient steps + one multiplier update), $x$ is $(0.5, 0.5)$,
the constraint violation is zero to printed precision, and $f = 0.5$ — the closest point to the
origin on the line $x_1 + x_2 = 1$.

## Recap in plain words

- Constrained optimization: minimize $f(x)$ while obeying $g(x) = 0$.
- The Lagrangian $f + \lambda g$ turns it into "set every derivative to zero", including the
  derivative in $\lambda$ (which gives back the constraint).
- Geometrically, at the optimum $\nabla f$ is parallel to $\nabla g$ — contour lines touch.
- The multiplier $\lambda^*$ is the shadow price: how fast the best value changes if you loosen
  the constraint.
- Minimum-norm solution of $Ax = b$: $x^* = A^T (A A^T)^{-1} b$, the pseudoinverse.
- Augmented Lagrangian: gradient steps on $x$, multiplier updates on $\lambda$, plus a penalty
  spring.

## Try it Yourself

```python
import numpy as np
from scipy.optimize import minimize

# Find the point on the unit circle closest to (3, 4)
# min (x-3)^2 + (y-4)^2  s.t. x^2 + y^2 = 1

def f(v): return (v[0]-3)**2 + (v[1]-4)**2
constraint = {'type': 'eq', 'fun': lambda v: v[0]**2 + v[1]**2 - 1}
result = minimize(f, [1.0, 0.0], constraints=[constraint])
x_opt = result.x

print(f"Optimal point: ({x_opt[0]:.6f}, {x_opt[1]:.6f})")
print(f"Distance from (3,4) to unit circle: {np.sqrt(f(x_opt)):.6f}")
print(f"Expected: (3/5, 4/5) = ({0.6:.6f}, {0.8:.6f})")
print(f"Constraint check: x^2+y^2 = {np.sum(x_opt**2):.6f}")
```

```output
Optimal point: (0.600002, 0.799998)
Distance from (3,4) to unit circle: 4.000000
Expected: (3/5, 4/5) = (0.600000, 0.800000)
Constraint check: x^2+y^2 = 1.000000
```

The closest point on the unit circle to $(3, 4)$ lies on the straight line from the origin to
$(3, 4)$, scaled to length 1: $(3, 4)/5 = (0.6, 0.8)$. The solver gets it to five decimals, and
the distance is $5 - 1 = 4$ (the point is 5 from the origin, the circle has radius 1). Try a
starting guess of `[-1.0, 0.0]`, on the far side of the circle, and see whether the solver
still finds the near point — or the farthest point, which is also a stationary point.

## Exercise

Use Lagrange multipliers (analytically, then verify numerically) to find the point on the line $x + 2y = 5$ closest to the origin.

> **Hint:** minimize the squared distance $x^2 + y^2$ (it has the same minimizer as the
> distance and is easier to differentiate). You'll get three equations in $x$, $y$, $\lambda$.

<details>
<summary>Solution</summary>

```python
import numpy as np

# Analytic: min x^2 + y^2 s.t. x + 2y = 5
# L = x^2 + y^2 + lambda*(x + 2y - 5)
# dL/dx = 2x + lambda = 0  => x = -lambda/2
# dL/dy = 2y + 2*lambda = 0 => y = -lambda
# Constraint: -lambda/2 + 2*(-lambda) = 5 => -5*lambda/2 = 5 => lambda = -2
# So x = 1, y = 2

x_star = np.array([1.0, 2.0])
print(f"Analytic solution: x*={x_star}")
print(f"Constraint satisfied: {np.isclose(x_star[0] + 2*x_star[1], 5)}")
print(f"Distance to origin: {np.linalg.norm(x_star):.6f}")

# Numerical verification
from scipy.optimize import minimize
result = minimize(lambda v: v[0]**2+v[1]**2, [0,0],
                  constraints={'type':'eq','fun':lambda v:v[0]+2*v[1]-5})
print(f"Numerical solution: {result.x.round(6)}")
```

Analytic: $x^*=1$, $y^*=2$, distance $= \sqrt{5} \approx 2.236$.
Notice $(1, 2)$ is a multiple of the line's coefficient vector $(1, 2)$: the closest point lies
along the line's **normal** (the direction perpendicular to it) — the geometric picture of
$\nabla f \parallel \nabla g$.
</details>
