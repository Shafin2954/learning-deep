## Why convexity is a superpower

A **convex** function is shaped like a single bowl — no bumps, no secret second valley. If
you roll a ball into a bowl, it always ends up at the one lowest point. That's why convex
problems are the "easy" ones in optimization: you can't get stuck.

A convex optimisation problem has one stunning property: **every local minimum is a global minimum**. When your loss function is convex, gradient descent is guaranteed to find the best solution, not just a good one. Understanding which losses are convex — and which aren't — tells you when you can trust your optimizer.

A **local minimum** is a point lower than everything right around it; a **global minimum** is
the lowest point anywhere.

> **Picture it:** a convex loss is a smooth salad bowl; a neural network's loss is a
> mountain range at night. In the bowl, "walk downhill" always takes you to the bottom. In
> the mountains, "walk downhill" takes you to *a* valley — maybe not the deepest one.

## Convex sets

A shape is **convex** if, for any two points inside it, the straight line between them stays
inside. A disc is convex; a crescent moon isn't (a line between its tips leaves the shape).

A set $C$ is **convex** if the line segment between any two points in $C$ stays in $C$:

$$
\forall\, x, y \in C,\; \theta \in [0,1]: \quad \theta x + (1-\theta)y \in C
$$

> **In plain words:** $\theta x + (1-\theta)y$ with $\theta$ between 0 and 1 is a point on
> the segment from $y$ (at $\theta = 0$) to $x$ (at $\theta = 1$). The formula says every such
> point is still in $C$. ($\forall$ reads "for all", $\in$ reads "is in".)

Examples: balls $\{x : \|x\| \le r\}$, halfspaces $\{x : a^T x \le b\}$, polyhedra $\{x : Ax \le b\}$.
A **halfspace** is everything on one side of a flat cut; a **polyhedron** is what's left
after several flat cuts — a gem shape.

The intersection of convex sets is convex — this is why Ridge regression (L2 ball $\cap$ residual-fitting ellipsoid) has a unique solution.
(More precisely, the uniqueness comes from the L2 penalty making the loss *strictly* convex:
ridge's Hessian $2X^TX/n + 2\lambda I$ is positive definite, a true bowl with a single
bottom — ch. 7.)

## Convex functions

A function is convex if a straight string tied between any two points on its graph always
sits *on or above* the graph. A bowl passes this test; a wavy line fails it.

A function $f : \mathbb{R}^d \to \mathbb{R}$ is **convex** if its graph lies below the chord between any two points:

$$
f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y) \quad \forall\, x, y,\; \theta \in [0,1]
$$

> **In plain words:** the left side is the function's value at a point between $x$ and $y$;
> the right side is the height of the straight chord at that same point. Convex means "the
> curve never pokes above the chord". (**Concave** is the mirror image: the curve never dips
> below its chords — an upside-down bowl.)

### Second-order condition

If you can take two derivatives, convexity is easier to check: the curvature must never be
negative anywhere.

For twice-differentiable $f$, convexity is equivalent to:

$$
\nabla^2 f(x) \succeq 0 \quad \forall\, x
$$

(the Hessian is positive semi-definite everywhere).

The symbol $\succeq 0$ means "is PSD" (ch. 7). In one dimension it's the school rule
"$f''(x) \ge 0$ everywhere": $x^2$ has $f'' = 2$, convex; $\sin x$ has $f'' = -\sin x$,
which changes sign, so it's not.

### First-order condition (the key inequality)

For a convex function, the tangent line at any point lies entirely below the curve. This is
the fact that makes "gradient = 0" a guarantee of the global minimum.

If $f$ is convex and differentiable:

$$
f(y) \ge f(x) + \nabla f(x)^T (y - x) \quad \forall\, x, y
$$

The tangent plane at $x$ is a **global lower bound** on $f$. Setting $\nabla f(x) = 0$ makes the tangent plane horizontal, proving the point is a global minimum.

> **In plain words:** if the gradient is zero, the right side becomes just $f(x)$, so the
> inequality says $f(y) \ge f(x)$ for *every* $y$ — nothing anywhere is lower than $x$.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Visualise the chord condition for a convex function
w = np.linspace(-3, 3, 300)
f = w**2   # convex

x1, x2 = -2.0, 1.5
theta = 0.4
x_mid = theta * x1 + (1 - theta) * x2

print("Chord condition check:")
print(f"  f(theta*x1 + (1-theta)*x2) = f({x_mid:.2f}) = {x_mid**2:.4f}")
print(f"  theta*f(x1) + (1-theta)*f(x2) = {theta*x1**2 + (1-theta)*x2**2:.4f}")
print(f"  Chord above graph: {theta*x1**2 + (1-theta)*x2**2 >= x_mid**2}")
```

```output
Chord condition check:
  f(theta*x1 + (1-theta)*x2) = f(0.10) = 0.0100
  theta*f(x1) + (1-theta)*f(x2) = 2.9500
  Chord above graph: True
```

At the midpoint-ish spot $0.4 \cdot (-2) + 0.6 \cdot 1.5 = 0.1$, the curve $w^2$ is at
height 0.01, while the chord between $(-2, 4)$ and $(1.5, 2.25)$ is at height 2.95 — far
above. That's the chord condition holding for one choice of points; convexity means it holds
for all of them.

## MSE loss is convex

**MSE** (mean squared error) is the average squared gap between predictions and targets.
For a linear model it's always a perfect bowl in the weights.

For linear regression with loss $f(w) = \|Xw - y\|^2 / n$, the Hessian is $2X^TX/n$, which is PSD. So MSE is always convex, and GD finds the global optimum. (**GD** = gradient
descent, ch. 9.)

```python
import numpy as np

rng = np.random.default_rng(0)
n, d = 100, 2
X = rng.standard_normal((n, d))
y = X @ np.array([2.0, -1.0]) + rng.standard_normal(n) * 0.5

def mse(w):
    return np.mean((X @ w - y)**2)

def mse_grad(w):
    return 2 * X.T @ (X @ w - y) / n

# Grid over w1, w2 space to verify single minimum
w1_grid = np.linspace(0, 4, 50)
w2_grid = np.linspace(-3, 1, 50)
W1, W2 = np.meshgrid(w1_grid, w2_grid)
Z = np.array([[mse(np.array([w1, w2])) for w1 in w1_grid] for w2 in w2_grid])

min_idx = np.unravel_index(Z.argmin(), Z.shape)
print(f"Grid minimum at w = ({w1_grid[min_idx[1]]:.2f}, {w2_grid[min_idx[0]]:.2f})")

# Normal equations give exact answer
w_star = np.linalg.solve(X.T @ X, X.T @ y)
print(f"Normal equation w* = ({w_star[0]:.4f}, {w_star[1]:.4f})")
print(f"Gradient at w*: {np.round(mse_grad(w_star), 8)}")
```

```output
Grid minimum at w = (1.96, -0.96)
Normal equation w* = (1.9533, -0.9228)
Gradient at w*: [0. 0.]
```

Three views of the same bottom. A brute-force search over a 50×50 grid lands at
$(1.96, -0.96)$, as close as the grid spacing allows; the exact normal-equation answer (ch. 2)
is $(1.9533, -0.9228)$; and the gradient there is $[0, 0]$. There's only one bowl bottom to
find. The data was generated with true weights $(2, -1)$ plus noise, so the fit is close to
the truth.

## Cross-entropy is convex (in the linear model weights)

**Logistic regression** predicts a probability with $\sigma(w^T x)$, where $\sigma$ (the
sigmoid) squashes any number into $(0, 1)$. Its cross-entropy loss is also a single bowl.

For logistic regression, $f(w) = -\frac{1}{n}\sum_i [y_i \log \sigma(w^T x_i) + (1-y_i)\log(1-\sigma(w^T x_i))]$. The Hessian is $X^T S X / n$ where $S = \text{diag}(\sigma_i(1-\sigma_i))$ — PSD. So logistic regression has a unique global minimum too.

> **Watch out:** "unique" needs a caveat. If the classes can be separated perfectly by a
> line, the loss keeps decreasing as $\|w\| \to \infty$ and the minimum is never reached —
> the weights blow up. Regularization (ch. 7's $+\varepsilon I$) restores a finite, unique
> answer.

## Neural network loss is NOT convex

Stack two layers with a bend (a non-linearity) between them and the bowl breaks into a
landscape of many valleys. You lose the guarantee — but gradient descent still works well in
practice.

The moment you compose two linear layers through a nonlinearity (ReLU, sigmoid), the loss becomes non-convex. Multiple local minima exist. Gradient descent finds a good — but not provably optimal — solution.

One easy way to see non-convexity: swap two hidden units (and their weights) and the network
computes the identical function. So if one weight setting is a minimum, the swapped setting
is another one, and the average of the two usually isn't — exactly the chord condition
failing.

```python
import numpy as np

rng = np.random.default_rng(1)

# Simple 1D non-convex: two-layer net output f(w) = relu(w)*w (schematic)
def f_nonconvex(w):
    return np.sin(3*w) + 0.5*w**2 - 2*np.cos(w)

w_vals = np.linspace(-4, 4, 1000)
f_vals = f_nonconvex(w_vals)

local_min_idx = np.where(
    (f_vals[1:-1] < f_vals[:-2]) & (f_vals[1:-1] < f_vals[2:])
)[0] + 1

print("Approximate local minima at w =", np.round(w_vals[local_min_idx], 3))
print("Function values             =", np.round(f_vals[local_min_idx], 3))
print("Global min at w =", round(w_vals[f_vals.argmin()], 3))
```

```output
Approximate local minima at w = [-0.388  1.125]
Function values             = [-2.694 -0.461]
Global min at w = -0.388
```

Two local minima: one at $w \approx -0.388$ with value $-2.694$ (the global one) and one at
$w \approx 1.125$ with value $-0.461$. Start gradient descent at $w = 2$ and it rolls into the
shallower valley and stops there.

So gradient descent finds different minima depending on initialisation.

## Recap in plain words

- Convex = one bowl: every local minimum is the global minimum, so gradient descent can't
  get stuck.
- A convex set contains the straight segment between any two of its points; intersections
  of convex sets stay convex.
- Convex function tests: chords lie above the graph; the Hessian is PSD everywhere; tangent
  planes lie below the graph.
- Linear regression (MSE) and logistic regression (cross-entropy) are convex in their
  weights; neural networks are not.
- For a convex differentiable function, gradient = 0 means global minimum.

## Try it Yourself

```python
import numpy as np

# Verify convexity of log-sum-exp by checking the chord condition
def log_sum_exp(x):
    c = x.max()
    return c + np.log(np.sum(np.exp(x - c)))

rng = np.random.default_rng(0)
n_checks = 1000
violations = 0
for _ in range(n_checks):
    x = rng.standard_normal(5)
    y = rng.standard_normal(5)
    theta = rng.uniform(0, 1)
    mid = theta * x + (1 - theta) * y
    lhs = log_sum_exp(mid)
    rhs = theta * log_sum_exp(x) + (1 - theta) * log_sum_exp(y)
    if lhs > rhs + 1e-9:
        violations += 1

print(f"Chord violations in {n_checks} random checks: {violations}")
print("log-sum-exp is convex:", violations == 0)
```

```output
Chord violations in 1000 random checks: 0
log-sum-exp is convex: True
```

**Log-sum-exp**, $\log \sum_i e^{x_i}$, is the "soft maximum" that sits inside softmax and
cross-entropy. 1000 random chords and zero violations is strong evidence it's convex (and
it is — provably). Random testing can't *prove* convexity, but a single violation proves a
function is *not* convex. Try replacing it with `np.sin(x).sum()` and count the violations.

Classify each function as convex, concave, or neither, and verify numerically using the chord condition on random inputs.

Functions: $f(x) = x^2$, $f(x) = \log x$ (for $x > 0$), $f(x) = \max(0, x)$ (ReLU), $f(x) = \sin x$.

```python
import numpy as np

rng = np.random.default_rng(0)

def check_convexity(f, lo, hi, n=2000):
    xs = rng.uniform(lo, hi, n)
    ys = rng.uniform(lo, hi, n)
    thetas = rng.uniform(0, 1, n)
    mids = thetas * xs + (1 - thetas) * ys
    lhs = f(mids)
    rhs = thetas * f(xs) + (1 - thetas) * f(ys)
    violations = (lhs > rhs + 1e-9).sum()
    return violations

fns = {
    "x^2":   (lambda x: x**2,      -5,   5),
    "log(x)": (lambda x: np.log(x), 0.1, 10),
    "relu(x)": (lambda x: np.maximum(0, x), -5, 5),
    "sin(x)": (lambda x: np.sin(x), -5,  5),
}

for name, (fn, lo, hi) in fns.items():
    v = check_convexity(fn, lo, hi)
    tag = "convex" if v == 0 else f"NOT convex ({v} violations)"
    print(f"f(x) = {name:10s}: {tag}")
```

`x^2` and `relu` are convex (0 violations). `log(x)` is concave (many violations of the convexity condition). `sin(x)` is neither (violations in both directions).
ReLU is the interesting one: it's convex (two straight pieces meeting in an upward kink),
yet stacking ReLU layers produces a non-convex loss — convexity doesn't survive composition
with weights on both sides.
