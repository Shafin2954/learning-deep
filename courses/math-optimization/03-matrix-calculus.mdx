## Why matrix calculus

Training a model means nudging thousands of numbers so the error shrinks. To know which
way to nudge each number, you need its **derivative** — how much the error changes when that
number changes a tiny bit. Matrix calculus is how you get all those derivatives at once.

Backpropagation is matrix calculus. When you call `loss.backward()` in PyTorch, it applies
the chain rule to a composition of matrix operations — automatically. Understanding the
derivations by hand means you can debug gradient bugs, implement custom layers, and read
papers that derive gradients without referencing a library.

> **Picture it:** you're blindfolded on a hillside and want to walk downhill. Feeling the
> slope under your feet in every direction is taking derivatives; the gradient is the
> single arrow that summarizes "uphill is this way, this steeply".

## The gradient: scalar output

When a function takes many numbers and returns one (like a loss), its **gradient** lists,
for every input, how fast the output changes as that input moves.

If $f : \mathbb{R}^n \to \mathbb{R}$, the **gradient** is the vector of partial derivatives:

$$
\nabla_x f(x) = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{bmatrix} \in \mathbb{R}^n
$$

A **partial derivative** $\partial f / \partial x_i$ is the ordinary slope of $f$ when you
move only $x_i$ and hold every other input fixed.

The gradient points in the direction of steepest *increase* of $f$. Gradient descent
moves in the direction $-\nabla f$ to decrease $f$.

### Gradient of a quadratic

Quadratics ($x$ times something times $x$) are the bowls of optimization: almost every loss
looks like one when you zoom in. Their gradients have tidy formulas.

For $f(x) = x^\top A x$ with symmetric $A$:

$$
\nabla_x (x^\top A x) = 2Ax
$$

For $f(x) = b^\top x$:

$$
\nabla_x (b^\top x) = b
$$

> **In plain words:** these are the matrix versions of the school rules
> $\frac{d}{dx}(a x^2) = 2ax$ and $\frac{d}{dx}(bx) = b$. The vector $x$ plays the role of
> the single number $x$, and the matrix $A$ plays the role of $a$.

Combining: $f(x) = \tfrac{1}{2} x^\top A x - b^\top x$ gives $\nabla f = Ax - b$.
This is the gradient of the least-squares objective — setting it to zero gives $Ax = b$.
(The $\tfrac{1}{2}$ is there only so the 2 from the first rule cancels.)

The code below checks the formula with **finite differences**: nudge one input up by a
tiny `eps`, nudge it down by `eps`, and divide the change in $f$ by $2 \cdot \text{eps}$.
That's the slope measured directly, with no calculus — the gold-standard test for a
hand-derived gradient.

```python
import numpy as np

def f(x, A, b):
    return 0.5 * x @ A @ x - b @ x

def grad_f(x, A, b):
    return A @ x - b       # analytic gradient

def grad_fd(x, A, b, eps=1e-5):
    """Finite-difference gradient for verification."""
    g = np.zeros_like(x)
    for i in range(len(x)):
        x_plus  = x.copy(); x_plus[i]  += eps
        x_minus = x.copy(); x_minus[i] -= eps
        g[i] = (f(x_plus, A, b) - f(x_minus, A, b)) / (2 * eps)
    return g

rng = np.random.default_rng(0)
n = 4
A = rng.standard_normal((n, n))
A = A.T @ A + np.eye(n)     # make symmetric PD
b = rng.standard_normal(n)
x = rng.standard_normal(n)

g_analytic = grad_f(x, A, b)
g_fd       = grad_fd(x, A, b)

print("analytic :", g_analytic.round(6))
print("finite-d :", g_fd.round(6))
print("max diff :", np.abs(g_analytic - g_fd).max())
```

```output
analytic : [-0.150127  3.176075 -1.372719 -1.193802]
finite-d : [-0.150127  3.176075 -1.372719 -1.193802]
max diff : 2.8120616946125665e-11
```

The two rows agree to every printed digit, and the largest difference is about $10^{-11}$ —
pure rounding error. When you derive a gradient by hand, this check is how you know you got
it right; a wrong formula shows differences of order 1, not $10^{-11}$.

> **Watch out:** finite differences cost two function evaluations *per input*, so they're
> far too slow for training a real network. Use them only to test a small case.

## The Jacobian: vector-to-vector

When a function takes $n$ numbers and returns $m$ numbers, there's one slope for every
(output, input) pair. Lay them out in an $m \times n$ grid and you have the Jacobian.

If $f : \mathbb{R}^n \to \mathbb{R}^m$, the **Jacobian** is the $m \times n$ matrix of all
partial derivatives:

$$
J = \frac{\partial f}{\partial x} = \begin{bmatrix}
\frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\
\vdots & \ddots & \vdots \\
\frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n}
\end{bmatrix} \in \mathbb{R}^{m \times n}
$$

Row $i$ of the Jacobian is the gradient of output $f_i$; column $j$ says how every output
reacts to input $x_j$.

The chain rule for vector functions: if $h = f \circ g$ then
$J_h = J_f \cdot J_g$ (matrix multiply). ($f \circ g$ means "apply $g$, then $f$".)

> **In plain words:** the chain rule says slopes of steps in a chain multiply. If $g$
> doubles small changes and $f$ triples them, the chain multiplies them by 6. With vectors,
> "multiply" becomes matrix multiplication of the Jacobians.

### Jacobian of a linear layer

For $y = Wx + b$ where $W \in \mathbb{R}^{m \times n}$:

$$
\frac{\partial y}{\partial x} = W
$$

The Jacobian is just $W$ itself. This is why the backward pass through a linear layer
multiplies the upstream gradient by $W^\top$: if $\ell$ is the scalar loss,
$\frac{\partial \ell}{\partial x} = W^\top \frac{\partial \ell}{\partial y}$.

That makes sense once you remember that a linear map has the same slope everywhere: output
$y_i$ changes by $W_{ij}$ for every unit of $x_j$, no matter where you start.

```python
import numpy as np

def jacobian_fd(f, x, eps=1e-5):
    """Numerical Jacobian via central differences."""
    y0 = f(x)
    m, n = len(y0), len(x)
    J = np.zeros((m, n))
    for j in range(n):
        xp = x.copy(); xp[j] += eps
        xm = x.copy(); xm[j] -= eps
        J[:, j] = (f(xp) - f(xm)) / (2 * eps)
    return J

rng = np.random.default_rng(1)
W = rng.standard_normal((3, 4))
b = rng.standard_normal(3)
x = rng.standard_normal(4)

f_linear = lambda x: W @ x + b
J_analytic = W
J_numerical = jacobian_fd(f_linear, x)

print("J_analytic:\n", J_analytic.round(4))
print("max |J_analytic - J_numerical|:", np.abs(J_analytic - J_numerical).max())
```

```output
J_analytic:
 [[ 0.3456  0.8216  0.3304 -1.3032]
 [ 0.9054  0.4464 -0.537   0.5811]
 [ 0.3646  0.2941  0.0284  0.5467]]
max |J_analytic - J_numerical|: 1.3004486376644309e-11
```

The numerical Jacobian matches $W$ to about $10^{-11}$, confirming $\partial y / \partial x
= W$. The bias $b$ doesn't appear in the Jacobian at all: shifting the output by a constant
doesn't change any slope.

## Gradient of the softmax cross-entropy

**Softmax** turns a model's raw scores (**logits**) into probabilities; **cross-entropy**
is the loss "minus log of the probability given to the right answer". Its gradient is the
most famous formula in deep learning, and it's beautifully simple.

This is the derivation every LLM practitioner should know. Let $z$ be the logit vector,
$p = \text{softmax}(z)$, $y$ the one-hot target, and $L = -\log p_y$. (**One-hot** means a
vector of zeros with a single 1 at the correct class.)

The cross-entropy gradient with respect to $z$:

$$
\frac{\partial L}{\partial z} = p - y
$$

"Predicted distribution minus target." The clean form arises because the $-1/p_y$ from
the log and the $p_y(1-p_i)$ from softmax's Jacobian cancel:

$$
\frac{\partial L}{\partial z_i} = p_i - \mathbf{1}[i = y]
$$

### The derivation, step by step

Softmax is $p_k = e^{z_k} / \sum_j e^{z_j}$. Its derivative has two cases, which the
indicator $\mathbf{1}[i = k]$ (1 if $i = k$, else 0) packs into one line:

$$
\frac{\partial p_k}{\partial z_i} = p_k \big(\mathbf{1}[i = k] - p_i\big)
$$

The loss only looks at the correct class, $L = -\log p_y$, so the chain rule gives

$$
\frac{\partial L}{\partial z_i}
= -\frac{1}{p_y} \cdot \frac{\partial p_y}{\partial z_i}
= -\frac{1}{p_y} \cdot p_y \big(\mathbf{1}[i = y] - p_i\big)
= p_i - \mathbf{1}[i = y]
$$

The $p_y$ cancels — that's the "magic". For the correct class the gradient is $p_y - 1$
(negative, so descent *raises* its score); for every wrong class it's $p_i$ (positive, so
descent *lowers* its score, more strongly the more probability it stole).

```python
import numpy as np

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

def cross_entropy(z, y_idx):
    return -np.log(softmax(z)[y_idx])

def grad_ce_analytic(z, y_idx):
    p = softmax(z)
    g = p.copy()
    g[y_idx] -= 1.0
    return g

rng = np.random.default_rng(2)
z = rng.standard_normal(5)
y_idx = 2

g_a = grad_ce_analytic(z, y_idx)
g_n = np.array([(cross_entropy(z + 1e-5 * np.eye(5)[i], y_idx) -
                  cross_entropy(z - 1e-5 * np.eye(5)[i], y_idx)) / (2e-5)
                 for i in range(5)])

print("analytic:", g_a.round(6))
print("numeric :", g_n.round(6))
print("max diff:", np.abs(g_a - g_n).max())
```

```output
analytic: [ 0.140518  0.06896  -0.923045  0.010123  0.703444]
numeric : [ 0.140518  0.06896  -0.923045  0.010123  0.703444]
max diff: 1.7028711774003114e-11
```

The correct class is index 2, and its gradient is the only negative entry ($-0.923$, i.e.
$p_2 - 1$, so the model gave it only about 8% probability). The other entries are just the
probabilities of the wrong classes, and the whole vector sums to zero — probabilities sum to
1, the target sums to 1. Finite differences agree to about $10^{-11}$.

## The Hessian: second-order information

The gradient tells you the slope; the **Hessian** tells you how the slope itself changes —
the *curvature*. A sharp valley and a gentle bowl can have the same slope at a point but
very different Hessians.

For $f : \mathbb{R}^n \to \mathbb{R}$, the **Hessian** is the $n \times n$ matrix of
second partial derivatives:

$$
H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}
$$

For $f(x) = \tfrac{1}{2} x^\top A x - b^\top x$ with symmetric $A$, the Hessian is $A$
itself. The Hessian tells you the curvature: a large Hessian eigenvalue means the loss
changes rapidly in that direction — requiring a small learning rate.

> **Picture it:** walking downhill in a narrow ravine, a big stride sideways sends you up
> the opposite wall. The Hessian measures how narrow the ravine is in each direction; the
> narrowest direction limits how big your steps can be (ch. 9 makes this exact).

```python
import numpy as np

def hessian_fd(f, x, eps=1e-4):
    n = len(x)
    H = np.zeros((n, n))
    fx = f(x)
    for i in range(n):
        for j in range(i, n):
            ei = np.eye(n)[i] * eps
            ej = np.eye(n)[j] * eps
            H[i, j] = (f(x+ei+ej) - f(x+ei-ej) - f(x-ei+ej) + f(x-ei-ej)) / (4*eps**2)
            H[j, i] = H[i, j]
    return H

rng = np.random.default_rng(0)
n = 3
A = rng.standard_normal((n, n)); A = A.T @ A + np.eye(n)
b = rng.standard_normal(n)
x = rng.standard_normal(n)

f = lambda x: 0.5 * x @ A @ x - b @ x
H_num = hessian_fd(f, x)
print("Hessian (numeric):\n", H_num.round(4))
print("A (analytic):\n", A.round(4))
print("max diff:", np.abs(H_num - A).max())
```

```output
Hessian (numeric):
 [[ 2.7272  1.1622 -0.7992]
 [ 1.1622  2.2014 -0.9448]
 [-0.7992 -0.9448  2.0361]]
A (analytic):
 [[ 2.7272  1.1622 -0.7992]
 [ 1.1622  2.2014 -0.9448]
 [-0.7992 -0.9448  2.0361]]
max diff: 6.759398196720667e-08
```

The numeric Hessian matches $A$ to about $10^{-8}$ (second differences divide by
$\text{eps}^2$, so they're noisier than first differences). It's also symmetric, as every
Hessian of a smooth function is: the order you take the two partial derivatives in doesn't
matter.

## Recap in plain words

- The gradient lists the slope of a scalar function along every input and points uphill;
  descent goes the opposite way.
- Quadratic rules: $\nabla(x^\top A x) = 2Ax$ (symmetric $A$) and $\nabla(b^\top x) = b$.
- The Jacobian is the grid of slopes of a vector function; the chain rule multiplies
  Jacobians.
- A linear layer's Jacobian is $W$, so backprop multiplies by $W^\top$.
- Softmax + cross-entropy has gradient $p - y$: prediction minus target.
- The Hessian is the curvature; large eigenvalues mean you need small steps.
- Always check a hand-derived gradient against finite differences.

## Try it Yourself

```python
import numpy as np

# Derive and verify the gradient of the L2 loss f(w) = ||Xw - y||^2
# Analytic: grad = 2 X^T (Xw - y)
rng = np.random.default_rng(5)
m, n = 10, 4
X = rng.standard_normal((m, n))
y = rng.standard_normal(m)
w = rng.standard_normal(n)

def loss(w):
    r = X @ w - y
    return r @ r   # = ||r||^2

def grad_analytic(w):
    return 2 * X.T @ (X @ w - y)

def grad_fd(w, eps=1e-5):
    return np.array([(loss(w + eps*np.eye(n)[i]) - loss(w - eps*np.eye(n)[i])) / (2*eps)
                     for i in range(n)])

g_a = grad_analytic(w)
g_n = grad_fd(w)
print("analytic:", g_a.round(4))
print("numeric :", g_n.round(4))
print("max err :", np.abs(g_a - g_n).max())
```

```output
analytic: [ 2.7872 -8.1294  2.5306 -9.8915]
numeric : [ 2.7872 -8.1294  2.5306 -9.8915]
max err : 1.7371393212783914e-10
```

Same recipe, new loss: the analytic gradient $2X^\top(Xw - y)$ and the finite-difference
slope agree to about $10^{-10}$. Read the formula as "residuals $Xw - y$, sent back through
$X^\top$ to each weight, doubled". Try breaking the formula on purpose (drop the 2, or use
`X` instead of `X.T`) and watch the error jump to order 1.

## Exercise

Derive by hand the gradient $\nabla_W L$ where $L = \|XW - Y\|_F^2$, $X \in \mathbb{R}^{m \times d}$,
$W \in \mathbb{R}^{d \times k}$, $Y \in \mathbb{R}^{m \times k}$ and $\|\cdot\|_F$ is the
Frobenius norm. Then implement it and verify with finite differences.

> **Hint:** the **Frobenius norm** squared is the sum of squares of every entry — the L2
> norm of the matrix flattened into one long vector. Each column of $W$ behaves exactly like
> the $w$ in the Try it Yourself, so the answer should look familiar.

<details>
<summary>Solution</summary>

```python
import numpy as np

# L = ||XW - Y||_F^2 = tr((XW-Y)^T(XW-Y))
# grad_W L = 2 X^T (XW - Y)

rng = np.random.default_rng(6)
m, d, k = 8, 4, 3
X = rng.standard_normal((m, d))
W = rng.standard_normal((d, k))
Y = rng.standard_normal((m, k))

def loss(W):
    R = X @ W - Y
    return np.sum(R**2)   # Frobenius norm squared

def grad_analytic(W):
    return 2 * X.T @ (X @ W - Y)    # shape (d, k)

def grad_fd(W, eps=1e-5):
    G = np.zeros_like(W)
    for i in range(W.shape[0]):
        for j in range(W.shape[1]):
            Wp = W.copy(); Wp[i,j] += eps
            Wm = W.copy(); Wm[i,j] -= eps
            G[i,j] = (loss(Wp) - loss(Wm)) / (2*eps)
    return G

g_a = grad_analytic(W)
g_n = grad_fd(W)
print("max |grad_analytic - grad_fd|:", np.abs(g_a - g_n).max())
```

The derivation: $L = \text{tr}(R^\top R)$ where $R = XW - Y$.
$\frac{\partial}{\partial W} \text{tr}(R^\top R) = 2X^\top R = 2X^\top(XW - Y)$.
The shape check is a free sanity test: $X^\top$ is $d \times m$ and $R$ is $m \times k$, so
the gradient is $d \times k$ — the same shape as $W$, as every gradient must be.
</details>
