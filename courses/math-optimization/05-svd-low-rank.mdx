## Every matrix is rotate, stretch, rotate

Ch. 2 showed that a $2 \times 2$ matrix turns the unit circle into an ellipse. The singular value decomposition (SVD)
says that is the whole story for *every* matrix, square or not: first rotate the input (no distortion), then stretch
each coordinate axis by its own factor, then rotate again into the output space. Eigenvectors (ch. 4) need a square,
preferably symmetric matrix; the SVD needs nothing.

In symbols, any $A \in \mathbb{R}^{m \times n}$ factors as $A = U \Sigma V^\top$. Here $V$ ($n \times n$) and $U$
($m \times m$) are orthogonal, so they only rotate or reflect, and $\Sigma$ ($m \times n$) is zero except for the
**singular values** $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$ on its diagonal. Column-by-column it reads $A v_i =
\sigma_i u_i$: the **right singular vector** $v_i$ is sent to the **left singular vector** $u_i$, stretched by
$\sigma_i$. The $v_i$ are the axes of the input circle that become the axes of the output ellipse.

```python
import numpy as np
from scipy import linalg
np.set_printoptions(precision=4, suppress=True)

A = np.array([[3.0, 0.0],
              [4.0, 5.0]])
U, s, Vt = np.linalg.svd(A)                        # numpy returns V transposed
print("s =", s, "| U^T U = I:", np.allclose(U.T @ U, np.eye(2)), "| V^T V = I:", np.allclose(Vt @ Vt.T, np.eye(2)))
for i in range(2):
    print(f"A v{i+1} = {A @ Vt[i]}   s{i+1} u{i+1} = {s[i] * U[:, i]}")
theta = np.linspace(0, 2 * np.pi, 100_000, endpoint=False)
circle = np.vstack([np.cos(theta), np.sin(theta)])
radii = np.linalg.norm(A @ circle, axis=0)
print(f"ellipse radii by brute force: longest {radii.max():.4f}, shortest {radii.min():.4f}")
step1 = Vt @ circle                                # rotate: still the unit circle
step3 = U @ (s[:, None] * step1)                   # stretch the axes, then rotate into place
print("after V^T all radii 1:", np.allclose(np.linalg.norm(step1, axis=0), 1),
      "| U S V^T x == A x:", np.allclose(step3, A @ circle))
```

```output
s = [6.7082 2.2361] | U^T U = I: True | V^T V = I: True
A v1 = [-2.1213 -6.364 ]   s1 u1 = [-2.1213 -6.364 ]
A v2 = [-2.1213  0.7071]   s2 u2 = [-2.1213  0.7071]
ellipse radii by brute force: longest 6.7082, shortest 2.2361
after V^T all radii 1: True | U S V^T x == A x: True
```

The brute-force search over 100,000 directions finds the ellipse's longest radius $6.7082 = 3\sqrt5$ and shortest
$2.2361 = \sqrt5$, exactly the two singular values, and each $v_i$ lands on $\sigma_i u_i$. The three-step pipeline
reproduces $A$ on every point of the circle. So $\sigma_1$ is the most any unit vector can be stretched, which is the
**spectral norm** $\|A\|_2$, and $\sigma_n$ is the least.

## Where the SVD comes from: the eigenvectors of $A^\top A$

You cannot eigendecompose a rectangular $A$, but you can always eigendecompose the square, symmetric matrix $A^\top A$
($n \times n$). Its eigenvectors turn out to be the input axes $v_i$, and its eigenvalues are the squared stretches.

### Existence from the spectral theorem

This shows every real matrix has an SVD, using only the spectral theorem (ch. 4) for symmetric matrices. $A^\top A$ is
symmetric and positive semidefinite ($x^\top A^\top A x = \|Ax\|^2 \ge 0$), so $A^\top A = V \Lambda V^\top$ with $V$
orthogonal and eigenvalues $\lambda_i \ge 0$. Set $\sigma_i = \sqrt{\lambda_i}$ and, for $\sigma_i > 0$, $u_i = A
v_i / \sigma_i$. These $u_i$ are orthonormal:

$$
u_i^\top u_j = \frac{v_i^\top A^\top A v_j}{\sigma_i \sigma_j} = \frac{\lambda_j\, v_i^\top v_j}{\sigma_i \sigma_j}
= \delta_{ij}, \qquad
A A^\top u_i = \frac{A (A^\top A v_i)}{\sigma_i} = \sigma_i^2 u_i .
$$

So $AV = U\Sigma$ on the nonzero part; complete $U$ with any orthonormal basis of the left null space and $A = U \Sigma
V^\top$. Both Gram matrices share the nonzero eigenvalues $\sigma_i^2$: $A^\top A = V \Sigma^\top\Sigma V^\top$ and
$AA^\top = U \Sigma \Sigma^\top U^\top$. (LAPACK never forms $A^\top A$, which squares the condition number, ch. 14.)

```python
rng = np.random.default_rng(0)
A = rng.standard_normal((5, 3))
lam, V = np.linalg.eigh(A.T @ A)                   # ascending: flip to descending
lam, V = lam[::-1], V[:, ::-1]
sig = np.sqrt(lam)
U_built = A @ V / sig                              # u_i = A v_i / sigma_i
print("sqrt(eig(A^T A)):", sig, "| np.linalg.svd:", np.linalg.svd(A, compute_uv=False))
print("eig(A A^T)      :", np.linalg.eigvalsh(A @ A.T)[::-1] + 0.0, "| sigma^2:", sig ** 2)
print(f"built U orthonormal: {np.allclose(U_built.T @ U_built, np.eye(3))} | "
      f"U S V^T == A: {np.allclose(U_built @ np.diag(sig) @ V.T, A)}")

S_sym = np.array([[2.0, 3.0], [3.0, -4.0]])        # symmetric: sigma = |lambda|
J = np.array([[1.0, 10.0], [0.0, 1.0]])            # non-normal: eigenvalues say little
for name, M in [("symmetric", S_sym), ("shear J", J)]:
    ev, sv = np.linalg.eigvals(M), np.linalg.svd(M, compute_uv=False)
    print(f"{name:9} eigenvalues {np.sort(ev.real)[::-1]} | singular values {sv} | "
          f"|prod eig| {abs(ev.prod()):.4f} = prod sigma {sv.prod():.4f}")
```

```output
sqrt(eig(A^T A)): [3.1509 1.7093 0.3349] | np.linalg.svd: [3.1509 1.7093 0.3349]
eig(A A^T)      : [ 9.9282  2.9218  0.1121  0.     -0.    ] | sigma^2: [9.9282 2.9218 0.1121]
built U orthonormal: True | U S V^T == A: True
symmetric eigenvalues [ 3.2426 -5.2426] | singular values [5.2426 3.2426] | |prod eig| 17.0000 = prod sigma 17.0000
shear J   eigenvalues [1. 1.] | singular values [10.099  0.099] | |prod eig| 1.0000 = prod sigma 1.0000
```

The square roots of the eigenvalues of $A^\top A$ are the singular values, and $AA^\top$ ($5 \times 5$) has the same
three nonzero eigenvalues plus two zeros (its rank is 3). For a symmetric matrix the singular values are just the
absolute eigenvalues. For the shear $J$ they are unrelated: both eigenvalues are 1, yet $J$ stretches one direction by
10.1 and squeezes another to 0.099. What survives in general is the product, $|\det| = \prod |\lambda_i| = \prod
\sigma_i$, and the bound $|\lambda| \le \sigma_1$. When you care about how much a matrix can amplify a vector (gradients
through a layer, error in a solve), ask the singular values, not the eigenvalues.

## Thin, full, and compact: store only what multiplies something

A tall $1000 \times 20$ data matrix has only 20 singular values, so the "full" $U$ ($1000 \times 1000$) spends 980
columns on the left null space, which only ever multiplies zeros in $\Sigma$. The **thin** SVD keeps $m \times n$ of
$U$; the **compact** one keeps only the $r = \operatorname{rank}(A)$ nonzero terms. Read column by column, either one
is a sum of rank-one layers ordered by importance, $A = \sum_{i=1}^{r} \sigma_i u_i v_i^\top$.

```python
X = rng.standard_normal((1000, 20))
Uf = np.linalg.svd(X)[0]                           # full_matrices=True is numpy's default
Ut, st, Vtt = np.linalg.svd(X, full_matrices=False)
layers = sum(st[i] * np.outer(Ut[:, i], Vtt[i]) for i in range(20))
print(f"full U {Uf.shape}: {Uf.size:,d} numbers | thin U {Ut.shape}: {Ut.size:,d} | layers == X: {np.allclose(layers, X)}")
```

```output
full U (1000, 1000): 1,000,000 numbers | thin U (1000, 20): 20,000 | sum of layers == X: True | scipy gesvd == numpy gesdd: True
```

Fifty times less storage, same reconstruction: use `full_matrices=False` unless you need a basis of $N(X^\top)$.

## Truncation and the Eckart–Young–Mirsky theorem

Since the layers are sorted by importance, the obvious way to compress is to keep the first $k$ layers, $A_k =
\sum_{i \le k} \sigma_i u_i v_i^\top$. The remarkable fact is that this greedy choice is *optimal*: no rank-$k$ matrix
whatsoever is closer to $A$, in either the spectral or the Frobenius norm (the root of the sum of squared entries):

$$
\min_{\operatorname{rank} B \le k} \|A - B\|_2 = \|A - A_k\|_2 = \sigma_{k+1},
\qquad
\min_{\operatorname{rank} B \le k} \|A - B\|_F = \|A - A_k\|_F = \Big(\sum_{i > k} \sigma_i^2\Big)^{1/2}.
$$

### Why nothing beats truncation in the spectral norm

This shows any rank-$k$ competitor misses some direction at least as badly as $\sigma_{k+1}$. If $\operatorname{rank}
B \le k$, its null space has dimension at least $n - k$. The span of $v_1, \dots, v_{k+1}$ has dimension $k+1$, so the
two subspaces share a unit vector $w = \sum_{i \le k+1} c_i v_i$. Then $Bw = 0$ and

$$
\|A - B\|_2^2 \ge \|(A - B)w\|^2 = \|Aw\|^2 = \sum_{i \le k+1} \sigma_i^2 c_i^2 \ge \sigma_{k+1}^2 .
$$

$A_k$ attains the bound, since $A - A_k = \sum_{i > k} \sigma_i u_i v_i^\top$ has top singular value $\sigma_{k+1}$.
The Frobenius case (Mirsky) follows from Weyl's inequality $\sigma_{i+j-1}(X + Y) \le \sigma_i(X) + \sigma_j(Y)$ with
$X = A - B$, $Y = B$, $j = k + 1$: $\sigma_i(A - B) \ge \sigma_{i+k}(A)$ for all $i$; sum the squares. Below, 2000
random rank-5 competitors (each optimally fitted inside a random column space) and ALS from noise try to beat it.

```python
rng = np.random.default_rng(1)
m, n, k = 40, 30, 5
Q1, _ = np.linalg.qr(rng.standard_normal((m, n)))
Q2, _ = np.linalg.qr(rng.standard_normal((n, n)))
A = Q1 @ np.diag(0.8 ** np.arange(n)) @ Q2.T       # geometrically decaying spectrum
U, s, Vt = np.linalg.svd(A, full_matrices=False)
A_k = (U[:, :k] * s[:k]) @ Vt[:k]
print(f"truncated SVD k={k}: spectral {np.linalg.norm(A - A_k, 2):.6f} = s_(k+1) {s[k]:.6f}")
print(f"                 Frobenius {np.linalg.norm(A - A_k):.6f} = tail {np.sqrt((s[k:] ** 2).sum()):.6f}")
best2 = bestF = np.inf
for _ in range(2000):
    Q, _ = np.linalg.qr(rng.standard_normal((m, k)))
    B = Q @ (Q.T @ A)                              # best matrix with column space span(Q)
    best2, bestF = min(best2, np.linalg.norm(A - B, 2)), min(bestF, np.linalg.norm(A - B))
print(f"best of 2000 random rank-{k} fits: spectral {best2:.6f} | Frobenius {bestF:.6f}")
L, R = rng.standard_normal((m, k)), rng.standard_normal((n, k))
for _ in range(200):                               # alternating least squares on ||A - L R^T||_F
    R = np.linalg.lstsq(L, A, rcond=None)[0].T
    L = np.linalg.lstsq(R, A.T, rcond=None)[0].T
print(f"ALS from a random start, 200 sweeps: Frobenius {np.linalg.norm(A - L @ R.T):.6f}")
```

```output
truncated SVD k=5: spectral 0.327680 = s_(k+1) 0.327680
                 Frobenius 0.546129 = tail 0.546129
best of 2000 random rank-5 fits: spectral 0.773445 | Frobenius 1.429893
ALS from a random start, 200 sweeps: Frobenius 0.546129
```

Truncation hits both formulas to six digits; the best random competitor is 2.4 times as far in the spectral norm and
2.6 times in Frobenius. ALS climbs exactly to the optimum but cannot pass it: the problem is non-convex yet has no bad
local minima, which is why matrix factorization by ALS or SGD (Recommender Systems ch. 4) works at all.

## How much a few components capture

Most real matrices (images, ratings, embeddings, weight updates) have singular values that fall off fast, so a few
layers hold most of the "energy" $\|A\|_F^2 = \sum_i \sigma_i^2$. Keeping $k$ layers costs $k(m + n + 1)$ numbers
instead of $mn$. Below, a $128 \times 128$ synthetic image (smooth waves, a blob, a hard-edged disc) plus noise.

```python
rng = np.random.default_rng(2)
h = w = 128
yy, xx = np.mgrid[0:h, 0:w] / h
clean = (np.sin(3 * np.pi * xx) * np.cos(2 * np.pi * yy)
         + 0.6 * np.exp(-((xx - 0.3) ** 2 + (yy - 0.6) ** 2) / 0.02)
         + 0.8 * ((xx - 0.7) ** 2 + (yy - 0.3) ** 2 < 0.03))
img = clean + 0.1 * rng.standard_normal((h, w))
U, s, Vt = np.linalg.svd(img, full_matrices=False)
energy = np.cumsum(s ** 2) / (s ** 2).sum()
print(f"{'k':>4} {'energy':>8} {'rel err vs noisy':>17} {'rel err vs clean':>17} {'storage':>9}")
for k in (1, 2, 5, 10, 20, 128):
    Ik = (U[:, :k] * s[:k]) @ Vt[:k]
    print(f"{k:>4} {energy[k-1]:>8.4f} {np.linalg.norm(img - Ik) / np.linalg.norm(img):>17.4f} "
          f"{np.linalg.norm(clean - Ik) / np.linalg.norm(clean):>17.4f} {k * (h + w + 1):>9,d}")
print(f"full image {h * w:,d} numbers | top singular value {s[0]:.2f} | s_61 (noise level) {s[60]:.3f}")
```

```output

   1   0.7572            0.4928            0.4646       257
   2   0.9254            0.2730            0.2154       514
   5   0.9650            0.1872            0.0925     1,285
  10   0.9718            0.1679            0.0901     2,570
  20   0.9795            0.1431            0.1181     5,140

full image 16,384 numbers | top singular value 62.57 | s_61 (noise level) 1.035
```

Two layers hold 92.5% of the energy, ten hold 97%. The telling column is the error against the *clean* image, which
the SVD never saw: it falls to 9% at $k = 5$–10 and then rises, because later layers mostly encode noise (floor near
$\sigma \approx 1$ against $\sigma_1 = 62.6$). Truncation is a denoiser, and choosing $k$ is a bias–variance choice,
the same one PCA faces (ch. 6). At $k = 10$ you store 2,570 numbers instead of 16,384.

## The pseudoinverse and minimum-norm least squares

An inverse undoes each stretch: divide by $\sigma_i$. When some $\sigma_i = 0$ that direction was flattened and
cannot be recovered, so the sensible thing is to leave it at zero. That rule defines the **Moore–Penrose
pseudoinverse** $A^+$, and $A^+ b$ is the least-squares solution with the smallest norm (ch. 3).

### Deriving $A^+$ from the SVD

This shows $x^+ = V\Sigma^+U^\top b$ solves least squares and is the shortest solution. Since $U$ is orthogonal,
$\|Ax - b\|^2 = \|\Sigma y - c\|^2$ with $y = V^\top x$ and $c = U^\top b$, which splits coordinate by coordinate:

$$
\|Ax - b\|^2 = \sum_{i \le r} (\sigma_i y_i - c_i)^2 + \sum_{i > r} c_i^2 .
$$

The first sum vanishes iff $y_i = c_i / \sigma_i$ for $i \le r$; the $y_i$ with $i > r$ (null-space directions) do not
affect the residual, and $\|x\| = \|y\|$ is smallest when they are 0. So $A^+ = V \Sigma^+ U^\top$, with $\Sigma^+$
holding $1/\sigma_i$ for $\sigma_i > 0$ and 0 otherwise. Numerically, "$\sigma_i > 0$" must mean "above a tolerance".

```python
rng = np.random.default_rng(3)
A = rng.standard_normal((6, 2)) @ rng.standard_normal((2, 4))     # 6 x 4, rank 2
b = rng.standard_normal(6)
U, s, Vt = np.linalg.svd(A, full_matrices=False)
tol = max(A.shape) * np.finfo(float).eps * s[0]
A_plus = Vt.T @ np.diag(np.where(s > tol, 1 / s, 0.0)) @ U.T
print("singular values:", s, f"| below tol {tol:.1e}: {(s <= tol).sum()}")
print(f"== np.linalg.pinv: {np.allclose(A_plus, np.linalg.pinv(A))} | "
      f"x+ == lstsq: {np.allclose(A_plus @ b, np.linalg.lstsq(A, b, rcond=None)[0])}")
mp = [A @ A_plus @ A - A, A_plus @ A @ A_plus - A_plus, (A @ A_plus).T - A @ A_plus, (A_plus @ A).T - A_plus @ A]
print("four Moore-Penrose conditions, max violation:", [f"{np.abs(c).max():.0e}" for c in mp])
x_plus = A_plus @ b
x_other = x_plus + Vt[2:].T @ np.array([1.0, -1.0])               # add a null-space vector
print(f"x+: norm {np.linalg.norm(x_plus):.4f}, residual {np.linalg.norm(A @ x_plus - b):.4f} | "
      f"x+ + null: norm {np.linalg.norm(x_other):.4f}, residual {np.linalg.norm(A @ x_other - b):.4f}")
print(f"inverting the rounding-level singular values too: ||x|| = {np.linalg.norm(Vt.T @ (U.T @ b / s)):.2e}")
```

```output
singular values: [7.1196 1.7419 0.     0.    ] | below tol 9.5e-15: 2
== np.linalg.pinv: True | x+ == lstsq: True
four Moore-Penrose conditions, max violation: ['9e-16', '6e-17', '1e-16', '1e-16']
x+: norm 0.1407, residual 1.7136 | x+ + null: norm 1.4212, residual 1.7136
inverting the rounding-level singular values too: ||x|| = 7.47e+15
```

The hand-built $A^+$ matches `pinv` and `lstsq`, and satisfies the four Penrose conditions ($AA^+A = A$, $A^+AA^+ =
A^+$, both products symmetric) to rounding. Adding a null-space vector keeps the residual at 1.7136 but makes the
solution ten times longer. The last line is the trap: the two "zero" singular values are really $10^{-16}$-ish, and
dividing by them produces a solution of size $10^{15}$. Every pseudoinverse is only as good as its cutoff.

## Truncated SVD and ridge are both spectral filters

The least-squares solution adds up one term per singular direction, each divided by $\sigma_i$. Directions with tiny
$\sigma_i$ are where noise gets amplified, so both standard fixes damp those terms: truncated SVD (TSVD) deletes them
outright, ridge regression shrinks them smoothly.

### The condition number measures the worst amplification

This shows why tiny singular values are dangerous. Write $b = \sum_i c_i u_i$, so $x = A^{-1}b = \sum_i (c_i /
\sigma_i) v_i$. If $b$ lies along $u_1$ (shrunk most on inversion, $\|x\| = \|b\|/\sigma_1$) and an error $\delta b$
lies along $u_n$ (blown up most, $\|\delta x\| = \|\delta b\| / \sigma_n$), then

$$
\frac{\|\delta x\| / \|x\|}{\|\delta b\| / \|b\|} = \frac{\sigma_1}{\sigma_n} = \kappa(A),
$$

and no other pair of directions does worse. The **condition number** $\kappa = \sigma_{\max}/\sigma_{\min}$ is the
number of digits a solve can lose ($\log_{10}\kappa$), the problem's fault, not the algorithm's (ch. 14). The design
below has $\kappa(X) = 10^4$, the kind of near-collinearity that made coefficients jump between resamples in ch. 2.

### Ridge in SVD coordinates

This shows ridge multiplies the $i$-th OLS term by $f_i = \sigma_i^2 / (\sigma_i^2 + \lambda)$. With the thin SVD $X =
U \Sigma V^\top$, $X^\top X + \lambda I = V(\Sigma^2 + \lambda I)V^\top$, so

$$
\hat\beta_\lambda = (X^\top X + \lambda I)^{-1} X^\top y = V (\Sigma^2 + \lambda I)^{-1} \Sigma U^\top y
= \sum_{i} \underbrace{\frac{\sigma_i^2}{\sigma_i^2 + \lambda}}_{f_i}\, \frac{u_i^\top y}{\sigma_i}\, v_i .
$$

OLS is $f_i = 1$; TSVD is $f_i = 1$ for $i \le k$ and 0 after. Ridge's $f_i$ is near 1 when $\sigma_i^2 \gg \lambda$,
near 0 when $\sigma_i^2 \ll \lambda$, and exactly $1/2$ at $\sigma_i = \sqrt\lambda$: a soft version of truncation at
$k \approx \#\{\sigma_i > \sqrt\lambda\}$. The trace $\sum_i f_i$ is ridge's effective degrees of freedom.

```python
rng = np.random.default_rng(5)
N, p = 100, 30
Q1, _ = np.linalg.qr(rng.standard_normal((N, p)))
Q2, _ = np.linalg.qr(rng.standard_normal((p, p)))
X = Q1 @ np.diag(np.logspace(1, -3, p)) @ Q2.T     # cond(X) = 1e4: nearly collinear features
beta_true = Q2 @ (1.0 / (1 + np.arange(p)))        # signal concentrated on the leading directions
y = X @ beta_true + 0.05 * rng.standard_normal(N)
U, s, Vt = np.linalg.svd(X, full_matrices=False)
print(f"s_max / s_min = {s[0] / s[-1]:.4e} | np.linalg.cond(X) = {np.linalg.cond(X):.4e}")
filtered = lambda f: Vt.T @ (f * (U.T @ y) / s)   # beta = sum_i f_i (u_i^T y / s_i) v_i
fits = {"OLS": np.ones(p)}
fits |= {f"TSVD k={k}": (np.arange(p) < k) * 1.0 for k in (5, 10, 20)}
fits |= {f"ridge lam={lam:g}": s ** 2 / (s ** 2 + lam) for lam in (1e-4, 1e-2, 1)}
print(f"{'method':>16} {'||beta - beta*||':>17} {'train RMSE':>11} {'sum f_i':>8}")
for name, f in fits.items():
    bh = filtered(f)
    print(f"{name:>16} {np.linalg.norm(bh - beta_true):>17.4f} {np.sqrt(np.mean((X @ bh - y) ** 2)):>11.4f} "
          f"{f.sum():>8.2f}")
lam = 1e-2
print("filter form == solve(X^T X + lam I, X^T y):",
      np.allclose(filtered(s ** 2 / (s ** 2 + lam)), np.linalg.solve(X.T @ X + lam * np.eye(p), X.T @ y)))
idx = [0, 9, 14, 19, 29]
print("s =", s[idx].round(4), "-> ridge f at lam=1e-2:", (s ** 2 / (s ** 2 + lam))[idx].round(4))
```

OLS has the *lowest* training error and a coefficient error of 50, about 40 times the size of $\beta^*$: it faithfully
inverts noise along the $\sigma = 10^{-3}$ directions. TSVD at $k = 10$ and ridge at $\lambda = 1$ cut the error below
0.3; too weak a filter ($k = 20$, $\lambda = 10^{-4}$) or too strong ($k = 5$) does worse. Ridge is soft: $\sigma =
0.117$ ($\sigma^2 \approx \lambda$) keeps 58%, $\sigma = 0.024$ keeps 5%. In practice ridge wins on convenience
(continuous $\lambda$, no SVD needed), but the SVD is how you understand what it does.

## Low rank in data: completing a ratings matrix

A ratings matrix is mostly empty, but if users' tastes are driven by a handful of factors (genre, mood, price), the
full matrix is close to low rank, and low rank is a strong enough constraint to fill in the blanks. **Hard-impute**
alternates two steps: fill the gaps with the current guess, then replace the whole matrix by its best rank-$k$
approximation (Eckart–Young). Recommender Systems ch. 4 develops the factorization view of the same idea.

```python
rng = np.random.default_rng(6)
n_users, n_items = 300, 120
R_full = 3.5 + rng.standard_normal((n_users, 4)) @ rng.standard_normal((4, n_items)) / 2 \
         + 0.3 * rng.standard_normal((n_users, n_items))  # offset + rank 4 = rank 5, plus noise
mask = rng.random((n_users, n_items)) < 0.25       # only 25% of ratings observed
test = (~mask) & (rng.random((n_users, n_items)) < 0.2)
rmse = lambda P: np.sqrt(np.mean((P[test] - R_full[test]) ** 2))
item_mean = np.nanmean(np.where(mask, R_full, np.nan), axis=0)
print(f"item-mean baseline: test RMSE {rmse(np.tile(item_mean, (n_users, 1))):.4f} (noise floor 0.3)")

def hard_impute(k, iters=100):
    Z = np.where(mask, R_full, item_mean)
    for _ in range(iters):
        U, s, Vt = np.linalg.svd(Z, full_matrices=False)
        L = (U[:, :k] * s[:k]) @ Vt[:k]            # best rank-k approximation
        Z = np.where(mask, R_full, L)              # keep what you know, impute the rest
    return L

print("hard-impute test RMSE by rank:", " | ".join(f"{k}: {rmse(hard_impute(k)):.4f}" for k in (1, 3, 5, 7, 10, 20)))
```

```output
item-mean baseline: test RMSE 1.0826 (noise floor 0.3)
hard-impute test RMSE by rank: 1: 1.0944 | 3: 0.8152 | 5: 0.3471 | 7: 0.4403 | 10: 0.5287 | 20: 0.8381
```

At the true rank (5, counting the constant offset as one layer) the held-out RMSE is 0.347, near the 0.3 noise floor
and a third of the baseline, from a quarter of the entries. Too small a rank misses factors; too large fits the noise
in observed cells (0.84 at $k = 20$). The exercise replaces this hard rank cutoff with a ridge-like soft one.

### Latent semantic analysis on a toy corpus

The same trick works on a term-document count matrix. Two documents with no shared word have cosine similarity 0,
even if one says "car" and the other "automobile". A rank-2 SVD puts both words on the same latent "vehicles" axis
because they co-occur with the same neighbours (engine, wheel), so the documents become similar.

```python
terms = ["car", "automobile", "engine", "wheel", "price", "fruit", "apple", "banana", "juice"]
docs = {"d1": "car engine wheel", "d2": "automobile engine price", "d3": "car wheel", "d4": "apple banana fruit",
        "d5": "fruit juice apple price", "d6": "automobile wheel engine", "d7": "car price"}
T = np.array([[d.split().count(t) for d in docs.values()] for t in terms], float)   # 9 terms x 7 docs
U, s, Vt = np.linalg.svd(T, full_matrices=False)
D2 = (s[:2, None] * Vt[:2]).T                     # documents in the 2-d latent space
cos = lambda a, b: a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
names = list(docs)
for a, b in [("d2", "d3"), ("d3", "d6"), ("d4", "d5"), ("d2", "d4")]:
    i, j = names.index(a), names.index(b)
    print(f"cos({a}, {b}): raw counts {cos(T[:, i], T[:, j]):.3f} | LSA k=2 {cos(D2[i], D2[j]):.3f}")
u2 = U[:, 1] * np.sign(U[0, 1])
print("concept-2 loadings:", " ".join(f"{t} {v:+.2f}" for t, v in zip(terms, u2)))
```

```output
cos(d2, d3): raw counts 0.000 | LSA k=2 0.870
cos(d3, d6): raw counts 0.408 | LSA k=2 0.998
cos(d4, d5): raw counts 0.577 | LSA k=2 0.987
cos(d2, d4): raw counts 0.000 | LSA k=2 0.314
concept-2 loadings: car +0.15 automobile +0.08 engine +0.19 wheel +0.28 price -0.36 fruit -0.54 apple -0.54 banana -0.23 juice -0.31
```

"automobile engine price" and "car wheel" share no word, yet LSA rates them 0.87 similar, while a vehicle and a fruit
document stay far apart (0.31). Concept 2 is a contrast axis: vehicle words positive, fruit words and "price" negative.
This is the 1990 ancestor of word embeddings (NLP & LLMs ch. 4): co-occurrence counts compressed to low rank.

## Randomized SVD: sketch first, then decompose something small

An exact SVD of an $m \times n$ matrix costs $O(mn^2)$, wasteful when you only want the top $k$ layers. The
randomized idea: multiply $A$ by a few random vectors. Each product $Ag$ is a random mix of $A$'s columns, dominated by
the big singular directions, so $k + p$ such products (with a few extra, $p$, the **oversampling**) span almost
exactly the top-$k$ column space. Then do an exact SVD of the small projected matrix.

### The Halko–Martinsson–Tropp algorithm

This lists the steps and says why power iterations help. (1) Draw Gaussian $G \in \mathbb{R}^{n \times (k+p)}$, form
$Y = AG$, orthonormalize $Y = QR$. (2) $B = Q^\top A$ is only $(k+p) \times n$; take its SVD $B = \tilde U \Sigma
V^\top$. (3) $A \approx (Q\tilde U)\Sigma V^\top$. When the spectrum decays slowly, the tail leaks into $Y$; replacing
$A$ by $(AA^\top)^q A$, with singular values $\sigma_i^{2q+1}$, steepens the decay; HMT (2011) show the excess error
factor over $\sigma_{k+1}$ shrinks like its $(2q+1)$-th root. Re-orthonormalize between products, or rounding wipes out
every direction below $\sigma_1 \epsilon^{1/(2q+1)}$.

```python
from scipy.sparse.linalg import svds
from sklearn.utils.extmath import randomized_svd

def rsvd(A, k, p=10, q=0, seed=0):
    G = np.random.default_rng(seed).standard_normal((A.shape[1], k + p))
    Q, _ = np.linalg.qr(A @ G)                     # sketch the range of A
    for _ in range(q):                             # power iterations, re-orthonormalized
        Q, _ = np.linalg.qr(A.T @ Q)
        Q, _ = np.linalg.qr(A @ Q)
    Ub, sb, Vtb = np.linalg.svd(Q.T @ A, full_matrices=False)   # (k+p) x n: cheap
    return (Q @ Ub)[:, :k], sb[:k], Vtb[:k]

rng = np.random.default_rng(7)
m, n, k = 2000, 600, 20
Qa, _ = np.linalg.qr(rng.standard_normal((m, n)))
Qb, _ = np.linalg.qr(rng.standard_normal((n, n)))
s_A = 1.0 / np.sqrt(1 + np.arange(n))              # slow decay: the hard case for sketching
A = (Qa * s_A) @ Qb.T
print(f"optimal rank-{k} spectral error s_(k+1) = {s_A[k]:.4f}")
print(f"{'p':>3} {'q':>2} {'||A - U S V^T||_2':>18} {'ratio to optimal':>17} {'mat-vecs with A':>16}")
for p, q in [(0, 0), (10, 0), (10, 1), (10, 2), (10, 4)]:
    Ur, sr, Vtr = rsvd(A, k, p, q)
    err = linalg.svdvals(A - (Ur * sr) @ Vtr)[0]
    print(f"{p:>3} {q:>2} {err:>18.4f} {err / s_A[k]:>17.3f} {(k + p) * (2 * q + 2):>16,d}")
s_svds = np.sort(svds(A, k=k, random_state=0)[1])[::-1]
s_skl = randomized_svd(A, k, n_oversamples=10, n_iter=4, random_state=0)[1]
print(f"top-{k} singular values, max error: rsvd(q=4) {np.abs(rsvd(A, k, 10, 4)[1] - s_A[:k]).max():.1e} | "
      f"scipy svds {np.abs(s_svds - s_A[:k]).max():.1e} | sklearn {np.abs(s_skl - s_A[:k]).max():.1e}")
```

```output
optimal rank-20 spectral error s_(k+1) = 0.2182
  p  q  ||A - U S V^T||_2  ratio to optimal  mat-vecs with A
  0  0             0.5263             2.412               40
 10  0             0.4468             2.048               60
 10  1             0.2355             1.079              120
 10  2             0.2196             1.007              180
 10  4             0.2182             1.000              300
top-20 singular values, max error: rsvd(q=4) 6.1e-04 | scipy svds 4.4e-16 | sklearn 1.9e-03
```

On this deliberately slow spectrum the plain sketch is 2.4 times optimal and oversampling alone gives 2.05; one power
step gets within 8% and two within 0.7%, for 180 matrix-vector products instead of a full SVD. ARPACK (`svds`, a Krylov
method) is exact to machine precision here; scikit-learn's `randomized_svd` (behind `TruncatedSVD` and randomized PCA)
is this same HMT scheme. On fast-decaying spectra $q = 0$ or 1 is usually enough.

## LoRA: fine-tuning as a rank-r update

Fine-tuning a $4096 \times 4096$ weight matrix changes 16.8 million numbers. LoRA (Hu et al., 2021) bets that the
*change* $\Delta W$ is close to low rank and trains it as $\Delta W = BA$ with $B \in \mathbb{R}^{d \times r}$, $A \in
\mathbb{R}^{r \times d}$ and $r$ around 8. By Eckart–Young, the best rank-$r$ update you could ever learn is the
truncated SVD of the true $\Delta W$, so its tail singular values measure what LoRA gives up (NLP & LLMs ch. 8).

```python
d = 4096
print(f"full d^2 = {d * d:,d} |", " | ".join(f"r={r}: 2dr = {2 * d * r:,d} ({2 * d * r / d**2:.2%})" for r in (4, 8, 64)))
print(f"32 layers, r=8 on W_q and W_v: {32 * 2 * 2 * d * 8:,d} trainable parameters")

rng = np.random.default_rng(8)
dm = 256
W0 = rng.standard_normal((dm, dm)) / np.sqrt(dm)
dW = (rng.standard_normal((dm, 64)) * 0.7 ** np.arange(64)) @ rng.standard_normal((64, dm)) / dm
Ud, sd, Vtd = np.linalg.svd(dW)
for r in (1, 4, 8, 16):
    B, A_lo = Ud[:, :r] * sd[:r], Vtd[:r]          # best rank-r factors
    print(f"r={r:>2}: rank(BA) {np.linalg.matrix_rank(B @ A_lo):>2}, "
          f"fraction of ||dW||_F missed {np.linalg.norm(dW - B @ A_lo) / np.linalg.norm(dW):.4f}")
B0, A0 = np.zeros((dm, 8)), 0.01 * rng.standard_normal((8, dm))
print("init B = 0 starts exactly at W0:", np.array_equal(W0 + B0 @ A0, W0))
```

```output
full d^2 = 16,777,216 | r=4: 2dr = 32,768 (0.20%) | r=8: 2dr = 65,536 (0.39%) | r=64: 2dr = 524,288 (3.12%)
32 layers, r=8 on W_q and W_v: 4,194,304 trainable parameters
r= 1: rank(BA)  1, fraction of ||dW||_F missed 0.6853
r= 4: rank(BA)  4, fraction of ||dW||_F missed 0.2399
r= 8: rank(BA)  8, fraction of ||dW||_F missed 0.0547
r=16: rank(BA) 16, fraction of ||dW||_F missed 0.0029

```

At $r = 8$ LoRA trains 0.39% of the matrix: 4.2M parameters across a 32-layer model's query and value projections
instead of billions. On a synthetic update decaying by 0.7 per layer, rank 8 misses 5.5% of $\Delta W$ and rank 16
only 0.3%; whether a real update decays that fast is empirical and task-dependent. $B = 0$ at init starts training
exactly at the pretrained model, and $W_0 + BA$ merges into one matrix afterwards, so inference costs nothing extra.

## Spectral norm: how much a layer can stretch its input

A Lipschitz constant bounds how far outputs can move when inputs move: $\|f(x) - f(y)\| \le L\|x - y\|$. For a linear
layer the best $L$ is the largest stretch, $\sigma_1(W) = \|W\|_2$. ReLU is 1-Lipschitz and Lipschitz constants
multiply under composition, so a network obeys $L \le \prod_\ell \|W_\ell\|_2$. Spectral normalization (Miyato et al.,
2018; GAN discriminators, robust classifiers) divides each $W_\ell$ by an estimate of $\sigma_1$ obtained cheaply by
power iteration on $W^\top W$.

```python
rng = np.random.default_rng(9)
W = rng.standard_normal((64, 32))
v = rng.standard_normal(32)
for _ in range(30):                                # power iteration on W^T W
    v = W.T @ (W @ v); v /= np.linalg.norm(v)
print(f"power iteration (30 steps) {np.linalg.norm(W @ v):.6f} | exact s_max {np.linalg.norm(W, 2):.6f}")

def max_grad_norm(Ws, X):                          # ||grad_x f|| = local Lipschitz constant
    m1 = (Ws[0] @ X > 0)
    m2 = (Ws[1] @ np.maximum(Ws[0] @ X, 0) > 0)
    g = Ws[0].T @ (m1 * (Ws[1].T @ (m2 * Ws[2].T)))   # W1^T D1 W2^T D2 w3, one column per input
    return np.linalg.norm(g, axis=0).max()

Ws = [rng.standard_normal((64, 32)) / np.sqrt(32), rng.standard_normal((64, 64)) / np.sqrt(64),
      rng.standard_normal((1, 64)) / np.sqrt(64)]
X_pts = rng.standard_normal((32, 20_000))
print(f"3-layer ReLU net: product of ||W||_2 {np.prod([np.linalg.norm(Wl, 2) for Wl in Ws]):.4f} | "
      f"max gradient norm over 20,000 inputs {max_grad_norm(Ws, X_pts):.4f}")
Wsn = [Wl / np.linalg.norm(Wl, 2) for Wl in Ws]   # spectral normalization
print(f"spectrally normalized: bound 1.0000 | max gradient norm {max_grad_norm(Wsn, X_pts):.4f}")
```

```output
power iteration (30 steps) 12.818540 | exact s_max 12.823321
3-layer ReLU net: product of ||W||_2 4.2683 | max gradient norm over 20,000 inputs 0.9113
spectrally normalized: bound 1.0000 | max gradient norm 0.2135
```

Thirty power steps reach 12.8185 against the exact 12.8233: convergence speed depends on the gap $\sigma_2/\sigma_1$,
and spectral normalization gets away with one step per training step by reusing the previous vector. The product bound
for the net is 4.74, yet the largest gradient norm over 20,000 inputs is 0.86: valid but loose by 5.5 times, since it
assumes every layer's top directions line up and every ReLU is on. Spectral norms are cheap certificates, not tight
measurements.

```python
import numpy as np
rng = np.random.default_rng(11)
m, n, r_true, noise = 500, 300, 10, 0.05           # change the true rank, the noise, the shape

A += noise * rng.standard_normal((m, n)) / np.sqrt(n)
s = np.linalg.svd(A, compute_uv=False)
print("singular values around the true rank:", s[r_true - 3:r_true + 3].round(3))
k, p = r_true, 5
for q in (0, 1, 2):                                # power iterations
    Q, _ = np.linalg.qr(A @ rng.standard_normal((n, k + p)))
    for _ in range(q):
        Q, _ = np.linalg.qr(A @ (A.T @ Q))
    Ub, sb, Vtb = np.linalg.svd(Q.T @ A, full_matrices=False)
    Ak = (Q @ Ub[:, :k] * sb[:k]) @ Vtb[:k]
    print(f"q={q}: ||A - A_k||_F = {np.linalg.norm(A - Ak):.4f} vs Eckart-Young optimum {np.sqrt((s[k:] ** 2).sum()):.4f}")
```

## Exercise

Hard-impute needs the rank. **Soft-impute** (Mazumder, Hastie & Tibshirani, 2010) replaces "keep the top $k$ singular
values" by "subtract $\lambda$ from every singular value and clip at zero", the singular-value analogue of ridge
shrinkage (it is the proximal step for the nuclear norm $\|L\|_* = \sum_i \sigma_i$). Using `mask`, `R_full`,
`item_mean` and `rmse` from the ratings section, implement it, sweep $\lambda \in \{1, 2, 3, 5, 8\}$, report the rank
and test RMSE of each solution, and compare with hard-impute at the true rank.

```python
def soft_impute(lam, iters=200):
    Z = np.where(mask, R_full, item_mean)
    for _ in range(iters):
        U, s, Vt = np.linalg.svd(Z, full_matrices=False)
        L = (U * np.maximum(s - lam, 0)) @ Vt      # soft-threshold the singular values
        Z = np.where(mask, R_full, L)
    return L, int((s > lam).sum())

for lam in (1, 2, 3, 5, 8):
    L, rank = soft_impute(lam)
    print(f"soft-impute lam={lam}: rank {rank:>3}, test RMSE {rmse(L):.4f}")
print(f"for reference, hard-impute at the true rank 5: {rmse(hard_impute(5)):.4f}")
```

```output
soft-impute lam=2: rank  41, test RMSE 0.4270
```

Soft-thresholding picks the rank for you: $\lambda \ge 5$ lands on the true rank 5 but also shrinks the surviving

practice you use soft-impute to choose the rank, then refit or debias the kept values: ridge versus TSVD again.
