## What PCA is doing, mathematically

**PCA** (principal component analysis) turns your data so that its widest spread lies along
the first axis, the next-widest along the second, and so on. Then, if you want fewer
columns, you keep the first few axes and drop the thin ones.

Principal Component Analysis finds a new orthonormal basis for your data such that the first axis captures the most variance, the second the next most (orthogonal to the first), and so on. The result is a rotation — no scale distortion, no information loss when you keep all components.

> **Picture it:** you photograph a flat, tilted surfboard from many angles. The best angle
> shows its full length and width; from the edge-on angle it nearly vanishes. PCA finds the
> "best photo" angle for your data cloud: axis 1 along the board's length, axis 2 across its
> width, axis 3 through its thin edge.

Two derivation paths exist: via the **covariance matrix's eigendecomposition** and via the **SVD of the centred data matrix**. Both give the same answer.

## The eigendecomposition path

First shift the data so every feature averages zero, then measure how the features vary
together (the covariance matrix), then find that matrix's eigenvectors (ch. 4).

Centre each feature: $X_c = X - \bar{X}$ where $\bar{X}$ is the row-wise mean — that is,
the mean of each feature (column) taken across all the rows, subtracted from every row. The
sample covariance matrix is

$$
C = \frac{1}{n-1} X_c^T X_c \in \mathbb{R}^{d \times d}
$$

$C$ is symmetric positive semi-definite, so its eigendecomposition is

$$
C = Q \Lambda Q^T, \quad \Lambda = \text{diag}(\lambda_1, \ldots, \lambda_d), \quad \lambda_1 \ge \cdots \ge \lambda_d \ge 0
$$

with the eigenvalues sorted from largest to smallest.

The columns of $Q$ are the **principal directions**. The projection of $X_c$ onto the first $k$ principal directions gives the PC scores. A **PC score** is a sample's coordinate
along a principal direction — "how far along the surfboard's length is this point?".

> **In plain words:** entry $(i, j)$ of $C$ is the average of (feature $i$ minus its mean)
> × (feature $j$ minus its mean). The $n - 1$ instead of $n$ is the usual correction that
> makes a sample variance unbiased.

```python
import numpy as np

rng = np.random.default_rng(0)
n, d = 200, 3

# Generate correlated data
A_true = np.array([[1.0, 0.8, 0.3],
                   [0.0, 0.6, 0.7],
                   [0.0, 0.0, 0.5]])
X = rng.standard_normal((n, d)) @ A_true

# Centre
Xc = X - X.mean(axis=0)

# Covariance matrix
C = Xc.T @ Xc / (n - 1)
print("Covariance matrix:")
print(np.round(C, 4))

# Eigendecomposition (eigh for symmetric → real, sorted ascending)
eigvals, eigvecs = np.linalg.eigh(C)

# Sort descending
idx = np.argsort(eigvals)[::-1]
eigvals = eigvals[idx]
eigvecs = eigvecs[:, idx]

print("\nEigenvalues (descending):", np.round(eigvals, 4))
```

```output
Covariance matrix:
[[1.0328 0.8194 0.2551]
 [0.8194 1.0108 0.614 ]
 [0.2551 0.614  0.7691]]

Eigenvalues (descending): [2.1255 0.6205 0.0668]
```

The covariance matrix shows strongly related features (0.82 between features 1 and 2), and
its three eigenvalues drop steeply: 2.13, 0.62, 0.07. The third direction has hardly any
spread — the data is close to a flat sheet in 3-D.

The **explained variance ratio** tells you how much information each PC carries:

It is each eigenvalue divided by their sum — the share of the total spread along that
axis.

```python
import numpy as np

rng = np.random.default_rng(0)
n, d = 200, 3
A_true = np.array([[1.0, 0.8, 0.3], [0.0, 0.6, 0.7], [0.0, 0.0, 0.5]])
X = rng.standard_normal((n, d)) @ A_true
Xc = X - X.mean(axis=0)
C = Xc.T @ Xc / (n - 1)
eigvals, eigvecs = np.linalg.eigh(C)
idx = np.argsort(eigvals)[::-1]
eigvals = eigvals[idx]
eigvecs = eigvecs[:, idx]

evr = eigvals / eigvals.sum()
print("Explained variance ratio:", np.round(evr, 4))
print("Cumulative               :", np.round(evr.cumsum(), 4))
```

```output
Explained variance ratio: [0.7557 0.2206 0.0237]
Cumulative               : [0.7557 0.9763 1.    ]
```

The first PC captures about 76% of variance; the first two together about 98% (the
`0.7557` and `0.9763` in the output). Dropping the third axis would lose only about 2% of
the spread while cutting a column.

## The SVD path

You can skip building the covariance matrix and take the SVD (ch. 5) of the centred data
directly. Its right singular vectors *are* the principal directions.

Instead of forming $C$ explicitly, apply SVD directly to the centred data:

$$
X_c = U \Sigma V^T
$$

The columns of $V$ are the **principal directions** (same as eigenvectors of $C$). The singular values relate to eigenvalues via $\lambda_i = \sigma_i^2 / (n-1)$.

> **In plain words:** $X_c^T X_c = V \Sigma^2 V^T$ (ch. 5), and $C$ is that divided by
> $n - 1$. So the eigenvectors of $C$ are the columns of $V$, and each eigenvalue is a
> squared singular value divided by $n - 1$.

```python
import numpy as np

rng = np.random.default_rng(0)
n, d = 200, 3
A_true = np.array([[1.0, 0.8, 0.3], [0.0, 0.6, 0.7], [0.0, 0.0, 0.5]])
X = rng.standard_normal((n, d)) @ A_true
Xc = X - X.mean(axis=0)

# SVD of centred data
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)
V_svd = Vt.T   # columns are principal directions

# Eigendecomposition of covariance
C = Xc.T @ Xc / (n - 1)
eigvals, eigvecs = np.linalg.eigh(C)
idx = np.argsort(eigvals)[::-1]
V_eig = eigvecs[:, idx]

# Compare: directions match up to sign flip
print("SVD principal directions (columns of V):")
print(np.round(V_svd, 4))
print("\nEig principal directions:")
print(np.round(V_eig, 4))
print("\nDot products (should be ±1):", np.round(np.diag(V_svd.T @ V_eig), 4))
```

```output
SVD principal directions (columns of V):
[[-0.6052  0.6187  0.5009]
 [-0.6763 -0.0676 -0.7336]
 [-0.42   -0.7827  0.4593]]

Eig principal directions:
[[-0.6052 -0.6187  0.5009]
 [-0.6763  0.0676 -0.7336]
 [-0.42    0.7827  0.4593]]

Dot products (should be ±1): [ 1. -1.  1.]
```

The two matrices are identical except that the middle column has every sign flipped — the
dot products $[1, -1, 1]$ say exactly that. A direction and its opposite describe the same
axis.

Both paths give the same subspace; the sign flip (here only PC2's) is arbitrary since eigenvectors have no canonical sign.

> **Watch out:** because the sign is arbitrary, PC scores from two libraries (or two
> versions of one library) can come out mirrored. Never compare PCs without aligning signs
> first, and never give a PC's sign a meaning without fixing a convention.

### Why prefer SVD?

Forming $C = X_c^T X_c$ squares the condition number. If $X_c$ has condition $\kappa$, then $C$ has condition $\kappa^2$. SVD on $X_c$ directly is numerically twice as stable
in the sense that matters: going through $C$ loses about twice as many digits of precision.
That's why scikit-learn's `PCA` uses the SVD.

## Scree plot and choosing k

A **scree plot** lists the explained variance of each component in order. Real signal shows
up as a few big values; noise is the long flat tail. The **elbow** — where big values turn
into the flat tail — suggests how many components to keep.

```python
import numpy as np

rng = np.random.default_rng(1)
n, d = 300, 10
# Low-rank signal + noise
W = rng.standard_normal((d, 3)) * 2
X = rng.standard_normal((n, 3)) @ W.T + rng.standard_normal((n, d)) * 0.5
Xc = X - X.mean(axis=0)

_, s, _ = np.linalg.svd(Xc, full_matrices=False)
evr = s**2 / (s**2).sum()

print(f"{'PC':>4}  {'var%':>6}  {'cumvar%':>8}")
for i, (v, cv) in enumerate(zip(evr, evr.cumsum()), 1):
    marker = " ← elbow" if i == 3 else ""
    print(f"{i:>4}  {100*v:>6.1f}%  {100*cv:>7.1f}%{marker}")
```

```output
  PC    var%   cumvar%
   1    63.1%     63.1%
   2    31.0%     94.1%
   3     3.8%     97.9% ← elbow
   4     0.4%     98.3%
   5     0.3%     98.6%
   6     0.3%     98.9%
   7     0.3%     99.2%
   8     0.3%     99.5%
   9     0.3%     99.8%
  10     0.2%    100.0%
```

The data was built as a 3-dimensional signal (`W` has 3 columns) plus small noise in all
10 dimensions. The table shows it: components 1–3 carry 97.9% together, and from component 4
on every one is a tiny, nearly equal 0.2–0.4% — the noise floor.

The elbow at $k=3$ correctly recovers the 3-dimensional signal.

## Recap in plain words

- PCA rotates centred data so variance is sorted along perpendicular axes.
- Path 1: covariance matrix $C$, then its eigenvectors (directions) and eigenvalues
  (variance along each).
- Path 2: SVD of the centred data; $V$ gives the directions, $\sigma_i^2 / (n - 1)$ the
  variances. Preferred, because it never squares the condition number.
- Explained variance ratio = eigenvalue / sum of eigenvalues; keep components up to the
  elbow of the scree plot.
- Signs of principal directions are arbitrary.

## Try it Yourself

```python
import numpy as np

rng = np.random.default_rng(5)
n = 150
X = rng.standard_normal((n, 5))
X[:, 2] = 0.9 * X[:, 0] + 0.1 * rng.standard_normal(n)
X[:, 4] = -0.7 * X[:, 1] + 0.3 * rng.standard_normal(n)

Xc = X - X.mean(axis=0)
_, s, _ = np.linalg.svd(Xc, full_matrices=False)
evr = s**2 / (s**2).sum()

print("Explained variance ratios:", np.round(evr, 4))
print("Cumulative               :", np.round(evr.cumsum(), 4))
```

```output
Explained variance ratios: [0.4328 0.3446 0.2101 0.0114 0.0012]
Cumulative               : [0.4328 0.7774 0.9874 0.9988 1.    ]
```

Five columns, but two of them were built from the others (column 2 from column 0, column 4
from column 1). So only about 3 independent directions exist, and the cumulative line hits
98.7% at 3 components, with components 4 and 5 left holding about 1%. Try making the
copies exact (drop the noise terms) and watch the last two ratios fall to almost zero.

## Exercise

Implement PCA from scratch (eigendecomposition only, no sklearn) on a 100×4 dataset, then compare your PC scores to `sklearn.decomposition.PCA`. The scores should match up to a sign flip.

> **Hint:** centre, build $C$, `eigh`, sort descending, project with `Xc @ W`. To compare
> with sklearn, flip each of your columns by the sign of its dot product with sklearn's.

<details>
<summary>Solution</summary>

```python
import numpy as np
from sklearn.decomposition import PCA

rng = np.random.default_rng(0)
X = rng.standard_normal((100, 4))
X[:, 3] = X[:, 0] * 0.8 + rng.standard_normal(100) * 0.2

# From scratch
Xc = X - X.mean(axis=0)
C = Xc.T @ Xc / (len(X) - 1)
eigvals, eigvecs = np.linalg.eigh(C)
idx = np.argsort(eigvals)[::-1]
W = eigvecs[:, idx]         # principal directions, shape (4, 4)
scores_manual = Xc @ W     # shape (100, 4)

# sklearn
pca = PCA()
scores_sklearn = pca.fit_transform(X)

# Compare first two PCs (up to sign)
for i in range(2):
    dot = np.dot(scores_manual[:, i], scores_sklearn[:, i])
    sign = np.sign(dot)
    err = np.max(np.abs(scores_manual[:, i] - sign * scores_sklearn[:, i]))
    print(f"PC{i+1} max error after sign alignment: {err:.2e}")
```

Both implementations agree to numerical precision (error ~1e-14).
The sign alignment is the whole trick: once each column's sign is matched, the scores are
the same numbers, because both methods find the same axes.
