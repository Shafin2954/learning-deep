## What MultiIndex is and when you get one

Sometimes one label per row isn't enough: a sales figure belongs to *a year and a month*.
A MultiIndex gives each row a label made of several parts, like a street address with
city, street, and house number.

A **MultiIndex** is a row (or column) index with more than one level. Each **level** is one
part of the label (here: `year`, then `month`). You encounter it after groupby with multiple
keys, after `stack`, or after reading multi-level CSV headers.
It looks impressive, causes confusion, and is usually best flattened immediately with
`reset_index()`. But you need to understand it to handle it correctly.

> **Picture it:** a filing cabinet with drawers (years) and folders inside each drawer
> (months). To find one folder you name the drawer *and* the folder. Naming only the drawer
> gives you every folder in it.

```python
import pandas as pd

# Create one directly
df = pd.DataFrame(
    data={'sales': [100, 200, 150, 300]},
    index=pd.MultiIndex.from_tuples(
        [('2023', 'jan'), ('2023', 'feb'), ('2024', 'jan'), ('2024', 'feb')],
        names=['year', 'month'],
    ),
)
print(df)
print("\nindex type:", type(df.index).__name__)
print("index names:", df.index.names)
```

```output
            sales
year month
2023 jan      100
     feb      200
2024 jan      150
     feb      300

index type: MultiIndex
index names: ['year', 'month']
```

The printout hides repeated outer labels: the blank under `2023` means "still 2023". Each
row's full label is a tuple, like `('2023', 'feb')`, and `index.names` lists the level
names in order, outermost first.

## Selecting from a MultiIndex with `.loc`

You select by giving as much of the address as you know. The outer level alone gives a
whole drawer; the full tuple gives a single folder.

`.loc` works on MultiIndex using tuples. Pass a tuple to select a specific level-combination;
pass a single value to select across all values of the second level.

```python
import pandas as pd

df = pd.DataFrame(
    data={'sales': [100, 200, 150, 300]},
    index=pd.MultiIndex.from_tuples(
        [('2023', 'jan'), ('2023', 'feb'), ('2024', 'jan'), ('2024', 'feb')],
        names=['year', 'month'],
    ),
)

# All months in 2023
print(df.loc['2023'])
print()
# Specific combination
print(df.loc[('2024', 'feb')])
print()
# Cross-section: all years, just 'jan'
print(df.xs('jan', level='month'))
```

```output
       sales
month
jan      100
feb      200

sales    300
Name: (2024, feb), dtype: int64

      sales
year
2023    100
2024    150
```

Three results, three levels of detail. `df.loc['2023']` returned both 2023 months, and the
`year` level disappeared because you already fixed it. The full tuple `('2024', 'feb')`
returned one row (as a Series named after the tuple). `xs('jan', level='month')` cut across
the *inner* level — January of every year — which plain `.loc` can't do as neatly.

`.xs()` (cross-section) is the clean way to select by level name without constructing a
tuple. It returns a copy.

> **Watch out:** slicing a MultiIndex with `.loc` (for example `df.loc['2023':'2024']`)
> needs the index to be **sorted**. On an unsorted index pandas warns or raises an
> `UnsortedIndexError`; call `df.sort_index()` first.

## Flattening MultiIndex — the usual first step

**Flattening** means turning the levels of the label into ordinary columns, so every row
has a plain number again and every piece of information is a normal column.

After a groupby-agg with multiple keys, the result has a MultiIndex. Flatten it immediately:

```python
import pandas as pd

df = pd.DataFrame({
    'region': ['N', 'N', 'S', 'S'],
    'month':  ['jan', 'feb', 'jan', 'feb'],
    'sales':  [100, 200, 150, 120],
})

g = df.groupby(['region', 'month'])['sales'].sum()
print("MultiIndex result:")
print(g)
print()
# Flatten
g_df = g.reset_index()
print("Flattened:")
print(g_df)
```

```output
MultiIndex result:
region  month
N       feb      200
        jan      100
S       feb      120
        jan      150
Name: sales, dtype: int64

Flattened:
  region month  sales
0      N   feb    200
1      N   jan    100
2      S   feb    120
3      S   jan    150
```

Before flattening, `region` and `month` are parts of the row label; after `reset_index()`
they are ordinary columns with a fresh 0–3 row number. The flat version is what you can
safely merge, filter, and save.

If you get a MultiIndex on columns (from `agg` with multiple functions), flatten with
`df.columns = ['_'.join(c).strip('_') for c in df.columns]`.

> **In plain words:** each column label is a tuple like `('sales', 'sum')`; joining its
> parts with `_` gives the single name `sales_sum`.

## `stack` and `unstack` revisited

Think of `unstack` as "pull a level of the row label up into the column header" and
`stack` as "push a level of the column header down into the row label".

`unstack` moves the innermost row level into columns; `stack` does the reverse.
Together they let you reshape without pivot_table.

```python
import pandas as pd

g = pd.DataFrame({
    'region': ['N', 'N', 'S', 'S'],
    'month':  ['jan', 'feb', 'jan', 'feb'],
    'sales':  [100, 200, 150, 120],
}).groupby(['region', 'month'])['sales'].sum()

# Unstack: month level → column
wide = g.unstack(level='month')
print(wide)
```

```output
month   feb  jan
region
N       200  100
S       120  150
```

The `month` level left the row label and became the columns, so the 4-row Series turned
into a 2×2 table: one row per region, one column per month.

```python
import pandas as pd

wide = pd.DataFrame(
    {'feb': {'N': 200, 'S': 120}, 'jan': {'N': 100, 'S': 150}},
)
wide.index.name = 'region'
wide.columns.name = 'month'

# Stack back: columns → innermost row level
long = wide.stack()
print(long)
```

```output
region  month
N       feb      200
        jan      100
S       feb      120
        jan      150
dtype: int64
```

And `stack` folded the month columns back into the row label, giving the same 4 rows as the
original groupby result.

## MultiIndex on columns

MultiIndexes can also live on the columns: a two-row header, like a spreadsheet with merged
cells above the column names.

After `pivot_table` with multiple values, columns become a MultiIndex:

```python
import pandas as pd

df = pd.DataFrame({
    'region': ['N', 'N', 'S', 'S'],
    'month':  ['jan', 'feb', 'jan', 'feb'],
    'sales':  [100, 200, 150, 120],
    'units':  [10, 20, 15, 12],
})

piv = df.pivot_table(index='region', columns='month',
                     values=['sales', 'units'], aggfunc='sum')
print(piv)
print("\ncol type:", type(piv.columns).__name__)
```

```output
       sales      units
month    feb  jan   feb jan
region
N        200  100    20  10
S        120  150    12  15

col type: MultiIndex
```

The header has two rows: the top level is the measure (`sales`, `units`) and the lower
level is the month. Each column's full name is a tuple such as `('sales', 'feb')`.

Flatten the column MultiIndex when saving to CSV or passing to sklearn:

```python
import pandas as pd

df = pd.DataFrame({
    'region': ['N', 'N', 'S', 'S'],
    'month':  ['jan', 'feb', 'jan', 'feb'],
    'sales':  [100, 200, 150, 120],
    'units':  [10, 20, 15, 12],
})
piv = df.pivot_table(index='region', columns='month',
                     values=['sales', 'units'], aggfunc='sum')

piv.columns = [f'{v}_{m}' for v, m in piv.columns]
piv = piv.reset_index()
print(piv)
```

```output
  region  sales_feb  sales_jan  units_feb  units_jan
0      N        200        100         20         10
1      S        120        150         12         15
```

Each `(value, month)` tuple became one plain name like `sales_feb`, and `region` became an
ordinary column. CSV files and scikit-learn both expect exactly this: one header row of
simple strings.

## Recap in plain words

- A MultiIndex is a label with several parts (levels), like drawer + folder.
- `.loc['outer']` selects a whole outer group; a full tuple selects one row; `.xs(value,
  level=name)` cuts across any level.
- Slicing needs a sorted index (`sort_index()`).
- `reset_index()` flattens row levels into columns; joining tuples flattens column levels.
- `unstack` lifts a row level into columns; `stack` pushes a column level into rows.

## Try it Yourself

```python
import pandas as pd
import numpy as np

rng = np.random.default_rng(14)
N = 48
df = pd.DataFrame({
    'country':  rng.choice(['BD', 'IN', 'PK'], N),
    'year':     rng.choice([2022, 2023], N),
    'quarter':  rng.choice(['Q1', 'Q2', 'Q3', 'Q4'], N),
    'revenue':  rng.integers(1000, 5000, N),
})

# 1) Build a MultiIndex groupby and immediately flatten it
g = df.groupby(['country', 'year', 'quarter'])['revenue'].sum().reset_index()
print("Flat groupby shape:", g.shape)
print(g.head(4))

# 2) Pivot so rows=country, columns=year+quarter
piv = g.pivot_table(index='country', columns=['year', 'quarter'],
                    values='revenue', aggfunc='sum', fill_value=0)
piv.columns = [f'{y}_Q{q[-1]}' for y, q in piv.columns]
piv = piv.reset_index()
print("\nPivoted:\n", piv.to_string(index=False))
```

```output
Flat groupby shape: (22, 4)
  country  year quarter  revenue
0      BD  2022      Q1     7522
1      BD  2022      Q2     2984
2      BD  2022      Q3     9559
3      BD  2022      Q4     4234

Pivoted:
 country  2022_Q1  2022_Q2  2022_Q3  2022_Q4  2023_Q1  2023_Q2  2023_Q3  2023_Q4
     BD     7522     2984     9559     4234     2439     2499        0     5832
     IN     7343        0     6488     4159     4064     7231     4148    11201
     PK     3489     9383     3886     8766     8049     7664     3011     9621
```

The flat groupby has one row per (country, year, quarter) combination that actually
occurred in the random data — fewer than the $3 \times 2 \times 4 = 24$ possible ones if
some combination never came up. The pivot fills those missing combinations with
`fill_value=0`, which is why a few cells read `0`. Try `fill_value=np.nan` to make the gaps
explicit.

## Exercise

Take the pivoted DataFrame from the Try it Yourself (country × quarter–year revenue).
Use `stack` to convert it back to a long format, then use `.xs()` to extract all 2023 rows.
Verify the round-trip shape matches.

> **Hint:** the columns need to be a two-level MultiIndex (month, year) first. Stack the
> level you want to *select on*, so it ends up in the row label where `.xs` can reach it.

<details>
<summary>Solution</summary>

```python
import pandas as pd

# Minimal reproduction
data = {
    'country': ['BD', 'IN'],
    'jan_2022': [100, 200],
    'feb_2022': [110, 210],
    'jan_2023': [120, 220],
    'feb_2023': [130, 230],
}
wide = pd.DataFrame(data).set_index('country')

# Create MultiIndex columns: (month, year)
wide.columns = pd.MultiIndex.from_tuples(
    [(c.split('_')[0], c.split('_')[1]) for c in wide.columns],
    names=['month', 'year'],
)

# Stack year level → row level (month stays as the columns)
stacked = wide.stack(level='year')
print("stacked shape:", stacked.shape)
print(stacked.head(4))

# Cross-section: all rows for year=2023
xs_2023 = stacked.xs('2023', level='year')
print("\n2023 data:\n", xs_2023)
```

`stack(level='year')` moves the year level into the row index (innermost), giving a
`(country, year)` MultiIndex while the months stay as columns. `.xs('2023', level='year')`
then selects the 2023 rows for every country. (Stacking `month` instead would leave `year`
in the columns, and `.xs(..., level='year')` on the rows would raise a `KeyError`.)
