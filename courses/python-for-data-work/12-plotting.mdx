## Three layers of the Python plotting stack

A plot is how you *see* data instead of reading numbers. Python has a low-level drawing
kit where you control every line (matplotlib), a statistics layer that makes common charts
in one call (seaborn), and an interactive layer you can hover and zoom (plotly).

Python has three mainstream plotting libraries, each building on (or alongside) the previous:

| Library | Level | When to use |
|---------|-------|-------------|
| **matplotlib** | low-level, full control | custom figures, publication plots, embedding in larger systems |
| **seaborn** | statistical, wraps matplotlib | quick distribution/relationship plots, themes |
| **plotly** | interactive, browser-based | dashboards, exploratory analysis you'll share |

You need all three. Seaborn calls matplotlib internally, so matplotlib mastery unlocks
everything.

> **Picture it:** matplotlib is a set of pens and rulers, seaborn is a stencil kit for the
> charts statisticians draw every day (still drawn with those pens), and plotly is a
> touchscreen poster people can poke at.

## matplotlib anatomy: Figure, Axes, Artists

A matplotlib picture is built like a framed painting: the frame (Figure), one or more
canvases inside it (Axes), and every brushstroke on a canvas (Artists).

Every matplotlib plot is built from:
- **Figure** — the canvas. Has size (`figsize`), DPI, and one or more Axes.
- **Axes** (`ax`) — one plot panel. Has x/y axes, title, labels, gridlines, and the actual
  data renderers.
- **Artists** — everything drawn: lines, bars, patches, text, images.

`figsize` is in inches; **DPI** (dots per inch) sets how many pixels each inch gets, so
`figsize=(6, 3)` at 100 DPI is a 600×300-pixel image.

```python
import matplotlib.pyplot as plt
import numpy as np

# The object-oriented API (use this — not plt.plot() shortcuts)
fig, ax = plt.subplots(figsize=(6, 3))

x = np.linspace(0, 2 * np.pi, 200)
ax.plot(x, np.sin(x), label='sin(x)', color='steelblue', linewidth=2)
ax.plot(x, np.cos(x), label='cos(x)', color='tomato',    linestyle='--')

ax.set_title('Sine and cosine')
ax.set_xlabel('x (radians)')
ax.set_ylabel('amplitude')
ax.legend(loc='upper right')
ax.grid(alpha=0.3)

fig.tight_layout()
plt.show()
```

```output
[Figure: sine and cosine curves on clean axes with legend]
```

The code reads like a description of the picture: two lines on one panel (`ax.plot` twice),
then a title, axis labels, a legend, and a faint grid. Each call changes one Artist on that
one Axes, which is why the result is predictable.

Always use the object-oriented API (`fig, ax = plt.subplots()`), not `plt.plot()` /
`plt.xlabel()`. The latter mutates a global state that breaks the moment you have two
subplots. The OO API is explicit and predictable.

> **In plain words:** `plt.xlabel(...)` means "label whichever panel matplotlib currently
> thinks is active". `ax.set_xlabel(...)` means "label *this* panel". With one panel they
> agree; with several, only the second is safe.

### Subplots — multiple panels

```python
import matplotlib.pyplot as plt
import numpy as np

fig, axes = plt.subplots(1, 3, figsize=(12, 3), sharey=True)

x = np.linspace(0, 4, 100)
fns  = [np.sin, np.cos, lambda t: np.sin(t) * np.exp(-t/3)]
names = ['sin', 'cos', 'damped sin']

for ax, fn, name in zip(axes, fns, names):
    ax.plot(x, fn(x), linewidth=2)
    ax.set_title(name)
    ax.grid(alpha=0.3)

fig.tight_layout()
plt.show()
```

```output
[Figure: three side-by-side plots sharing the y-axis scale]
```

`plt.subplots(1, 3)` returned a Figure and an array of 3 Axes, one per panel, and the loop
draws one function on each.

`sharey=True` locks the y-axis range across all three panels so comparisons are honest.
`fig.tight_layout()` prevents labels from overlapping.

> **Watch out:** without `sharey=True`, each panel picks its own y-range, so a tiny wiggle
> and a huge swing can look the same height. Shared axes are the honest default when
> panels are meant to be compared.

## seaborn: statistical plots with one call

seaborn takes a DataFrame and column names and draws the chart a statistician would want —
including splitting it by groups in different colours — in a single call.

seaborn wraps matplotlib and understands pandas DataFrames directly. It adds:
- Automatic grouping by a `hue` column (`hue` = "colour the marks by this column").
- Built-in themes (`sns.set_theme()`).
- Distribution plots that would be tedious in raw matplotlib.

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

sns.set_theme(style='whitegrid', palette='muted')

rng = np.random.default_rng(5)
df = pd.DataFrame({
    'group':  rng.choice(['A', 'B', 'C'], 300),
    'value':  np.concatenate([
                  rng.normal(10, 2, 100),
                  rng.normal(14, 3, 100),
                  rng.normal(12, 1.5, 100),
              ]),
})

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# Distribution per group
sns.histplot(data=df, x='value', hue='group', bins=20, ax=axes[0], alpha=0.7)
axes[0].set_title('Histograms by group')

# Box plot
sns.boxplot(data=df, x='group', y='value', ax=axes[1])
axes[1].set_title('Box plot by group')

fig.tight_layout()
plt.show()
```

```output
[Figure: histogram with three overlapping distributions and a box plot showing medians and spread per group]
```

One call per panel. The **histogram** counts how many values fall into each of 20 bins,
with one colour per group. The **box plot** summarizes each group in five numbers: the
box spans the middle 50% of values (the IQR from ch. 6), the line inside is the median,
the whiskers reach the bulk of the rest, and dots beyond them are outliers. Because seaborn
draws onto `ax=axes[0]` and `ax=axes[1]`, it fits into an ordinary matplotlib layout.

### Scatter with regression line

```python
import seaborn as sns
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

sns.set_theme(style='whitegrid')
rng = np.random.default_rng(0)
n = 100
x = rng.uniform(0, 10, n)
y = 2 * x + rng.normal(0, 3, n)
df = pd.DataFrame({'x': x, 'y': y})

fig, ax = plt.subplots(figsize=(5, 4))
sns.regplot(data=df, x='x', y='y', ax=ax, scatter_kws={'alpha': 0.5})
ax.set_title('Linear relationship with regression line')
plt.show()
```

```output
[Figure: scatter plot of ~100 points with a fitted regression line and confidence band]
```

`regplot` draws every (x, y) point, fits a straight line through them, and shades a
**confidence band** — the range where the true line plausibly lies given this much noise.
The data was generated as $y = 2x + \text{noise}$, so the fitted line rises by about 2 per
unit of $x$.

## plotly: interactive plots

plotly makes charts you can touch: hover a point to read its values, click the legend to
hide a group, drag to zoom.

plotly Express (`px`) is plotly's high-level API. The output is an interactive HTML widget
that renders in a browser or Jupyter notebook (the code-runner displays it inline).

```python
import plotly.express as px
import pandas as pd
import numpy as np

rng = np.random.default_rng(3)
N = 500
df = pd.DataFrame({
    'x':      rng.standard_normal(N),
    'y':      rng.standard_normal(N),
    'size':   rng.uniform(5, 20, N),
    'group':  rng.choice(['cat', 'dog', 'bird'], N),
    'value':  rng.exponential(50, N).round(1),
})

fig = px.scatter(
    df, x='x', y='y', color='group', size='size',
    hover_data=['value'],
    title='Interactive scatter (hover for value)',
    template='plotly_white',
)
fig.show()
```

```output
[Interactive plotly figure: scatter plot with colored groups; hover tooltips show 'value'. Zoom and pan enabled.]
```

One `px.scatter` call mapped four columns to four visual channels: position (`x`, `y`),
colour (`group`), and marker size (`size`), while `hover_data` adds `value` to the tooltip.

plotly charts are interactive: hover for tooltips, click legend to toggle groups, drag
to zoom, double-click to reset. This is the right tool for exploratory analysis you'll
share with others.

### When to use which

- **matplotlib** for publication-quality static figures (papers, slides), custom layouts, and
  whenever you need precise pixel control.
- **seaborn** for quick EDA plots: distributions, correlations, facets. Its `pairplot` and
  `heatmap` are hard to beat for speed. (**EDA** = exploratory data analysis, the first
  look at a new dataset; **facets** = the same chart repeated per group.)
- **plotly** when the reader needs to interact with the data — explore subsets, read exact
  values, compare scales interactively.

## Heatmap — seaborn's correlation matrix

A **heatmap** colours each cell of a table by its value. Applied to a correlation matrix,
it shows at a glance which columns move together.

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

rng = np.random.default_rng(7)
df = pd.DataFrame(rng.standard_normal((100, 5)), columns=list('ABCDE'))
df['B'] = df['A'] * 0.8 + rng.standard_normal(100) * 0.3   # correlate B with A

corr = df.corr()
fig, ax = plt.subplots(figsize=(5, 4))
sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm', center=0, ax=ax)
ax.set_title('Correlation matrix')
fig.tight_layout()
plt.show()
```

```output
[Figure: 5×5 heatmap with annotated correlation values; A-B correlation ≈ 0.93; others near 0]
```

A **correlation** runs from $-1$ (one goes up exactly when the other goes down) through 0
(no straight-line relationship) to $+1$ (they move together). The diagonal is always 1 —
every column is perfectly correlated with itself. Look for the A–B cell: B was built from A,
so it is strongly positive (dark red with `cmap='coolwarm'` and `center=0`), while the
unrelated pairs sit near 0 (pale).

## Recap in plain words

- matplotlib = Figure (frame) → Axes (panels) → Artists (everything drawn); use
  `fig, ax = plt.subplots()` and `ax.` methods.
- `sharey=True` keeps panels honest to compare; `tight_layout()` stops label overlap.
- seaborn draws statistical charts from DataFrame columns, split by `hue`, onto matplotlib
  Axes.
- plotly Express makes interactive charts with tooltips and zoom.
- A correlation heatmap shows which columns move together; the diagonal is always 1.

## Try it Yourself

```python
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd

sns.set_theme(style='whitegrid')
rng = np.random.default_rng(11)

# Build a small time series with two groups
idx = pd.date_range('2023-01-01', periods=60, freq='D')
df = pd.DataFrame({
    'date':    list(idx) * 2,
    'group':   ['product_A']*60 + ['product_B']*60,
    'revenue': np.concatenate([
        50 + 0.5 * np.arange(60) + rng.normal(0, 5, 60),
        70 + 0.2 * np.arange(60) + rng.normal(0, 8, 60),
    ]).round(1),
})

fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# 1) Line plot by group (matplotlib)
for grp, sub in df.groupby('group'):
    axes[0].plot(sub['date'], sub['revenue'], label=grp, alpha=0.8)
axes[0].set_title('Daily revenue by product')
axes[0].legend()
axes[0].tick_params(axis='x', rotation=30)

# 2) Box plot by month using seaborn
df['month'] = df['date'].dt.strftime('%b')
month_order = ['Jan', 'Feb', 'Mar']
sns.boxplot(data=df, x='month', y='revenue', hue='group',
            order=month_order, ax=axes[1])
axes[1].set_title('Monthly revenue distribution')

fig.tight_layout()
plt.show()
```

```output
[Figure: left panel shows two rising trend lines for products A and B over 60 days; right panel shows side-by-side box plots per month and group showing revenue spread]
```

The left panel is plain matplotlib: one `ax.plot` per group from a pandas groupby loop. The
right panel is seaborn: one call grouped by month on the x-axis and by product with `hue`.
product_A starts lower but grows faster (slope 0.5 per day vs 0.2), which you can see as
its boxes climbing month over month. Try `sharey=True` in `plt.subplots`, or swap the
boxplot for `sns.violinplot`.

## Exercise

Load (or simulate) a DataFrame with columns `feature_1` … `feature_5` and `target` (100
rows, some correlated). Produce:

1. A seaborn `pairplot` colored by `target > target.median()`.
2. A matplotlib bar chart of the correlation of each feature with `target`.

> **Hint:** make the high/low flag a column first — `pairplot` wants the *name* of the
> `hue` column. `df.corrwith(df['target'])` gives one correlation per feature.

<details>
<summary>Solution</summary>

```python
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

rng = np.random.default_rng(0)
n = 100
base = rng.standard_normal(n)
df = pd.DataFrame({
    'feature_1': base + rng.normal(0, 0.3, n),
    'feature_2': -base * 0.6 + rng.normal(0, 0.5, n),
    'feature_3': rng.standard_normal(n),
    'feature_4': rng.standard_normal(n),
    'feature_5': rng.standard_normal(n),
    'target':    base * 2 + rng.normal(0, 1, n),
})
df['target_high'] = (df['target'] > df['target'].median()).map({True: 'high', False: 'low'})

# 1) Pairplot
g = sns.pairplot(df, hue='target_high', corner=True, plot_kws={'alpha': 0.5})
g.fig.suptitle('Pairplot', y=1.01)
plt.show()

# 2) Correlation bar chart
corrs = df.drop(['target', 'target_high'], axis=1).corrwith(df['target']).sort_values()
fig, ax = plt.subplots(figsize=(5, 3))
colors = ['tomato' if c < 0 else 'steelblue' for c in corrs]
ax.barh(corrs.index, corrs.values, color=colors)
ax.axvline(0, color='black', linewidth=0.8)
ax.set_title('Correlation with target')
fig.tight_layout()
plt.show()
```

A **pairplot** draws a scatter for every pair of columns (and a histogram per column on the
diagonal), so correlated features show up as tilted clouds. In the bar chart, `feature_1`
(built from `base`) should be strongly positive and `feature_2` (built from `-base`)
negative, while the three pure-noise features hover near zero.
</details>

## Under the Trench

Rare and advanced topics you should at least know the name of. You won't need them daily,
but you'll stop being surprised when you meet them.

- **NumPy strides & `as_strided`** — make sliding windows with zero copies by editing the stride numbers (ch. 1) directly; the data never moves, only the view's shape changes. Extremely sharp edges: wrong strides read garbage memory.
- **Structured/record arrays (`np.dtype([('x', float), ('y', int)])`)** — C-struct-like typed arrays where each element has named fields, like a tiny row with columns; rare outside reading binary file formats or interfacing with C code.
- **Memory-mapping (`np.memmap`, `np.load(..., mmap_mode='r')`)** — treat a file on disk as an ndarray; only the pages you touch are loaded into RAM. Essential for arrays larger than available memory.
- **Copy-on-write (CoW) & SettingWithCopy** — pandas 3.0 makes CoW the default (opt-in since 2.0): a slice behaves like a view until you write to it, then it copies. The old warning was about chained indexing returning unexpected copies (ch. 5); CoW removes the ambiguity but changes mutation semantics.
- **Broadcasting tricks for pairwise ops** — outer subtraction `a[:, np.newaxis] - b[np.newaxis, :]` computes every pairwise difference without a loop (ch. 2); used for distance matrices, kernel matrices, attention logits.
- **Arrow-backed pandas & zero-copy interchange** — pandas 2+ supports `ArrowDtype` columns backed by PyArrow memory (pandas 3's default `str` dtype is one), and Arrow-backed data can be passed zero-copy to polars, DuckDB, and other Arrow-native tools.
